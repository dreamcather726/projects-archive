程序结构思维导图

灵巧手控制器程序
main.py（主入口）
功能：整合4个模块，绑定信号，启动程序
主要类：FingerControllerApp
主要方法：
  • __init__() - 初始化应用
  • _bind_signals() - 绑定信号
  • closeEvent() - 处理窗口关闭
模块结构
ui_module.py
  • 功能：创建和显示界面控件
  • 主要类：FingerControllerUI
  • 主要方法：_setup_ui() - 设置界面
interaction_module.py
  • 功能：处理用户交互逻辑
  • 主要类：InteractionController
  • 主要方法：
    • refresh_ports() - 刷新串口
    • toggle_connection() - 连接/断开
    • on_slider_changed() - 处理滑块变化
    • apply_preset_by_name() - 应用预设动作
    • run_script() - 执行脚本
serial_module.py
  • 功能：与机械手通信
  • 主要类：SerialPortClient
  • 主要方法：
    • scan_ports() - 扫描串口
    • connect() - 连接串口
    • disconnect() - 断开连接
    • send_command() - 发送命令
script_module.py
  • 功能：执行脚本指令
  • 主要类：
    • ScriptRunner - 脚本执行线程
    • ScriptService - 脚本服务
  • 主要方法：
    • run() - 执行脚本
    • start() - 启动脚本
    • stop() - 停止脚本
执行流程
1. 启动程序
  • 执行 python main.py
  • 导入必要的库和模块
  • 定义FingerControllerApp类
2. 初始化应用
  • 创建QApplication实例
  • 创建FingerControllerApp实例
  • 初始化各个模块
  • 绑定信号
  • 刷新串口列表
3. 运行应用
  • 显示窗口
  • 执行应用程序主循环
  • 等待用户操作
4. 处理用户操作
  • 点击按钮
  • 滑动滑块
  • 运行脚本
5. 关闭应用
  • 处理窗口关闭事件
  • 停止脚本线程
  • 关闭串口
  • 退出程序
信号与槽
UI控件信号
  • refresh_btn.clicked → controller.refresh_ports
  • connect_btn.clicked → controller.toggle_connection
  • slider.valueChanged → controller.on_slider_changed
  • preset_btn.clicked → controller.apply_preset_by_name
  • load_btn.clicked → controller.load_script
  • save_btn.clicked → controller.save_script
  • run_btn.clicked → controller.run_script
  • stop_btn.clicked → controller.stop_script
脚本服务信号
  • script_service.log_signal → script_log.append
  • script_service.finished_signal → controller.on_script_finished
