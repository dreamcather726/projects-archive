## 第三部分：程序整体结构（15:00\-25:00）

很多同学看到代码会觉得头疼，其实这个程序一点都不复杂，它就像搭积木一样，由四个“积木块”组成，层层递进，每一部分都有明确的作用，我们一步步来看：

第一层：导入工具库。这就像是我们打开工具箱，把需要用到的工具都拿出来，对应代码的第1\-17行，我们导入了cv2、numpy、mediapipe等所有需要的库，为后续的功能实现做好准备。

第二层：两个工具函数。这两个函数是程序的“小帮手”，专门处理手指相关的计算：第一个函数叫get\_finger\_bend，负责计算单个手指的弯曲程度，用0到1之间的数值表示，数值越小，手指越弯；第二个函数叫map\_bend\_to\_angle，负责把弯曲程度转换成90度到180度的角度，其中90度代表手指完全伸直，180度代表手指完全弯曲。

第三层：两个线程。线程就像是两条并行的“流水线”，可以让程序同时做两件事，不会卡顿。第一个线程是ScriptRunner（脚本执行线程），负责读取我们写的脚本指令，按顺序执行，然后把指令发送给机器手；第二个线程是HandTrackingThread（手部追踪线程），负责打开摄像头、识别手部动作、计算手指角度，然后把数据传给主界面。

第四层：主程序窗口。这是整个程序的“指挥中心”，对应代码中的MainApplication类，它把前面所有的模块都整合在一起，做成我们能直观操作的界面，比如串口设置区、手指控制滑块、手部追踪显示区、脚本编辑区，让我们可以轻松操控机器手。

简单总结一下，整个程序的结构就是：导入工具库→用工具函数做计算→用线程同时处理追踪和脚本→用主窗口整合所有功能，这样的结构清晰明了，也让程序运行得更流畅。

## 第四部分：核心代码详解（25:00\-35:00）

接下来，我们重点讲解程序中最核心的三部分内容，不用逐行看代码，只要理解它的作用和逻辑就可以，这也是我们看懂整个程序的关键。下面我们结合对应的核心代码片段，一步步拆解，大家不用记代码细节，重点看代码能实现什么功能。

第一部分：手指弯曲度计算与角度映射。我们的手指有指尖和指根，程序通过mediapipe找到指尖和指根的位置，计算两者之间的距离——手指伸直时，距离最远，弯曲度数值最大；手指弯曲时，距离最近，弯曲度数值最小。然后通过map\_bend\_to\_angle函数，把这个数值转换成90到180度的角度，而且每个手指的伸直和弯曲标准不一样，比如大拇指比其他手指短，所以它的阈值和其他手指不同，程序已经帮我们设置好了对应的阈值，不用我们自己调整。

第二部分：手部追踪线程。这个线程的工作流程很简单，就像一个“循环”：首先打开电脑摄像头，读取每一帧画面，然后把画面水平翻转（这样我们看到的画面和自己的手势方向一致），接着用mediapipe识别画面中的手部，找到手指的关键点，计算每个手指的弯曲度和角度，再把处理后的画面（带有手部骨骼线）和手指数据发送给主界面，最后一直重复这个过程，直到我们停止追踪。

第三部分：脚本执行线程。这个线程专门处理我们写的脚本指令，它会逐行读取脚本中的命令，跳过空行和注释（注释就是用\#开头的文字，用来备注说明，程序不会执行），然后根据命令类型执行对应的操作：如果是FINGER开头的命令，就控制单个手指的角度；如果是ALL开头的命令，就同时控制所有手指；如果是DELAY开头的命令，就等待指定的时间。执行完所有命令后，会通知主界面，显示“脚本执行完成”。

这三部分内容，就像是程序的“大脑”，负责处理所有的核心逻辑，让摄像头能看懂我们的手，让机器手能跟着我们的指令动起来。

第一部分：手指弯曲度计算与角度映射。这部分对应程序中两个核心工具函数，先看计算手指弯曲度的代码，非常简洁：

```python
def get_finger_bend(landmarks, tip_idx, mcp_idx):
    """计算单个手指的弯曲程度（0~1 数值越小越弯）"""
    tip = np.array([landmarks.landmark[tip_idx].x, landmarks.landmark[tip_idx].y])
    mcp = np.array([landmarks.landmark[mcp_idx].x, landmarks.landmark[mcp_idx].y])
    dist = np.linalg.norm(tip - mcp)
    return dist
```

大家看，这个函数叫get\_finger\_bend，它的作用就是计算手指的弯曲程度。它会先找到指尖（tip）和指根（mcp）的坐标，用numpy（我们之前认识的“超级计算器”）计算两者之间的距离（dist），最后把这个距离返回——距离越近，手指越弯，数值就越小；距离越远，手指越直，数值就越大。

然后是把弯曲度转换成角度的代码，对应map\_bend\_to\_angle函数：

```python
def map_bend_to_angle(bend_value, finger_type):
    """将弯曲度映射到90-180范围
    90: 全部伸直
    180: 全弯曲
    """
    # 为每个手指设置不同的伸直和弯曲阈值
    finger_thresholds = {
        'thumb': {'straight': 0.11, 'bend': 0.08},    # 拇指
        'index': {'straight': 0.24, 'bend': 0.09},    # 食指
        'middle': {'straight': 0.25, 'bend': 0.10},   # 中指
        'ring': {'straight': 0.24, 'bend': 0.10},     # 无名指
        'pinky': {'straight': 0.17, 'bend': 0.08}     # 小指
    }
    thresholds = finger_thresholds.get(finger_type, {'straight': 0.11, 'bend': 0.10})
    straight_threshold = thresholds['straight']
    bend_threshold = thresholds['bend']
    
    if bend_value >= straight_threshold:
        return 90
    elif bend_value <= bend_threshold:
        return 180
    else:
        return int(90 + (180 - 90) * (straight_threshold - bend_value) / (straight_threshold - bend_threshold))
```

这段代码最关键的就是“阈值”——程序给每根手指都设置了“伸直标准”和“弯曲标准”，比如大拇指的伸直阈值是0\.11，弯曲阈值是0\.08。如果计算出的弯曲度大于等于0\.11，就返回90度（完全伸直）；小于等于0\.08，就返回180度（完全弯曲）；中间的数值就线性转换成对应的角度，这样机器手就能精准知道该弯多少、伸多少了。而且每个手指的阈值不一样，就是因为我们的大拇指比其他手指短，程序早就帮我们考虑到啦！

        self.running = True

                        # 其他手指计算逻辑相同（省略）
                
                # 发送画面和数据到主界面

大家看这段代码，它的工作流程和我们之前说的一模一样：首先用OpenCV打开摄像头（cv2\.VideoCapture\(0\)），然后用mediapipe（mp\_hands\.Hands）识别画面中的手部，接着调用我们刚才讲的两个工具函数，计算每根手指的弯曲度和角度，最后把处理后的画面（带手部骨骼线）和手指数据，发送到主界面显示。整个过程一直在循环，直到我们点击“停止追踪”，线程才会停止，摄像头也会关闭。

第三部分：脚本执行线程。这是负责执行脚本指令的核心线程，对应ScriptRunner类的run和send\_command方法，核心代码片段如下：

```python
class ScriptRunner(QThread):
    """脚本执行线程"""
    log_signal = pyqtSignal(str)
    finished_signal = pyqtSignal()
    
    def __init__(self, serial_port, commands):
        super().__init__()
        self.serial_port = serial_port  # 串口对象（和机器手通信）
        self.commands = commands        # 脚本命令列表
        self.running = True
    
    def run(self):
        for cmd in self.commands:
            if not self.running:
                break
            cmd = cmd.strip()
            if not cmd or cmd.startswith('#'):  # 跳过空行和注释（#开头）
                continue
            # 解析命令
            if cmd.startswith('ALL:') or cmd.startswith('FINGER'):
                self.send_command(cmd)  # 发送控制指令
            elif cmd.startswith('DELAY'):
                try:
                    delay_ms = int(cmd.split(':')[1])
                    self.log_signal.emit(f'等待 {delay_ms}ms')
                    time.sleep(delay_ms / 1000)  # 等待指定时间
                except:
                    self.log_signal.emit(f'无效的DELAY命令: {cmd}')
            else:
                self.log_signal.emit(f'未知命令: {cmd}')
        self.finished_signal.emit()  # 通知主界面脚本执行完成
    
    def send_command(self, command):
        if self.serial_port and self.serial_port.is_open:
            try:
                full_cmd = command + '\n'  # 加换行符，告诉机器手指令结束
                self.serial_port.write(full_cmd.encode('utf-8'))  # 发送指令
                self.log_signal.emit(f'发送: {command}')
                time.sleep(0.05)  # 等待50ms，确保机器手接收指令
            except Exception as e:
                self.log_signal.emit(f'发送失败: {str(e)}')
```
