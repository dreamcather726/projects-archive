# 第一模块 引言

## 1. 本课目标与现象导入

### 1.1 本课目标
- 本课要完成的实验任务：
  - 完成基础语法与串口输出实验。
  - 完成普通 LED 闪烁实验。
  - 完成按键控制 LED 实验。
  - 完成 PWM 呼吸灯实验。
  - 完成 RGB 灯颜色控制实验。
  - 完成 WS2812 彩灯基础显示实验。
- 本课要掌握的核心知识点：
  - `setup()` 和 `loop()` 的基本作用。
  - `Serial.begin()`、`Serial.println()` 的基本用法。
  - `pinMode()`、`digitalWrite()`、`digitalRead()`、`analogWrite()` 的基本用法。
  - `int`、`float`、`char`、`bool` 的基础含义。
  - `if`、`while`、`for` 的基础写法。
  - GPIO 输入输出、PWM、RGB 混色和 `WS2812` 控制的基本概念。

### 1.2 现象导入
- 现象：
  - 串口监视器会周期性输出基础语法示例结果。
  - 普通 LED 会按固定节奏闪烁。
  - 按下一次按键后，LED 状态切换一次。
  - LED 会从暗到亮、再从亮到暗循环变化。
  - RGB 灯会显示红、绿、蓝、白等不同颜色。
  - WS2812 彩灯会依次显示红、绿、蓝后熄灭。

## 2. 本课共用预备知识

### 2.1 共用预备知识
- 本课会用到的旧知识：
  - 认识 `ESP32-S3` 开发板、USB 下载和串口监视器。
  - 知道高电平、低电平、正极、负极和 `GND` 的基本概念。
- 本课新增的核心概念：
  - `setup()`：初始化区域，只执行一次。
  - `loop()`：主循环区域，会反复执行。
  - GPIO：既可以做输入，也可以做输出。
  - PWM：通过快速开关改变平均亮度。
  - `WS2812`：自带控制芯片的彩灯，通常只需要一根数据线。
- 本课涉及的重点英文单词(函数命名、变量命名等使用的英文单词)：
  - `setup`：初始化
  - `loop`：循环
  - `serial`：串口
  - `print`：打印 / 输出
  - `println`：打印并换行
  - `pin`：引脚
  - `mode`：模式
  - `input`：输入
  - `output`：输出
  - `digital`：数字的 / 数字电平的
  - `analog`：模拟的
  - `read`：读取
  - `write`：写入 / 输出
  - `button`：按键
  - `blink`：闪烁
  - `light`：灯光 / 亮度
  - `red`：红色
  - `green`：绿色
  - `blue`：蓝色
  - `high`：高
  - `low`：低
  - `delay`：延时
  - `pullup`：上拉
  - `state`：状态
  - `value`：数值 / 值
- 学生开始实验前必须先知道的内容：
  - 一个 `.ino` 程序至少包含 `setup()` 和 `loop()`。
  - 上传程序前要检查板卡和串口选择是否正确。
  - LED 需要串联限流电阻，GPIO 输入电压不能超过 `3.3V`。
  - `WS2812` 实验需要提前安装 `Adafruit NeoPixel` 库。

## 3. 本课共用器材与基础接线约定

### 3.1 所需器材
- 开发板：
  - `ESP32-S3` 开发板 `1` 块
- 传感器/执行器/模块：
  - 普通 LED
  - 按键
  - 公共阴极 RGB 灯
  - `WS2812` 彩灯模块或板载 `WS2812`
- 电阻、面包板、杜邦线：
  - `220Ω` 电阻若干
  - 面包板 `1` 块
  - 杜邦线若干
- USB 数据线：
  - 开发板对应数据线 `1` 根
- 软件环境：
  - `Arduino IDE`
  - `esp32` 开发板支持包
  - `Adafruit NeoPixel` 库

### 3.2 共用硬件介绍
- 本课涉及的器件名称：
  - 普通 LED、按键、公共阴极 RGB 灯、`WS2812`
- 每个器件的作用：
  - 普通 LED：显示最基础的亮灭现象。
  - 按键：提供最简单的输入信号。
  - RGB 灯：通过三路亮度组合显示不同颜色。
  - `WS2812`：通过单总线显示不同颜色。
- 关键特性说明：
  - LED 有方向，需要串联限流电阻。
  - 按键在 `INPUT_PULLUP` 模式下按下读到 `LOW`。
  - 公共阴极 RGB 灯公共端接 `GND`。
  - `WS2812` 设置颜色后必须调用 `show()` 才会刷新显示。
- 容易出错的地方：
  - LED 正负极接反。
  - 忘记串联限流电阻。
  - 按键没有共地。
  - RGB 灯公共端接错。
  - `WS2812` 数据引脚与程序定义不一致。
