# ESP32-S3 基础与 LED 课堂实验

这套代码用于课堂手敲。每个文件只讲一个主要知识点，变量名短而清楚，
不使用暂时讲不到的复杂写法。

## 课程安排

### 第 1 课时：基础认识

1. 认识 ESP32-S3、GPIO、3.3V、GND 和 USB 接口。
2. 认识 Arduino 程序中的 `setup()` 和 `loop()`。
3. 学习 `int`、`float`、`char`、`bool`。
4. 学习 `if`、`while`、`for`。
5. 编译、上传程序，打开串口监视器。

使用代码：`01_basic_syntax/01_basic_syntax.ino`

### 第 2 课时：LED 代码（一）

1. 用 `pinMode()`设置 GPIO。
2. 用 `digitalWrite()`控制 LED 亮灭。
3. 用 `digitalRead()`读取按键。
4. 理解按键内部上拉和“按下为 LOW”。

使用代码：

- `02_led_blink/02_led_blink.ino`
- `03_button_led/03_button_led.ino`

### 第 3 课时：LED 代码（二）

1. 用 PWM 改变 LED 亮度。
2. 用 `for` 循环制作呼吸灯。
3. 用三个 PWM 引脚混合 RGB 颜色。
4. 选讲 WS2812 灯带。

使用代码：

- `04_pwm_breathing/04_pwm_breathing.ino`
- `05_rgb_led/05_rgb_led.ino`
- `06_ws2812/06_ws2812.ino`（选讲）

### 第 4 课时：LED 原理

讲解：

- GPIO 的 HIGH 约为 3.3V，LOW 约为 0V。
- 普通 LED 有方向，长脚为正极，必须串联 220Ω～1kΩ 电阻。
- PWM 是快速开关，不是输出真正连续变化的电压。
- 普通 RGB 灯有三个发光芯片；WS2812 内部带控制芯片。

### 第 5 课时：LED 实验

让学生独立完成：

1. 修改闪烁速度。
2. 实现“按下亮、松开灭”。
3. 修改呼吸灯的速度和平滑程度。
4. 调出黄色、青色和紫色。
5. 选做：让 WS2812 逐个点亮。

## 力敏传感器课程（3 课时）

### 第 1 课时：代码讲解（一）

1. 使用 `analogRead()` 读取力敏传感器。
2. 通过串口观察压力数值。
3. 使用 `if` 判断压力是否超过设定值。
4. 压力较大时打开有源蜂鸣器。
5. 压力较大时启动 PWM 呼吸灯。

使用代码：

- `07_force_buzzer/07_force_buzzer.ino`
- `08_force_breathing/08_force_breathing.ino`

### 第 2 课时前半：代码讲解（二）

1. 使用 `constrain()` 限制传感器数值。
2. 使用 `map()` 把压力转换为 LED 亮度。
3. 根据不同的压力范围显示不同颜色。

使用代码：

- `09_force_led_level/09_force_led_level.ino`
- `10_force_rgb/10_force_rgb.ino`

### 第 2 课时后半：原理讲解

- 力敏电阻受到的压力越大，电阻通常越小。
- ESP32-S3 不能直接测量电阻，需要使用分压电路把电阻变化变成电压变化。
- 本例使用 12 位 ADC，理论读取范围为 `0～4095`。
- 传感器存在个体差异，报警值和最大值需要通过实验调整。
- PWM 可以让普通 LED 改变亮度；WS2812 可以分别控制红、绿、蓝三种颜色。

### 第 3 课时：学生实验

1. 打开串口监视器，记录未按压、轻按和重按时的数值。
2. 修改 `FORCE_LIMIT`，设置合适的蜂鸣器报警压力。
3. 修改呼吸灯的变化速度和平滑程度。
4. 让 LED 亮度随压力逐渐变化。
5. 设置轻按、中等压力和重按对应的颜色。

### 力敏传感器接线

本组实验按你提供的 GOOOUUU ESP32-S3-CAM 引脚图编写：

| 元件 | ESP32-S3 引脚 | 接法 |
|---|---:|---|
| 力敏电阻 | GPIO 1 | 3.3V → 力敏电阻 → GPIO 1 → 10kΩ 电阻 → GND |
| 有源蜂鸣器模块 | GPIO 21 | 模块 IN → GPIO 21，GND 与开发板共地 |
| 板载普通 LED | GPIO 2 | 使用板上的 `LED_ON` |
| 板载 RGB 灯 | GPIO 48 | 使用板载 WS2812 |

> GPIO 输入电压不能超过 3.3V。有源蜂鸣器模块可以由 GPIO 控制输入端；
> 如果使用电流较大的裸蜂鸣器，应增加三极管驱动，不能直接由 GPIO 供电。

## 默认接线

以下引脚适用于常见 ESP32-S3 开发板，但上传前仍要检查自己板卡的引脚图。

| 元件 | ESP32-S3 引脚 | 接法 |
|---|---:|---|
| 普通 LED | GPIO 4 | GPIO 4 → 220Ω 电阻 → LED 正极，LED 负极 → GND |
| 按键 | GPIO 5 | 按键一端 → GPIO 5，另一端 → GND |
| RGB 红色脚 | GPIO 6 | 串联 220Ω 电阻 |
| RGB 绿色脚 | GPIO 7 | 串联 220Ω 电阻 |
| RGB 蓝色脚 | GPIO 8 | 串联 220Ω 电阻 |
| RGB 公共阴极 | GND | 本例按公共阴极 RGB 灯编写 |
| WS2812 数据线 | GPIO 9 | GPIO 9 → DIN，电源与开发板共地 |

> 板载 LED 在不同 ESP32-S3 开发板上可能是普通 LED，也可能是 WS2812。
> 为了让课堂结果一致，前四个 LED 实验建议使用外接元件。

## Arduino IDE 使用方法

1. 安装 Arduino IDE 和 Espressif 的 `esp32` 3.x 开发板支持包。
2. 在“工具 → 开发板”中选择自己的 ESP32-S3 板卡。
3. 每次只打开一个实验文件夹中的 `.ino` 文件。
4. 连接 USB，选择串口，点击“上传”。
5. 基础语法实验使用波特率 `115200` 打开串口监视器。
6. WS2812 实验还要在库管理器安装 `Adafruit NeoPixel`。

代码书写约定见 `CODE_STYLE.md`。
