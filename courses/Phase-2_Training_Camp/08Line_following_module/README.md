# ESP32-S3 八路巡线模块 I2C 模拟量课程

本课程共 3 课时。按照提供的示例程序，只读取 I2C 模拟量并通过串口显示，不加入
阈值二值化、权重误差、电机控制或巡线算法。

## 协议参数

| 参数 | 数值 |
|---|---:|
| SDA | GPIO 8 |
| SCL | GPIO 9 |
| I2C 地址 | `0x27` |
| 读取命令 | `0x01` |
| 每次读取长度 | 32 字节 |
| 有效模拟量 | 后 16 字节，共 8 路 `uint16_t` |

## 3 课时安排

### 第 1 课时：代码讲解（一）

1. 使用 `Wire.begin(8, 9)` 启动 I2C。
2. 使用 `beginTransmission(0x27)` 选择巡线模块。
3. 使用 `Wire.write(0x01)` 发送读取命令。
4. 检查 `endTransmission()` 是否返回 `0`。
5. 使用 `requestFrom(0x27, 32)` 请求 32 字节。
6. 使用 `Wire.read()` 逐字节读取并以十六进制显示。

使用代码：

- `01_line_raw_bytes/01_line_raw_bytes.ino`

### 第 2 课时前半：代码讲解（二）

1. 跳过协议中前 16 个字节。
2. 每一路模拟量由高字节和低字节组成。
3. 使用 `highByte * 256 + lowByte` 合成 `uint16_t`。
4. 使用长度为 8 的数组保存八路数据。
5. 编写 `readSensorValues()`，用 `true/false` 表示读取结果。
6. 在串口中显示 S1～S8 的模拟量。

使用代码：

- `02_line_analog_values/02_line_analog_values.ino`

### 第 2 课时后半：原理讲解（0.5 课时）

- 红外发射管向地面发射红外光，接收器测量反射强度。
- 白色、黑色、不同材质和不同高度会产生不同模拟量。
- I2C 传输单位是字节，而一路模拟量使用 16 位，所以需要两个字节。
- 大端格式先发送高字节，后发送低字节。
- `uint8_t` 保存 0～255，`uint16_t` 保存 0～65535。
- 模拟量应先观察和标定，不能直接照搬其他场地的阈值。
- 本课程只采集数据，后续 PID 课程再使用这些数值计算误差。

### 第 3 课时：学生实验（1 课时）

1. 运行 I2C 扫描器，确认能够找到 `0x27`。
2. 运行原始字节程序，确认每次收到 32 字节。
3. 运行模拟量程序，观察 S1～S8。
4. 把模块放在白纸、黑线和桌面上，分别记录八路数值。
5. 改变模块与地面的高度，观察模拟量变化。
6. 用手依次遮挡每一路传感器，确认 S1～S8 的排列方向。
7. 选做：把输出改成逗号分隔的 8 个数字，在串口绘图器观察曲线。

## 32 字节数据布局

本代码按照你提供的示例协议解析：

```text
字节 0～15   ：本课暂不使用
字节 16～17 ：S1 高字节、S1 低字节
字节 18～19 ：S2 高字节、S2 低字节
...
字节 30～31 ：S8 高字节、S8 低字节
```

如果实物模块的说明书定义不同，应以该模块协议为准。

## 关键代码

### 发送命令并请求数据

```cpp
Wire.beginTransmission(SENSOR_ADDRESS);
Wire.write(READ_COMMAND);
Wire.endTransmission();

delay(10);
Wire.requestFrom(SENSOR_ADDRESS, DATA_LENGTH);
```

### 合成一路 16 位模拟量

```cpp
uint8_t highByte = Wire.read();
uint8_t lowByte = Wire.read();
uint16_t value = highByte * 256 + lowByte;
```

例如高字节为 `0x12`、低字节为 `0x34`：

```text
0x12 × 256 + 0x34 = 0x1234 = 4660
```

## 为什么读取失败时要清空缓冲区

```cpp
while (Wire.available() > 0) {
  Wire.read();
}
```

如果实际字节数不是 32，当前数据帧不完整。把残留字节读掉后，下一次读取可以重新开始，
避免新旧数据混在一起。

## 常见问题

- **一直读取失败：** 检查地址 `0x27`、SDA GPIO 8、SCL GPIO 9、供电和共地。
- **收到的字节不是 32 个：** 增加命令后的等待时间，检查线长和 I2C 时钟。
- **所有模拟量不变化：** 检查模块高度、红外发射是否工作以及协议命令是否正确。
- **S1～S8 顺序相反：** 这与模块安装方向有关，记录实物方向即可，不需要巡线逻辑。
- **数值与示例阈值不同：** 属于正常现象，应针对实际场地重新记录和标定。
