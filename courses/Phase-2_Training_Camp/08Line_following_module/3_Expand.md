# 第三模块 拓展

## 1. 知识拓展
- 本课相关原理的进一步解释：
  - 巡线模块通常通过红外发射与反射原理工作，不同颜色、材质和高度会影响反射强度。
  - 白底通常反射更强，黑线通常吸收更多红外光，因此对应模拟量会不同，但具体大小规律要以实测为准。
  - 本课程序没有直接做“黑白判断”，而是先读取模拟量，这是因为不同场地、灯光和安装高度下，阈值会变化。
  - I2C 传输的基本单位是字节，而一路巡线模拟量使用 `16` 位，所以需要两个字节共同表示一个通道值。
  - 当前示例协议把后 `16` 个字节定义为 `8` 路模拟量，本课按这个协议解析；如果实物说明书不同，应按实际协议修改。
  - 读取失败时清空缓冲区，是为了避免“半帧旧数据 + 半帧新数据”混在一起，影响下一次解析。
  - 本课只做到“采集数据、理解协议、观察变化”，后续如果要做真正巡线，还需要继续学习阈值判断、加权位置、误差计算和电机控制。

## 2. 速查表
- 重要函数速查：
  - `Wire.begin()`：启动 I2C
  - `Wire.setClock()`：设置 I2C 时钟
  - `Wire.beginTransmission()`：开始一次 I2C 发送
  - `Wire.write()`：写入命令字节
  - `Wire.endTransmission()`：结束发送并返回结果
  - `Wire.requestFrom()`：请求设备返回数据
  - `Wire.available()`：查看缓冲区里还有多少字节
  - `Wire.read()`：读取一个字节
- 重要参数速查：
  - `PIN_SDA = 8`：I2C 数据线引脚
  - `PIN_SCL = 9`：I2C 时钟线引脚
  - `SENSOR_ADDRESS = 0x27`：巡线模块 I2C 地址
  - `READ_COMMAND = 0x01`：读取命令
  - `DATA_LENGTH = 32`：一次读取长度
  - `16`：当前课程中需要跳过的前半段字节数
  - `8`：模拟量通道数
  - `100000`：本课使用的 I2C 时钟频率
- 重要单词速查：
  - `line`：巡线 / 线
  - `sensor`：传感器
  - `raw`：原始的
  - `byte`：字节
  - `analog`：模拟量的
  - `value`：数值
  - `address`：地址
  - `command`：命令
  - `data`：数据
  - `length`：长度
  - `high`：高
  - `low`：低
  - `read`：读取
  - `request`：请求
  - `available`：可用的
