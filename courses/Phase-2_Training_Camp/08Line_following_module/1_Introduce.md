# 第一模块 引言

## 1. 本课目标与现象导入

### 1.1 本课目标
- 本课要完成的实验任务：
  - 完成八路巡线模块原始字节读取实验。
  - 完成八路巡线模块模拟量解析实验。
- 本课要掌握的核心知识点：
  - 理解八路巡线模块通过 I2C 返回数据的基本过程。
  - 学会使用 `Wire.beginTransmission()`、`Wire.write()`、`Wire.requestFrom()` 完成一次读取。
  - 理解本模块使用地址 `0x27`、读取命令 `0x01`、单次返回 `32` 字节。
  - 学会观察原始字节，并把其中后 `16` 个字节解析成 `8` 路 `uint16_t` 模拟量。
  - 理解高字节、低字节和大端格式的基本含义。

### 1.2 现象导入
- 现象：
  - 上传原始字节程序后，串口会持续显示 `32` 个十六进制字节。
  - 当探头经过白底、黑线、桌面等不同表面时，部分字节会明显变化。
  - 上传模拟量程序后，串口会显示 `S1` 到 `S8` 八路数值。
  - 用手依次遮挡不同探头时，对应通道的数值会发生变化。
  - 改变模块与地面的高度时，八路数值也会变化。

## 2. 本课共用预备知识

### 2.1 共用预备知识
- 本课会用到的旧知识：
  - 会使用 `Arduino IDE` 上传程序并打开串口监视器。
  - 已经掌握 I2C 的基础接线方法。
  - 知道 `0x27` 这类十六进制地址写法。
- 本课新增的核心概念：
  - 八路巡线模块通过 I2C 向主控返回一整帧数据。
  - 这一课的示例协议中，读取命令是 `0x01`，返回总长度是 `32` 字节。
  - 课程当前只使用后 `16` 个字节，把它们解析成 `8` 路 `uint16_t` 模拟量。
  - 一路 `uint16_t` 数据由两个字节组成：高字节在前、低字节在后。
  - 模拟量不是固定阈值，它会受颜色、高度、材质和环境光影响。
- 本课涉及的重点英文单词(函数命名、变量命名等使用的英文单词)：
  - `line`：巡线 / 线
  - `sensor`：传感器
  - `raw`：原始的
  - `byte`：字节
  - `analog`：模拟量的
  - `value`：数值
  - `address`：地址
  - `command`：命令
  - `data`：数据
  - `length`：长度
  - `high`：高
  - `low`：低
  - `read`：读取
  - `request`：请求
  - `available`：可用的
- 学生开始实验前必须先知道的内容：
  - 本章统一使用 `SDA = GPIO 8`、`SCL = GPIO 9`。
  - 模块 I2C 地址为 `0x27`。
  - 本章协议命令为 `0x01`，每次读取 `32` 字节。
  - 如果模块说明书与示例协议不同，应以实物模块协议为准。

## 3. 本课共用器材与基础接线约定

### 3.1 所需器材
- 开发板：
  - `ESP32-S3` 开发板 `1` 块
- 传感器/执行器/模块：
  - 八路巡线模块 `1` 个
- 电阻、面包板、杜邦线：
  - 面包板 `1` 块
  - 杜邦线若干
- USB 数据线：
  - 开发板对应数据线 `1` 根
- 软件环境：
  - `Arduino IDE`
  - `esp32` 开发板支持包
  - 串口监视器

### 3.2 共用硬件介绍
- 本课涉及的器件名称：
  - 八路巡线模块
- 每个器件的作用：
  - 八路巡线模块：采集地面反射情况，并通过 I2C 返回 8 路检测数据。
- 关键特性说明：
  - 模块使用 I2C 通信，便于只用两根信号线读取多路数据。
  - 本课示例程序先读取完整数据帧，再做解析。
  - 模块输出的是模拟量，不是已经判断好的“黑/白”结果。
  - 不同场地和不同高度下，数值范围会变化。
- 容易出错的地方：
  - `SDA`、`SCL` 接反。
  - 地址不是 `0x27`，却直接照搬程序。
  - 误以为前 `16` 个字节就是模拟量。
  - 没有收到完整 `32` 字节就直接解析，导致数据错乱。
