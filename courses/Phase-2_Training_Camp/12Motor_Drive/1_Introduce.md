# 第一模块——电机驱动入门

## 1. 本课任务

本课只完成四件事：

1. 让电机正转。
2. 让电机反转。
3. 让电机停止。
4. 使用编码器计算距离。

## 2. 基本原理

- 电机不能直接连接 ESP32 GPIO，必须使用电机驱动板。
- `DIR` 控制电机方向。
- `PWMA` 接收 PWM，控制电机速度。
- 电机驱动板、ESP32、电机电源和编码器必须共地。
- 换向前先停止，可以减小冲击。

## 3. LEDC PWM

本课使用：

- 频率：20kHz。
- 分辨率：8 位。
- 通道：0。
- Duty：0～255。

```cpp
ledcAttachChannel(
  MOTOR_PWM_PIN,
  20000,
  8,
  0
);
```

输出速度：

```cpp
ledcWriteChannel(0, 100);
```

停止电机：

```cpp
ledcWriteChannel(0, 0);
```

## 4. 接线

| 功能 | ESP32-S3 |
|---|---:|
| 电机 A：PWMA | GPIO 42 |
| 电机 A：AN1（方向） | GPIO 1 |
| 电机 A：编码器 A+ | GPIO 4 |
| 电机 A：编码器 A- | GPIO 5 |
| GND | 所有模块共地 |

## 5. 串口命令

| 命令 | 功能 |
|:---:|---|
| `F` | 正转 |
| `B` | 反转 |
| `S` | 停止 |
| `R` | 编码器清零 |

## 6. 重点单词

- `motor`：电机
- `direction`：方向
- `forward`：前进、正转
- `back`：后退、反转
- `PWM`：脉宽调制
- `frequency`：频率
- `resolution`：分辨率
- `channel`：通道
- `encoder`：编码器
- `distance`：距离

## 7. 安全要求

1. 断电后再接线。
2. 第一次运行时抬起车轮。
3. 电机堵转或驱动板过热时立即断电。
4. 不要让电机线卷入轮子。
