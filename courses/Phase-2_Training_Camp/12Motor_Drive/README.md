# ESP32-S3 电机驱动与小车组装课程

本课程共 4 课时。根据扩展板引脚图，电机 A 使用 AN1=GPIO 1、PWMA=GPIO 42，
编码器 A+/A-=GPIO 4/5；电机 B 使用 BN1=GPIO 2、PWMB=GPIO 41，编码器
B+/B-=GPIO 6/7。电机 PWM 统一使用 LEDC 20kHz、8 位、通道 0。

## 安全要求

1. 电机必须通过驱动芯片供电，不能直接接 ESP32 GPIO。
2. 电机电源按电机和驱动板额定电压选择。
3. ESP32、驱动板、编码器和电机电源必须共地。
4. 首次运行时把车轮抬离桌面，并准备断开电源。
5. 换向前先把 PWM 设为 0，等待电机减速后再改变 DIR。
6. 不要在电机堵转时长时间保持大 PWM，驱动芯片和电机可能过热。

## PCB 原理讲解

### 1. 电源路径

电池或外部电源先进入电机驱动功率端，再由驱动芯片把电流送给电机。ESP32 的 GPIO
只提供方向和 PWM 控制信号，不承担电机工作电流。

### 2. H 桥和方向

H 桥通过改变流过电机的电流方向控制正反转。本课程驱动板把复杂的 H 桥控制封装成：

- `DIR`：选择电流方向。
- `PWMA`：使用 PWM 改变平均电压和速度。

### 3. 感性负载和续流

电机线圈是感性负载，关断时会产生反向电压。驱动芯片内部或 PCB 上必须有续流路径，
否则可能损坏驱动器或干扰 ESP32。

### 4. 去耦和抗干扰

- 驱动电源入口附近放置电解电容和陶瓷电容。
- 电机两端可按硬件方案增加抑制噪声的电容。
- 功率走线应短而宽，编码器信号线远离电机大电流走线。
- 信号地和功率地要可靠连接，避免细长回路。

### 5. PCB 检查顺序

1. 断电检查短路、焊锡桥和元件方向。
2. 万用表确认电源正负极和 GND 连通。
3. 不接电机先上电，检查逻辑电压。
4. 接电机但抬起车轮，从低 PWM 开始测试。
5. 观察驱动芯片温度、电机电流和 ESP32 是否复位。

## 四个代码实验

### 1. 电机基础驱动

`01_motor_basic`：正转、停止、反转、停止。重点理解 `digitalWrite()` 控制方向，
`ledcAttachChannel()` 配置 PWM，`ledcWriteChannel()` 控制 Duty。本实验使用电机 A：
AN1=GPIO 1、PWMA=GPIO 42。

### 2. 电机串口控制

`02_motor_serial` 使用 115200 和单字符命令：

```text
F  正转
B  反转
S  停止
```

PWM 使用 20kHz、8 位、通道 0，固定 Duty 为100。

### 3. 电机+编码器+TFT

`03_motor_encoder_tft` 使用电机 B：BN1=GPIO 2、PWMB=GPIO 41、编码器 B+/B-=GPIO 6/7。
编码器使用 `CHANGE` 2倍频计数，每200ms计算距离和速度，并局部刷新 ST7789 数值区域。
当前使用60mm车轮；实测单边沿每圈430次，因此双边沿每圈按860次计算。

### 4. 电机+编码器+串口距离（无屏幕版）

`04_motor_encoder_distance_serial` 承接学生的单上升沿编码器程序，不使用 TFT。电机仍使用
电机 A：AN1=GPIO 1、PWMA=GPIO 42，编码器 A+/A-=GPIO 4/5；A+ 使用 `RISING`，
每圈按430次计算，
轮径为60mm。电机 PWM 使用 `ledcAttachChannel()` 和 `ledcWriteChannel()`；串口使用
`F`、`B`、`S` 和 `R` 控制，并每200ms输出计数与厘米距离。
距离必须使用 `float` 保存，避免小数部分丢失。

## 小车组装顺序

1. 固定左右电机，确认轴线平行。
2. 安装轮胎，手动转动确认无卡滞。
3. 固定电池和 PCB，保持重心尽量居中。
4. 连接电机线、编码器线和电源线。
5. 用扎带或固定座整理线缆，避免卷入轮胎。
6. 抬起车轮运行基础程序，确认方向。
7. 若左右方向不一致，交换对应电机线或修改 DIR 逻辑。
8. 最后放到地面，从低速度开始测试。

## 常见问题

- **电机不转：** 检查电机电源、共地、PWM、DIR 和驱动使能。
- **ESP32 一转电机就复位：** 电源容量不足、压降或电机干扰过大。
- **只能一个方向：** 检查 DIR 信号和驱动器方向输入。
- **编码器计数为负：** 交换 A/B，或交换计数加减方向。
- **速度不准：** 校准每圈计数和轮径。
- **驱动芯片过热：** 检查堵转、负载、电源和驱动额定电流。
