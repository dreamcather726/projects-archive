# 第三模块——简单拓展

## 1. 修改电机速度

原速度：

```cpp
const int MOTOR_SPEED = 100;
```

改成：

```cpp
const int MOTOR_SPEED = 150;
```

数值变大后，电机通常会转得更快。8 位 PWM 的范围为 `0～255`。

## 2. 修改输出周期

原程序每200ms输出一次距离：

```cpp
delay(200);
```

改为500ms：

```cpp
delay(500);
```

修改后，串口数据更新得更慢，但不影响编码器中断计数。

## 3. 实验要求

1. 第一次测试时抬起车轮。
2. 修改前先停止电机并断电。
3. 每次只修改一个数值。
4. 记录修改前后的实际现象。
