# 第三模块 拓展

## 1. 知识拓展
- 本课相关原理的进一步解释：
  - 力敏传感器本质上是受力后阻值变化的器件，常通过分压电路把变化转换成开发板可以读取的电压。
  - `analogRead()` 读取到的是模拟输入值，通常随受力大小变化，但不同模块和接线方式下的具体数值范围会有差异。
  - 阈值判断适合做“超过某个条件就触发”的实验，例如蜂鸣器报警或触发呼吸灯。
  - `map()` 适合把连续变化的传感器数据转换为另一个连续变化的控制量，例如 LED 亮度。
  - `constrain()` 适合先限制输入范围，避免数据过大或过小导致映射结果异常。
  - `WS2812` 更适合用颜色变化来表达压力等级，因为颜色比单纯亮度更容易区分多个状态。
  - `WS2812` 和普通 LED 的区别在于：普通 LED 直接控制引脚输出，`WS2812` 需要先设置颜色缓存，再调用 `show()` 刷新。

## 2. 速查表
- 重要函数速查：
  - `analogRead()`：读取模拟输入值
  - `digitalWrite()`：输出高低电平
  - `analogWrite()`：输出 PWM 数值
  - `Serial.begin()`：启动串口通信
  - `Serial.print()`：串口输出内容但不换行
  - `Serial.println()`：串口输出内容并换行
  - `constrain()`：限制数值范围
  - `map()`：做范围映射
  - `rgb.setBrightness()`：设置彩灯整体亮度
  - `rgb.setPixelColor()`：设置指定灯珠颜色
  - `rgb.clear()`：清除彩灯缓存
  - `rgb.show()`：刷新彩灯显示
- 重要参数速查：
  - `FORCE_LIMIT`：压力触发阈值
  - `FORCE_MAX`：映射时使用的最大压力值
  - `0~4095`：常见模拟量读取范围
  - `0~255`：常见 PWM 亮度范围
  - `115200`：本章串口波特率
  - `NEO_GRB`：`WS2812` 颜色顺序
  - `NEO_KHZ800`：`WS2812` 通信格式
- 重要单词速查：
  - `force`：压力 / 受力
  - `sensor`：传感器
  - `buzzer`：蜂鸣器
  - `limit`：限制值 / 阈值
  - `max`：最大值
  - `light`：灯光 / 亮度
  - `analog`：模拟的
  - `read`：读取
  - `digital`：数字的 / 数字电平的
  - `write`：写入 / 输出
  - `brightness`：亮度
  - `color`：颜色
  - `red`：红色
  - `green`：绿色
  - `blue`：蓝色
  - `clear`：清除
  - `show`：显示 / 刷新显示
  - `map`：映射
  - `constrain`：限制范围
  - `value`：数值 / 值
