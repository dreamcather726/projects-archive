# 第一模块 引言

## 1. 本课目标与现象导入

### 1.1 本课目标
- 本课要完成的实验任务：
  - 完成力敏传感器控制有源蜂鸣器报警实验。
  - 完成力敏传感器触发 LED 呼吸灯实验。
  - 完成力敏传感器控制 LED 亮度等级实验。
  - 完成力敏传感器控制 `WS2812` 彩灯颜色实验。
- 本课要掌握的核心知识点：
  - `analogRead()` 读取模拟量的方法。
  - 阈值判断与分段判断的基本思路。
  - `digitalWrite()`、`analogWrite()` 在输出控制中的作用。
  - `map()`、`constrain()` 在数值转换中的作用。
  - `Adafruit_NeoPixel` 控制 `WS2812` 的基本方法。
  - 力敏传感器“压力越大，电压变化越明显”的基本特性。

### 1.2 现象导入
- 现象：
  - 轻轻按压力敏传感器时，串口中的数值会发生变化。
  - 当压力超过设定阈值时，有源蜂鸣器会发出报警声。
  - 当压力超过设定阈值时，LED 会出现呼吸变化效果。
  - 按压力度越大，LED 会越亮。
  - 无压力、轻压、中压、重压时，`WS2812` 会显示不同颜色。

## 2. 本课共用预备知识

### 2.1 共用预备知识
- 本课会用到的旧知识：
  - 会使用 `Arduino IDE` 上传程序并打开串口监视器。
  - 知道 GPIO 输入输出、`HIGH`、`LOW`、`GND` 的基本概念。
  - 已经了解 LED、蜂鸣器、`PWM`、`WS2812` 的基础使用方法。
- 本课新增的核心概念：
  - 力敏传感器是一种“受力后阻值变化”的传感器。
  - `analogRead()` 读取的是模拟输入值，常见范围是 `0~4095`。
  - 阈值判断适合做“达到条件就触发”的实验。
  - `map()` 可以把一个范围的数值映射到另一个范围。
  - `constrain()` 可以把数值限制在设定区间内，避免超范围。
- 本课涉及的重点英文单词(函数命名、变量命名等使用的英文单词)：
  - `force`：压力 / 受力
  - `sensor`：传感器
  - `buzzer`：蜂鸣器
  - `limit`：限制值 / 阈值
  - `max`：最大值
  - `light`：灯光 / 亮度
  - `analog`：模拟的
  - `read`：读取
  - `digital`：数字的 / 数字电平的
  - `write`：写入 / 输出
  - `brightness`：亮度
  - `color`：颜色
  - `red`：红色
  - `green`：绿色
  - `blue`：蓝色
  - `clear`：清除
  - `show`：显示 / 刷新显示
  - `map`：映射
  - `constrain`：限制范围
  - `value`：数值 / 值
- 学生开始实验前必须先知道的内容：
  - 力敏传感器接到模拟输入引脚时，读取值会随压力变化。
  - 不同程序中力敏传感器连接引脚可能不同，必须以程序定义为准。
  - `WS2812` 相关实验需要提前安装 `Adafruit NeoPixel` 库。
  - 有源蜂鸣器和 LED 都需要按照程序中定义的引脚连接。

## 3. 本课共用器材与基础接线约定

### 3.1 所需器材
- 开发板：
  - `ESP32-S3` 开发板 `1` 块
- 传感器/执行器/模块：
  - 力敏传感器模块 `1` 个
  - 有源蜂鸣器模块 `1` 个
  - 普通 LED 或板载 LED
  - `WS2812` 彩灯模块或板载 `WS2812`
- 电阻、面包板、杜邦线：
  - `220Ω` 电阻若干
  - 面包板 `1` 块
  - 杜邦线若干
- USB 数据线：
  - 开发板对应数据线 `1` 根
- 软件环境：
  - `Arduino IDE`
  - `esp32` 开发板支持包
  - `Adafruit NeoPixel` 库

### 3.2 共用硬件介绍
- 本课涉及的器件名称：
  - 力敏传感器、有源蜂鸣器、LED、`WS2812`
- 每个器件的作用：
  - 力敏传感器：把按压力度转换为电压变化，供开发板读取。
  - 有源蜂鸣器：达到条件时直接发声报警。
  - LED：用亮度变化表达压力大小。
  - `WS2812`：用颜色变化表达压力等级。
- 关键特性说明：
  - 力敏传感器输出是模拟量，通常接到支持模拟读取的引脚。
  - 有源蜂鸣器只需要高低电平即可控制开关。
  - LED 呼吸灯和亮度等级实验都依赖 `PWM` 输出。
  - `WS2812` 改变颜色后必须调用 `show()` 才会刷新显示。
- 容易出错的地方：
  - 力敏传感器信号线接错引脚，导致串口数值不变化。
  - 不同实验的力敏引脚定义不同，接线时没有按程序核对。
  - 忘记共地，导致蜂鸣器、LED 或 `WS2812` 现象异常。
  - `WS2812` 安装了库但没有调用 `show()`，看不到颜色变化。
