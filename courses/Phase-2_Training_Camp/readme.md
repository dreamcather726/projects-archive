- 第 4 课时：LED 控制 `代码讲解`（2）。讲按键控制灯、PWM 呼吸灯、RGB 灯基本写法并现场运行。

- 第 2 课时：串口通信 `代码讲解`（1）。逐行讲 `01_serial_read_char.ino`，理解 `Serial.begin()`、`available()`、`peek()`、`read()`、`print()`、`println()`、`write()` 和回车换行。
- 第 3 课时：串口通信 `代码讲解`（2）。讲 `SerialFrame.h`、协议常量、`calculateChecksum()` 和 `sendFrame()`，完成数组组帧与原始字节发送。
- 第 4 课时：串口通信 `代码讲解`（3）。逐段讲 `readFrame()`：等待完整帧、寻找帧头、读取字段、检查长度/帧尾/校验和、保存结果。
- 第 5 课时：串口通信 `代码讲解+验证`。完整手敲 `08_data_frame_ping` 三文件工程，讲 LED 指令、PING、成功/错误应答并用 HEX 工具验证，最后与当日作业逐题衔接。

- 第 2 课时：串口数据 `发送讲解`。复习数组下标与六个字段的对应关系，讲 `calculateChecksum()`、`sendFrame(command, data)` 和 `Serial.write(frame, FRAME_SIZE)`，完成数据帧组帧与发送。

- 第 5 课时：串口收发 `综合实验`。学生完成正确帧、错误校验帧、帧前干扰数据和未知指令测试，观察接收、丢帧、执行及应答结果。
