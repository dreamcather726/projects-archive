# 第一模块 引言

## 1. 本课目标与现象导入

### 1.1 本课目标
- 本课要完成的实验任务：
  - 先用电脑里的“虚拟小车”观察 PID 怎样追赶目标，不接电机也能实验。
  - 让电机在负载变化时，自动把转速拉回目标速度。
  - 让电机转到指定位置，并在接近目标后停下来。
  - 让八路巡线小车沿着黑线前进，发现偏离时自动修正方向。
- 本课要掌握的核心知识点：
  - 知道“目标值、当前值、误差、输出”分别表示什么。
  - 理解闭环控制就是“做动作—看结果—再修正”的循环。
  - 能用生活中的例子理解 P、I、D 的作用。
  - 会调用 `PID_Init()`、`PID_Clear()` 和 `PID_IncPIDCal()`。
  - 知道调参数要按照“小步修改、每次观察、及时记录”的方法进行。

### 1.2 现象导入
- 现象：
  - 想象骑自行车沿一条线前进：偏得多就多转一点车把，偏得少就少转一点。这就是 P 的基本想法。
  - 如果一直有一点点偏差，就把这些小偏差记下来，再多修正一点。这像 I 在帮忙。
  - 如果车头转得太快，眼看就要冲过头，就提前收一点力。这像 D 在帮忙。
  - 实验成功后，串口绘图器中的当前值会逐渐靠近目标值；电机能稳住速度、转到指定位置，小车也能跟随黑线。
  - PID 不是“算一次就结束”，而是像人走平衡木一样，不断观察、不断微调。

## 2. 本课共用预备知识

### 2.1 共用预备知识
- 本课会用到的旧知识：
  - 会使用 Arduino IDE 上传程序，并打开 `115200` 波特率的串口监视器或串口绘图器。
  - 会使用 `millis()` 做非阻塞计时。
  - 了解 PWM 可以控制电机速度。
  - 知道编码器可以把电机转动变成计数。
  - 知道巡线模块可以分辨黑线和背景。
- 本课新增的核心概念：
  - `目标值`：我们希望系统达到的结果，例如 `100 RPM`。
  - `当前值`：传感器实际测到的结果，例如现在只有 `82 RPM`。
  - `误差`：`目标值 - 当前值`。误差不是“程序写错了”，而是“还差多少”。
  - `输出`：PID 算出的控制力度，例如给电机的 PWM。
  - `闭环`：输出会改变设备，传感器再把新结果送回来，程序继续修正。
  - `P（比例）`：看现在差多少；差得越多，修正得越用力。
  - `I（积分）`：把过去的小偏差积累起来，帮助消除长期差一点的问题。
  - `D（微分）`：看误差变化得有多快，帮助减小冲过头和来回摆动。
  - 本课使用的是增量式 PID：每次算出“输出应该增加或减少多少”，再加到上一次输出上。
- 本课涉及的重点英文单词（函数命名、变量命名等使用的英文单词）：
  - `target`：目标
  - `current` / `input`：当前值 / 输入值
  - `error`：误差
  - `output`：输出
  - `feedback`：反馈
  - `control`：控制
  - `closed loop`：闭环
  - `proportional`：比例，对应 P
  - `integral`：积分，对应 I
  - `derivative`：微分，对应 D
  - `increment`：增量
  - `speed`：速度
  - `position`：位置
  - `correction`：修正量
  - `threshold`：阈值
  - `line`：线
  - `lost`：丢失
  - `clear`：清除
  - `limit`：限制
- 学生开始实验前必须先知道的内容：
  - PID 没有一组适合所有机器的“万能参数”，换电机、换电源、换重量后都可能要重新调。
  - 每次只改一个参数，并记录修改前后的现象，才能知道是谁带来了变化。
  - 电机实验必须使用驱动板和合适的独立电源，ESP32 与电机电源必须共地。
  - 第一次调试电机方向和 PID 时要抬起车轮，避免小车突然冲出桌面。
  - 出现高速振荡、堵转、异味或驱动板明显发热时，要立即断电并请老师检查。
  - `speed_pid.h`、`speed_pid.cpp` 和 `.ino` 文件要放在同一个实验文件夹中。

## 3. 本课共用器材与基础接线约定

### 3.1 所需器材
- 开发板：
  - `ESP32-S3` 开发板 `1` 块
- 传感器/执行器/模块：
  - 带编码器的直流电机和电机驱动板
  - 双电机小车底盘（巡线实验使用）
  - 八路 I2C 巡线模块（地址 `0x27`）
  - 电机独立电源
- 面包板、杜邦线与辅助材料：
  - 杜邦线若干
  - 根据套件需要准备面包板或接线端子
- USB 数据线：
  - ESP32-S3 对应 USB 数据线 `1` 根
- 软件环境：
  - Arduino IDE
  - ESP32 Arduino 开发板支持包
  - 串口监视器和串口绘图器

### 3.2 共用硬件介绍
- 编码器：像装在电机旁边的“小计步器”，电机每转动一点，它就发出脉冲。
- 电机驱动板：像电机的“力量放大器”。ESP32 只发命令，驱动板负责提供电机需要的电流。
- 巡线模块：像小车底部的八只眼睛，负责判断黑线在左边、中间还是右边。
- PID 控制器：不是一块额外硬件，而是一段反复计算修正量的程序。

### 3.3 基础接线约定
- 调速与位置实验：
  - 电机方向 `DIR -> GPIO 2`
  - 电机调速 `PWM -> GPIO 1`
  - 编码器 A 相 `-> GPIO 6`
  - 编码器 B 相 `-> GPIO 7`
- 巡线小车实验：
  - 左电机 `PWM -> GPIO 42`，`DIR -> GPIO 41`
  - 右电机 `PWM -> GPIO 1`，`DIR -> GPIO 2`
  - 巡线模块 `SDA -> GPIO 8`，`SCL -> GPIO 9`
- 所有使用电机的实验都要让 ESP32、驱动板、电机电源和传感器共地。
- 软件模拟实验不接电机，只连接 USB 数据线即可。
- 实物引脚若与课程套件不同，应先由老师确认，再修改程序顶部的引脚常量。
