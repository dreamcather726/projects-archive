# ESP32-S3 PID 闭环控制课程

本课程共 8 课时，从软件模拟开始，逐步完成电机调速、位置控制和八路巡线小车。
每个实验目录都使用青潮智科项目提供的 `speed_pid.h/.cpp` 增量式PID文件，实验可以
单独打开和编译。

## PID 基本关系

```text
误差 e = 目标值 - 当前值
本次输出 = 上次输出 + 本次输出增量
```

- P：当前误差越大，立即给出越大的修正。
- I：累计过去误差，用于消除长期小偏差。
- D：观察误差变化速度，提前抑制冲过目标和振荡。

PID 必须形成闭环：

```text
目标值 → PID → 执行器 → 被控对象 → 传感器反馈
              ↑___________________________|
```

## speed_pid 增量式算法

提供的 `speed_pid.cpp` 使用下面的增量式公式：

```text
当前误差 e = 目标值 - 当前值
输出增量 = P×(e-e1) + I×e + D×(e-2×e1+e2)
本次输出 = 上次输出 + 输出增量
```

其中 `e1` 是上一次误差，`e2` 是上上次误差。计算完成后，程序保存两次历史误差，
并把输出限制在设定范围内。

### 三个常用函数

```cpp
PID speedPid;

PID_Init(&speedPid, 0.5, 1.4, 0.2, 255, 0);
PID_Clear(&speedPid);
float output = PID_IncPIDCal(&speedPid, currentValue, targetValue);
```

- `PID_Init()`：设置P、I、D和输出最大值、最小值。
- `PID_Clear()`：清除历史误差和历史输出，PID参数保持不变。
- `PID_IncPIDCal()`：输入当前值和目标值，返回本次PID输出。
- `&speedPid` 表示把这组PID数据交给函数，这是所提供 `speed_pid` 接口的固定写法。

增量式PID没有传入时间参数，因此控制周期应保持稳定。调速实验固定每100ms计算一次，
修改控制周期后通常需要重新整定参数。

## 四个实验

### 1. PID 闭环软件演示

目录：`01_pid_closed_loop`

不连接硬件，用简单公式模拟被控对象。串口发送：

```text
target 80
target 30
```

打开串口绘图器观察 Target、Input、Output。

### 2. PID 电机调速

目录：`02_pid_speed`

电机 DIR=GPIO2、PWM=GPIO1，编码器 A=GPIO6、B=GPIO7。串口命令：

```text
speed 100
speed 150
stop
```

程序使用 A 相 CHANGE 2倍频，每 100ms 由编码器计算 RPM，再由 PID 更新 PWM。
实测单边沿每圈430次，所以程序使用双边沿每圈860次计算转速。

### 3. PID 电机位置控制

目录：`03_pid_position`

```text
position 400
position -400
zero
stop
```

位置反馈同样使用 A 相 CHANGE 2倍频。PID 输出范围为 -255～255，正负号选择方向，
绝对值作为 PWM。

### 4. PID 巡线小车

目录：`04_pid_line_car`

| 功能 | 引脚 |
|---|---:|
| 左轮（电机 A）PWMA | GPIO 42 |
| 左轮（电机 A）AN1 | GPIO 1 |
| 右轮（电机 B）PWMB | GPIO 41 |
| 右轮（电机 B）BN1 | GPIO 2 |
| 巡线 SDA | GPIO 8 |
| 巡线 SCL | GPIO 9 |

巡线模块地址为 `0x27`，每次读取 32 字节，跳过前 16 字节参考值，再解析八路当前值。
八个通道使用从左到右的权重：

```text
-70  -50  -30  -10   10   30   50   70
```

黑线在中央时误差接近 0。黑线偏向一侧时，PID 输出改变左右轮速度差。

## PID 整定步骤

### 第一步：只调 Kp

1. 先设置 `Ki=0`、`Kd=0`。
2. 从较小 Kp 开始。
3. 缓慢增加 Kp，直到响应足够快但还没有明显连续振荡。

### 第二步：增加 Kd

1. 如果冲过目标或左右摆动，逐渐增加 Kd。
2. Kd 太大会放大传感器噪声，输出可能抖动。

### 第三步：最后增加 Ki

1. 如果长期存在小偏差，再增加少量 Ki。
2. Ki 太大容易积分累积，造成过冲和恢复缓慢。
3. `speed_pid` 会限制最终输出，但仍应避免设置过大的I参数。
4. 每次更换目标或停止时调用 `PID_Clear()`，清除以前累计的输出和误差。

## 调速与位置控制差异

| 项目 | 反馈 | PID 输出 | 目标 |
|---|---|---|---|
| 调速 | RPM | 0～255 PWM | 保持速度 |
| 位置 | 编码器累计计数 | -255～255 | 到达位置 |
| 巡线 | 黑线位置误差 | 左右速度差 | 误差为0 |

## 实验安全

1. 电机必须使用驱动板和独立合适电源，并与 ESP32 共地。
2. 调试方向和 PID 前先抬起车轮。
3. 从低 PWM、低 Kp 开始。
4. 发现高速振荡、堵转或驱动过热时立即断电。
5. 串口调试时保持小车固定，防止突然移动跌落桌面。

## 常见问题

- **PID 越调越偏：** 反馈方向反了，交换编码器方向或电机方向。
- **电机只响不转：** PWM 低于启动死区，检查电源并适当提高最小 PWM。
- **速度波动大：** 增大测速周期、检查编码器噪声、降低 Kp/Kd。
- **位置不断来回摆动：** 降低 Kp、增加少量 Kd、扩大停止误差范围。
- **巡线左右摆动：** 降低 Kp 或基础速度，增加少量 Kd。
- **小车完全反向修正：** 交换左右速度加减方向或巡线权重正负号。
- **读不到巡线模块：** 先运行 I2C 扫描器确认地址 `0x27`。
