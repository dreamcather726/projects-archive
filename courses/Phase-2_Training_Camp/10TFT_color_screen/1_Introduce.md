# 第一模块 引言

## 1. 本课目标与现象导入

### 1.1 本课目标
- 本课要完成的实验任务：
  - 完成 ST7789 TFT 基础显示实验。
  - 完成 TFT 综合仪表盘实验。
- 本课要掌握的核心知识点：
  - 理解 ST7789 TFT 使用 SPI 通信，而不是 I2C。
  - 学会使用 `Adafruit_ST7789` 和 `Adafruit_GFX` 初始化彩屏。
  - 学会使用 `fillScreen()`、`drawRect()`、`drawFastHLine()`、`setCursor()`、`print()` 绘制界面。
  - 理解 `screen.init(240, 320)` 和 `setRotation(3)` 的作用。
  - 学会把 `MPU6050`、红外、超声波和 RGB 状态整合显示在 TFT 上。
  - 理解“固定标签只画一次，动态数值局部刷新”的屏幕刷新思路。

### 1.2 现象导入
- 现象：
  - 基础程序运行后，彩屏会显示标题、边框和红绿蓝三个色块。
  - 整合程序运行后，屏幕会显示 `Yaw`、`Pitch`、`Roll`、红外状态、超声波距离和 RGB 状态。
  - 转动 `MPU6050` 时，姿态角会变化。
  - 遮挡红外模块时，屏幕上的状态会在 `DETECTED` 和 `CLEAR` 之间切换。
  - 移动障碍物时，距离数值和 RGB 颜色会一起变化。

## 2. 本课共用预备知识

### 2.1 共用预备知识
- 本课会用到的旧知识：
  - 会使用 `Arduino IDE` 上传程序。
  - 已经了解 `MPU6050`、红外模块、超声波模块、WS2812 的基础用法。
  - 已掌握 I2C 接线和 `MPU6050` DMP 姿态解算的基本流程。
- 本课新增的核心概念：
  - TFT 彩屏这节使用的是 SPI，不是 I2C。
  - 屏幕丝印上的 `SDA`、`SCL` 在本模块里其实表示 `MOSI` 和 `SCK`。
  - `CS` 用来片选设备，`DC` 用来区分“命令”和“数据”。
  - `setRotation(3)` 把原本 `240x320` 的屏幕旋转为横向 `320x240`。
  - 整屏频繁重画会更容易闪烁，所以综合程序采用“局部清除 + 局部重绘”。
- 本课涉及的重点英文单词(函数命名、变量命名等使用的英文单词)：
  - `screen`：屏幕
  - `color`：颜色
  - `rotation`：旋转
  - `dashboard`：仪表盘
  - `static`：静态的
  - `update`：更新
  - `integrated`：整合的
  - `error`：错误
  - `distance`：距离
  - `detected`：检测到
  - `clear`：无遮挡 / 清除
  - `width`：宽度
  - `height`：高度
  - `refresh`：刷新
  - `native`：原生的
- 学生开始实验前必须先知道的内容：
  - TFT 的 `CS = GPIO 47`、`DC = GPIO 21`、`SDA(MOSI) = GPIO 20`、`SCL(SCK) = GPIO 19`。
  - `TFT_RST_PIN` 统一为 `-1`，表示不单独接复位引脚。
  - 传感器仍然使用 I2C `GPIO 8`、`GPIO 9`，不要和 TFT 的 `20/19` 混淆。
  - `GPIO 21` 在这章作为 TFT 的 `DC`，不能再接蜂鸣器等其他外设。
  - `GPIO 48` 在这章接 WS2812，不能同时接其他冲突器件。

## 3. 本课共用器材与基础接线约定

  - `Arduino IDE`
  - `Adafruit ST7735 and ST7789 Library`
  - `Adafruit GFX Library`
  - `MPU6050 by Electronic Cats`
  - `Adafruit NeoPixel`

### 3.2 共用硬件介绍
- 本课涉及的器件名称：
  - `ST7789 TFT`、`MPU6050`、红外模块、超声波模块、`WS2812 RGB`
- 每个器件的作用：
  - TFT：负责彩色图形和文字显示。
  - `MPU6050`：提供姿态角。
  - 红外模块：提供障碍检测状态。
  - 超声波模块：提供距离信息。
  - `WS2812 RGB`：提供颜色反馈。
- 关键特性说明：
  - TFT 走 SPI，总线引脚与 I2C 传感器引脚不同。
  - 课程代码使用软件 SPI 方式创建屏幕对象。
  - 彩屏原生尺寸为 `240x320`，旋转后以横屏 `320x240` 使用。
  - 综合实验中 RGB 颜色由距离区间决定。
- 容易出错的地方：
  - 把 TFT 丝印 `SDA/SCL` 误接到 I2C 的 `GPIO 8/9`。
  - 忘记设置 `setRotation(3)`，导致方向不对。
  - 超声波 `ECHO` 没分压。
  - `GPIO 21`、`GPIO 48` 与前面实验残留接线冲突。
