# ESP32-S3 蜂鸣器课堂实验

本课程共 2 课时，每课时 45 分钟。学生将学习有源蜂鸣器和无源蜂鸣器的区别，
用无源蜂鸣器播放《两只老虎》，并观察有源蜂鸣器的不同鸣叫频率。

## 课程安排

### 第 1 课时前半：代码讲解（0.5 课时）

1. 复习 `pinMode()`、`digitalWrite()`、`delay()` 和 `for` 循环。
2. 学习 `tone(引脚, 频率, 时间)` 和 `noTone()`。
3. 认识数组，理解音高数组和时长数组一一对应。
4. 用频率表示音高：频率越高，听到的音越高。
5. 用高、低电平控制有源蜂鸣器响和停。
6. 计算周期：周期为 `1000 / 频率` 毫秒，高、低电平各占半个周期。

使用代码：

- `01_passive_two_tigers/01_passive_two_tigers.ino`
- `02_active_buzzer_frequency/02_active_buzzer_frequency.ino`

扩展示例：

- `03_passive_happy_birthday/03_passive_happy_birthday.ino`：使用无源蜂鸣器播放《生日快乐》，接线仍为 GPIO 48。

### 第 1 课时后半：原理讲解（0.5 课时）

#### 无源蜂鸣器

- “无源”表示内部没有振荡电路，不表示它不需要电源。
- 控制器必须连续输出一定频率的方波，蜂鸣器才会发声。
- 改变方波频率可以改变音高，因此可以用来播放旋律。
- 示例中的 `262 Hz`、`294 Hz`、`330 Hz` 分别接近 C4、D4、E4。

#### 有源蜂鸣器

- 有源蜂鸣器内部带振荡电路，输入有效电平后就会以固定音调发声。
- `digitalWrite(HIGH)` 让模块响，`digitalWrite(LOW)` 让模块停。
- 本实验中的 1 Hz、2 Hz、5 Hz 是“响—停”的重复频率，也就是鸣叫节奏，
  不是蜂鸣器内部声音的音高。
- 普通有源蜂鸣器通常不能用 `tone()` 改变音高。要播放歌曲，应使用无源蜂鸣器。

### 第 2 课时：学生实验（1 课时）

#### 必做实验

1. 连接无源蜂鸣器，上传《两只老虎》程序并听完整旋律。
2. 把第一个音符从 `262` 改为 `392`，比较音高变化。
3. 修改 `noteTime` 中的数值，比较歌曲速度变化。
4. 连接有源蜂鸣器模块，依次观察 1 Hz、2 Hz 和 5 Hz 的鸣叫节奏。
5. 把其中一组改为 10 Hz，并通过串口监视器确认当前频率。

#### 选做实验

1. 修改音符和时长数组，编写一小段自己的旋律。
2. 让有源蜂鸣器先慢后快，制作倒计时报警声。
3. 用按键控制歌曲开始和停止。

## 接线

无源蜂鸣器使用 GPIO 48，有源蜂鸣器使用 GPIO 21。

| 元件 | ESP32-S3 引脚 | 接法 |
|---|---:|---|
| 无源蜂鸣器驱动输入 | GPIO 48 | GPIO 48 → 驱动电路输入 |
| 有源蜂鸣器模块 IN | GPIO 21 | 模块 IN → GPIO 21 |
| 蜂鸣器 GND | GND | 与 ESP32-S3 共地 |
| 蜂鸣器电源 | 按模块标注 | 连接 3.3V 或 5V，不能接错 |

> 建议使用带三极管驱动的蜂鸣器模块。裸蜂鸣器或工作电流较大的模块不要直接由
> GPIO 供电，应使用三极管和限流电阻组成驱动电路。ESP32-S3 的 GPIO 电压为 3.3V，
> 不可输入 5V。

## 课堂重点代码

### 播放一个音符

```cpp
tone(PIN_BUZZER, 262, 400);
delay(460);
noTone(PIN_BUZZER);
```

`262` 是频率，决定音高；`400` 是持续时间，决定音符长短。

### 计算有源蜂鸣器的鸣叫周期

```cpp
int halfPeriod = 500 / frequency;
```

例如频率为 2 Hz 时，一个完整周期为 500 ms，响 250 ms，再停 250 ms，
一秒钟正好完成两次。

## 常见问题

- **无源蜂鸣器只“咔哒”一下：** 检查是否误用了 `digitalWrite()`；无源蜂鸣器需要方波。
- **有源蜂鸣器不能改变音高：** 这是正常现象，它的内部振荡频率通常是固定的。
- **完全没有声音：** 检查蜂鸣器类型、正负极、供电电压和共地连接；无源蜂鸣器检查
  GPIO 48，有源蜂鸣器检查 GPIO 21。
- **程序逻辑相反：** 少数模块为低电平触发，可将代码中的 `HIGH` 与 `LOW` 对调。
