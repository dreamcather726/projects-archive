# 第二模块 实验

## 实验1

### 1. 实验1预备知识
- 本实验在共用预备知识基础上，额外需要知道的内容：
  - 本实验使用无源蜂鸣器播放旋律，核心是给蜂鸣器输出不同频率的声音。
  - 一首歌可以拆成“音符频率数组”和“音符时长数组”。
  - 两个数组中的同一位置数据要一一对应，表示同一个音符的音高和时长。
- 本实验新增的术语、模块或函数：
  - `tone()`
  - `noTone()`
  - `melody[]`
  - `noteTime[]`
  - `NOTE_COUNT`
- 开始本实验前需要特别提醒的点：
  - 本实验只能使用无源蜂鸣器。
  - 无源蜂鸣器连接在程序定义的 `GPIO 48`。
  - 修改频率会改变音高，修改时长会改变节奏快慢。

### 2. 实验1接线
- 接线表：

| 元件 | ESP32-S3 引脚 | 接法 |
| --- | --- | --- |
| 无源蜂鸣器驱动输入 | `GPIO 48` | 控制端接 `GPIO 48` |
| 无源蜂鸣器地线 | `GND` | 与开发板共地 |
| 无源蜂鸣器电源 | 按模块标注 | 按模块说明供电 |

### 3. 完整程序及注释讲解

```cpp
/*
  程序功能：使用 GPIO 48 驱动无源蜂鸣器，播放《两只老虎》歌曲。
  使用方法：把无源蜂鸣器驱动输入连接 GPIO 48，上传程序后直接运行。
  运行结果：无源蜂鸣器按照音符频率和节拍播放《两只老虎》。
*/

// 无源蜂鸣器连接 GPIO 48，通过不同频率发出不同音高
#define PIN_BUZZER 48

// 《两只老虎》使用的音符频率，单位是 Hz
const int melody[] = {
  262, 294, 330, 262,
  262, 294, 330, 262,
  330, 349, 392,
  330, 349, 392,
  392, 440, 392, 349, 330, 262,
  392, 440, 392, 349, 330, 262,
  262, 196, 262,
  262, 196, 262
};

// 每个音符持续的时间，单位是毫秒
const int noteTime[] = {
  400, 400, 400, 400,
  400, 400, 400, 400,
  400, 400, 800,
  400, 400, 800,
  200, 200, 200, 200, 400, 400,
  200, 200, 200, 200, 400, 400,
  400, 400, 800,
  400, 400, 800
};

// 数组中的音符数量
const int NOTE_COUNT = sizeof(melody) / sizeof(melody[0]);

void setup() {
  // 把蜂鸣器引脚设置为输出模式
  pinMode(PIN_BUZZER, OUTPUT);
}

void loop() {
  // 按顺序播放数组中的每一个音符
  for (int i = 0; i < NOTE_COUNT; i = i + 1) {
    // 让蜂鸣器在当前音符频率下发声，持续对应时长
    tone(PIN_BUZZER, melody[i], noteTime[i]);

    // 多等待一小会儿，让相邻音符能够分开
    delay(noteTime[i] + 60);

    // 关闭当前音符，防止声音连在一起
    noTone(PIN_BUZZER);
  }

  // 一遍歌曲播放完毕后停顿 2 秒
  delay(2000);
}
```

### 4. 程序主流程及执行过程
- 程序整体分几步执行：
  1. 定义无源蜂鸣器引脚、旋律数组和时长数组。
  2. 计算数组中音符的总数量。
  3. 在 `setup()` 中把蜂鸣器引脚设置为输出模式。
  4. 在 `loop()` 中用 `for` 循环按顺序播放每个音符。
  5. 每个音符播放后稍作停顿，再关闭当前声音。
  6. 一整首歌播放完成后暂停 2 秒，再重新开始。
- `setup()` 的作用：
  - 初始化蜂鸣器引脚。
- `loop()` 的作用：
  - 不断按顺序播放整首歌曲。
- 数据输入、处理、输出的执行过程：
  - 输入：程序中预先写好的音符频率和时长数组。
  - 处理：程序按数组顺序逐个读取音高和节拍数据。
  - 输出：无源蜂鸣器发出对应频率和时长的声音。

### 5. 核心函数及代码讲解
- 本实验新出现的关键函数/语句：
  - `tone(PIN_BUZZER, melody[i], noteTime[i])`
  - `noTone(PIN_BUZZER)`
  - `sizeof(melody) / sizeof(melody[0])`
  - `for (int i = 0; i < NOTE_COUNT; i = i + 1)`
- 每个函数的作用、写法、参数和返回值：
  - `tone(PIN_BUZZER, melody[i], noteTime[i])`
    - 函数作用：让无源蜂鸣器按指定频率发声，并持续指定时间。
    - 参数1：`PIN_BUZZER`，表示蜂鸣器连接引脚。
    - 参数2：`melody[i]`，表示当前音符频率，单位是 `Hz`。
    - 参数3：`noteTime[i]`，表示当前音符持续时间，单位是毫秒。
    - 返回值：无返回值。
  - `noTone(PIN_BUZZER)`
    - 函数作用：停止指定引脚上的发声。
    - 参数1：`PIN_BUZZER`，表示要停止发声的引脚。
    - 返回值：无返回值。
  - `sizeof(melody) / sizeof(melody[0])`
    - 作用：计算旋律数组里一共有多少个音符。
- 关键代码片段分析：
  - `tone(...); delay(noteTime[i] + 60); noTone(...);`
    - 这一组语句负责完整播放一个音符，并给下一个音符留出短暂停顿。
- 为什么这样写：
  - 旋律本质上就是“多个音高 + 多个时长”的顺序组合，用数组最容易组织整首歌数据。

## 实验2

### 1. 实验2预备知识
- 本实验在共用预备知识基础上，额外需要知道的内容：
  - 本实验使用的是有源蜂鸣器，不是通过 `tone()` 改变音高，而是通过开关节奏改变鸣叫频率。
  - `1 Hz` 表示每秒完整鸣叫 1 次，`2 Hz` 表示每秒完整鸣叫 2 次。
  - 一个完整周期由“响一次”和“停一次”组成，所以半周期时间要除以 `2`。
- 本实验新增的术语、模块或函数：
  - `beepAtFrequency()`
  - `halfPeriod`
  - `beepCount`
  - `Serial.println()`
- 开始本实验前需要特别提醒的点：
  - 本实验只能使用有源蜂鸣器。
  - 有源蜂鸣器控制端连接 `GPIO 21`。
  - 串口监视器波特率要设置为 `115200`。

### 2. 实验2接线
- 接线表：

| 元件 | ESP32-S3 引脚 | 接法 |
| --- | --- | --- |
| 有源蜂鸣器模块 IN | `GPIO 21` | 控制端接 `GPIO 21` |
| 有源蜂鸣器地线 | `GND` | 与开发板共地 |
| 有源蜂鸣器电源 | 按模块标注 | 按模块说明供电 |

### 3. 完整程序及注释讲解

```cpp
/*
  程序功能：控制有源蜂鸣器周期性鸣叫，观察鸣叫次数与开关频率的关系。
  使用方法：有源蜂鸣器接 GPIO 21，上传后打开波特率为 115200 的串口监视器。
  运行结果：蜂鸣器依次以 1 Hz、2 Hz、5 Hz 鸣叫，串口显示当前频率。
*/

// 有源蜂鸣器模块的控制端连接 GPIO 21
#define PIN_BUZZER 21

void setup() {
  // 启动串口通信，方便观察当前鸣叫频率
  Serial.begin(115200);

  // 把蜂鸣器控制引脚设为输出模式
  pinMode(PIN_BUZZER, OUTPUT);

  // 程序开始时先关闭蜂鸣器
  digitalWrite(PIN_BUZZER, LOW);
}

void loop() {
  // 每秒鸣叫 1 次，持续 3 秒
  Serial.println("1 Hz：每秒鸣叫 1 次");
  beepAtFrequency(1, 3);
  delay(1000);

  // 每秒鸣叫 2 次，持续 3 秒
  Serial.println("2 Hz：每秒鸣叫 2 次");
  beepAtFrequency(2, 3);
  delay(1000);

  // 每秒鸣叫 5 次，持续 3 秒
  Serial.println("5 Hz：每秒鸣叫 5 次");
  beepAtFrequency(5, 3);
  delay(2000);
}

// frequency 表示每秒“响一次再停一次”的次数
// seconds 表示这一组鸣叫持续多少秒
void beepAtFrequency(int frequency, int seconds) {
  // 一个完整周期中，高电平和低电平各占一半时间
  int halfPeriod = 500 / frequency;

  // 总鸣叫次数 = 每秒鸣叫次数 × 持续秒数
  int beepCount = frequency * seconds;

  // 按设定次数循环执行“响一下、停一下”
  for (int i = 0; i < beepCount; i = i + 1) {
    // 输出高电平，让有源蜂鸣器发声
    digitalWrite(PIN_BUZZER, HIGH);
    delay(halfPeriod);

    // 输出低电平，让有源蜂鸣器停止
    digitalWrite(PIN_BUZZER, LOW);
    delay(halfPeriod);
  }
}
```

### 4. 程序主流程及执行过程
- 程序整体分几步执行：
  1. 在 `setup()` 中启动串口并初始化蜂鸣器引脚。
  2. 在 `loop()` 中依次演示 `1 Hz`、`2 Hz`、`5 Hz` 三组鸣叫节奏。
  3. 每演示一组频率前，先在串口输出提示信息。
  4. 调用 `beepAtFrequency()` 完成具体鸣叫。
  5. 在函数内部先计算半周期和总鸣叫次数，再循环执行“响一下、停一下”。
- `setup()` 的作用：
  - 初始化串口和蜂鸣器控制引脚。
- `loop()` 的作用：
  - 反复展示不同鸣叫节奏。
- 数据输入、处理、输出的执行过程：
  - 输入：程序中预设的频率值和持续时间。
  - 处理：函数根据频率计算半周期和总次数。
  - 输出：有源蜂鸣器按设定节奏鸣叫，串口同步显示当前频率。

### 5. 核心函数及代码讲解
- 本实验新出现的关键函数/语句：
  - `beepAtFrequency(int frequency, int seconds)`
  - `int halfPeriod = 500 / frequency`
  - `int beepCount = frequency * seconds`
  - `digitalWrite(PIN_BUZZER, HIGH/LOW)`
- 每个函数的作用、写法、参数和返回值：
  - `beepAtFrequency(int frequency, int seconds)`
    - 函数作用：让有源蜂鸣器按指定节奏鸣叫指定时长。
    - 参数1：`frequency`，表示每秒完整鸣叫多少次。
    - 参数2：`seconds`，表示这一组鸣叫持续多少秒。
    - 返回值：无返回值。
  - `int halfPeriod = 500 / frequency`
    - 作用：计算半周期时间，单位是毫秒。
    - 原因：完整周期是 `1000 / frequency` 毫秒，而高低电平各占一半，所以用 `500 / frequency`。
  - `int beepCount = frequency * seconds`
    - 作用：计算总共需要执行多少次“响一下、停一下”。
- 关键代码片段分析：
  - `digitalWrite(HIGH) -> delay(halfPeriod) -> digitalWrite(LOW) -> delay(halfPeriod)`
    - 这一段构成一次完整鸣叫周期。
- 为什么这样写：
  - 有源蜂鸣器内部已经决定了音高，程序不能像无源蜂鸣器那样直接“播放旋律”，所以这里重点展示的是节奏控制。

## 总结
- 实验目标：
  - 学会区分无源蜂鸣器和有源蜂鸣器。
  - 学会用 `tone()` 和 `noTone()` 控制无源蜂鸣器播放旋律。
  - 学会使用数组组织歌曲中的音符频率和时长。
  - 学会通过高低电平切换控制有源蜂鸣器的鸣叫节奏。
- 单词：
  - `buzzer`：蜂鸣器
  - `passive`：无源的
  - `active`：有源的
  - `tone`：音调 / 发出指定频率声音
  - `frequency`：频率
  - `melody`：旋律
  - `note`：音符
  - `time`：时间
  - `count`：数量 / 计数
  - `song`：歌曲
  - `period`：周期
  - `half`：一半
  - `high`：高
  - `low`：低
  - `sound`：声音
  - `delay`：延时
  - `array`：数组
  - `seconds`：秒
  - `beep`：鸣叫
- 接线：
  - 无源蜂鸣器控制端接 `GPIO 48`。
  - 有源蜂鸣器控制端接 `GPIO 21`。
  - 两类蜂鸣器都必须正确供电并与开发板共地。
- 关键函数和参数：
  - `tone(pin, frequency, duration)`
  - `noTone(pin)`
  - `sizeof(array) / sizeof(array[0])`
  - `Serial.println(...)`
  - `digitalWrite(pin, HIGH/LOW)`
  - `beepAtFrequency(frequency, seconds)`
- 关键程序：
  - 无源蜂鸣器播放《两只老虎》程序
  - 有源蜂鸣器不同节奏鸣叫程序
- 实验现象：
  - 无源蜂鸣器可以播放有旋律的声音。
  - 改变音符频率会改变音高。
  - 改变音符时长会改变歌曲速度。
  - 有源蜂鸣器会按 `1 Hz`、`2 Hz`、`5 Hz` 显示不同鸣叫节奏。
- 本课重点：
  - 无源蜂鸣器看“频率决定音高”，有源蜂鸣器看“开关节奏决定鸣叫频率”。
  - 有源蜂鸣器实验中的频率是“每秒鸣叫次数”，不是蜂鸣器实际音高。
