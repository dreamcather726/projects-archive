# ESP32-S3 舵机控制课程

本课程共 2.5 课时，统一使用 ESP32-S3 LEDC 输出 50Hz 舵机 PWM，不安装额外 Servo 库。
舵机信号暂定 GPIO 4，按键暂定 GPIO 5；如 PCB 引脚不同，只修改代码顶部定义。

## 接线和供电

| 舵机线 | 接法 |
|---|---|
| 信号线 | GPIO 4 |
| 电源线 | 符合舵机额定电压的独立电源 |
| GND | 舵机电源 GND 与 ESP32 GND 共地 |

| 按键 | 接法 |
|---|---|
| 一端 | GPIO 5 |
| 另一端 | GND |

不要使用 ESP32 的 GPIO 给舵机供电。舵机启动和堵转电流较大，供电不足会导致 ESP32
复位、屏幕闪烁或舵机抖动。

## 舵机 PWM 原理

普通位置舵机通常使用约 50Hz 控制信号，也就是每 20ms 一个周期。高电平脉宽对应
目标角度。本课程使用 14 位 LEDC：

```cpp
ledcAttachChannel(SERVO_PIN, 50, 14, SERVO_CHANNEL);
```

角度换算：

```cpp
int duty = map(angle, 0, 180, 410, 2048);
ledcWriteChannel(SERVO_CHANNEL, duty);
```

其中 0°、90°、180° 对应的示例 Duty 约为 410、1229、2048。不同舵机的机械范围
可能不同，如果端点发出持续嗡鸣或卡住，应缩小 Duty 范围。

## 四个实验

### 1. 串口控制舵机

文件：`01_serial_servo`

串口设为 115200、Newline，发送：

```text
g0
g90
g180
```

### 2. TFT 显示+舵机

文件：`02_tft_servo`

ST7789 引脚：CS47、DC21、MOSI20、SCK19、RST=-1。串口命令与第一个实验相同，
屏幕局部刷新 Angle 和 Duty。

### 3. 按键调理+舵机

文件：`03_button_servo`

按键使用 `INPUT_PULLUP`，按下为 LOW。程序检测下降沿，并要求两次有效动作至少间隔
50ms，用来过滤机械触点抖动。每次有效按键让角度增加 15°。

### 4. 舵机角度数据抓取

文件：`04_servo_data_capture`

串口输出 CSV：

```text
Time,Angle,Duty
100,5,455
200,10,501
```

这里记录的是程序发出的“命令角度”和 Duty，不是舵机轴的真实测量角度。普通三线舵机
没有位置反馈输出；若要抓取真实角度，需要带反馈线的舵机、外接电位器或编码器。

## 2.5 课时安排

### 第 1 课时：代码讲解

- 50Hz、周期、脉宽、LEDC 通道和分辨率。
- `map()`、`constrain()`、串口命令解析。
- 角度和 Duty 的关系。

### 第 2 课时前半：原理讲解

- 舵机内部电机、减速齿轮、电位器和内部闭环。
- 电源电流、共地、机械限位和堵转风险。
- 命令角度与真实角度的区别。

### 第 2 课时后半～第 3 课时前半：实验

1. 串口发送 0°、90°、180°。
2. TFT 显示角度和 Duty。
3. 按键消抖并循环角度。
4. 串口抓取扫描数据。
5. 根据实物缩小端点 Duty，避免机械卡死。

## 常见问题

- **舵机不动：** 检查独立电源、共地、GPIO4 和 50Hz 设置。
- **ESP32 复位：** 舵机电流导致电源压降，改用容量足够的独立电源。
- **舵机持续抖动：** 检查供电、信号地和 Duty 范围。
- **角度方向相反：** 使用 `180-angle`，或调整机械安装方向。
- **端点嗡鸣：** 缩小 410～2048 的范围，不要强行顶住机械限位。
- **按一次变化多次：** 增加消抖时间，检查按键和接线。
