# 第一模块 引言

## 1. 本课目标与现象导入

### 1.1 本课目标
- 本课要完成的实验任务：
  - 从串口发送角度命令，让舵机转到 `0°～180°` 之间的位置。
  - 在 TFT 彩屏上显示舵机的目标角度、Duty 数值和角度进度条。
  - 用按键控制舵机，每按一次增加 `15°`，超过 `180°` 后回到 `0°`。
  - 让舵机自动往返扫描，并用串口记录时间、命令角度和 Duty 数据。
- 本课要掌握的核心知识点：
  - 知道舵机和普通直流电机的不同：舵机更擅长“转到指定角度”。
  - 理解 `50Hz`、周期、高电平脉宽和 Duty 的基本关系。
  - 会用 ESP32-S3 的 LEDC 功能产生舵机控制信号。
  - 会用 `map()` 换算角度，用 `constrain()` 限制安全范围。
  - 能分清“程序命令的角度”和“舵机真实转到的角度”。

### 1.2 现象导入
- 现象：
  - 舵机像一只能听懂“转到几度”的小手臂。发送 `g90`，它就会朝大约 `90°` 的位置转动。
  - 串口只需要改变一个数字，就能让舵机去往不同位置。
  - 彩屏上的数字和进度条会跟着目标角度变化。
  - 按键每按一次，舵机会向前走一小格；走到尽头后又从 `0°` 开始。
  - 自动扫描时，串口会输出一排整齐的数据，可以保存后画成图表。

## 2. 本课共用预备知识

### 2.1 共用预备知识
- 本课会用到的旧知识：
  - 会上传 Arduino 程序，并使用 `115200` 波特率串口监视器。
  - 会使用 `if`、函数、变量和 `millis()`。
  - 会读取按键，知道 `INPUT_PULLUP` 模式下按下通常是 `LOW`。
  - 了解 TFT 彩屏的基本接线和显示函数。
- 本课新增的核心概念：
  - 普通位置舵机内部有电机、齿轮和位置检测装置，会自己努力转到命令指定的位置。
  - `50Hz` 表示一秒钟发送 `50` 个控制周期，每个周期约 `20ms`。
  - 舵机主要根据每个周期中高电平持续多久来判断目标角度。
  - 本课使用 ESP32-S3 的 LEDC 输出 `50Hz`、`14` 位分辨率的 PWM。
  - `Duty` 是程序写给 LEDC 的数值。本课用 `410～2048` 大致对应 `0°～180°`。
  - 不同舵机的安全角度范围可能不同，端点持续嗡鸣说明它可能被机械限位卡住了。
- 本课涉及的重点英文单词（函数命名、变量命名等使用的英文单词）：
  - `servo`：舵机
  - `angle`：角度
  - `frequency`：频率
  - `period`：周期
  - `pulse`：脉冲
  - `duty`：占空相关数值
  - `channel`：通道
  - `resolution`：分辨率
  - `attach`：连接 / 绑定
  - `write`：写入
  - `button`：按键
  - `step`：步长
  - `debounce`：消抖
  - `screen`：屏幕
  - `monitor`：监视器
  - `capture`：采集 / 抓取
  - `current`：当前的
  - `constrain`：限制范围
  - `map`：映射 / 换算
- 学生开始实验前必须先知道的内容：
  - 绝对不能用 ESP32 的 GPIO 给舵机供电，GPIO 只连接舵机信号线。
  - 舵机要使用符合额定电压、供电能力足够的电源，并和 ESP32 共地。
  - 第一次运行时不要安装会撞到周围物体的长舵盘或机械臂。
  - 如果舵机持续嗡鸣、抖动或顶住不动，要马上断电，并缩小角度或 Duty 范围。
  - 本课串口实验要把行结尾设置为 `Newline`（换行符）。
  - 自动采集程序记录的是“命令角度”，不是传感器测得的真实角度。

### 3.1 所需器材
- 开发板：
  - `ESP32-S3` 开发板 `1` 块
- 传感器/执行器/模块：
  - 普通三线位置舵机 `1` 个
  - 容量足够、符合舵机额定电压的独立电源
  - 按键 `1` 个（实验3使用）
  - `ST7789 240×320` TFT 彩屏 `1` 块（实验2使用）
- 面包板、杜邦线与辅助材料：
  - 面包板 `1` 块
  - 杜邦线若干
- USB 数据线：
  - ESP32-S3 对应 USB 数据线 `1` 根
- 软件环境：
  - Arduino IDE
  - ESP32 Arduino 开发板支持包
  - 实验2需要 `Adafruit GFX Library` 和 `Adafruit ST7735 and ST7789 Library`

### 3.2 共用硬件介绍
- 舵机三根线：
  - 信号线：接收 ESP32 发出的角度控制脉冲。
  - 电源线：连接舵机独立电源正极。
  - GND：连接舵机电源负极，并与 ESP32 GND 共地。
- 舵机信号使用 `GPIO 4`，LEDC 通道使用通道 `0`。
- 按键使用 `GPIO 5`，另一端接 `GND`。
- TFT 使用课程程序中的固定引脚：`CS 47`、`DC 21`、`MOSI 20`、`SCK 19`、`RST -1`。

### 3.3 基础接线约定
| 元件 | 引脚或线路 | 连接位置 |
| --- | --- | --- |
| 舵机信号线 | Signal | `GPIO 4` |
| 舵机电源线 | VCC | 独立舵机电源正极 |
| 舵机地线 | GND | 独立电源 GND，并与 ESP32 GND 共地 |
| 按键一端 | Signal | `GPIO 5` |
| 按键另一端 | GND | ESP32 `GND` |

- 接线和拔线前先断开舵机电源。
- 不确定舵机线序时先看模块标签或数据手册，不要只凭线的颜色猜测。
- 若实物舵机安全范围小于 `0°～180°`，应在老师指导下缩小 `map()` 的 Duty 端点。
