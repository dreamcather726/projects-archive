# 第三模块 拓展

## 1. 知识拓展
- 本课相关原理的进一步解释：
  - I2C 只使用 `SDA` 和 `SCL` 两根信号线，但可以让多个模块并联在同一总线上。
  - 主机通过发送地址来区分不同从机，因此 I2C 地址在总线中相当于“门牌号”。
  - I2C 使用开漏结构，设备只能主动把总线拉低，释放后需要依靠上拉电阻恢复高电平。
  - 主机发出地址后，如果对应从机存在并正常工作，就会返回 `ACK`，扫描器正是利用这个原理找设备。
  - `endTransmission()` 返回 `0` 时通常表示当前地址有设备应答；返回其他值则说明没有正常应答或存在通信问题。
  - 常见 I2C 模块地址包括：`MPU6050` 常见 `0x68`，`SSD1306 OLED` 常见 `0x3C`，但最终以实际扫描结果为准。
  - 如果总线上有两个相同地址的模块，就会出现地址冲突，主机无法正确区分它们。

## 2. 速查表
- 重要函数速查：
  - `Wire.begin()`：启动 I2C
  - `Wire.setClock()`：设置 I2C 时钟频率
  - `Wire.beginTransmission()`：开始一次 I2C 写传输
  - `Wire.write()`：写入一个字节到发送缓冲区
  - `Wire.endTransmission()`：真正发送并返回结果
  - `Wire.requestFrom()`：向从机请求数据
  - `Wire.available()`：查看接收缓冲区还有多少字节
  - `Wire.read()`：读取一个字节
- 重要参数速查：
  - `PIN_SDA = 8`：本课 I2C 数据线引脚
  - `PIN_SCL = 9`：本课 I2C 时钟线引脚
  - `100000`：常用 `100kHz` I2C 时钟
  - `0x68`：`MPU6050` 常见地址
  - `0x69`：`MPU6050` 另一常见地址
  - `0x3C`：`SSD1306 OLED` 常见地址
  - `0x3D`：少数 `SSD1306 OLED` 地址
  - `0x27`：八路巡线模块常见地址
- 重要单词速查：
  - `I2C`：I2C 总线
  - `SDA`：串行数据线
  - `SCL`：串行时钟线
  - `address`：地址
  - `device`：设备
  - `scanner`：扫描器
  - `master`：主机
  - `slave`：从机
  - `transmission`：传输
  - `clock`：时钟
  - `read`：读取
  - `write`：写入
  - `ack`：应答
  - `bus`：总线
  - `data`：数据
