# 第一模块 引言

## 1. 本课目标与现象导入

### 1.1 本课目标
- 本课要完成的实验任务：
  - 完成 I2C 地址扫描实验。
- 本课要掌握的核心知识点：
  - 理解 I2C 使用 `SDA` 和 `SCL` 两根线通信。
  - 理解主机、从机、设备地址和 `ACK` 的基本概念。
  - 学会使用 `Wire.begin()` 指定 `SDA`、`SCL` 并启动 I2C。
  - 学会使用 `beginTransmission()` 和 `endTransmission()` 扫描设备地址。
  - 理解 I2C 总线上拉电阻和地址冲突的意义。

### 1.2 现象导入
- 现象：
  - 上传扫描程序后，串口监视器会显示 I2C 总线上找到的设备地址。
  - 连接不同的 I2C 模块时，会看到不同的十六进制地址。
  - 如果没有连接正确或地址冲突，可能扫不到设备或只扫到部分设备。
  - 常见现象包括：`MPU6050` 显示 `0x68`，`OLED` 常显示 `0x3C`。

## 2. 本课共用预备知识

### 2.1 共用预备知识
- 本课会用到的旧知识：
  - 会使用 `Arduino IDE` 上传程序并打开串口监视器。
  - 理解 GPIO 基础接线和共地规则。
  - 知道十六进制显示形式，例如 `0x68`、`0x3C`。
- 本课新增的核心概念：
  - I2C 只用两根信号线：`SDA` 传数据，`SCL` 传时钟。
  - `ESP32-S3` 在本课中作为主机发起通信。
  - 每个 I2C 从机都有一个 7 位地址，同一总线不能有两个相同地址的设备。
  - I2C 是开漏结构，`SDA` 和 `SCL` 需要上拉电阻。
  - 主机发送地址后，从机会用 `ACK` 表示“我收到了”。
- 本课涉及的重点英文单词(函数命名、变量命名等使用的英文单词)：
  - `I2C`：I2C 总线
  - `SDA`：串行数据线
  - `SCL`：串行时钟线
  - `address`：地址
  - `device`：设备
  - `scanner`：扫描器
  - `master`：主机
  - `slave`：从机
  - `transmission`：传输
  - `clock`：时钟
  - `read`：读取
  - `write`：写入
  - `ack`：应答
  - `bus`：总线
  - `data`：数据
- 学生开始实验前必须先知道的内容：
  - 本章统一使用 `SDA = GPIO 8`、`SCL = GPIO 9`。
  - 所有 I2C 模块都必须与开发板共地。
  - 先确认模块 `SDA`、`SCL` 不会被上拉到 `5V`，避免损伤 `ESP32-S3`。
  - 串口监视器波特率设置为 `115200`。

## 3. 本课共用器材与基础接线约定

### 3.1 所需器材
- 开发板：
  - `ESP32-S3` 开发板 `1` 块
- 传感器/执行器/模块：
  - 任意 I2C 模块 `1` 个或多个，例如 `MPU6050`、`SSD1306 OLED`
- 电阻、面包板、杜邦线：
  - 面包板 `1` 块
  - 杜邦线若干
  - 如模块本身没有上拉，可准备上拉电阻
- USB 数据线：
  - 开发板对应数据线 `1` 根
- 软件环境：
  - `Arduino IDE`
  - `esp32` 开发板支持包
  - 串口监视器

### 3.2 共用硬件介绍
- 本课涉及的器件名称：
  - `ESP32-S3`、I2C 外设模块
- 每个器件的作用：
  - `ESP32-S3`：作为 I2C 主机发起通信和地址扫描。
  - I2C 外设：作为从机，根据地址响应主机扫描。
- 关键特性说明：
  - 多个 I2C 模块可以并联在同一组 `SDA`、`SCL` 上。
  - 同一总线上的 I2C 地址不能重复。
  - `SDA`、`SCL` 依赖上拉电阻恢复高电平。
  - 扫描器程序通过依次尝试地址 `0x01~0x7E` 来查找设备。
- 容易出错的地方：
  - `SDA`、`SCL` 接反。
  - 没有共地。
  - 总线上没有合适的上拉。
  - 两个模块地址冲突。
  - 模块信号被上拉到 `5V`。
