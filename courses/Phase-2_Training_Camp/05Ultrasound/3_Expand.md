# 第三模块 拓展

## 1. 知识拓展
- 本课相关原理的进一步解释：
  - `HC-SR04` 通过发射超声波并接收反射波来测量距离，本质上测到的是“往返时间”。
  - 常温下声速约为 `343 m/s`，换算后约为 `0.0343 cm/us`，所以距离公式写成 `回波时间 × 0.0343 ÷ 2`。
  - 必须除以 `2`，因为超声波经历了“模块到障碍物”和“障碍物回到模块”两段路程。
  - `pulseIn()` 属于阻塞式测量函数，程序会在等待脉冲时停住，基础实验里简单直观，但后续多任务场景里要考虑非阻塞方法。
  - 超声波测量结果容易受障碍物材质、角度、距离过近、环境噪声和多模块互相干扰影响。
  - 经典 `HC-SR04` 的 `ECHO` 常接近 `5V`，而 `ESP32-S3` 是 `3.3V` 逻辑电平，所以必须分压或电平转换。
  - 倒车雷达的核心不是“播放不同音高”，而是把距离分级后转成不同报警节奏。

## 2. 速查表
- 重要函数速查：
  - `pinMode()`：设置引脚模式
  - `digitalWrite()`：输出高低电平
  - `delayMicroseconds()`：按微秒延时
  - `pulseIn()`：测量脉冲持续时间
  - `Serial.begin()`：启动串口通信
  - `Serial.print()`：输出内容但不换行
  - `Serial.println()`：输出内容并换行
  - `measureDistance()`：完成一次完整测距
  - `beepOnce()`：完成一次蜂鸣器节奏报警
- 重要参数速查：
  - `PIN_TRIG = 12`：超声波触发引脚
  - `PIN_ECHO = 13`：超声波回波引脚
  - `PIN_BUZZER = 21`：有源蜂鸣器控制引脚
  - `10us`：常用触发脉冲宽度
  - `30000us`：`pulseIn()` 超时时间
  - `0.0343 cm/us`：常温下常用声速换算值
  - `20 cm`：危险距离阈值
  - `50 cm`：较近距离阈值
  - `100 cm`：注意距离阈值
- 重要单词速查：
  - `ultrasonic`：超声波的
  - `distance`：距离
  - `measure`：测量
  - `echo`：回波
  - `trigger`：触发
  - `pulse`：脉冲
  - `microseconds`：微秒
  - `radar`：雷达
  - `buzzer`：蜂鸣器
  - `danger`：危险
  - `safe`：安全
  - `time`：时间
  - `sound`：声音
  - `quiet`：安静 / 静音间隔
  - `high`：高
  - `low`：低
