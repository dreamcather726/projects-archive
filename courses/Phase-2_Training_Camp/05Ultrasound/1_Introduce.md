# 第一模块 引言

## 1. 本课目标与现象导入

### 1.1 本课目标
- 本课要完成的实验任务：
  - 完成超声波串口测距实验。
  - 完成超声波倒车雷达实验。
- 本课要掌握的核心知识点：
  - 理解超声波发射、反射、接收的测距过程。
  - 学会使用 `delayMicroseconds()` 产生 `10us` 触发脉冲。
  - 学会使用 `pulseIn()` 测量 `ECHO` 高电平持续时间。
  - 学会使用公式把回波时间换算为厘米距离。
  - 学会使用多段 `if` 按距离划分报警区间。
  - 学会让有源蜂鸣器随距离变近而加快报警节奏。

### 1.2 现象导入
- 现象：
  - 移动障碍物时，串口监视器会持续显示距离变化。
  - 障碍物离开测量范围时，会提示“未收到回波”。
  - 障碍物距离较远时，蜂鸣器不响。
  - 障碍物逐渐靠近时，蜂鸣器会从慢速报警变成快速报警。
  - 进入危险距离后，蜂鸣器会连续鸣叫。

## 2. 本课共用预备知识

### 2.1 共用预备知识
- 本课会用到的旧知识：
  - 会使用 `Arduino IDE` 上传程序并打开串口监视器。
  - 了解 GPIO 输入输出、`HIGH`、`LOW` 和有源蜂鸣器的基础控制方法。
  - 理解共地和基础接线规则。
- 本课新增的核心概念：
  - 超声波模块通过“发射超声波 - 接收反射波”来测量距离。
  - `TRIG` 负责触发测量，`ECHO` 返回回波时间信息。
  - `pulseIn()` 测到的是回波高电平持续时间，单位是微秒。
  - 距离计算公式为：`距离 = 回波时间 × 0.0343 ÷ 2`。
  - `pulseIn()` 超时会返回 `0`，表示没有收到有效回波。
- 本课涉及的重点英文单词(函数命名、变量命名等使用的英文单词)：
  - `ultrasonic`：超声波的
  - `distance`：距离
  - `measure`：测量
  - `echo`：回波
  - `trigger`：触发
  - `pulse`：脉冲
  - `microseconds`：微秒
  - `radar`：雷达
  - `buzzer`：蜂鸣器
  - `danger`：危险
  - `safe`：安全
  - `time`：时间
  - `sound`：声音
  - `quiet`：安静 / 静音间隔
  - `high`：高
  - `low`：低
- 学生开始实验前必须先知道的内容：
  - 本章程序统一使用 `TRIG = GPIO 12`、`ECHO = GPIO 13`、蜂鸣器 `GPIO 21`。
  - 经典 `HC-SR04` 的 `ECHO` 可能接近 `5V`，不能直接接入 `ESP32-S3`，必须先分压或电平转换。
  - 超声波模块和蜂鸣器都必须与开发板共地。
  - 串口监视器波特率设置为 `115200`。

## 3. 本课共用器材与基础接线约定

### 3.1 所需器材
- 开发板：
  - `ESP32-S3` 开发板 `1` 块
- 传感器/执行器/模块：
  - `HC-SR04` 超声波模块 `1` 个
  - 有源蜂鸣器模块 `1` 个
- 电阻、面包板、杜邦线：
  - `1kΩ` 电阻 `1` 个
  - `2kΩ` 电阻 `1` 个
  - 面包板 `1` 块
  - 杜邦线若干
- USB 数据线：
  - 开发板对应数据线 `1` 根
- 软件环境：
  - `Arduino IDE`
  - `esp32` 开发板支持包
  - 串口监视器

### 3.2 共用硬件介绍
- 本课涉及的器件名称：
  - `HC-SR04` 超声波模块、有源蜂鸣器
- 每个器件的作用：
  - `HC-SR04`：测量障碍物与传感器之间的距离。
  - 有源蜂鸣器：根据距离发出不同节奏的报警声。
- 关键特性说明：
  - `TRIG` 需要一个至少 `10us` 的高电平脉冲来启动测量。
  - `ECHO` 高电平持续时间表示超声波往返所需时间。
  - `HC-SR04` 常用 `5V` 供电，`ECHO` 输出需要降压到 `3.3V` 左右。
  - 有源蜂鸣器只需要控制“响”和“停”即可。
- 容易出错的地方：
  - 把 `ECHO` 直接接到 `ESP32-S3` 引脚，没有做分压。
  - `TRIG` 和 `ECHO` 接反。
  - 模块没有共地，导致测量值异常。
  - 距离公式忘记除以 `2`，导致结果接近实际值的两倍。
