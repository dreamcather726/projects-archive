# 第一模块 引言

## 1. 本课目标与现象导入

### 1.1 本课目标
- 本课要完成的实验任务：
  - 完成 OLED 基础文字显示实验。
  - 完成 OLED 显示 `MPU6050` 姿态角实验。
  - 完成 OLED 显示红外状态实验。
  - 完成 OLED 显示超声波距离实验。
  - 完成 OLED 显示 RGB 颜色实验。
  - 完成 OLED 综合仪表盘实验。
- 本课要掌握的核心知识点：
  - 理解 `SSD1306` OLED 的 I2C 通信方式和地址设置。
  - 学会使用 `Adafruit_SSD1306` 和 `Adafruit_GFX` 库初始化屏幕。
  - 学会使用 `clearDisplay()`、`setCursor()`、`print()`、`println()`、`display()` 完成显示流程。
  - 理解 OLED 与 `MPU6050` 可以共用同一组 `SDA`、`SCL`。
  - 学会把传感器数据转化为适合显示的文字和数字。
  - 理解整合实验中“采集数据 -> 处理状态 -> OLED 显示 -> RGB 反馈”的完整流程。

### 1.2 现象导入
- 现象：
  - 基础程序运行后，OLED 会显示文字信息。
  - 连接 `MPU6050` 后，OLED 会实时显示 `Yaw`、`Pitch`、`Roll`。
  - 遮挡红外模块时，OLED 会在 `DETECTED` 和 `CLEAR` 间切换。
  - 移动障碍物时，OLED 会刷新超声波距离。
  - RGB 实验中，彩灯变色的同时 OLED 会显示对应颜色名称。
  - 整合程序运行后，OLED 会同时显示姿态、红外、距离和颜色状态。

## 2. 本课共用预备知识

### 2.1 共用预备知识
- 本课会用到的旧知识：
  - 会使用 `Arduino IDE` 上传程序并打开串口监视器。
  - 已掌握 I2C 基础接线和地址扫描方法。
  - 已了解 `MPU6050`、红外模块、超声波模块、WS2812 的基础用法。
- 本课新增的核心概念：
  - `SSD1306` OLED 使用 I2C 通信，常见地址为 `0x3C`。
  - OLED 的绘图和文字输出先写入缓冲区，必须调用 `display.display()` 才会真正刷新屏幕。
  - OLED 和 `MPU6050` 可以并联在同一组 I2C 总线上，因为地址不同。
  - 默认 ASCII 字体主要支持英文和数字，基础课先使用英文标签显示。
  - 刷新太快会占用较多 I2C 时间，所以基础实验一般加 `100~200ms` 刷新间隔。
- 本课涉及的重点英文单词(函数命名、变量命名等使用的英文单词)：
  - `display`：显示
  - `screen`：屏幕
  - `clear`：清除
  - `cursor`：光标
  - `text`：文本
  - `color`：颜色
  - `white`：白色
  - `distance`：距离
  - `detected`：检测到
  - `clear`：无遮挡 / 清除
  - `integrated`：综合的 / 整合的
  - `dashboard`：仪表盘
  - `error`：错误
  - `address`：地址
  - `refresh`：刷新
- 学生开始实验前必须先知道的内容：
  - 本章统一使用 `SDA = GPIO 8`、`SCL = GPIO 9`。
  - OLED 地址默认是 `0x3C`，少数模块可能是 `0x3D`。
  - `OLED_RESET` 在本章统一设为 `-1`。
  - 超声波 `ECHO` 若来自 `5V` 模块，必须先分压再接入 `ESP32-S3`。
  - `PIN_RGB = GPIO 48` 与前面某些章节用过的器件引脚可能冲突，切换实验前要重新按当前接线接线。

## 3. 本课共用器材与基础接线约定

### 3.1 所需器材
- 开发板：
  - `ESP32-S3` 开发板 `1` 块
- 传感器/执行器/模块：
  - `128x64 I2C SSD1306 OLED` `1` 个
  - `MPU6050` 模块 `1` 个
  - 红外模块 `1` 个
  - 超声波模块 `1` 个
  - `WS2812 RGB` 灯珠 `1` 个
- 电阻、面包板、杜邦线：
  - 面包板 `1` 块
  - 杜邦线若干
  - 超声波 `ECHO` 分压所需电阻若干
- USB 数据线：
  - 开发板对应数据线 `1` 根
- 软件环境：
  - `Arduino IDE`
  - `esp32` 开发板支持包
  - `Adafruit SSD1306`
  - `Adafruit GFX Library`
  - `Adafruit NeoPixel`
  - `MPU6050 by Electronic Cats`

### 3.2 共用硬件介绍
- 本课涉及的器件名称：
  - `SSD1306 OLED`、`MPU6050`、红外模块、超声波模块、`WS2812 RGB`
- 每个器件的作用：
  - OLED：负责文字和数据可视化显示。
  - `MPU6050`：提供姿态角数据。
  - 红外模块：提供障碍检测状态。
  - 超声波模块：提供距离数据。
  - `WS2812 RGB`：提供颜色反馈。
- 关键特性说明：
  - OLED 与 `MPU6050` 共用 I2C 总线，地址分别为 `0x3C` 和 `0x68`。
  - `display.display()` 是 OLED 刷新的关键一步。
  - `OLED_RESET` 设为 `-1`，表示不使用单独复位引脚。
  - 整合实验里 RGB 颜色会根据超声波距离变化。
- 容易出错的地方：
  - 忘记调用 `display.display()`，导致画面不更新。
  - OLED 地址不对，导致初始化失败。
  - OLED、`MPU6050` 未共地或 I2C 接线反了。
  - 超声波 `ECHO` 没分压。
  - 红外模块触发电平与程序假设相反。
