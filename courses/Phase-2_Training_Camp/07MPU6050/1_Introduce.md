# 第一模块 引言

## 1. 本课目标与现象导入

### 1.1 本课目标
- 本课要完成的实验任务：
  - 完成 `MPU6050` 六轴原始数据读取实验。
  - 完成 `MPU6050` 原始值换算为物理量实验。
  - 完成 `MPU6050` DMP 姿态角解算实验。
- 本课要掌握的核心知识点：
  - 理解 `MPU6050` 的三轴加速度计和三轴陀螺仪作用。
  - 学会使用 `Wire.begin()` 和 `mpu.initialize()` 初始化模块。
  - 学会使用 `mpu.testConnection()` 检查 I2C 通信是否正常。
  - 学会使用 `getMotion6()` 读取六轴原始数据。
  - 学会把原始值换算为 `g` 和 `°/s`。
  - 理解 DMP、FIFO、四元数、重力向量和 `Yaw/Pitch/Roll` 的基本关系。

### 1.2 现象导入
- 现象：
  - 移动模块时，串口中的 `AX`、`AY`、`AZ` 原始值会变化。
  - 转动模块时，`GX`、`GY`、`GZ` 原始值会变化。
  - 平放模块时，某一加速度轴换算值通常接近 `1g`。
  - DMP 程序运行后，串口会持续显示 `Yaw`、`Pitch`、`Roll`。
  - 上电校准时如果保持静止，姿态显示会更稳定。

## 2. 本课共用预备知识

### 2.1 共用预备知识
- 本课会用到的旧知识：
  - 会使用 `Arduino IDE` 上传程序并打开串口监视器。
  - 已经了解 I2C 基础接线和地址扫描方法。
  - 知道 `SDA`、`SCL`、`GND` 和模块共地的意义。
- 本课新增的核心概念：
  - `MPU6050` 是六轴姿态传感器，包含三轴加速度计和三轴陀螺仪。
  - `int16_t` 常用于保存原始寄存器值，范围是 `-32768 ~ 32767`。
  - 默认量程下，加速度原始值除以 `16384` 可得到 `g`，角速度原始值除以 `131` 可得到 `°/s`。
  - DMP 是 `MPU6050` 内部用于姿态解算的数据处理模块。
  - DMP 输出的数据先进入 `FIFO`，程序取到完整数据包后再计算姿态角。
  - `Yaw` 没有磁力计约束时可能缓慢漂移。
- 本课涉及的重点英文单词(函数命名、变量命名等使用的英文单词)：
  - `mpu`：姿态传感器对象名
  - `accel`：加速度
  - `gyro`：陀螺仪 / 角速度
  - `raw`：原始的
  - `units`：物理单位
  - `yaw`：偏航角
  - `pitch`：俯仰角
  - `roll`：横滚角
  - `quaternion`：四元数
  - `gravity`：重力向量
  - `fifo`：先进先出缓冲区
  - `motion`：运动
  - `connection`：连接
  - `initialize`：初始化
  - `calibrate`：校准
- 学生开始实验前必须先知道的内容：
  - 本章统一使用 `SDA = GPIO 8`、`SCL = GPIO 9`，默认地址为 `0x68`。
  - `AD0` 接高电平时，地址通常会变成 `0x69`。
  - 本章必须安装 `MPU6050 by Electronic Cats` 库，不要装成同名其他库。
  - DMP 姿态程序上电校准期间要保持模块静止、水平放置。

## 3. 本课共用器材与基础接线约定

### 3.1 所需器材
- 开发板：
  - `ESP32-S3` 开发板 `1` 块
- 传感器/执行器/模块：
  - `MPU6050` 模块 `1` 个
- 电阻、面包板、杜邦线：
  - 面包板 `1` 块
  - 杜邦线若干
- USB 数据线：
  - 开发板对应数据线 `1` 根
- 软件环境：
  - `Arduino IDE`
  - `esp32` 开发板支持包
  - `MPU6050 by Electronic Cats`
  - 串口监视器

### 3.2 共用硬件介绍
- 本课涉及的器件名称：
  - `MPU6050` 姿态传感器模块
- 每个器件的作用：
  - 加速度计：测量三个方向的加速度和静止时的重力分量。
  - 陀螺仪：测量绕三个轴旋转的角速度。
  - DMP：在芯片内部融合数据，输出姿态相关结果。
- 关键特性说明：
  - 模块通过 I2C 与开发板通信。
  - 默认地址通常为 `0x68`。
  - DMP 程序本课使用轮询 `FIFO` 的简化方式，不连接 `INT` 引脚。
  - `Yaw` 没有磁力计参考时会存在漂移。
- 容易出错的地方：
  - 安装了错误版本的 `MPU6050` 库。
  - `SDA`、`SCL` 接反或地址不匹配。
  - 校准期间移动了模块，导致姿态角抖动更大。
  - 忽略了默认量程，直接照搬换算系数。
