# 第三模块 拓展

## 1. 知识拓展
- 本课相关原理的进一步解释：
  - `MPU6050` 同时包含三轴加速度计和三轴陀螺仪，因此可以同时感知线性加速度和角速度。
  - 加速度计静止时也会测到重力，所以平放时某一轴常接近 `1g`，这不是“误差”，而是正常现象。
  - 只看加速度计可以估计倾斜，但会受到运动加速度干扰；只看陀螺仪积分又会逐渐漂移。
  - DMP 会在芯片内部融合加速度和陀螺仪数据，并把结果放入 `FIFO`，减轻主控计算负担。
  - 四元数是姿态的一种数学表示方式，优点是适合做姿态计算并避免欧拉角某些问题；本课阶段先理解它是“中间结果”即可。
  - `Yaw/Pitch/Roll` 更适合课堂观察，但 `Yaw` 没有磁力计参考时会缓慢漂移，这属于 `MPU6050` 的正常现象。
  - DMP 程序上电后先校准再读取姿态角，校准期间保持模块静止会明显影响结果稳定性。

## 2. 速查表
- 重要函数速查：
  - `Wire.begin()`：启动 I2C
  - `Wire.setClock()`：设置 I2C 时钟
  - `mpu.initialize()`：初始化 `MPU6050`
  - `mpu.testConnection()`：检查连接是否成功
  - `mpu.getMotion6()`：读取六轴原始值
  - `mpu.dmpInitialize()`：初始化 DMP
  - `mpu.CalibrateAccel()`：校准加速度计
  - `mpu.CalibrateGyro()`：校准陀螺仪
  - `mpu.dmpGetCurrentFIFOPacket()`：读取一包 DMP FIFO 数据
  - `mpu.dmpGetQuaternion()`：提取四元数
  - `mpu.dmpGetGravity()`：提取重力向量
  - `mpu.dmpGetYawPitchRoll()`：计算姿态角
- 重要参数速查：
  - `PIN_SDA = 8`：I2C 数据线引脚
  - `PIN_SCL = 9`：I2C 时钟线引脚
  - `0x68`：默认 I2C 地址
  - `0x69`：`AD0` 接高电平时的常见地址
  - `16384.0`：默认 ±2g 量程下的加速度换算系数
  - `131.0`：默认 ±250°/s 量程下的角速度换算系数
  - `100000`：原始值和单位换算程序常用 I2C 时钟
  - `400000`：DMP 姿态程序里使用的较高 I2C 时钟
- 重要单词速查：
  - `mpu`：姿态传感器对象名
  - `accel`：加速度
  - `gyro`：陀螺仪 / 角速度
  - `raw`：原始的
  - `units`：物理单位
  - `yaw`：偏航角
  - `pitch`：俯仰角
  - `roll`：横滚角
  - `quaternion`：四元数
  - `gravity`：重力向量
  - `fifo`：先进先出缓冲区
  - `motion`：运动
  - `connection`：连接
  - `initialize`：初始化
  - `calibrate`：校准
