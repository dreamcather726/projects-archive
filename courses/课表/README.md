# 教师课程排课助手

这是一个基于 Qt 的课程排课小工具，支持 `PySide6`、`PyQt6` 或 `PyQt5`。

## 运行方式

```powershell
python course_schedule_app.py
```

如果提示缺少 Qt 库，可以安装其中一个：

```powershell
pip install PyQt5
```

## 当前功能

- 按每周一、三、五晚 19:30 自动生成上课安排。
- 默认将下一个周一设为第 1 节课程日期，也可以在界面里修改开课日期。
- 显示今天是否有课、今天上哪一节课。
- 显示每节课的课程链接；今天没课时，会提示可以预习下一节课内容并显示下一节课链接。
- 显示未来一周的上课时间安排。
- 学生界面只显示已发布课程内容；当前已发布 59 节，代码内部保留 60 节课次槽位，方便后续继续补课。
