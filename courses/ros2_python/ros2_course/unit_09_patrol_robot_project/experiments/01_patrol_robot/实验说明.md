# 实验 9：自主巡检移动机器人综合项目

## 为什么要做这个实验

分章节掌握 API 不等于能搭建机器人系统。综合实验要求学生处理接口选择、状态管理、并发回调、仿真接入、安全停止和可观测性，检验是否真正理解各知识点之间的关系。

## 实验的作用

- 复用第 8 章 Gazebo 仿真作为底层系统，学习 overlay 工作空间。
- 使用话题接收传感器和控制底盘。
- 使用动作管理长时巡检任务，使用服务处理急停。
- 用 QoS、执行器和回调组保证传感器与任务回调及时处理。
- 形成从启动、运行、故障注入到验收记录的完整交付。

## 本实验重点

1. 动作回调不直接计算每个速度命令，控制定时器持续运行状态机。
2. 激光、里程计、动作与急停回调共享状态，需要明确优先级。
3. 所有失败、取消和退出路径都必须发布零速度。
4. 当前算法是无地图反应式巡检，应明确能力边界。

## 运行步骤

### 第 1 步：构建第 8 章仿真 underlay

```bash
source /opt/ros/jazzy/setup.bash
cd <课程仓库>/ros2_course/unit_08_gazebo_simulation/experiments/01_gazebo_lidar/ros2_ws
colcon build --symlink-install
source install/setup.bash
```

### 第 2 步：构建本章 overlay

在同一个终端继续执行：

```bash
cd <课程仓库>/ros2_course/unit_09_patrol_robot_project/experiments/01_patrol_robot/ros2_ws
rosdep install --from-paths src --ignore-src -r -y
colcon build --symlink-install
source install/setup.bash
```

构建本章前加载第 8 章工作空间，Launch 才能找到 `gazebo_patrol_py`。

### 第 3 步：启动完整系统

```bash
ros2 launch patrol_project_py patrol_bringup.launch.py
```

### 第 4 步：发送巡检目标

新终端依次加载系统 ROS、第 8 章和第 9 章工作空间，然后执行：

```bash
ros2 run patrol_project_py patrol_client --ros-args -p target_distance:=8.0
```

### 第 5 步：观察系统

```bash
ros2 topic echo /patrol/status
ros2 topic hz /scan
ros2 topic hz /odom
ros2 action info /patrol_distance
ros2 service list -t | grep patrol
```

### 第 6 步：故障与安全测试

急停：

```bash
ros2 service call /patrol/emergency_stop std_srvs/srv/SetBool "{data: true}"
```

解除急停：

```bash
ros2 service call /patrol/emergency_stop std_srvs/srv/SetBool "{data: false}"
```

动作取消：

```bash
ros2 run patrol_project_py patrol_client --ros-args \
  -p target_distance:=20.0 -p cancel_after:=5.0
```

传感器超时：运行任务时停止 bridge，控制器应进入 FAULT 并停车。

## 预期现象

- 动作接受后小车开始行驶并周期返回距离和完成百分比。
- 接近墙体时状态切换到 TURNING，小车转向后继续前进。
- 达到目标距离时动作成功结束，速度归零。
- 急停、取消或传感器超时均立即停止，并返回可解释的结果。

## 验收任务

1. 完成 8 米巡检，保存终端反馈和最终结果。
2. 注入一次急停，证明速度归零并且动作以失败结束。
3. 记录 `/scan /odom /cmd_vel /patrol/status` 到 rosbag2 并回放分析。
4. 调整安全距离、前进速度和转向速度，解释现象变化。
5. 写一页复盘：当前策略在哪些场地会失败，如何使用地图导航改进。

## 常见问题

- Launch 找不到 `gazebo_patrol_py`：构建本章前没有加载第 8 章工作空间。
- 动作目标被拒绝：等待 `/scan` 和 `/odom` 都开始更新，确认急停已解除且没有其他目标执行。
- 小车一直转向：检查激光扇区、模型朝向和安全距离参数。
- 达到距离后仍在运动：检查是否还有其他节点同时发布 `/cmd_vel`。
- 关闭 bridge 后没有立即故障：等待 `sensor_timeout` 指定的超时时间并确认节点使用仿真时钟。
