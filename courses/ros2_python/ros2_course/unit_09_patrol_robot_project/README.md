# 第 9 模块：ROS 2 综合考核——自主巡检移动机器人

课程材料：[知识点详解](第9章_授课讲义.md) · [实验说明与代码](experiments/01_patrol_robot/实验说明.md)

## 内容范围

- 前八章知识在可配置、可诊断机器人系统中的组合使用。
- 巡检目标、进度反馈、取消、急停和异常恢复。
- 话题、服务、动作、参数、QoS、Launch、TF 和仿真工具的综合验收。

## 系统需求

- 输入：激光雷达 `/scan`、里程计 `/odom`。
- 输出：底盘速度 `/cmd_vel`、巡检状态 `/patrol/status`。
- 动作：`/patrol_distance` 接受目标巡检距离，反馈距离、进度和状态。
- 服务：`/patrol/emergency_stop` 设置或解除急停。
- 行为：安全时前进，遇障碍转向，达到目标距离后停止。
- 安全：传感器或里程计超时、动作取消、急停时必须发布零速度。

## 详细知识点

### 1. 需求到接口

- 区分持续数据、短时请求和长时任务。
- 为每个接口定义名称、类型、方向、频率、QoS、单位和坐标系。
- 把“能跑”转化为可验证的验收条件。
- 定义正常、暂停、转向、完成、取消、故障和急停状态。

### 2. 节点与模块设计

- 传感器输入、行为决策、速度输出、任务管理和状态报告的职责。
- 纯 Python 决策逻辑与 ROS 适配层分离。
- 回调之间共享状态的同步问题。
- 定时控制循环与传感器事件回调的分工。
- 任何异常路径都要进入明确状态并输出零速度。

### 3. 反应式巡检策略

- 前方扇区取最小有效距离。
- 左右扇区比较决定转向方向。
- 使用进入阈值与退出阈值避免临界距离频繁切换。
- 用里程计相邻位置累加实际行驶距离。
- 反应式策略没有全局地图，不保证最优路径或一定能走出复杂死角。

### 4. 动作任务管理

- 目标校验和拒绝条件。
- 动作执行与控制循环解耦。
- 周期反馈：已行驶距离、完成比例、当前状态。
- 成功、取消、急停和传感器故障对应不同结果。
- 防止同时执行多个互相冲突的控制目标。

### 5. 安全与故障处理

- 未收到传感器前保持停止。
- 激光或里程计超过限定时间未更新则故障停止。
- 急停优先级高于动作目标和普通控制。
- 取消动作后立即停止并返回已完成距离。
- 节点退出前发布零速度；底盘侧仍应配置命令超时作为第二层保护。

### 6. 系统集成与验收

- 使用 overlay 工作空间复用第 8 章仿真包。
- Launch 一键启动仿真、bridge 和巡检节点。
- rosbag2 记录输入、输出、状态和动作结果。
- 用 `rqt_graph`、topic hz、action info、service list 形成诊断证据。
- 使用参数文件保存可重复的验收配置。

## 验收标准

- 一个 Launch 命令启动系统，接口和参数清晰。
- 能完成指定距离巡检并持续反馈进度。
- 障碍物、取消、急停和传感器超时都会安全停车。
- 能用 ROS 2 工具证明各接口的类型、频率、QoS 和状态。
- 提交源码、参数、运行说明、实验记录和问题复盘。
