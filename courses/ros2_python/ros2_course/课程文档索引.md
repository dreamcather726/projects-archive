# ROS 2 Python 课程文档索引

本课程只讲 Python 版 ROS 2 开发，核心客户端库为 `rclpy`。课程从工程基础开始，依次覆盖通信机制、节点工具、模块化与生命周期、执行器、机器人模型、仿真，最后完成自主巡检移动机器人综合项目。

## 课程环境

- 操作系统：Ubuntu 24.04 LTS
- ROS 2：Jazzy Jalisco
- 编程语言：Python 3
- 构建类型：业务节点使用 `ament_python`
- 仿真环境：Gazebo Harmonic 与 `ros_gz`
- 可视化工具：RViz2
- 课程不设置其他语言版本的节点实验

> 自定义消息、服务和动作的接口包需要使用 ROS 2 的接口生成工具链；这不改变业务节点全部使用 Python 编写的课程范围。

## 推荐学习顺序

```text
工程与节点 → 话题 → 服务与动作 → 参数、Launch 与 TF
           → Python 模块化与生命周期 → 执行器与 QoS
           → URDF/Xacro/RViz → Gazebo → 综合项目
```

## 每个模块的教学结构

1. 内容导读：说明本模块讨论的问题和知识范围。
2. 详细知识点：概念、Python API、命令行工具和工程规范。
3. 课堂演示：教师可逐步操作的最小示例。
4. 实验任务：学生独立完成的可运行程序。
5. 常见问题：容易混淆的概念与高频报错。
6. 验收标准：通过命令、输出和现象判断是否达标。

## 工程目录约定

- 每个模块的 `README.md` 是该模块的详细备课提纲。
- Python 功能包统一采用小写加下划线命名，例如 `patrol_robot_py`。
- 节点源码放在与功能包同名的 Python 模块中，使用 `console_scripts` 注册入口。
- `launch/`、`config/`、`urdf/`、`rviz/`、`worlds/` 按资源类型分目录管理。
- 工作空间中的 `src/` 保存源码；`build/`、`install/`、`log/` 为构建产物，不作为课程源码提交。
- 每次构建前加载 `/opt/ros/jazzy/setup.bash`，构建后加载工作空间的 `install/setup.bash`。
