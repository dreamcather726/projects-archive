# 第四单元知识点详解

## ROS 2 参数、Launch、数据记录与 TF2

这份文档讲解节点参数、命名空间、重映射、Python Launch、rosbag2 和 TF2 坐标变换。重点是把硬编码配置改为可复用工程配置，并建立可以验证的机器人坐标树。

配套实验位于 [experiments/01_tf_toolchain](experiments/01_tf_toolchain)。

## 1. 参数：配置不应散落在源码中

安全距离、设备端口、控制周期在不同机器人上会变化。如果写死在源码中，每次部署都要修改、重建并容易漏改。

节点使用参数前应先声明。声明不仅给默认值，还可以提供描述、范围和只读约束。读取参数得到的是 Parameter 对象或其中的值，注意类型。

参数设置回调应完成整体校验。例如最小距离必须小于最大距离，不能分别校验后留下矛盾配置。非法配置应拒绝并说明原因。

YAML 中最常见的错误是节点键名不匹配或漏掉 `ros__parameters`：

```yaml
monitor_node:
  ros__parameters:
    safe_distance: 0.8
```

## 2. 节点名称与重映射

同一节点可以通过命名空间运行多份：`/robot_1/monitor`、`/robot_2/monitor`。接口名称也应尽量允许重映射。这样算法包不需要知道部署时机器人编号。

强调三个概念：节点名决定计算图身份；命名空间提供层级隔离；重映射改变某个名称在本次运行中的解析结果。

## 3. Python Launch

Launch 描述系统如何启动，而不是业务算法。它负责：

- 启动哪些节点。
- 节点叫什么、属于哪个命名空间。
- 加载哪个参数文件。
- 哪些话题需要重映射。
- 哪些子系统按条件启用。
- 包含哪些下级 Launch。

资源文件在源码目录存在不代表安装后存在。`setup.py` 必须把 `launch/` 和 `config/` 安装到 `share/<包名>`，然后通过 ament index 查找，不能依赖当前工作目录。

## 4. rosbag2

rosbag2 记录序列化后的话题数据和元数据，适用于复现传感器问题、回归测试和离线算法调试。

教学要点：bag 不是普通日志文本；记录哪些话题、使用何种 QoS、时间戳来自哪里，都会影响回放结果。回放数据前应停止同名真实发布者，避免两套数据混在一起。

## 5. 坐标系为什么必要

激光雷达报告“前方 1 米有障碍”，这个“前方”属于雷达坐标系。雷达安装在底盘左侧时，该点转换到底盘或地图坐标后才可与其他数据比较。

TF2 管理随时间变化的坐标变换树。树中每个子坐标系只能有一个直接父坐标系，否则同一坐标的位置定义会产生冲突。

常用坐标语义：

- `map`：长期稳定的全局参考。
- `odom`：短期连续但可能漂移的里程计参考。
- `base_link`：机器人底盘主体。
- `laser_link`、`camera_link`：传感器安装坐标。

## 6. 平移、旋转和四元数

变换包含平移和旋转。欧拉角便于理解，但存在旋转顺序和奇异性问题；ROS 消息通常使用四元数。学生至少要会：角度先转弧度；四元数必须有效且应归一化；不能把 yaw 直接填进 quaternion.z。

## 7. 静态与动态 TF

固定安装的传感器使用静态变换；机器人在里程计坐标中的移动使用动态变换。静态 TF 具有适合后加入订阅者的持久性，不应该用高频定时器反复发布。

动态 TF 每次必须携带正确时间戳。TF2 在缓存中按时间查询，如果请求时刻早于最旧数据或晚于最新数据，就会发生外推错误。

## 8. Python 查询变换

Buffer 保存变换历史，TransformListener 订阅 `/tf` 与 `/tf_static`。查询时要说清：把源坐标系中的数据转换到哪个目标坐标系。

```python
transform = buffer.lookup_transform(
    'base_link', 'laser_link', Time()
)
```

含义是查询 `laser_link` 到 `base_link` 的变换。查询可能因为尚未发现、树不连通或时间不匹配而失败，节点要捕获 TransformException，而不是崩溃。

## 9. TF 排错证据

依次使用：

```bash
ros2 run tf2_ros tf2_echo base_link laser_link
ros2 run tf2_tools view_frames
ros2 topic echo /tf_static --once
```

在 RViz 中选择正确 Fixed Frame，并结合 TF 显示检查断裂、方向和时间。
