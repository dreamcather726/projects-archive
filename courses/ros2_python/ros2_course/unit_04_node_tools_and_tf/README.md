# 第 4 模块：ROS 2 节点基础工具与坐标变换系统

课程材料：[知识点详解](第4章_授课讲义.md) · [实验说明与代码](experiments/01_tf_toolchain/实验说明.md)

## 内容范围

- 节点名称、命名空间、重映射、参数、日志、Launch 和 rosbag2。
- TF2 坐标树、时间与坐标变换的基本含义。
- Python 静态/动态坐标变换的发布、监听与排查。

## 详细知识点

### 1. 节点名称、命名空间与重映射

- 节点名称、完全限定名称和命名空间的关系。
- 同名节点造成的诊断歧义。
- 通过命令行和 Python Launch 重映射节点名与话题名。
- 多机器人系统使用命名空间隔离接口。
- 相对名称、绝对名称和私有名称的解析结果。

### 2. ROS 2 参数

- 参数属于节点，不是全局共享变量。
- 参数类型：布尔、整数、浮点、字符串及数组。
- `declare_parameter()`、`get_parameter()`、参数值与参数对象。
- 未声明参数、默认值和参数描述符。
- `ros2 param list/get/set/describe/dump/load`。
- 使用 YAML 为单节点、多节点和命名空间组织参数。
- 参数设置回调：检查范围、拒绝非法值和保持配置一致性。
- 启动时参数与运行时动态修改的边界。

### 3. 日志、时钟与调试

- 节点 logger、日志级别、格式化输出和节流输出。
- ROS 时间、系统时间、稳态时间的用途差异。
- `use_sim_time` 与 `/clock`。
- 使用 `rqt_graph` 观察计算图。
- 使用 `ros2 doctor` 检查环境和网络配置。
- 通过 `ros2 node info` 反查节点接口。

### 4. Python Launch 系统

- Launch 用于声明和编排系统，而不是把多条终端命令简单拼接。
- Python Launch 文件的 `generate_launch_description()`。
- `LaunchDescription`、`Node`、`DeclareLaunchArgument` 和 `LaunchConfiguration`。
- 参数文件、节点参数、命名空间和重映射在 Launch 中的配置。
- 条件启动、分组、包含其他 Launch 文件和延迟启动。
- 安装 `launch/`、`config/` 等资源到功能包共享目录。
- 使用 `ros2 launch` 传入参数并定位资源安装问题。

### 5. rosbag2 数据记录与回放

- 记录指定话题和记录全部话题的区别。
- 查看 bag 元数据、播放速率、循环和暂停。
- 回放数据时的 QoS、时间戳和 `/clock` 注意事项。
- 用离线数据复现传感器算法问题。

### 6. TF2 核心概念

- 坐标系、父子关系与坐标树；每个子坐标系只能有一个直接父坐标系。
- 平移、旋转、欧拉角、四元数的基本含义。
- `map`、`odom`、`base_link`、传感器坐标系的职责。
- 变换“谁相对谁”的方向问题。
- 静态变换与动态变换的选择。
- 时间缓存、查询时刻、外推错误和数据时间同步。

### 7. Python TF2 编程

- `TransformBroadcaster` 发布动态变换。
- `StaticTransformBroadcaster` 发布固定安装关系。
- `Buffer` 与 `TransformListener` 查询变换。
- `lookup_transform()` 的目标坐标系、源坐标系和时间参数。
- 查询前检查变换、捕获异常并避免阻塞回调。
- 使用 `tf2_echo`、`view_frames` 和 RViz 排查坐标树。

## 课堂演示

1. 用 YAML 配置安全距离和发布周期，并在运行时修改参数。
2. 编写 Launch 文件一次启动发布者、监控节点和参数配置。
3. 记录传感器话题，停止真实发布者后使用 bag 回放。
4. 发布 `base_link → laser_frame` 静态变换。
5. 发布 `odom → base_link` 动态变换，并查询激光点在 `odom` 中的位置。

## 实验任务

构建多传感器坐标系统：

- 用参数文件保存激光雷达与摄像头的安装位姿。
- Python 节点发布静态安装变换和机器人动态里程计变换。
- 另一个 Python 节点定时查询传感器到机器人底盘的变换。
- 使用 Launch 一键启动，使用 rosbag2 记录关键话题。

## 常见问题

- 参数 YAML 中节点名或 `ros__parameters` 层级错误。
- Launch 文件已写好但没有通过 `setup.py` 安装。
- TF 父子方向颠倒，或出现一子多父、坐标树断裂。
- 时间戳为零、过旧或来自不同时间源，导致外推异常。
- 把角度值直接当弧度传入旋转计算。

## 验收标准

- 能通过命令行和 YAML 查看、修改和加载参数。
- 一个命令可启动完整节点组，参数和重映射均生效。
- TF 树连通且无重复父节点，RViz 中模型与传感器数据对齐。
- 能解释并解决常见的 TF 查询和时间错误。
