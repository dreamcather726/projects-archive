# 第七单元知识点详解

## ROS 2 中的 URDF、Xacro 与 RViz2

这份文档讲解机器人模型中的 Link、Joint、Visual、Collision、Inertial，介绍 Xacro 参数化、`robot_state_publisher`、关节状态和 RViz2 显示与排错。

配套实验位于 [experiments/01_xacro_rviz](experiments/01_xacro_rviz)。

## 1. 机器人软件怎样知道雷达装在哪里

雷达节点只发布 `laser_link` 下的扫描，导航算法却在 `base_link` 或 `map` 下工作。系统必须有统一模型描述每个刚体、关节和坐标系。URDF 是描述机器人本体树形结构的 XML 格式。

## 2. Link 与 Joint

Link 表示刚体和它的坐标系；Joint 连接父 Link 与子 Link。一个合法 URDF 通常只有一个根 Link，其他 Link 通过 Joint 形成树。

Joint 的 origin 描述子结构相对父结构的安装位置。初学者常把它误写成世界坐标。模型整体移动时，各局部关系仍保持或按关节自由度变化。

## 3. 同一个 Link 的三种几何

- visual：给人看的外观，可使用颜色和高精度 mesh。
- collision：给碰撞检测用，通常选简单几何提高计算效率。
- inertial：给动力学计算用，包括质量、质心和惯性矩阵。

RViz 主要关心 visual 和 TF；Gazebo 物理仿真还需要合理 collision/inertial。模型在 RViz 看起来正确，不表示仿真一定稳定。

## 4. 关节类型与轴

fixed 用于固定传感器；continuous 用于无限旋转车轮；revolute 有角度上下限；prismatic 沿轴平移。

轴向和几何姿态必须一致。圆柱默认轴向、车轮的旋转轴和关节 axis 如果不匹配，外观看似车轮但运动方向会错误。

## 5. Xacro 解决重复和参数不一致

左右轮结构相同，只是名字和 y 坐标不同。复制两份 XML 容易改一处漏一处。Xacro 使用 property 和 macro 生成最终 URDF：

- property 集中尺寸和质量。
- macro 封装重复结构。
- 参数决定名称、位置和颜色。
- 表达式计算派生尺寸。

先用 `xacro model.xacro > model.urdf` 展开，再用 `check_urdf` 检查，有利于区分 Xacro 生成错误与 URDF 结构错误。

## 6. robot_state_publisher 与 joint_states

`robot_state_publisher` 读取 `robot_description`。固定关节可以直接发布；可动关节需要 `/joint_states` 给出当前位置。

`joint_state_publisher_gui` 适合教学和模型检查，不是真实机器人关节驱动。真实系统应由硬件驱动或控制器发布关节状态。

不要同时手写发布与 URDF 重复的 TF，否则同一子坐标系可能有两个来源。

## 7. RViz2 的显示逻辑

RViz 把所有数据转换到 Fixed Frame 后显示。Fixed Frame 不存在、TF 树不连通或时间不匹配都会产生错误。

建议课堂依次添加：TF → RobotModel → LaserScan/Odometry。每添加一个 Display 就观察 Status，要求学生解释绿色、黄色和红色状态信息，而不是只看画面。

## 8. 模型排错顺序

1. XML 能否解析。
2. Xacro 能否展开。
3. `check_urdf` 是否确认树合法。
4. `robot_description` 是否加载。
5. `/joint_states` 是否覆盖可动关节。
6. TF 是否连通。
7. RViz Fixed Frame 和资源路径是否正确。
