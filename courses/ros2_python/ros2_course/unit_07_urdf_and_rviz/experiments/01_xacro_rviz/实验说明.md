# 实验 7：使用 Xacro 构建差速小车并在 RViz2 显示

## 为什么要做这个实验

通信节点只描述“机器人做什么”，机器人模型描述“机器人长什么样、部件如何连接”。导航、传感器融合和仿真都依赖一致的连杆与坐标系。本实验让学生第一次把抽象 TF 树变成可视化机器人。

## 实验的作用

- 掌握 URDF 连杆、关节、外观、碰撞和惯性。
- 使用 Xacro 属性与宏消除重复结构。
- 理解 `robot_state_publisher` 如何把模型和关节状态转换为 TF。
- 学会在 RViz 中通过状态提示排查模型问题。

## 实验重点

1. 左右车轮共用一个 Xacro 宏，但位置和名称不同。
2. 激光雷达通过 fixed joint 固定在 `base_link`。
3. 可动车轮需要 `/joint_states`，固定关节不需要。
4. RViz 显示正确不等于 Gazebo 动力学参数一定正确。

## 运行步骤

```bash
source /opt/ros/jazzy/setup.bash
cd <课程仓库>/ros2_course/unit_07_urdf_and_rviz/experiments/01_xacro_rviz/ros2_ws
rosdep install --from-paths src --ignore-src -r -y
colcon build --symlink-install
source install/setup.bash
ros2 launch robot_description_py display.launch.py
```

检查 Xacro 展开结果：

```bash
ros2 pkg prefix robot_description_py
xacro src/robot_description_py/urdf/my_robot.urdf.xacro > /tmp/my_robot.urdf
check_urdf /tmp/my_robot.urdf
```

在 RViz 中确认 Fixed Frame 为 `base_link`，添加或检查 RobotModel 与 TF。拖动 Joint State Publisher GUI 的车轮关节滑块，观察关节状态变化。

## 预期现象

- 蓝色底盘、两个深色车轮和顶部橙色激光雷达完整显示。
- TF 中 `base_link` 是根，左右轮和 `laser_link` 均与其连接。
- 修改车轮关节值不会改变车轮位置，但会改变其旋转姿态。

## 验收任务

1. 增加 `camera_link` 与摄像头外观。
2. 把底盘长宽高提取为 Xacro property。
3. 增加 `base_footprint` 并解释它与 `base_link` 的用途差异。
4. 保存自己的 RViz 配置并在 Launch 中自动加载。

## 常见问题

- Xacro 报 XML 错误：先检查标签闭合和属性引号。
- RobotModel 显示红色错误：展开 Xacro 并使用 `check_urdf`。
- 车轮位置错误：joint 的 origin 是相对父连杆，不是世界坐标。
- 模型部分消失：检查对应关节状态和 TF 是否存在。
