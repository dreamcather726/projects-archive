# 第八单元知识点详解

## Gazebo 物理仿真与 Python 控制

这份文档讲解 Gazebo Harmonic 的世界、模型、物理参数、差速驱动、激光传感器、`ros_gz` 桥接、仿真时间和 Python 安全控制。

配套实验位于 [experiments/01_gazebo_lidar](experiments/01_gazebo_lidar)。

## 1. RViz 和 Gazebo 的根本区别

RViz 展示 ROS 数据，不计算重力、碰撞和轮胎摩擦。Gazebo 是仿真器，会根据质量、惯性、关节、接触和插件计算下一时刻状态。

一个只有 visual 的模型在 RViz 中可能显示正常，但进入仿真后可能没有碰撞、质量不合理或直接穿过地面。“显示模型”和“物理模型”不是一回事。

## 2. Gazebo 世界与 SDF

SDF 可以描述世界、灯光、物理引擎、静态模型、机器人、传感器和系统插件。核心层次为 World → Model → Link/Joint/Sensor。

Jazzy 课程采用 Gazebo Harmonic。应使用 `gz sim`、`ros_gz_sim` 和 `ros_gz_bridge` 体系，避免把旧版工具命令和插件混入课程。

## 3. 动力学参数

### 质量与惯性

质量决定受力后的加速度；惯性描述绕不同轴旋转的难易。惯性全零、数量级不合理或质心超出物体，都可能导致模型抖动、飞散或求解失败。

### 碰撞与摩擦

外观 mesh 可以复杂，但碰撞几何应尽量用盒、圆柱等简单形状。车轮与地面的摩擦不足会空转，参数过激也可能让求解不稳定。

### 仿真步长

更小步长通常提高数值稳定性，但计算开销更大。传感器更新率不应被误解为物理步长。

## 4. 差速驱动模型

左右轮同速同向时直行，速度不同产生转弯，反向等速可原地旋转。轮半径和轮距必须与模型一致，否则命令运动与里程计估计产生系统性偏差。

DiffDrive system 连接轮关节、接收速度命令并发布里程计。配置中的 joint 名必须与模型完全一致。

## 5. 激光雷达仿真

关键参数包括水平角度范围、采样数、最小/最大量程、分辨率和更新率。真实激光会有噪声、无效值和反射问题；算法不应假定 ranges 中每个值都有限。

传感器 Link 的位姿决定扫描坐标系。它必须与 TF/模型语义一致，否则算法可能把侧面的障碍当成正前方。

## 6. ros_gz 桥接

Gazebo Transport 和 ROS 2 是独立通信系统。仿真内部存在 `/scan` 不代表 `ros2 topic list` 一定能看到它。

桥接配置包含：话题名、ROS 消息类型、Gazebo 消息类型、方向。传感器通常从 Gazebo 到 ROS，速度命令从 ROS 到 Gazebo，时钟从 Gazebo 到 ROS。

排错时先用 `gz topic -l` 检查仿真侧，再检查 bridge 进程，最后用 `ros2 topic` 检查 ROS 侧。

## 7. 仿真时间

仿真可暂停、加速或减速，因此节点应使用 ROS 时钟并设置 `use_sim_time=true`。系统时间继续流逝而仿真暂停时，混用时间源会产生超时误判和 TF 问题。

## 8. 安全的 Python 控制器

控制循环不能在“没有新激光”时继续沿用旧速度。安全默认应是零速度。处理 LaserScan 时要：

1. 根据角度计算前方索引，而不是假定数组固定长度。
2. 过滤 inf/nan。
3. 使用扇区最小值而不是单个点。
4. 检查消息年龄。
5. 节点退出前发布零速度。
