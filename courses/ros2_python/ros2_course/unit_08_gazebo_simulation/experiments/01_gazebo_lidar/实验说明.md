# 实验 8：Gazebo 差速小车、激光雷达与 Python 避障

## 为什么要做这个实验

前面章节中的传感器值大多是程序生成的。真实机器人调试成本高，并且错误速度命令可能损坏设备。物理仿真允许学生在安全环境中验证模型、坐标、传感器和控制算法，再迁移到真实平台。

## 实验的作用

- 建立 Gazebo 世界和具备质量、碰撞、关节的差速小车。
- 通过 `ros_gz_bridge` 打通 `/scan`、`/odom`、`/cmd_vel` 和 `/clock`。
- 使用 Python 订阅激光数据并发布速度命令。
- 理解仿真模型错误与 ROS 节点错误需要分层排查。

## 实验重点

1. 仿真器内的话题必须经过 bridge 才能成为 ROS 2 话题。
2. 控制器在尚未收到激光数据时必须发布零速度。
3. `LaserScan` 中可能出现 inf 或 nan，算法要过滤无效值。
4. 本实验是反应式避障，不等于已经具备地图和全局路径规划。

## 运行步骤

```bash
source /opt/ros/jazzy/setup.bash
cd <课程仓库>/ros2_course/unit_08_gazebo_simulation/experiments/01_gazebo_lidar/ros2_ws
rosdep install --from-paths src --ignore-src -r -y
colcon build --symlink-install
source install/setup.bash
ros2 launch gazebo_patrol_py simulation.launch.py
```

默认启动 Gazebo、桥接和 Python 避障节点。新终端执行：

```bash
source /opt/ros/jazzy/setup.bash
cd <实验目录>/ros2_ws
source install/setup.bash
ros2 topic list
ros2 topic hz /scan
ros2 topic echo /odom --once
ros2 topic echo /cmd_vel
```

如需手动控制，启动时关闭自动控制器：

```bash
ros2 launch gazebo_patrol_py simulation.launch.py start_controller:=false
ros2 topic pub --rate 10 /cmd_vel geometry_msgs/msg/Twist \
  "{linear: {x: 0.3}, angular: {z: 0.0}}"
```

## 预期现象

- 世界中出现四面墙和一台差速小车。
- 小车在前方距离充足时直行，接近墙体时原地左转。
- `/scan` 有有效距离数组，`/odom` 随运动更新。
- 暂停仿真后，仿真时钟和运动停止。

## 验收任务

1. 修改安全距离参数，比较小车开始转向的位置。
2. 修改轮半径配置并观察里程计误差或运动差异。
3. 在世界中增加一个箱体障碍物。
4. 增加“连续多帧安全后再恢复直行”的防抖逻辑。

## 常见问题

- Gazebo 无法启动：确认安装与 Jazzy 匹配的 Gazebo Harmonic 和 `ros_gz`。
- `/scan` 不存在：检查世界的 Sensors system 和 bridge 参数。
- 有 `/cmd_vel` 但车不动：检查 DiffDrive 插件、关节名、仿真是否暂停。
- 控制器一直等待激光：检查 bridge 方向以及激光话题名。
