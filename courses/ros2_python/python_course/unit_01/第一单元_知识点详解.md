# 第一单元知识点详解

## Python 基础语法与机器人数据表示

这份文档作为第一单元的课堂主讲义，也用于课后复习。重点是正确表示机器人名称、电量、速度、开关状态和暂缺数据，并能完成基本计算、判断和文本处理。

配套代码位于 [examples](examples)、[experiments](experiments) 和 [answers](answers) 文件夹。运行方式见文末的“配套代码与运行”，课后作业附在最后。

## 1. Python 程序的运行

### 1.1 Python 解释器

Python 代码需要由 Python 解释器执行。先在终端检查环境：

```powershell
python --version
```

Linux 或 macOS 通常使用：

```bash
python3 --version
```

能够看到 `Python 3.x.x`，说明当前终端可以找到 Python 解释器。

### 1.2 交互式运行

在终端输入 `python` 后，会看到提示符 `>>>`：

```pycon
>>> 2 + 3
5
>>> print("Hello Robot")
Hello Robot
```

交互式环境适合快速测试一两行代码。`>>>` 是解释器提示符，不属于代码。

使用下面的命令退出：

```pycon
>>> exit()
```

### 1.3 运行 Python 文件

创建 `hello_robot.py`：

```python
robot_name = "robot_01"
print(f"Hello, {robot_name}")
```

运行：

```powershell
python hello_robot.py
```

输出：

```text
Hello, robot_01
```

Python 文件通常使用 `.py` 扩展名，并保存为 UTF-8 编码。

### 1.4 终端命令、Python 代码和输出

三者不能混在一起：

| 内容 | 示例 | 应该出现在哪里 |
| --- | --- | --- |
| 终端命令 | `python robot_status.py` | PowerShell、终端 |
| Python 代码 | `print("Hello")` | `.py` 文件或 `>>>` 后面 |
| 程序输出 | `Hello` | 终端显示结果 |

## 2. Python 基础语法

### 2.1 语句和表达式

表达式会计算出一个值：

```python
2 + 3
0.30 * 10
battery_percent > 20
```

语句完成一个操作：

```python
battery_percent = 85
print(battery_percent)
```

赋值语句把计算结果保存起来，`print()` 将内容显示到终端。

### 2.2 缩进

Python 使用缩进表示代码的层级。通常使用四个空格：

```python
battery_percent = 85

if battery_percent > 20:
    print("电量充足")
    print("允许继续处理")

print("程序结束")
```

两个缩进的 `print()` 属于 `if`。最后一个 `print()` 回到行首，不属于 `if`。

常见问题：

- 应该缩进的代码没有缩进。
- 同一代码块的缩进数量不一致。
- 混用 Tab 和空格。
- 在普通顶层代码前多加空格。

### 2.3 注释

`#` 后面的内容是注释，解释器不会把它当作普通代码执行：

```python
# 机器人当前线速度，单位为 m/s
linear_speed_mps = 0.30

battery_percent = 85  # 电量百分数
```

字符串中的 `#` 仍然是字符串的一部分：

```python
print("robot#01")
```

### 2.4 英文符号

Python 语法通常使用英文半角符号：

```python
print("robot_01")
```

下面的中文引号不能作为 Python 字符串引号：

```text
print(“robot_01”)
```

中文可以正常出现在字符串、注释和输出中。

## 3. 标识符、关键字与命名规则

### 3.1 什么是标识符

标识符是程序员在代码中定义的名称，用来给变量、函数、类、模块等命名。

```python
robot_name = "robot_01"
battery_percent = 85
```

这段代码中：

- `robot_name` 是变量的标识符。
- `battery_percent` 也是变量的标识符。
- `"robot_01"` 和 `85` 是值，不是标识符。
- `=` 是赋值运算符，不是标识符。

后续还会见到其他标识符：

```python
def calculate_speed():
    pass


class RobotState:
    pass
```

- `calculate_speed` 是函数名。
- `RobotState` 是类名。
- 函数和类将在后续单元详细学习，这里只需要知道它们的名字也属于标识符。

### 3.2 标识符命名规则

初学阶段统一使用英文字母、数字和下划线组成标识符，并遵守以下规则。

1. **可以包含字母、数字和下划线。**
2. **不能以数字开头。**
3. **不能包含空格、减号和其他普通标点。**
4. **严格区分大小写。**
5. **不能使用 Python 关键字。**

合法标识符：

```python
age = 18
user_name = "student_01"
robot2 = "robot_02"
_temporary_value = 0.30
MAX_SPEED_MPS = 0.50
```

不合法标识符：

```text
2robot       不能以数字开头
robot-name   包含减号，会被理解成减法
robot name   包含空格
speed.mps    包含点号
if           Python 关键字
```

Python 实际上允许部分非英文字符出现在标识符中，例如 `机器人名称`。为了统一代码风格，并方便阅读 ROS 2 示例，本课程使用英文标识符，中文写在注释和字符串中。

### 3.3 标识符区分大小写

下面是三个不同的标识符：

```python
speed = 0.30
Speed = 0.40
SPEED = 0.50

print(speed)
print(Speed)
print(SPEED)
```

输出：

```text
0.3
0.4
0.5
```

如果定义的是 `robot_name`，却写成 `Robot_name`，通常会产生 `NameError`。

### 3.4 常用命名风格

命名风格不是解释器强制语法，但统一风格能让代码更容易阅读。

| 对象 | 推荐风格 | 示例 |
| --- | --- | --- |
| 变量 | 小写单词，下划线分隔 | `battery_percent` |
| 函数 | 小写单词，下划线分隔 | `calculate_speed()` |
| 类 | 每个单词首字母大写 | `RobotState` |
| 常量 | 全部大写，下划线分隔 | `MAX_SPEED_MPS` |
| 模块文件 | 小写单词，下划线分隔 | `robot_status.py` |

推荐使用能够表达含义的名称：

```python
linear_speed_mps = 0.30
```

不推荐使用含义模糊的名称：

```python
x = 0.30
a = 85
data = True
```

循环中很短的局部计数变量可以使用 `i`，但机器人状态和物理量应尽量使用完整名称。

### 3.5 什么是 Python 关键字

关键字是 Python 语言已经保留、具有特殊语法含义的单词。程序员不能把关键字当作普通标识符。

下面的代码不合法：

```python
if = 85
class = "robot_01"
```

因为 `if` 用于条件判断，`class` 用于定义类。

可以用标准库 `keyword` 查看当前 Python 版本的关键字：

```python
import keyword

print(keyword.kwlist)
print(keyword.iskeyword("if"))
print(keyword.iskeyword("robot_name"))
```

后两行输出：

```text
True
False
```

不同 Python 版本的关键字可能略有变化，以当前解释器的 `keyword.kwlist` 为准。

### 3.6 常量与逻辑关键字

| 关键字 | 含义 | 简单示例 |
| --- | --- | --- |
| `True` | 布尔真值 | `is_enabled = True` |
| `False` | 布尔假值 | `emergency_stop = False` |
| `None` | 暂时没有值 | `distance_m = None` |
| `and` | 多个条件都满足 | `enabled and battery_ok` |
| `or` | 至少一个条件满足 | `low_battery or obstacle` |
| `not` | 对条件取反 | `not emergency_stop` |
| `in` | 判断成员是否存在 | `"robot" in robot_name` |
| `is` | 判断是否为同一个对象 | `distance_m is None` |

`True`、`False` 和 `None` 的首字母必须大写：

```python
is_enabled = True
distance_m = None
```

`and`、`or`、`not` 用来组合条件：

```python
can_move = (
    is_enabled
    and battery_percent > 20
    and not emergency_stop
)
```

`in` 常用于成员判断：

```python
print("robot" in "robot_01")
```

`is` 在第一单元主要用于检查 `None`：

```python
if distance_m is None:
    print("尚未获得测距数据")
```

普通数值是否相等使用 `==`，不要使用 `is`：

```python
battery_percent == 85
```

### 3.7 条件和循环关键字

| 关键字 | 含义 | 所属内容 |
| --- | --- | --- |
| `if` | 如果条件成立，执行代码 | 条件判断 |
| `elif` | 前面条件不成立时，继续判断另一个条件 | 条件判断 |
| `else` | 前面的条件都不成立时执行 | 条件判断、异常处理 |
| `for` | 依次遍历数据 | 循环 |
| `while` | 条件为真时重复执行 | 循环 |
| `break` | 立即结束当前循环 | 循环控制 |
| `continue` | 跳过本轮循环剩余代码 | 循环控制 |
| `pass` | 暂时什么也不做 | 空代码占位 |

条件判断示例：

```python
if distance_m <= 0.40:
    action = "停车"
elif distance_m <= 0.80:
    action = "减速"
else:
    action = "前进"
```

循环示例：

```python
for distance_m in distances_m:
    if distance_m is None:
        continue

    if distance_m <= 0.40:
        break
```

`pass` 常用于语法上需要代码块、但暂时没有具体代码的地方：

```python
if battery_percent > 20:
    pass
```

这些关键字将在第二单元详细学习。

### 3.8 函数和类相关关键字

| 关键字 | 含义 | 后续课程位置 |
| --- | --- | --- |
| `def` | 定义函数或方法 | 第三单元 |
| `return` | 结束函数并返回结果 | 第三单元 |
| `lambda` | 创建简短匿名函数 | 第三单元拓展 |
| `yield` | 从生成器中逐次产生数据 | 第三单元 |
| `class` | 定义类 | 第五单元 |

函数预览：

```python
def calculate_distance(speed_mps, duration_s):
    return speed_mps * duration_s
```

- `def` 表示开始定义函数。
- `return` 把计算结果交给调用者，同时结束本次函数调用。

类预览：

```python
class Robot:
    pass
```

- `class` 表示定义一个类。
- `pass` 暂时占位，让空的类定义保持语法完整。

### 3.9 模块和导入相关关键字

| 关键字 | 含义 | 示例 |
| --- | --- | --- |
| `import` | 导入模块 | `import math` |
| `from` | 从模块中导入指定内容 | `from math import pi` |
| `as` | 为导入内容设置别名 | `import math as m` |

三种写法：

```python
import math
print(math.pi)
```

```python
from math import pi
print(pi)
```

```python
import math as m
print(m.pi)
```

`as` 还会出现在异常处理和 `with` 语句中。模块将在第四单元详细学习。

### 3.10 异常处理和资源管理关键字

| 关键字 | 含义 |
| --- | --- |
| `try` | 尝试执行可能出错的代码 |
| `except` | 捕获并处理指定异常 |
| `finally` | 无论是否出错都执行 |
| `raise` | 主动抛出异常 |
| `assert` | 检查开发阶段预期条件 |
| `with` | 在上下文中管理文件等资源 |

异常处理预览：

```python
try:
    battery_percent = int("85")
except ValueError:
    print("电量格式错误")
```

文件资源管理预览：

```python
with open("robot.txt", "r", encoding="utf-8") as file:
    text = file.read()
```

- `with` 帮助程序正确管理文件资源。
- `as file` 把打开的文件对象命名为 `file`。
- 这些内容将在第四单元详细学习。

### 3.11 作用域、删除和异步关键字

| 关键字 | 含义 | 说明 |
| --- | --- | --- |
| `global` | 声明使用全局名称 | 第三单元作用域 |
| `nonlocal` | 声明使用外层函数的名称 | 第三单元拓展 |
| `del` | 删除名称或容器中的项目 | 第二单元 |
| `async` | 定义异步函数或异步上下文 | 后续拓展 |
| `await` | 等待异步操作完成 | 后续拓展 |

删除列表中的一项：

```python
distances_m = [1.20, 0.55, 0.32]
del distances_m[1]
```

`global` 和 `nonlocal` 会影响名称查找，初学阶段应优先通过参数、返回值和对象属性传递数据。

`async` 与 `await` 属于异步编程语法。ROS 2 中出现回调并不代表所有回调函数都要写成 `async def`，具体方式要看 API 要求。

### 3.12 软关键字

某些单词只在特定语法位置具有关键字作用，称为软关键字。当前 Python 版本中可能包括 `match`、`case`、`_`、`type` 等。

模式匹配示意：

```python
match action:
    case "停车":
        print("速度设为 0")
    case _:
        print("保持处理")
```

它们在其他普通位置可能仍能作为名称使用，但容易引起理解混乱。本课程建议避免使用这些单词给普通机器人变量命名。

可以查看当前版本的软关键字：

```python
import keyword

print(keyword.softkwlist)
```

### 3.13 关键字与内置名称的区别

`print`、`int`、`float`、`str`、`type`、`len` 不是普通保留关键字，而是 Python 提供的内置名称。

从语法上看，可以重新给它们赋值：

```python
print = "robot"
```

但这样会覆盖原来的内置函数，后面再写 `print("Hello")` 就会产生错误。因此不要使用内置名称给普通变量命名。

推荐：

```python
robot_type = "mobile"
text_length = 8
```

不推荐：

```python
type = "mobile"
len = 8
str = "robot_01"
```

可以用下面的代码判断一个单词是否为关键字：

```python
import keyword

print(keyword.iskeyword("if"))     # True
print(keyword.iskeyword("print"))  # False
```

`print` 虽然不是关键字，仍然不适合用作自己的变量名，因为它是常用内置名称。

### 3.14 标识符常见错误

| 错误写法或现象 | 原因 | 建议写法 |
| --- | --- | --- |
| `2robot = "a"` | 数字开头 | `robot2 = "a"` |
| `robot-name = "a"` | 减号被理解为运算符 | `robot_name = "a"` |
| `robot name = "a"` | 名称中包含空格 | `robot_name = "a"` |
| `if = 1` | 使用关键字 | `condition = 1` |
| `print = "a"` | 覆盖内置函数 | `message = "a"` |
| 定义 `speed`，使用 `Speed` | 大小写不一致 | 始终使用 `speed` |
| `a1b2c3` | 合法但含义不清楚 | 使用 `battery_percent` 等描述性名称 |

## 4. 变量与赋值

### 4.1 什么是变量

变量是数据的名称：

```python
robot_name = "robot_01"
battery_percent = 85
linear_speed_mps = 0.30
```

右边是值，左边是变量名，`=` 表示赋值。

### 4.2 变量可以重新赋值

```python
battery_percent = 85
battery_percent = 80
print(battery_percent)
```

输出为 `80`，因为第二次赋值让变量保存了新值。

也可以根据旧值计算新值：

```python
battery_percent = 85
battery_percent = battery_percent - 5
print(battery_percent)
```

执行顺序：

1. 读取右边原来的 `battery_percent`，值为 85。
2. 计算 `85 - 5`，得到 80。
3. 将 80 重新赋给 `battery_percent`。

### 4.3 赋值不是比较

```python
battery_percent = 85      # 赋值
is_full = battery_percent == 100  # 比较
```

- `=`：把值保存到变量。
- `==`：判断两边的值是否相等，结果是 `True` 或 `False`。

### 4.4 变量命名规则

合法名称：

```python
robot_name = "robot_01"
speed_1 = 0.30
linear_speed_mps = 0.30
```

错误或不推荐的名称：

```text
1_robot       不能以数字开头
robot-name    连字符会被看作减号
class         Python 关键字
print         会覆盖常用内置函数名称
```

推荐使用小写英文单词和下划线：

```python
battery_percent = 85
travel_distance_m = 3.0
angular_speed_radps = 0.5
```

### 4.5 在变量名中提示单位

Python 不会自动检查物理单位，因此建议将单位写进变量名：

| 后缀 | 含义 |
| --- | --- |
| `_m` | 米 |
| `_s` | 秒 |
| `_mps` | 米每秒 |
| `_kmh` | 千米每小时 |
| `_deg` | 度 |
| `_rad` | 弧度 |
| `_radps` | 弧度每秒 |

下面两个变量虽然都是浮点数，但意义不同：

```python
heading_rad = 1.57          # 朝向角，单位 rad
angular_speed_radps = 1.57  # 角速度，单位 rad/s
```

数据类型相同，不代表单位和含义相同。

## 5. 基本数据类型

### 5.1 类型、值和含义

机器人数据需要同时明确三件事：

```text
数据类型 + 物理单位 + 数据含义
```

例如：

```python
linear_speed_mps = 0.30
```

- 类型：`float`
- 单位：m/s
- 含义：机器人的线速度

### 5.2 int：整数

整数没有小数部分：

```python
battery_percent = 85
message_count = 10
```

常见用途：电量百分数、计数器、编号。

```python
print(type(battery_percent))
```

输出：

```text
<class 'int'>
```

### 5.3 float：浮点数

浮点数用于表示带小数的数据：

```python
linear_speed_mps = 0.30
distance_m = 1.25
```

普通输出可能不保留末尾零：

```python
print(0.30)
```

输出：

```text
0.3
```

`0.30` 与 `0.3` 是相同数值，只是显示形式不同。

很多十进制小数不能用二进制浮点数精确表示：

```python
print(0.1 + 0.2)
```

输出通常为：

```text
0.30000000000000004
```

机器人测量值本身也存在误差。以后比较浮点测量值时，需要结合传感器精度设置合理容差。

### 5.4 bool：布尔值

布尔值只有两个：

```python
is_enabled = True
emergency_stop = False
```

注意首字母大写，不能写成 `true` 或 `false`。

布尔值常用于表示：

- 是否已经使能。
- 是否检测到障碍物。
- 配置是否有效。
- 某个条件是否满足。

### 5.5 str：字符串

字符串用于保存文本：

```python
robot_name = "robot_01"
robot_state = "READY"
```

单引号和双引号都可以：

```python
name_a = 'robot_01'
name_b = "robot_01"
```

字符串中的数字仍然是文本：

```python
speed_text = "0.30"
linear_speed_mps = 0.30
```

两者显示接近，但只有第二个可以直接参与正常的速度计算。

### 5.6 None：暂时没有值

`None` 用于表示缺失、未知或尚未得到结果：

```python
distance_m = None
```

判断是否为 `None`：

```python
print(distance_m is None)
print(distance_m is not None)
```

`None` 与下面这些值不同：

```python
0
0.0
False
""
"None"
```

示例：

```python
distance_m = None  # 尚未获得数据
distance_m = 0.0   # 已经有一个数值
```

对普通数值是否相等使用 `==`；检查 `None` 通常使用 `is None`。

### 5.7 使用 type 查看类型

```python
print(type("robot_01"))
print(type(85))
print(type(0.30))
print(type(True))
print(type(None))
```

`type()` 适合在学习和排错时确认数据类型。

## 6. 数据类型转换

### 6.1 为什么需要转换

配置文件、终端输入和某些设备协议可能提供文本：

```python
battery_text = "85"
speed_text = "0.30"
```

要进行数值计算，需要先转换：

```python
battery_percent = int(battery_text)
linear_speed_mps = float(speed_text)
```

### 6.2 常用转换

| 写法 | 作用 | 示例结果 |
| --- | --- | --- |
| `int("85")` | 整数文本转整数 | `85` |
| `float("0.30")` | 小数文本转浮点数 | `0.3` |
| `str(85)` | 数值转字符串 | `"85"` |
| `bool(0)` | 按真值规则转布尔值 | `False` |

转换产生一个新结果，原变量不会自动改变：

```python
speed_text = "0.30"
linear_speed_mps = float(speed_text)

print(type(speed_text))
print(type(linear_speed_mps))
```

### 6.3 int 转换与小数

```python
print(int(3.9))
print(int(-3.9))
```

输出：

```text
3
-3
```

`int()` 在这里舍去小数部分，不是四舍五入。

下面会失败：

```python
int("0.30")
```

因为 `"0.30"` 不是整数格式文本，应使用：

```python
float("0.30")
```

### 6.4 bool 转换规则

常见假值包括：

```python
False
None
0
0.0
""
```

非零数值和非空字符串通常为真：

```python
print(bool(0))        # False
print(bool(0.30))     # True
print(bool(""))       # False
print(bool("False"))  # True
```

`bool("False")` 为 `True`，因为它是非空字符串，Python 不会自动理解单词含义。

按约定解析布尔文本：

```python
enabled_text = "False"
is_enabled = enabled_text.lower() == "true"
```

实际接收外部输入时，还应先检查文本是否属于允许的值。

## 7. 运算符

### 7.1 算术运算符

| 运算符 | 含义 | 示例 | 结果 |
| --- | --- | --- | --- |
| `+` | 加法 | `8 + 3` | `11` |
| `-` | 减法 | `8 - 3` | `5` |
| `*` | 乘法 | `8 * 3` | `24` |
| `/` | 普通除法 | `8 / 4` | `2.0` |
| `//` | 向下取整除法 | `8 // 3` | `2` |
| `%` | 取余数 | `8 % 3` | `2` |
| `**` | 乘方 | `2 ** 3` | `8` |

不要使用 `^` 表示乘方。Python 中的乘方是 `**`。

机器人路程计算：

```python
linear_speed_mps = 0.30
travel_duration_s = 10.0
travel_distance_m = linear_speed_mps * travel_duration_s
```

单位关系：

```text
m/s × s = m
```

### 7.2 运算优先级

```python
print(2 + 3 * 4)      # 14
print((2 + 3) * 4)    # 20
```

通常先乘除、后加减。复杂表达式建议使用括号明确计算顺序。

### 7.3 增强赋值

```python
battery_percent = 85
battery_percent -= 5

sample_count = 0
sample_count += 1

linear_speed_mps = 0.30
linear_speed_mps *= 2
```

常见增强赋值：

| 写法 | 大致等价写法 |
| --- | --- |
| `x += 1` | `x = x + 1` |
| `x -= 1` | `x = x - 1` |
| `x *= 2` | `x = x * 2` |
| `x /= 2` | `x = x / 2` |

`x =+ 1` 与 `x += 1` 不同。`x =+ 1` 是给 `x` 赋值为正数 1。

### 7.4 比较运算符

比较结果是布尔值：

| 运算符 | 含义 |
| --- | --- |
| `>` | 大于 |
| `<` | 小于 |
| `>=` | 大于等于 |
| `<=` | 小于等于 |
| `==` | 等于 |
| `!=` | 不等于 |

```python
battery_percent = 85

print(battery_percent > 20)   # True
print(battery_percent == 85)  # True
print(battery_percent != 85)  # False
```

范围比较：

```python
battery_valid = 0 <= battery_percent <= 100
```

不要直接比较单位不同的数据：

```python
speed_mps = 0.50
speed_kmh = 1.80
```

它们可能表示同一速度，但不能只按数字大小判断。

### 7.5 逻辑运算符

| 运算符 | 含义 |
| --- | --- |
| `and` | 所有条件都满足 |
| `or` | 至少一个条件满足 |
| `not` | 对条件取反 |

```python
battery_percent = 85
is_enabled = True
emergency_stop = False

can_move = (
    is_enabled
    and battery_percent > 20
    and not emergency_stop
)
```

这里的 `can_move` 只是逻辑判断结果，不会自动控制机器人。

逻辑运算存在短路：

- `and` 左边已经为假，不再计算右边。
- `or` 左边已经为真，不再计算右边。

### 7.6 成员运算符

`in` 判断某个内容是否存在：

```python
robot_name = "robot_01"

print("robot" in robot_name)  # True
print("car" in robot_name)    # False
```

`not in` 表示不存在：

```python
print("car" not in robot_name)  # True
```

## 8. 单位换算

### 8.1 m/s 与 km/h

```python
linear_speed_mps = 0.30
linear_speed_kmh = linear_speed_mps * 3.6
```

反向换算：

```python
linear_speed_mps = linear_speed_kmh / 3.6
```

### 8.2 角度与弧度

```python
import math

heading_deg = 90.0
heading_rad = heading_deg * math.pi / 180.0
```

反向换算：

```python
heading_deg = heading_rad * 180.0 / math.pi
```

关系：

```text
180° = π rad
360° = 2π rad
```

### 8.3 单位与物理量不能混淆

| 物理量 | 常用单位 | 示例变量 |
| --- | --- | --- |
| 距离 | m | `distance_m` |
| 时间 | s | `duration_s` |
| 线速度 | m/s | `linear_speed_mps` |
| 朝向角 | rad | `heading_rad` |
| 角速度 | rad/s | `angular_speed_radps` |

角度与角速度都是浮点数，但一个描述位置方向，一个描述转动快慢。

## 9. 字符串

### 9.1 创建字符串

```python
robot_name = "robot_01"
state = 'READY'
```

字符串拼接：

```python
full_name = "robot_" + "01"
```

字符串重复：

```python
print("-" * 10)
```

数字与字符串不能直接拼接：

```python
battery_percent = 85
print("电量：" + str(battery_percent) + "%")
```

更推荐使用 f-string。

### 9.2 转义字符

| 写法 | 含义 |
| --- | --- |
| `\n` | 换行 |
| `\t` | 制表符 |
| `\\` | 反斜杠 |
| `\"` | 双引号 |

```python
print("状态：\nREADY")
```

输出：

```text
状态：
READY
```

### 9.3 字符串索引

```text
字符：   r  o  b  o  t  _  0  1
正索引： 0  1  2  3  4  5  6  7
负索引：-8 -7 -6 -5 -4 -3 -2 -1
```

```python
robot_name = "robot_01"

print(robot_name[0])   # r
print(robot_name[-1])  # 1
```

字符串长度为 8，最大正索引为 7。访问 `robot_name[8]` 会出现 `IndexError`。

### 9.4 字符串切片

格式：

```text
text[start:stop:step]
```

常用切片包含 `start`，不包含 `stop`：

```python
robot_name = "robot_01"

print(robot_name[0:5])  # robot
print(robot_name[6:])   # 01
print(robot_name[:5])   # robot
print(robot_name[-2:])  # 01
print(robot_name[::2])  # rbt0
```

切片超出右边界通常不会报错：

```python
print(robot_name[6:100])  # 01
```

### 9.5 字符串不能原地修改

下面的代码会报错：

```python
robot_name = "robot_01"
robot_name[0] = "R"
```

需要创建一个新字符串：

```python
updated_name = "R" + robot_name[1:]
```

字符串属于不可变对象。

### 9.6 常用字符串方法

| 方法 | 作用 | 示例 |
| --- | --- | --- |
| `strip()` | 去除两端空白 | `"  robot  ".strip()` |
| `lower()` | 转为小写 | `"TRUE".lower()` |
| `upper()` | 转为大写 | `"ready".upper()` |
| `replace()` | 替换文本 | `"robot_01".replace("01", "02")` |
| `split()` | 按分隔符拆分 | `"a|b".split("|")` |
| `find()` | 查找首次出现位置 | `"robot_01".find("_")` |
| `startswith()` | 判断开头 | `name.startswith("robot")` |
| `endswith()` | 判断结尾 | `name.endswith("01")` |
| `count()` | 统计出现次数 | `text.count("|")` |

字符串方法通常返回新结果，不修改原字符串：

```python
raw_name = "  Robot_01  "
clean_name = raw_name.strip().lower()

print(raw_name)    # 仍有空格和大写字母
print(clean_name)  # robot_01
```

### 9.7 split 拆分文本

```python
raw_status = "Robot_01|85|0.30|TRUE"
fields = raw_status.split("|")

print(fields)
```

结果：

```text
['Robot_01', '85', '0.30', 'TRUE']
```

拆分后的每个字段仍然是字符串：

```python
robot_name = fields[0].lower()
battery_percent = int(fields[1])
linear_speed_mps = float(fields[2])
is_enabled = fields[3].lower() == "true"
```

输入缺少字段时，访问不存在的索引会出现 `IndexError`。实际处理外部数据时，应先检查字段数量和格式。

## 10. f-string 格式化输出

### 10.1 基本写法

在字符串引号前加 `f`，变量或表达式放在 `{}` 中：

```python
robot_name = "robot_01"
battery_percent = 85

print(f"机器人：{robot_name}，电量：{battery_percent}%")
```

### 10.2 小数位数

```python
linear_speed_mps = 0.30
print(f"线速度：{linear_speed_mps:.2f} m/s")
```

`.2f` 表示以小数形式显示两位：

```text
线速度：0.30 m/s
```

其他示例：

| 格式 | 作用 | 示例结果 |
| --- | --- | --- |
| `.1f` | 一位小数 | `1.2` |
| `.2f` | 两位小数 | `1.20` |
| `.4f` | 四位小数 | `1.2000` |
| `02d` | 整数至少两位，不足补零 | `01` |

### 10.3 可以在花括号中计算

```python
linear_speed_mps = 0.30
print(f"速度：{linear_speed_mps * 3.6:.2f} km/h")
```

### 10.4 格式化不会改变原始值

```python
distance_m = 1.236
distance_text = f"{distance_m:.2f}"

print(distance_text)       # 1.24
print(distance_m)          # 1.236
print(type(distance_text)) # str
```

格式化结果是字符串，只改变显示形式，不改变原始浮点数。

## 11. 第一单元的数据处理流程

```text
外部文本
   ↓
字符串清理与拆分
   ↓
数据类型转换
   ↓
单位换算
   ↓
比较与逻辑判断
   ↓
f-string 格式化输出
```

示例：

```python
raw_status = "Robot_01|85|0.30|TRUE"
fields = raw_status.split("|")

robot_name = fields[0].lower()
battery_percent = int(fields[1])
linear_speed_mps = float(fields[2])
is_enabled = fields[3].lower() == "true"

linear_speed_kmh = linear_speed_mps * 3.6
can_move = is_enabled and battery_percent > 20

print(f"机器人：{robot_name}")
print(f"电量：{battery_percent}%")
print(f"速度：{linear_speed_mps:.2f} m/s")
print(f"换算速度：{linear_speed_kmh:.2f} km/h")
print(f"满足模拟运动条件：{can_move}")
```

## 12. 与 ROS 2 的联系

| Python 知识 | ROS 2 中的用途 |
| --- | --- |
| 变量 | 保存节点内部状态 |
| `int`、`float` | 保存计数、距离、速度等数据 |
| `bool` | 保存开关和判断结果 |
| `str` | 节点名称、日志和文本消息 |
| `None` | 表示节点内部暂时没有结果 |
| 类型转换 | 处理配置或外部文本数据 |
| 运算符 | 计算距离、速度并判断阈值 |
| 弧度换算 | 处理机器人角度数据 |
| f-string | 输出带数值和单位的日志 |

后续会看到类似代码：

```python
msg.linear.x = linear_speed_mps
msg.angular.z = angular_speed_radps
```

- `msg.linear.x` 通常表示线速度的一个分量。
- `msg.angular.z` 通常表示绕 Z 轴的角速度。
- 填入字段前，需要确认类型、单位和物理含义。
- 给消息字段赋值不等于消息已经发布，也不等于机器人已经运动。

## 13. 常见错误速查

| 错误或现象 | 常见原因 | 正确思路 |
| --- | --- | --- |
| `NameError` | 变量未赋值或名称拼错 | 检查变量名和执行顺序 |
| `TypeError` | 对不支持的类型进行运算 | 使用 `type()` 检查数据 |
| `ValueError` | 文本不能按要求转换 | 转换前检查文本格式 |
| `IndexError` | 字符串索引超出范围 | 先检查长度或使用合适切片 |
| `IndentationError` | 缩进不一致 | 同一代码块统一四个空格 |
| `SyntaxError` 指向变量名 | 使用关键字或不合法标识符 | 检查命名规则与关键字列表 |
| `print()` 不能正常调用 | 使用变量覆盖了 `print` | 修改变量名并重新启动程序 |
| `{robot_name}` 被原样输出 | 字符串前缺少 `f` | 使用 `f"..."` |
| `bool("False")` 得到 `True` | 非空字符串的真值为真 | 验证后与 `"true"` 比较 |
| `0.30` 显示为 `0.3` | 普通输出省略末尾零 | 使用 `{value:.2f}` 控制显示 |
| 角度结果错误 | 只改单位文字，没有计算 | 使用角度与弧度换算公式 |
| 速度判断错误 | 比较了不同单位 | 先统一单位，再比较 |
