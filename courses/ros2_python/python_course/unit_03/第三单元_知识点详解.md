# 第三单元知识点详解

## 函数、作用域与回调思维

函数把一组操作组织成可重复使用的代码。ROS 2 的定时器、订阅者、服务等都大量使用回调函数，因此本单元是进入 ROS 2 Python 编程的关键准备。

配套代码位于 [experiments](experiments) 文件夹，运行方式见文末的“配套代码与运行”，课后作业附在最后。

本单元会继续用“在 ROS 2 中的作用”说明各知识点的用途。可以先把节点理解成负责某项机器人功能的程序，把消息理解成节点之间传递的、具有规定格式的数据；定时器用于按设定时间间隔触发处理，订阅用于接收某个话题上的消息。相关写法会在第六单元展开。

## 1. 函数的基本概念

### 1.1 什么是函数

函数是一段带有名字、能够完成特定任务的代码。定义函数后，可以在不同位置重复调用。

**在 ROS 2 中的作用：** 把过滤测距、计算速度、整理状态等工作分别写成函数，节点收到新数据后就可以重复调用。后续从模拟数据换成真实消息时，也能继续使用这些处理函数。

```python
def show_robot_name():
    print("robot_01")


show_robot_name()
```

- `def` 是定义函数的关键字。
- `show_robot_name` 是函数标识符。
- `()` 中放参数。
- `:` 表示函数代码块开始。
- 缩进内容是函数体。

定义函数不会自动执行函数体，调用 `show_robot_name()` 时才执行。

### 1.2 为什么使用函数

- 减少重复代码。
- 让每段代码只负责一个任务。
- 修改逻辑时只改一个位置。
- 方便测试和复用。
- 可以作为回调交给其他程序调用。

函数名应使用小写英文和下划线，并表达行为：

```python
filter_distances()
choose_action()
show_robot_status()
```

## 2. 参数与实参

### 2.1 形参与实参

**参数是函数接收外部数据的入口。** 定义函数时写的名称叫“形参”，调用时实际交给函数的值或对象叫“实参”，可以理解为先留好接收位置，再把本次要处理的数据放进去。

**在 ROS 2 中的作用：** 订阅回调通过函数参数接收消息，回调还可以把消息中的距离交给计算函数。这里的 Python 函数参数用于一次函数调用；ROS 2 节点参数则用于保存节点的配置，例如速度上限，两者用途不同。

```python
def show_distance(distance_m):
    print(f"{distance_m:.2f} m")


show_distance(0.55)
```

- `distance_m` 是定义函数时使用的形参。
- `0.55` 是调用函数时传入的实参。
- 调用时，形参在本次函数调用中引用实参对应的对象。

### 2.2 位置参数

位置参数是按传入顺序与形参对应的实参。

**在 ROS 2 中的作用：** 节点调用距离计算函数时，可以依次传入速度和时间；理解顺序能避免把两个数值含义弄反。

```python
def calculate_distance(speed_mps, duration_s):
    return speed_mps * duration_s


result = calculate_distance(0.30, 10.0)
```

本例中，`0.30` 给 `speed_mps`，`10.0` 给 `duration_s`。

### 2.3 关键字参数

关键字参数是在调用时写出“参数名=值”，明确说明把数据交给哪个形参。

**在 ROS 2 中的作用：** 节点调用包含多个设置的处理函数时，写出参数名能让速度、时间、阈值等数据的用途更清楚。

```python
result = calculate_distance(
    duration_s=10.0,
    speed_mps=0.30,
)
```

使用参数名时，以上两个实参的顺序可以调整。参数名写错会产生 `TypeError`。

### 2.4 默认参数

默认参数是预先设置了默认值的形参，调用时可以省略对应实参。

**在 ROS 2 中的作用：** 可以为节点内部的状态显示或数据处理函数提供常用默认值，减少重复传值；需要不同设置时，再明确传入。

```python
def show_status(name, speed_mps=0.0):
    print(name, speed_mps)
```

调用时没有传入 `speed_mps`，就使用默认值：

```python
show_status("robot_01")
```

有默认值的普通参数通常放在没有默认值的参数后面。

### 2.5 可变默认参数问题

默认参数在函数定义时创建一次。把列表作为默认值，可能在多次调用之间保留数据：

```python
def add_distance(value, data=[]):
    data.append(value)
    return data
```

推荐使用 `None`：

```python
def add_distance(value, data=None):
    if data is None:
        data = []
    data.append(value)
    return data
```

这样省略 `data` 时，每次调用都会创建新列表。

**在 ROS 2 中的作用：** 回调会反复调用数据处理函数，使用 `None` 作为默认值可以避免不同次处理意外共用同一份列表，导致旧测距混入新结果。

### 2.6 `*args`

`*args` 接收数量不固定的位置参数，在函数内部得到元组。

**在 ROS 2 中的作用：** 节点内部的辅助函数可以用它接收多个测距值，装饰器也可以用它把位置参数继续传给原函数。回调需要接收哪些参数，仍要符合注册回调时的调用规则。

```python
def average_distance(*distances_m):
    return sum(distances_m) / len(distances_m)


average_distance(1.20, 0.80, 0.40)
```

星号表达“收集多个位置参数”。`args` 只是常用名称，可以换成更有意义的名称。

调用时，星号还可以展开序列：

```python
values = [1.20, 0.80, 0.40]
result = average_distance(*values)
```

### 2.7 `**kwargs`

`**kwargs` 接收数量不固定的关键字参数，在函数内部得到字典。

**在 ROS 2 中的作用：** 可以给节点内部的状态整理函数传入电量、速度等命名数据，或在包装函数中转交命名参数。这些 Python 字典项不会自动变成 ROS 2 节点参数。

```python
def show_robot(**state):
    print(state)


show_robot(name="robot_01", battery=85)
```

双星号表达“收集多个命名参数”。调用时也可以展开字典：

```python
state = {"name": "robot_01", "battery": 85}
show_robot(**state)
```

## 3. 返回值

**返回值是函数处理完后交还给调用者的结果。** 调用者可以把它保存到变量中，再用于判断、计算或其他操作。

**在 ROS 2 中的作用：** 距离处理函数可以返回建议速度，节点再把速度写入消息并调用发布者发送。`return` 本身不会发布消息，订阅回调的返回值也不会自动变成发给其他节点的响应。

### 3.1 return 关键字

`return` 把结果交给调用者，并立即结束本次函数调用：

```python
def choose_action(distance_m):
    if distance_m <= 0.40:
        return "停车"
    return "前进"
```

第一个 `return` 执行后，函数后面的代码不会继续执行。

### 3.2 没有写 return

函数没有执行到 `return` 时，默认返回 `None`：

```python
def show_name():
    print("robot_01")


result = show_name()
print(result)  # None
```

### 3.3 print 与 return

```python
def show_value(value):
    print(value)


def give_value(value):
    return value
```

- `print()` 面向终端显示。
- `return` 面向后续程序处理。

只打印而不返回，调用者通常无法直接继续使用该结果计算。

### 3.4 多返回值

多返回值是一次交还多个结果的写法；在下面的例子中，函数实际返回一个包含三项数据的元组。

**在 ROS 2 中的作用：** 测距分析函数可以一起返回有效数据、最近距离和建议速度，供节点分别记录状态、显示结果和准备控制消息。

```python
def get_state():
    return "robot_01", 85, 0.30


name, battery, speed_mps = get_state()
```

多个返回值会组成元组，再由多个变量解包。变量数量不匹配会产生 `ValueError`。

## 4. 作用域与 LEGB

### 4.1 什么是作用域

作用域决定一个名称可以在哪些位置被访问。函数会创建局部作用域。

**在 ROS 2 中的作用：** 回调内部临时计算的最近距离属于局部数据，其他函数不能直接通过该局部变量名读取它。需要跨多次回调保留的状态，可以在后续学习类时保存为节点对象的属性。

```python
def calculate():
    result = 3.0
    print(result)
```

`result` 是局部变量，通常不能在函数外直接使用。

### 4.2 LEGB 查找顺序

LEGB 是 Python 查找名称时所用的四层顺序，可以理解为先在身边找，再逐层向外找。

**在 ROS 2 中的作用：** 阅读节点代码时，能判断回调里的名称来自函数内部还是模块外层，排查“明明改了阈值，计算结果却没变”等同名变量问题。

Python 使用名称时，按以下顺序查找：

1. `L`：Local，当前函数局部作用域。
2. `E`：Enclosing，外层函数作用域。
3. `G`：Global，当前模块的全局作用域。
4. `B`：Built-in，Python 内置作用域。

```python
robot_name = "robot_01"


def show_name():
    robot_name = "local_robot"
    print(robot_name)


show_name()       # local_robot
print(robot_name) # robot_01
```

局部名称会优先于同名全局名称。

### 4.3 global 关键字

在函数中给名称赋值时，默认创建或修改局部名称。`global` 声明要修改模块全局名称：

```python
count = 0


def update_count():
    global count
    count += 1
```

过多修改全局变量会让数据来源难以追踪。常规计算优先使用参数和返回值。

**在 ROS 2 中的作用：** 阅读用全局变量累计消息数量的简单示例时，能理解回调如何修改计数；后续编写节点类时，通常把这类计数保存在节点对象中，便于区分不同节点的状态。

### 4.4 nonlocal 关键字

`nonlocal` 用于内层函数修改外层函数中的名称：

```python
def make_counter():
    count = 0

    def update():
        nonlocal count
        count += 1
        return count

    return update
```

这是闭包相关语法，当前以理解为主。

**在 ROS 2 中的作用：** 如果辅助函数生成了一个记住调用次数的回调，`nonlocal` 可以让这个回调更新外层函数的计数。当前先看懂这种写法，基础节点示例中的计数也可以用对象属性保存。

### 4.5 Python 作用域与 ROS 2 命名空间

Python 作用域决定变量名在代码中的可见范围。ROS 2 命名空间用于组织节点、话题和服务名称。二者不是同一个概念。

**在 ROS 2 中的作用：** Python 作用域帮助管理代码中的变量，ROS 2 命名空间帮助区分不同机器人或功能下的通信名称；修改话题所属的命名空间不会改变 Python 的变量查找规则。

## 5. 函数对象

**函数对象就是可以被保存、传递并调用的函数本身。** 函数定义完成后，函数名引用这个对象；写函数名是取到函数，写函数名加括号才是执行函数。

**在 ROS 2 中的作用：** 创建定时器或订阅者时，需要把对应的处理函数交给 ROS 2，供它之后调用。因此注册回调时传入函数本身，而不是提前执行后得到的结果。

```python
def show_distance(distance_m):
    print(distance_m)


callback = show_distance
callback(0.55)
```

函数可以：

- 赋值给变量。
- 放入列表或字典。
- 作为实参传给另一个函数。
- 由另一个函数返回。

判断对象是否可调用：

```python
print(callable(show_distance))  # True
```

## 6. 回调函数

### 6.1 什么是回调

回调是先交给其他代码、在特定时机由对方调用的函数。

**在 ROS 2 中的作用：** 订阅回调用于处理收到的消息，定时器回调用于定期输出状态或发布数据。节点先注册这些函数，再由执行器在相应事件准备好时调度它们。

```python
def sensor_simulator(distances_m, callback):
    for distance_m in distances_m:
        callback(distance_m)
```

`sensor_simulator` 保存调用规则，具体处理方式由 `callback` 决定。

### 6.2 传递函数与调用函数

```python
sensor_simulator(data, show_distance)
```

传递 `show_distance` 函数本身。

```python
sensor_simulator(data, show_distance())
```

这会先立即调用 `show_distance()`，而且缺少参数，通常直接产生 `TypeError`。即使函数不需要参数，传进去的也会是它的返回值，而不是函数本身。

### 6.3 回调参数必须匹配

模拟器调用：

```python
callback(distance_m)
```

回调就应能够接收一个参数：

```python
def show_distance(distance_m):
    print(distance_m)
```

参数数量不匹配会在回调真正执行时产生 `TypeError`。

**在 ROS 2 中的作用：** 第六单元的订阅回调接收消息参数，而基础定时器回调不接收消息参数；把普通函数改成回调时，需要先看清它会收到哪些实参。

### 6.4 普通回调与 ROS 2 回调

普通模拟程序由我们自己写的函数直接调用回调。ROS 2 中，执行器等待消息、定时器等事件准备好，再调度对应回调。

```python
self.create_timer(1.0, self.timer_callback)
```

这里传入 `self.timer_callback`，没有加括号。

## 7. lambda 匿名函数

**`lambda` 用来创建只包含一个表达式的简短函数，不需要用 `def` 为函数命名。** 表达式的计算结果就是返回值，也可以把得到的函数保存到变量中。

**在 ROS 2 中的作用：** 节点内部对一组测距记录排序时，可以用 `lambda` 指定按距离字段比较；只有一步的小转换也适合这种写法。处理完整消息的回调通常用 `def`，便于阅读和排错。

```python
double_value = lambda value: value * 2
print(double_value(0.30))
```

大致对应：

```python
def double_value(value):
    return value * 2
```

`lambda` 只适合简单表达式。复杂逻辑使用有名称的 `def`，更容易解释和排错。

## 8. 可迭代对象与迭代器

### 8.1 可迭代对象

能够逐项遍历的对象称为可迭代对象，例如列表、元组、字符串、字典和 `range`。

**在 ROS 2 中的作用：** 节点拿到一组测距数据后，可以用 `for` 逐项检查并筛选；理解可迭代对象，也能让处理函数接收列表等不同形式的数据来源。

```python
for distance_m in [1.20, 0.80]:
    print(distance_m)
```

### 8.2 迭代器

**迭代器是记住“当前取到哪里”、能够逐次提供下一个元素的对象。** 可迭代对象提供数据来源，迭代器负责按顺序取数据。

**在 ROS 2 中的作用：** 编写测距数据回放或分步处理工具时，可以每次从迭代器中取一条记录，并在取完后结束处理；普通批量筛选通常直接使用 `for` 即可。

`iter()` 从可迭代对象获得迭代器，`next()` 逐项取值：

```python
iterator = iter([1.20, 0.80])

print(next(iterator))
print(next(iterator))
```

数据取完后继续调用 `next()` 会产生 `StopIteration`。`for` 循环会自动处理这一过程。

## 9. 生成器

**生成器是一种按需产生数据的迭代器，取到下一项时才继续执行产生数据的代码。** 可以把它理解成需要一条就提供一条的数据来源，而不是先准备好整个列表。

**在 ROS 2 中的作用：** 可以逐条产生模拟传感器读数，或逐条读取记录交给与节点共用的处理函数，减少一次保存大量数据的需要。生成器负责提供 Python 数据，消息的发送和回调调度仍由相应 ROS 2 代码完成。

### 9.1 yield 关键字

只要函数体中使用 `yield`，调用该函数通常会得到生成器对象：

```python
def generate_distances():
    yield 1.20
    yield 0.80
    yield 0.40
```

`yield` 产生一个值并暂停函数；下一次取值时，从暂停位置继续。

### 9.2 生成器的使用

```python
for distance_m in generate_distances():
    print(distance_m)
```

生成器适合：

- 按需逐条产生数据。
- 避免一次创建很大的列表。
- 表示连续的数据处理流程。

生成器的 `yield` 与 ROS 2 的异步执行不是同一个概念。

### 9.3 return 与 yield 的区别

- `return` 返回结果并结束普通函数。
- `yield` 产生一个值并暂停生成器。
- 生成器可以多次产生值。

## 10. 装饰器

### 10.1 什么是装饰器

**装饰器是一种给函数增加附加行为的工具。** 本节的装饰器接收原函数，返回包装后的函数；调用新函数时，会先后执行附加操作和原来的处理逻辑。

**在 ROS 2 中的作用：** 可以给节点的数据处理函数统一增加调用记录或耗时统计，帮助观察某段处理花了多长时间。包装函数需要继续传入原参数，并保留原函数需要交还的返回值。

```python
def log_call(func):
    def wrapper(*args, **kwargs):
        print(f"开始：{func.__name__}")
        result = func(*args, **kwargs)
        print(f"结束：{func.__name__}")
        return result

    return wrapper
```

使用：

```python
@log_call
def choose_action(distance_m):
    return "停车" if distance_m <= 0.40 else "前进"
```

`@log_call` 大致等价于：

```python
choose_action = log_call(choose_action)
```

### 10.2 装饰器的用途

- 记录函数调用。
- 统计运行时间。
- 检查权限或参数。
- 在不修改核心函数主体的情况下增加通用行为。

本单元要求能够看懂基本包装过程，不要求编写复杂装饰器。

## 11. 类型注解

**类型注解是写在变量、参数或返回值旁边的类型说明。** 它告诉读者这里预期使用什么数据，例如浮点数、字符串或浮点数列表。

**在 ROS 2 中的作用：** 给订阅回调的消息参数和处理函数的输入、输出加上注解，可以帮助读者和编辑器识别数据类型。注解只是 Python 代码中的说明，不会代替 ROS 2 消息格式或自动完成数据转换。

### 11.1 参数和返回值注解

```python
def choose_action(distance_m: float | None) -> str:
    if distance_m is None:
        return "等待数据"
    return "前进"
```

- `distance_m: float | None`：提示参数可以是浮点数或 `None`。
- `-> str`：提示返回字符串。

### 11.2 注解不会自动转换数据

```python
def show_speed(speed_mps: float) -> None:
    print(speed_mps)
```

类型注解主要服务于阅读、编辑器和静态检查工具。Python 默认不会仅凭注解自动把字符串转换成浮点数。

### 11.3 常用注解

```python
name: str
battery: int
speed_mps: float
enabled: bool
distances_m: list[float]
position: tuple[float, float]
```

## 12. 本单元关键字详解

| 关键字 | 作用 | 注意 |
| --- | --- | --- |
| `def` | 定义函数或方法 | 定义后需要调用才执行 |
| `return` | 返回结果并结束函数 | 未执行到时默认返回 `None` |
| `yield` | 逐次产生生成器数据 | 会暂停并保留执行位置 |
| `lambda` | 创建简短匿名函数 | 只适合简单表达式 |
| `global` | 声明修改模块全局名称 | 常规逻辑尽量少用 |
| `nonlocal` | 声明修改外层函数名称 | 用于嵌套函数 |

本单元还会继续使用 `if`、`for`、`in`、`is`、`continue` 等上一单元关键字。

`callback`、`args`、`kwargs` 不是关键字，只是常用标识符。`@` 也不是关键字，它是装饰器语法符号。

## 13. 测距处理函数设计

**处理函数设计就是把一项任务拆成几个步骤，并明确每个函数接收什么、完成什么、返回什么。** 例如，把“检查距离”和“根据距离选择状态”分开，便于单独理解和修改。

**在 ROS 2 中的作用：** 订阅回调可以负责取出消息数据，再调用过滤和判断函数，最后记录结果或准备发布消息。这样同一套处理规则既能用于当前的模拟实验，也能接入后续节点。

推荐把任务分成职责单一的函数：

```text
filter_distance()   → 检查单个数据
choose_action()     → 根据距离返回状态
show_status()       → 输出结果
process_sensor_data() → 组织处理流程并调用回调
```

这样修改距离规则时，不需要改显示代码；更换输出方式时，也不需要改过滤规则。

## 14. 与 ROS 2 的联系

| Python 知识 | ROS 2 中的用途 |
| --- | --- |
| 函数 | 封装测距过滤、速度计算等可重复使用的处理步骤 |
| 形参与实参 | 让回调接收消息，让计算函数接收本次要处理的数据 |
| 位置参数与关键字参数 | 按顺序或名称把速度、时间等数据传给节点内部函数 |
| 默认参数 | 为辅助函数提供常用设置，避免反复填写相同实参 |
| 可变默认参数 | 避免反复处理消息时意外共用默认列表、混入旧数据 |
| `*args` 与 `**kwargs` | 在辅助函数中接收多个值，或在包装函数中继续传递参数 |
| 返回值与多返回值 | 把建议速度、最近距离等交给节点后续处理；不会自动发布消息 |
| 作用域与 LEGB | 区分回调局部数据和模块数据，排查同名变量问题 |
| `global` 与 `nonlocal` | 理解示例中如何更新外部计数，后续也可用节点属性保存状态 |
| ROS 2 命名空间 | 组织通信名称，与 Python 变量作用域分别理解 |
| 函数对象 | 把处理函数本身交给定时器或订阅者 |
| 回调函数与参数匹配 | 在消息到达或定时事件准备好后执行处理，并接收规定的实参 |
| `lambda` | 为节点内部的记录排序或简单转换提供短函数 |
| 可迭代对象 | 用循环逐项检查一组测距数据 |
| 迭代器 | 在数据回放或分步处理时逐条取出记录 |
| 生成器 | 按需提供模拟读数或记录，供处理函数使用 |
| 装饰器 | 给节点处理函数增加调用记录或耗时统计 |
| 类型注解 | 说明消息参数、计算输入与返回结果的预期类型 |
| 处理函数设计 | 把消息接收、数据处理与结果输出组织成清楚的步骤 |

ROS 2 预览：

```python
self.timer = self.create_timer(1.0, self.timer_callback)
```

`self.timer_callback` 是绑定到当前节点对象的回调方法，也属于可调用对象；写成 `self.timer_callback()` 会立即调用并把返回值传入，含义错误。

## 15. 常见错误速查

| 错误或现象 | 原因 | 正确思路 |
| --- | --- | --- |
| 函数没有执行 | 只定义，没有调用 | 添加 `function_name()` |
| 得到 `None` | 函数只打印，没有返回 | 使用 `return` 返回结果 |
| `TypeError` 参数数量错误 | 实参与形参数量不匹配 | 检查函数签名和调用位置 |
| 多次调用列表不断累积 | 使用可变默认参数 | 默认值改为 `None` |
| 函数外找不到变量 | 变量属于局部作用域 | 使用返回值传出 |
| 回调在注册时就执行 | 写成 `callback()` | 传入 `callback` |
| `next()` 出现异常 | 迭代器已经取完 | 使用 `for` 或处理 `StopIteration` |
| 生成器没有输出 | 只创建生成器，没有迭代 | 使用 `for` 或 `next()` |
| 装饰器后函数不返回结果 | 包装函数漏写 `return result` | 返回被包装函数结果 |
| 认为注解会自动检查类型 | 注解默认不强制运行时类型 | 仍需正确传值与验证 |
