# 第二单元知识点详解

## 容器、流程控制与传感器数据处理

本单元学习如何保存和处理多组机器人数据。核心任务是过滤无效测距值、找到最近障碍物，并生成“等待数据、停车、减速、前进”等模拟状态。

配套代码位于 [experiments](experiments) 文件夹，运行方式见文末的“配套代码与运行”，课后作业附在最后。

本单元会用“在 ROS 2 中的作用”说明各知识点的用途。可以先把“节点”理解成负责某项机器人功能的程序，把“消息”理解成节点之间传递的、具有规定格式的数据；收到消息后负责处理它的函数叫作“订阅回调函数”。这些概念会在第六单元展开。

## 1. 容器是什么

**容器是能够把多个数据组织在一起的对象。** 容器中保存的每一项通常称为“元素”。例如，把机器人连续三次测得的距离放在一起，就可以统一保存、查找和处理，而不用为每次测量单独起一个变量名。

第一单元主要使用单个变量：

```python
distance_1 = 1.20
distance_2 = 0.55
distance_3 = 0.32
```

数据较多时，可以使用容器集中保存：

```python
distances_m = [1.20, 0.55, 0.32]
```

Python 常用容器包括：

| 容器 | 写法 | 主要特点 | 机器人示例 |
| --- | --- | --- | --- |
| 列表 `list` | `[1.2, 0.5]` | 有顺序、可修改 | 多次测距 |
| 元组 `tuple` | `(1.5, 2.0)` | 有顺序、不可修改 | 固定坐标 |
| 字典 `dict` | `{"battery": 85}` | 使用键查找值 | 机器人状态 |
| 集合 `set` | `{101, 102}` | 数据不重复 | 错误码去重 |

## 2. 列表 list

**列表是 Python 中用来按顺序保存一组数据的容器，类型名称是 `list`。** 列表中的每一项叫作“元素”，可以通过元素的位置读取它，也可以在创建列表后增加、删除或修改元素。

可以把列表想成一张按记录顺序排列的测距记录表：第一项保存第一次测距，第二项保存第二次测距，后面还可以继续追加新的测距值。

列表有以下特点：

| 特点 | 含义 | 示例说明 |
| --- | --- | --- |
| 有顺序 | 元素有前后位置；“有序”不表示自动按大小排序 | `[1.20, 0.55]` 与 `[0.55, 1.20]` 的元素顺序不同 |
| 可修改 | 创建后可以增加、删除或替换元素 | 测到新的距离后，可以把它加入列表 |
| 允许重复 | 相同的值可以出现多次，每次都算一个元素 | `[0.55, 0.55]` 可以表示两次相同的测距结果 |
| 可以为空 | 暂时没有数据时，也可以先创建列表 | `[]` 表示有一个列表，但其中没有元素 |

当程序需要保存多次测量结果、依次处理一组数据，或不断添加新记录时，就可以使用列表。

**在 ROS 2 中的作用：** 节点收到激光雷达数据后，可以用列表保存筛选出的有效距离，再求最近障碍物距离。例如，[`LaserScan` 消息](https://github.com/ros2/common_interfaces/blob/jazzy/sensor_msgs/msg/LaserScan.msg) 的 `ranges` 字段包含一组距离数据，后续可以用这里学到的遍历和筛选方法处理。

### 2.1 创建列表

```python
distances_m = [1.20, 0.55, 0.32]
empty_data = []
```

这段代码中，`distances_m` 是变量名，右侧的 `[1.20, 0.55, 0.32]` 是一个列表。创建列表时用方括号 `[]` 包住元素，元素之间用逗号分隔。这个列表有 3 个元素，每个元素都是一个以米为单位的测距值。

对比 `distance_m = 1.20`，它保存的是一个浮点数；`distances_m = [1.20]` 保存的是一个只有 1 个元素的列表。即使只有一个元素，列表和单个数值也属于不同类型。

列表通常保存含义相同的一组数据。技术上可以混合不同类型，但机器人测量列表最好保持数据含义一致。

```python
raw_distances_m = [1.20, None, 0.55]
```

这里的 `None` 有明确含义：某次测量暂时无结果。

### 2.2 索引与切片

**索引是元素的位置编号，用来取出某一个元素；切片是按指定范围取出一段元素，得到一个新列表。**

列表索引从 0 开始：

```python
distances_m = [1.20, 0.55, 0.32]

print(distances_m[0])   # 1.2
print(distances_m[-1])  # 0.32
```

`distances_m[0]` 中的方括号表示按索引访问已有列表。索引 `0` 对应第一项，`1` 对应第二项，`2` 对应第三项；负数索引从末尾倒着数，`-1` 对应最后一项。这个列表只有 3 项，访问 `distances_m[3]` 会超出范围，产生 `IndexError`。

列表也支持切片：

```python
print(distances_m[0:2])  # [1.2, 0.55]
print(distances_m[1:])   # [0.55, 0.32]
print(distances_m[-2:])  # [0.55, 0.32]
```

常用正向切片包含开始位置，不包含结束位置。

### 2.3 增加数据

在末尾增加一个数据：

```python
distances_m.append(0.90)
```

在指定位置插入：

```python
distances_m.insert(1, 0.80)
```

一次加入多个数据：

```python
distances_m.extend([1.10, 1.30])
```

注意区别：

```python
data = [1.0]
data.append([2.0, 3.0])
print(data)  # [1.0, [2.0, 3.0]]
```

`append()` 把整个参数作为一项加入；`extend()` 把参数中的各项依次加入。

### 2.4 修改数据

```python
distances_m = [1.20, 0.55, 0.32]
distances_m[1] = 0.60
```

修改后：

```text
[1.2, 0.6, 0.32]
```

列表是可变对象，可以原地修改其中的数据。

### 2.5 删除数据

```python
distances_m = [1.20, 0.55, 0.32]

distances_m.remove(0.55)  # 删除第一个匹配值
last_value = distances_m.pop()  # 删除并返回最后一项
del distances_m[0]  # 按索引删除
distances_m.clear()  # 清空列表
```

注意：

- `remove(value)` 查找不到值会产生 `ValueError`。
- `pop()` 对空列表使用会产生 `IndexError`。
- 删除前应确认数据或索引是否存在。

### 2.6 常用列表操作

```python
distances_m = [1.20, 0.55, 0.32]

print(len(distances_m))  # 数量：3
print(min(distances_m))  # 最小值：0.32
print(max(distances_m))  # 最大值：1.2
print(sum(distances_m))  # 总和：2.07
```

平均值：

```python
if distances_m:
    average_distance_m = sum(distances_m) / len(distances_m)
```

空列表不能直接使用 `min()`、`max()`，计算平均值时也不能除以零，因此先判断列表是否有数据。

### 2.7 成员判断

```python
distances_m = [1.20, 0.55, 0.32]

print(0.55 in distances_m)      # True
print(None not in distances_m)  # True
```

`in` 判断数据是否存在，`not in` 判断数据是否不存在。

## 3. 元组 tuple

**元组是 Python 中按顺序保存一组数据、但创建后不能直接更改其中元素的容器，类型名称是 `tuple`。** 元组中的元素同样有位置编号，也允许重复值。

可以把元组想成一条已经确定各个位置含义的记录。例如，`(1.5, 2.0)` 可以约定第一项是机器人位置的 `x` 坐标，第二项是 `y` 坐标。元组本身不会自动给元素命名，这些含义由编写程序的人约定。

列表适合需要不断增删改的数据；元组适合表达一组不希望直接改动的记录，例如某一时刻的坐标快照。如果需要记录新的坐标，可以创建一个新元组，再把它赋给变量。

**在 ROS 2 中的作用：** 节点读取位置消息后，可以把其中的坐标取出，组成 `(x, y)` 元组，作为某一时刻的位置记录，方便传给计算距离等函数使用。这里的元组保存在 Python 程序内部；对外发送坐标时，需要填写相应 ROS 2 消息的字段。

### 3.1 创建元组

```python
robot_position = (1.5, 2.0)
```

元组有顺序，可以索引和切片：

```python
print(robot_position[0])
print(robot_position[-1])
```

### 3.2 元组不可修改

下面的代码会产生 `TypeError`：

```python
robot_position[0] = 2.0
```

元组适合表示创建后不希望直接修改的一组数据，例如某一时刻的坐标快照。

这里的“不可修改”指不能替换、增加或删除元组本身的元素。如果元组中的某个元素是列表，该列表内部的数据仍然可以修改；本节的坐标元组只包含数值，不涉及这种情况。

### 3.3 元组解包

```python
x, y = robot_position
print(x)
print(y)
```

变量数量应与元组中的数据数量一致。

### 3.4 单元素元组

```python
one_value = (1.20,)
```

逗号非常重要。`(1.20)` 只是加了括号的浮点数，不是元组。

## 4. 字典 dict

**字典是 Python 中通过“键—值”对应关系保存数据的容器，类型名称是 `dict`。** 每一项由一个键和它对应的值组成，称为“键值对”：键用来标识数据，值是实际保存的内容。

可以把字典想成一张机器人信息卡：标签“名字”对应 `"robot_01"`，标签“电量”对应 `85`。读取电量时，使用对应的键即可，不需要记住它是第几项。

字典中的键不能重复；给已有键赋值会更新对应的值。不同键对应的值可以相同，值也可以是不同类型。因此，字典适合把名称、电量、速度等含义不同的数据组织成一份机器人状态记录。

**在 ROS 2 中的作用：** 节点可以用字典集中保存最新的电量、速度和运行状态；每次收到新消息，就更新对应键的值。例如，收到新的电量数据后更新 `robot["battery"]`，供后续判断和日志输出使用。

### 4.1 键和值

字典使用键描述数据含义：

```python
robot = {
    "name": "robot_01",
    "battery": 85,
    "speed_mps": 0.30,
    "enabled": True,
}
```

创建字典时，用花括号 `{}` 包住键值对，用冒号 `:` 分隔每一项的键和值，用逗号分隔各项。例如，`"battery": 85` 中的 `"battery"` 是键，`85` 是值；`{}` 表示空字典。

读取数据：

```python
print(robot["name"])
print(robot["battery"])
```

列表通过位置访问，字典通过键访问。

### 4.2 增加和修改

```python
robot["battery"] = 80     # 修改已有键
robot["action"] = "前进"  # 增加新键
```

### 4.3 删除数据

```python
del robot["action"]
removed_value = robot.pop("battery")
```

如果键不存在，直接访问或删除可能产生 `KeyError`。

### 4.4 get 方法

```python
distance_m = robot.get("distance_m")
```

键不存在时，`get()` 默认返回 `None`。也可以设置默认值：

```python
action = robot.get("action", "等待数据")
```

如果 `None` 本身也是合法保存值，就需要另外判断键是否存在：

```python
print("distance_m" in robot)
```

### 4.5 遍历字典

```python
for key in robot:
    print(key)
```

同时获得键和值：

```python
for key, value in robot.items():
    print(key, value)
```

只遍历值：

```python
for value in robot.values():
    print(value)
```

### 4.6 字典键的要求

字典的键必须是可哈希对象。初学阶段常用字符串、整数作为键，不使用列表作为键。元组也可以作为键，但其中的所有元素都必须可哈希；例如，`(1, 2)` 可以作为键，包含列表的元组则不可以。

机器人状态字典推荐使用含义清楚的字符串键，并保持命名统一。

## 5. 集合 set

**集合是 Python 中用来保存不重复元素的容器，类型名称是 `set`。** 同一个值即使加入多次，集合中也只保留一份；集合可以增加或删除元素，但不能像列表一样通过索引读取第几项。

可以把集合想成一份“出现过的错误码名单”：错误码 `101` 出现三次，名单中仍然只记一个 `101`。因此，集合适合数据去重、判断某项是否存在，以及比较两组数据有哪些共同项或不同项。

集合不记录元素的位置顺序。如果需要保留每次故障发生的先后顺序和重复次数，应使用列表保存这些记录。

**在 ROS 2 中的作用：** 节点可以用集合记录已经出现过的错误码或设备名称。例如，同一错误码被多次上报时，只保留一份记录，并用 `in` 判断它是否已经出现过。

### 5.1 创建集合

```python
error_codes = {101, 102, 101, 103}
print(error_codes)
```

重复的 `101` 只保留一次。

创建空集合必须使用：

```python
error_codes = set()
```

`{}` 创建的是空字典。

### 5.2 增加和删除

```python
error_codes.add(104)
error_codes.remove(102)
error_codes.discard(999)
```

- `remove()` 找不到数据会产生 `KeyError`。
- `discard()` 找不到数据也不会报错。

### 5.3 集合运算

```python
current_errors = {101, 102}
known_errors = {101, 103}

print(current_errors & known_errors)  # 交集：共同存在
print(current_errors | known_errors)  # 并集：所有错误码
print(current_errors - known_errors)  # 差集：只在左侧存在
```

集合适合去重和成员判断，不适合依靠位置取值。集合显示顺序不应作为程序逻辑依据。

## 6. 可变对象、赋值与复制

**在 ROS 2 中的作用：** 节点处理测距列表时，有时需要保留处理前的数据，再修改副本。理解赋值与复制，可以避免两个变量引用同一个列表，导致修改处理结果时连原始记录也一起改变。

### 6.1 可变与不可变

| 类型 | 是否可变 |
| --- | --- |
| `int`、`float`、`bool` | 不可变 |
| `str`、`tuple` | 不可变 |
| `list`、`dict`、`set` | 可变 |

可变表示对象内容可以原地改变。

### 6.2 赋值不会自动复制列表

```python
data_a = [1.20, 0.55]
data_b = data_a

data_b.append(0.32)

print(data_a)
print(data_b)
```

两个变量都会显示：

```text
[1.2, 0.55, 0.32]
```

因为 `data_a` 和 `data_b` 引用同一个列表。

### 6.3 创建独立的浅复制

```python
data_b = data_a.copy()
```

也可以使用：

```python
data_b = data_a[:]
```

当列表只包含普通数值时，浅复制可以得到独立列表。

### 6.4 嵌套容器需要注意

```python
data_a = [[1.20, 0.55], [0.32]]
data_b = data_a.copy()
data_b[0].append(0.90)
```

外层列表不同，但内部列表仍可能被共同引用。处理复杂嵌套数据时，可以使用 `copy.deepcopy()`；本课程当前实验不需要复杂深复制。

## 7. 条件控制

**在 ROS 2 中的作用：** 节点需要根据收到的数据选择处理方式。例如，用 `if / elif / else` 判断障碍物距离，计算应当停车、减速还是前进，再将结果用于后续的控制消息。

### 7.1 if

```python
battery_percent = 85

if battery_percent > 20:
    print("电量充足")
```

条件为 `True` 时执行缩进代码。

### 7.2 if / else

```python
if battery_percent > 20:
    print("电量充足")
else:
    print("电量不足")
```

两个分支只会执行其中一个。

### 7.3 if / elif / else

```python
distance_m = 0.55

if distance_m <= 0.40:
    action = "停车"
elif distance_m <= 0.80:
    action = "减速"
else:
    action = "前进"
```

程序从上到下判断，执行第一个满足条件的分支，然后跳过其余分支。

### 7.4 判断顺序

距离规则应从更严格的范围开始：

```python
if distance_m <= 0.40:
    action = "停车"
elif distance_m <= 0.80:
    action = "减速"
```

如果先判断 `distance_m <= 0.80`，那么 0.30 也会首先满足该条件，从而错误地得到“减速”。

### 7.5 边界值

```python
distance_m <= 0.40
```

表示 0.40 也包含在停车范围内。`<` 与 `<=` 的选择会直接影响边界状态。

### 7.6 容器的真值

空容器在条件中视为假，非空容器视为真：

```python
valid_distances_m = []

if valid_distances_m:
    nearest_distance_m = min(valid_distances_m)
else:
    nearest_distance_m = None
```

这样可以避免对空列表调用 `min()`。

## 8. for 循环

**在 ROS 2 中的作用：** 一条传感器消息可能包含很多测量值，`for` 可以逐项检查。例如，遍历激光雷达的一组距离，筛选有效数据或查找近距离障碍物。

### 8.1 遍历列表

```python
distances_m = [1.20, 0.55, 0.32]

for distance_m in distances_m:
    print(distance_m)
```

循环依次把列表中的值赋给 `distance_m`。

### 8.2 循环变量

```python
for distance_m in distances_m:
    print(f"测距：{distance_m:.2f} m")
```

循环变量名应反映一项数据的含义。列表叫 `distances_m`，单项可以叫 `distance_m`。

### 8.3 range

```python
for number in range(3):
    print(number)
```

输出 `0`、`1`、`2`，不包含结束值 3。

常见写法：

```python
range(5)        # 0～4
range(2, 5)     # 2～4
range(0, 6, 2)  # 0、2、4
```

### 8.4 enumerate

同时获取序号和数据：

```python
for index, distance_m in enumerate(distances_m, start=1):
    print(f"第 {index} 次：{distance_m:.2f} m")
```

使用 `enumerate()` 通常比自己维护计数器更清楚。

### 8.5 zip

```python
directions = ["前", "左", "右"]
distances_m = [0.50, 1.20, 0.80]

for direction, distance_m in zip(directions, distances_m):
    print(direction, distance_m)
```

`zip()` 按相同位置配对。长度不同时，以最短的一组为准，多余数据不会进入循环。

## 9. while 循环

**在 ROS 2 中的作用：** `while` 可以用于需要按条件重复的处理，例如在限定次数内尝试读取设备。后续编写节点时，周期任务通常交给定时器；订阅回调中长时间运行的 `while` 可能拖延其他回调的执行。

条件为真时重复执行：

```python
battery_percent = 23

while battery_percent > 20:
    print(battery_percent)
    battery_percent -= 1
```

必须保证循环中的操作能让条件发生变化，否则可能形成无限循环：

```python
while True:
    print("不会自动结束")
```

处理已有容器通常优先使用 `for`；需要根据条件重复时考虑 `while`。

## 10. break 与 continue

**在 ROS 2 中的作用：** 逐项检查传感器数据时，`continue` 用于跳过无效测量；如果只需要判断“是否存在近距离障碍物”，找到一个后就可以用 `break` 结束本次搜索。`break` 只结束当前循环，不会自动停止节点或机器人。

### 10.1 continue

`continue` 跳过本次循环剩余代码，开始下一次循环：

```python
for distance_m in [1.20, None, -0.10, 0.32]:
    if distance_m is None or distance_m <= 0:
        continue
    print(distance_m)
```

### 10.2 break

`break` 立即结束当前循环：

```python
for distance_m in [1.20, 0.32, 0.90]:
    if distance_m <= 0.40:
        print("发现近距离障碍物")
        break
```

`continue` 只是跳过一轮，`break` 会离开整个循环。

## 11. 推导式

**在 ROS 2 中的作用：** 列表推导式可以简洁地筛选收到的测量数据；字典推导式可以把设备名称与对应状态整理成映射，方便节点后续按名称查询。

### 11.1 列表推导式

普通循环：

```python
valid_distances_m = []

for distance_m in raw_distances_m:
    if distance_m is not None and distance_m > 0:
        valid_distances_m.append(distance_m)
```

列表推导式：

```python
valid_distances_m = [
    distance_m
    for distance_m in raw_distances_m
    if distance_m is not None and distance_m > 0
]
```

阅读顺序：

1. 从 `raw_distances_m` 中逐个获得 `distance_m`。
2. 保留满足条件的数据。
3. 把保留的数据组成新列表。

复杂逻辑应使用普通循环，避免推导式难以阅读。

### 11.2 字典推导式

```python
distances_m = [1.20, 0.55, 0.32]

distance_map = {
    index: distance_m
    for index, distance_m in enumerate(distances_m, start=1)
}
```

结果：

```text
{1: 1.2, 2: 0.55, 3: 0.32}
```

## 12. 栈、队列与 deque

### 12.1 栈

栈遵循“后进先出”：最后加入的数据先取出。

**在 ROS 2 中的作用：** 如果节点需要保存操作历史、按相反顺序取出记录，可以使用栈。例如，先取出最近一次操作供程序检查或回退逻辑使用；取出记录本身不会让机器人自动执行反向动作。

```python
commands = []
commands.append("前进")
commands.append("停车")

latest_command = commands.pop()
print(latest_command)  # 停车
```

### 12.2 队列

队列通常遵循“先进先出”：最早加入的数据先取出。

**在 ROS 2 中的作用：** 节点可以把待处理任务放入队列，再按收到的先后顺序取出，例如依次处理设备检查请求。这里是程序自己维护的任务队列。

```python
from collections import deque

tasks = deque()
tasks.append("检查电量")
tasks.append("读取测距")

first_task = tasks.popleft()
print(first_task)  # 检查电量
```

### 12.3 保存最近 N 个数据

**在 ROS 2 中的作用：** 节点可以用 `deque(maxlen=N)` 缓存最近 N 次测距，便于计算近期平均值或观察变化；每次收到新数据时追加一项即可。

```python
from collections import deque

recent_distances_m = deque(maxlen=3)

recent_distances_m.append(1.20)
recent_distances_m.append(0.90)
recent_distances_m.append(0.70)
recent_distances_m.append(0.50)

print(recent_distances_m)
```

结果只保留最近三项：

```text
deque([0.9, 0.7, 0.5], maxlen=3)
```

超过最大长度后，最早的数据会自动移出。

## 13. 测距数据处理流程

**在 ROS 2 中的作用：** 本节流程可以作为后续订阅回调中的处理步骤：读取消息数据、过滤无效值、计算最近距离、更新节点状态，再由节点按需要发布处理结果。

### 13.1 原始数据

```python
raw_distances_m = [1.20, 0.55, None, -0.10, 0.32]
```

本课程约定：

- `None` 表示暂时无数据。
- 非正数在当前模拟中视为无效。
- 正数表示以米为单位的距离。

真实传感器的有效范围和特殊值必须查看设备说明，不能直接照搬这套教学规则。

### 13.2 过滤数据

```python
valid_distances_m = []

for distance_m in raw_distances_m:
    if distance_m is None or distance_m <= 0:
        continue
    valid_distances_m.append(distance_m)
```

### 13.3 找到最近距离

```python
if valid_distances_m:
    nearest_distance_m = min(valid_distances_m)
else:
    nearest_distance_m = None
```

### 13.4 生成模拟状态

```python
if nearest_distance_m is None:
    action = "等待数据"
elif nearest_distance_m <= 0.40:
    action = "停车"
elif nearest_distance_m <= 0.80:
    action = "减速"
else:
    action = "前进"
```

完整流程：

```text
原始测距列表
      ↓
循环读取每一项
      ↓
过滤无效数据
      ↓
寻找最近距离
      ↓
条件判断
      ↓
模拟运动状态
```

## 14. 与 ROS 2 的联系

下面汇总本单元知识点在 ROS 2 Python 节点中的用途。这些容器用于节点内部的数据组织；节点之间通过话题传递数据时，需要按消息类型创建消息对象并填写字段，再交给发布者发送。这个过程会在第六单元结合[官方 Python 发布者示例](https://github.com/ros2/examples/blob/jazzy/rclpy/topics/minimal_publisher/examples_rclpy_minimal_publisher/publisher_member_function.py) 展开。

| Python 知识 | ROS 2 中的用途 |
| --- | --- |
| 列表 `list` | 保存筛选后的测距值，便于后续统计和处理 |
| 元组 `tuple` | 保存从位置消息中取出的坐标，作为位置快照 |
| 字典 `dict` | 按名称保存并更新节点的电量、速度和运行状态 |
| 集合 `set` | 对上报的错误码或设备名称去重 |
| 索引与切片 | 读取一组传感器数据中的某一项或一段数据 |
| 增删改操作 | 加入新测量、更新状态、移除不再需要的记录 |
| `len / min / max / sum` | 统计有效测量数量、最近距离或平均距离 |
| `in / not in` | 判断某个设备或错误码是否已被记录 |
| 赋值与复制 | 需要修改数据时创建副本，保留原始记录 |
| `if / elif / else` | 根据距离阈值选择停车、减速或前进状态 |
| `for` | 逐项检查激光雷达等消息中的测量数据 |
| `range` | 按指定次数处理，例如检查固定数量的通道 |
| `enumerate` | 同时取得测量值和它在数据中的序号 |
| `zip` | 按位置配对已对应好的设备名称和测量值 |
| `while` | 按条件重复有限的处理；避免在回调中长时间占用执行线程 |
| `break` | 只需判断目标是否存在时，找到一个就结束搜索 |
| `continue` | 跳过无效测量，继续处理后面的数据 |
| 列表推导式 | 将符合条件的测量值组成新列表 |
| 字典推导式 | 整理设备名称与状态的对应关系 |
| 栈 | 保存操作历史，先取出最近加入的记录 |
| 队列 | 按收到的顺序处理节点内部的待办任务 |
| `deque(maxlen=N)` | 缓存最近 N 次测量，供平均值或趋势分析使用 |

ROS 2 预览：

```python
for distance_m in msg.ranges:
    if distance_m <= 0:
        continue
    print(distance_m)
```

这里假设 `msg` 是订阅回调收到的 `LaserScan` 消息，`msg.ranges` 是其中的一组距离数据，可以直接遍历，也可以用 `list(msg.ranges)` 创建 Python 列表用于本地处理。上面的片段只演示遍历和跳过数据；实际使用时还要检查无穷大、非数字值和消息中的有效量程限制，后续 ROS 2 课程再结合[消息定义](https://github.com/ros2/common_interfaces/blob/jazzy/sensor_msgs/msg/LaserScan.msg) 处理。

## 15. 本单元关键字速查

| 关键字 | 作用 | 示例 |
| --- | --- | --- |
| `if` | 条件为真时执行代码 | `if distance_m <= 0.4:` |
| `elif` | 前面条件不成立时继续判断 | `elif distance_m <= 0.8:` |
| `else` | 前面条件都不成立时执行 | `else:` |
| `for` | 依次遍历容器中的数据 | `for value in values:` |
| `while` | 条件为真时重复执行 | `while battery > 20:` |
| `break` | 立即结束当前循环 | 找到近距离障碍物后停止搜索 |
| `continue` | 跳过本轮循环 | 跳过 `None` 或无效数据 |
| `in` | 判断成员存在，或配合 `for` 遍历 | `None in values` |
| `is` | 判断是否为同一对象 | `value is None` |
| `not` | 对条件取反 | `value is not None` |
| `del` | 删除名称或容器项目 | `del values[0]` |
| `from` | 指定模块来源 | `from collections import deque` |
| `import` | 导入模块中的内容 | `import deque` 是上一行的一部分 |

关键字后面的冒号表示一个代码块即将开始。代码块内部必须统一缩进：

```python
if distance_m <= 0.40:
    action = "停车"
```

`range`、`enumerate`、`zip`、`len`、`min`、`max`、`sum` 不是关键字，它们是 Python 提供的内置名称。`append`、`remove`、`items` 等是对象的方法。关键字、内置函数和方法的使用形式不同。

## 16. 常见错误速查

| 问题 | 原因 | 处理思路 |
| --- | --- | --- |
| `IndexError` | 索引超出列表范围 | 检查 `len()` 和索引 |
| `KeyError` | 字典中不存在该键 | 检查键名或使用 `get()` |
| `ValueError` | `remove()` 找不到值 | 删除前使用 `in` 判断 |
| `TypeError` | `None` 与数值直接比较 | 先判断 `is None` |
| `min()` 报错 | 列表为空 | 先使用 `if valid_data` |
| 修改副本时原列表也变化 | 两个变量引用同一列表 | 使用 `copy()` 创建独立列表 |
| 0.30 被判断为减速而不是停车 | 条件顺序或边界规则错误 | 从严格范围开始判断 |
| 无限循环 | `while` 条件一直为真 | 在循环中更新条件或使用 `break` |
| 数据漏处理 | `zip()` 两组数据长度不同 | 先确认长度和配对关系 |
| 集合输出顺序变化 | 集合不依靠固定顺序 | 不使用集合位置表达业务含义 |
