# 面向 ROS 2 的 Python 编程基础——讲课大纲

## 一、课程定位

本课程覆盖图片中的 Python 知识点，以机器人状态、传感器数据和运动控制为案例，为后续 ROS 2 Python 编程课程做准备。

**课程目标：**学生学完后，能够看懂 ROS 2 Python 节点代码，理解类、回调函数和模块导入，并具备编写简单节点的 Python 基础。

ROS 2 官方示例中的 `Node` 继承、成员变量和定时器回调，可以作为本课程的衔接目标。参考：[ROS 2 官方 Python 节点示例](https://github.com/ros2/examples/blob/rolling/rclpy/topics/minimal_publisher/examples_rclpy_minimal_publisher/publisher_member_function.py)。

## 二、课时安排

建议安排 **6 个教学单元，共 24 小时**，每单元包含约 3 小时讲解与演示、1 小时练习。前五单元主要使用普通 Python，第六单元衔接 ROS 2。

**授课材料与方式：**每个单元使用一份「知识点详解」，按“讲解概念 → 运行示例 → 学生修改练习”的节奏推进。运行说明已并入讲义，课后作业附在各单元末尾，包含任务要求、完成标准与提交内容。材料入口见[课程文档索引](课程文档索引.md)。

| 教学单元 | 主题 | 讲解与演示 | 课堂练习 | 合计 |
| --- | --- | --- | --- | --- |
| 第一单元 | Python 基础语法与机器人数据表示 | 3 小时 | 1 小时 | 4 小时 |
| 第二单元 | 容器、流程控制与传感器数据处理 | 3 小时 | 1 小时 | 4 小时 |
| 第三单元 | 函数、作用域与回调思维 | 3 小时 | 1 小时 | 4 小时 |
| 第四单元 | 模块组织、文件操作与运行环境 | 3 小时 | 1 小时 | 4 小时 |

## 三、教学内容

### 第一单元：Python 基础语法与机器人数据表示

**对应图片：**基础语法、数据类型转换、运算符、字符串。

#### 1. 讲授知识点

- Python 程序的运行方式：交互式环境、`.py` 文件、终端运行。
- 缩进、注释、变量命名和赋值。
- 基本类型：`int`、`float`、`bool`、`str`，以及 `None`。
- 类型查看与转换：`type()`、`int()`、`float()`、`str()`。
- 算术、比较、逻辑和赋值运算符；运算优先级。
- 字符串索引、切片、常用方法和 f-string 格式化输出。

#### 2. 机器人案例

用变量表示机器人名称、电量、速度和运行状态；完成角度与弧度换算、速度单位换算，输出状态信息。

#### 3. ROS 2 衔接

为理解消息字段和参数值打基础，特别关注整数、浮点数、字符串的区别。

#### 4. 课堂练习

生成一条格式清晰的机器人状态信息，例如：

```text
robot_01：电量 85%，速度 0.30 m/s
```

### 第二单元：容器、流程控制与传感器数据处理

**对应图片：**列表、元组、字典、集合、条件控制、循环语句、推导式、数据结构。

#### 1. 讲授知识点

- 列表：创建、索引、切片、增删改查和遍历。
- 元组：不可变性、打包与解包。
- 字典：键值对、查询、更新和遍历。
- 集合：去重、成员判断、交集和并集。
- 可变与不可变对象；赋值与复制的区别。
- 条件判断：`if / elif / else`。
- 循环：`for`、`while`、`break`、`continue`。
- 常用遍历工具：`range()`、`enumerate()`、`zip()`。
- 列表和字典推导式。
- 数据结构的选择：用列表保存测量值、用字典组织状态；了解栈与队列，演示 `deque`。

#### 2. 机器人案例

用列表保存一组测距数据，用元组表示坐标，用字典记录机器人状态，根据最近障碍物距离判断是否停车。

#### 3. ROS 2 衔接

为处理传感器消息中的数组、组织节点内部状态做准备。这里的列表和字典用于本地数据处理；ROS 2 通信时仍需使用对应的消息类型。

#### 4. 课堂练习

过滤无效测距值，求最近障碍物距离，并输出“前进、减速、停车”的判断结果。

### 第三单元：函数、作用域与回调思维

**对应图片：**函数、命名空间和作用域、迭代器与生成器、装饰器。

#### 1. 讲授知识点

- 函数定义、调用、参数和返回值。
- 位置参数、关键字参数、默认参数；了解 `*args`、`**kwargs`。
- 多返回值与解包；避免使用可变对象作为默认参数。
- 局部变量、全局变量和 LEGB 名称查找规则。
- 函数也是对象：可以赋值，也可以作为参数传递。
- **重点区分：`callback` 是传递函数，`callback()` 是立即调用函数。**
- 可迭代对象、迭代器、`iter()`、`next()`。
- 生成器和 `yield`：按需产生数据。
- 装饰器：理解函数包装与 `@` 语法，能够看懂简单示例。

#### 2. 机器人案例

将距离过滤、速度计算、状态输出拆成函数；编写一个接收“处理函数”的模拟传感器程序。

#### 3. ROS 2 衔接

理解为什么创建定时器或订阅者时，需要传入回调函数，以及回调参数如何接收消息。

#### 4. 课堂练习

实现 `compute_speed(distance)`，再把它接入模拟数据处理流程。

#### 5. 教学重点

主要时间留给**函数和回调**；生成器、装饰器以理解和阅读为主。

### 第四单元：模块组织、文件操作与运行环境

**对应图片：**模块、输入与输出、File 文件操作、OS 文件/目录方法、`with` 关键字。

**建议补充：**异常处理。

#### 1. 讲授知识点

- `import`、`from ... import ...`、模块别名。
- 模块与包的区别，认识 `__init__.py`。
- 程序入口：`main()` 与 `if __name__ == '__main__':`。
- `print()`、`input()`，认识命令行参数。
- 文件读写模式、编码、逐行读取。
- `with open(...)` 与资源自动释放。
- 相对路径、绝对路径和当前工作目录。
- 常用 `os` 操作，并介绍更便于组织路径的 `pathlib`。
- 用 JSON 或 CSV 保存配置、测量记录。
- **补充：**`try / except / finally`，处理文件不存在、输入格式错误等情况。

#### 2. 机器人案例

读取配置文件中的机器人名称、速度上限和停车距离，将测距结果保存到文件。

#### 3. ROS 2 衔接

认识一个节点文件如何导入其他模块，以及 Python 包、ROS 2 功能包与可执行入口的关系。

ROS 2 的 `ament_python` 包通过 `setup.py` 等文件组织安装和入口，后续正式讲功能包时再展开。参考：[ROS 2 官方包开发指南](https://docs.ros.org/en/jazzy/How-To-Guides/Developing-a-ROS-2-Package.html)。

#### 4. 课堂练习

将程序拆成配置读取、数据处理和主程序三个模块，配置缺失时给出明确提示。

### 第五单元：面向对象编程与机器人功能封装

**对应图片：**Python 面向对象编程。

#### 1. 讲授知识点

- 类与对象：定义类、创建实例。
- 初始化方法 `__init__()`。
- `self`、实例属性和实例方法。
- 实例属性与类属性的区别。
- 封装：把数据及其操作组织在一起。
- 继承、方法重写和 `super()`。
- 组合：一个机器人对象中包含传感器对象。
- 认识 `@property`、`@staticmethod`、`@classmethod`，以阅读理解为主。

#### 2. 机器人案例

定义 `Robot` 类，保存名称、速度和电量，提供更新状态、设置速度、停车等方法；再定义 `MobileRobot` 子类。

#### 3. ROS 2 衔接

为理解以下典型写法做准备：

| 典型写法 | 对应知识点 |
| --- | --- |
| `class RobotNode(Node):` | 继承节点类 |
| `super().__init__('robot_node')` | 初始化父类 |
| `self.speed` | 保存节点实例的状态 |
| `self.timer_callback` | 将实例方法作为回调传入 |

#### 4. 课堂练习

创建两个机器人实例，分别修改速度，验证各自的状态互不影响。

### 第六单元：从 Python 程序过渡到 ROS 2 节点

**对应图片：**ROS 2 Python 面向对象编程，并综合复习前五单元。

#### 1. 讲授知识点

- 普通 Python 程序与 ROS 2 Python 节点的代码结构。
- 认识 `rclpy`、`Node` 和消息类型的导入。
- 编写继承 `Node` 的节点类。
- 在初始化方法中设置状态、创建定时器。
- 定时器回调与订阅回调的基本形式。
- 消息对象的创建、字段赋值与读取。
- `get_logger().info()` 日志输出。
- 认识 `rclpy.init()`、`rclpy.spin()` 与退出清理。
- 理解执行器负责调度回调；在默认单线程执行方式下，长时间运行的回调会延迟其他回调。

#### 2. 课堂演示

将之前的机器人状态程序改造成节点，定时更新模拟电量并输出日志；教师进一步演示发布和订阅状态消息。

#### 3. 课堂练习

让学生修改节点名称、定时周期、实例属性和回调内容，并解释每处修改对应的 Python 知识。

#### 4. 达标要求与后续衔接

本单元以**读懂节点结构、完成简单修改**为达标要求。

话题、服务、动作、QoS 和执行器机制留到后续 ROS 2 课程系统讲解。

## 五、教学侧重点与易混淆概念

### 1. 优先掌握

- 基础类型、列表、字典、条件判断和循环。
- 函数参数、返回值、函数对象与回调。
- 模块导入与程序入口。
- 类、实例、`self`、继承和 `super()`。
- 基础文件操作和异常处理。

### 2. 以理解和阅读为主

- 迭代器与生成器。
- 装饰器的工作方式。
- 栈、队列等数据结构的基本用途。
- `@property`、`@staticmethod`、`@classmethod`。

### 3. 图片之外建议补充

| 补充内容 | 教学目的 | 建议安排 |
| --- | --- | --- |
| 异常处理 | 处理输入、配置和文件读写错误 | 第四单元 |
| 函数对象与回调 | 理解定时器、订阅者为什么接收函数 | 第三单元 |
| 程序入口 | 理解节点的 `main()` 与模块执行方式 | 第四单元 |
| 基础类型注解 | 提高函数签名与代码的可读性 | 第三单元穿插介绍 |

### 4. 易混淆概念

- Python 的作用域与 ROS 2 的节点命名空间是不同概念。
- 生成器的 `yield` 不等于 ROS 2 的异步调用。
- 传递回调函数与立即调用函数是不同操作。
- Python 列表、字典用于本地数据组织，ROS 2 通信需使用对应的消息类型。

## 六、课程验收

1. **函数任务：**独立完成测距数据处理函数，能过滤无效数据并返回结果。
2. **面向对象任务：**编写带状态的机器人类，正确使用实例属性和实例方法。
3. **ROS 2 衔接任务：**读懂并修改一个简单的 ROS 2 Python 节点，能解释继承、初始化、回调和程序入口。
