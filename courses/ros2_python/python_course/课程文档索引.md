## 使用顺序

```text
课堂：知识点讲解 → 运行示例 → 学生修改练习
课后：回顾知识点 → 完成讲义末尾作业 → 对照完成标准检查
```

建议每个知识点按以下节奏展开：

1. **讲解概念**：结合机器人案例，说明这个知识点解决什么问题，再解释语法和规则。
2. **运行示例**：先让学生预测结果，再运行代码，对照输出解释关键语句。
3. **修改练习**：让学生改一个数值、条件或参数，观察结果并说明原因。
4. **检查理解**：结合常见错误提问；单元结束时布置讲义末尾的作业。

讲课时按小节停顿，把时间留给代码演示和学生操作。生成器、装饰器等内容按大纲以理解和阅读为主；单元结束时用知识点检查清单回顾。

第六单元需要 Ubuntu 24.04 与 ROS 2 Jazzy。前五单元使用普通 Python 3，不需要安装 ROS 2。
