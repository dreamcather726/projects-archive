# 第22课 编码器测速与测距

## 实验目标

用霍尔编码器统计电机脉冲，计算轮子转速和累计行驶距离。

## 需要的元器件

- ESP32-S3 开发板 1 块
- 带霍尔编码器的电机 1 个
- 电机驱动模块 1 个
- 杜邦线若干

## 接线

| 编码器 | ESP32-S3 引脚 |
| --- | --- |
| 信号 A | GPIO4 |
| VCC | 3.3V 或 5V |
| GND | GND |

如果编码器输出是 5V，建议加电平转换或分压后再接 ESP32-S3。

## 核心知识

- 编码器每转一圈会输出固定数量的脉冲。
- 使用外部中断计数，比普通轮询更不容易漏脉冲。
- 每秒新增的脉冲数可以换算成 RPM。
- 总脉冲数可以换算成轮子圈数，再乘以轮子周长得到距离。
- 单路编码器只能测速；AB 相编码器还可以判断方向。

## 实践项目

制作一个电机里程表：串口每秒输出一次电机 RPM 和累计行驶距离。
