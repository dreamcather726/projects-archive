# 第24课 电机速度开环控制

## 实验目标

用 PWM 控制一个直流减速电机的速度，观察电机从慢到快、从快到停的变化。

## 需要的元器件

- ESP32-S3 开发板 1 块
- TB6612 电机驱动模块 1 块
- 直流减速电机 1 个
- 电池盒或电机电源 1 组
- 杜邦线若干

## 接线

接线方式与第23课相同，只使用 TB6612 的 A 通道。

| TB6612 引脚 | ESP32-S3 引脚 |
| --- | --- |
| STBY | GPIO8 |
| AIN1 | GPIO9 |
| AIN2 | GPIO10 |
| PWMA | GPIO11 |
| VM | 电机电源正极 |
| VCC | 3.3V |
| GND | ESP32-S3 GND 和电机电源负极 |

## 核心知识

- PWM 不是直接改变电压，而是快速开关电机电源。
- PWM 数值越大，电机通常转得越快。
- PWM 太小时，电机可能只响不转，这个范围叫启动死区。
- `MIN_START_PWM` 用来补偿启动死区，让电机更容易转起来。
- 软启动是让 PWM 慢慢变大，避免电机突然冲起来。
- 软停止是让 PWM 慢慢变小，避免电机突然停下。
- 开环控制没有测速反馈，只能靠设定 PWM 估计速度。

## 调试方法

1. 先让电机架空，确认正转方向正确。
2. 修改 `MIN_START_PWM`，找到电机刚好能转起来的数值。
3. 修改 `TARGET_DRIVE_PWM`，观察不同 PWM 下电机速度变化。
4. 修改 `PWM_STEP`，观察加速和减速快慢。

## 实践项目

让一个电机反复执行软启动、稳定转动、软停止，并在串口观察当前 PWM。
