# 实验一 串口通信基础

## 实验目标

让 ESP32-S3 和电脑串口监视器互相发送数据，并增加一组额外串口，用来连接其他串口模块。

## 需要的元器件

- ESP32-S3 开发板 1 块
- USB 数据线 1 根
- USB 转 TTL 模块 1 个，可选
- 杜邦线若干

## 接线

电脑调试串口直接使用 USB 数据线，不需要额外接线。

如果测试额外串口，可以这样接：

| USB 转 TTL 模块 | ESP32-S3 引脚 |
| --- | --- |
| TXD | GPIO18 |
| RXD | GPIO17 |
| GND | GND |

TXD 要接对方 RX，RXD 要接对方 TX。不要把 5V 串口信号直接接到 ESP32-S3。

## 核心知识

- `Serial` 是 ESP32-S3 和电脑之间的 USB 调试串口。
- 串口监视器的波特率要设置为 `115200`。
- 额外串口使用 `HardwareSerial softSerial(1)`，并通过 `begin()` 指定 RX/TX 引脚。
- ESP32-S3 推荐使用这种新写法创建额外串口，比传统 `SoftwareSerial` 更稳定。
- 程序使用 `millis()` 定时输出状态，不会因为 `delay()` 卡住串口接收。

## 实践项目

打开 Arduino 串口监视器，输入文字或数字后按回车，观察 ESP32-S3 是否能原样返回。再连接 USB 转 TTL 模块，测试额外串口的数据收发。
