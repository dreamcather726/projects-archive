# 第23课 直流减速电机驱动原理

## 实验目标

用 TB6612 电机驱动模块控制一个直流减速电机，让电机完成正转、反转和停止。

## 需要的元器件

- ESP32-S3 开发板 1 块
- TB6612 电机驱动模块 1 块
- 直流减速电机 1 个
- 电池盒或电机电源 1 组
- 杜邦线若干

## 接线

| TB6612 引脚 | ESP32-S3 引脚 |
| --- | --- |
| STBY | GPIO8 |
| AIN1 | GPIO9 |
| AIN2 | GPIO10 |
| PWMA | GPIO11 |
| VM | 电机电源正极 |
| VCC | 3.3V |
| GND | ESP32-S3 GND 和电机电源负极 |
