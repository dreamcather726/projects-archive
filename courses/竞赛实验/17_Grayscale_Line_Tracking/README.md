# 第17课 灰度传感器与巡线检测

## 实验目标

用三路灰度传感器识别黑线位置，并输出小车应该直行、左转还是右转。

## 需要的元器件

- ESP32-S3 开发板 1 块
- 三路灰度传感器模块 1 个
- 黑色电工胶带或巡线地图 1 张
- 杜邦线若干

## 接线

| 传感器通道 | ESP32-S3 引脚 |
| --- | --- |
| 左路 AO | GPIO1 |
| 中路 AO | GPIO2 |
| 右路 AO | GPIO3 |
| VCC | 3.3V |
| GND | GND |

## 核心知识

- 灰度传感器通过红外反射强弱区分黑线和白底。
- 黑色反射弱，白色反射强，不同模块输出方向可能相反，需要先看串口数值。
- 阈值可以取黑线读数和白底读数的中间值。
- 三路传感器可以编码成二进制状态，例如 `010` 表示中间压线。

## 实践项目

做一个基础巡线判断程序：把传感器放在黑线正上方移动，观察串口输出的状态和动作。
