# 第26课 差速驱动机器人运动学

## 实验目标

理解左右轮速度和小车运动之间的关系，并用代码让小车走直线、原地转向和走弧线。

## 需要的元器件

- ESP32-S3 开发板 1 块
- TB6612 电机驱动模块 1 块
- 双电机小车底盘 1 套
- 电池盒或电机电源 1 组
- 杜邦线若干

## 接线

电机驱动接线与第23课相同。

## 核心知识

- 左右轮速度一样，小车走直线。
- 左右轮速度不一样，小车会转弯。
- 左右轮反向转，小车可以原地旋转。
- 轮距是左右轮中心之间的距离。
- 轮径决定轮子转一圈能走多远。
- 逆运动学：给定小车前进速度和转弯速度，计算左右轮速度。
- 正运动学：给定左右轮速度，估算小车实际前进和转弯速度。

## 实践项目

程序会依次演示：

1. 直线前进
2. 原地左转
3. 向右走弧线
4. 停止

串口会打印计算出来的左右轮目标速度。
