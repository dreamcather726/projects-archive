# 第25课 编码器电机闭环 PID 速度控制

## 实验目标

用编码器测量一个电机的速度，再用 PID 自动调整 PWM，让电机尽量稳定在目标速度。

## 需要的元器件

- ESP32-S3 开发板 1 块
- TB6612 电机驱动模块 1 块
- 带编码器的直流减速电机 1 个
- 电池盒或电机电源 1 组
- 杜邦线若干

## 接线

| 模块 | ESP32-S3 引脚 |
| --- | --- |
| TB6612 STBY | GPIO8 |
| 电机 AIN1/AIN2/PWMA | GPIO9/GPIO10/GPIO11 |
| 编码器 A 相 | GPIO4 |
