# 第19课 超声波测距 HC-SR04

## 实验目标

使用 HC-SR04 测量前方距离，并判断近距离障碍物。

## 需要的元器件

- ESP32-S3 开发板 1 块
- HC-SR04 超声波模块 1 个
- 杜邦线若干

## 接线

| HC-SR04 | ESP32-S3 引脚 |
| --- | --- |
| VCC | 5V |
| GND | GND |
| Trig | GPIO4 |
| Echo | GPIO5 |

如果 Echo 输出是 5V，建议加分压后再接 ESP32-S3。

## 核心知识

- Trig 给 10 微秒高电平，模块会发出超声波。
- Echo 高电平持续时间表示声音往返时间。
- 距离约等于 `时间 × 声速 / 2`。
- HC-SR04 常用范围约 2cm 到 400cm。
- 多个超声波模块不能同时测量，应该轮流触发，避免互相干扰。

## 实践项目

制作一个前方避障检测器：距离小于 25cm 时，在串口输出发现障碍物。
