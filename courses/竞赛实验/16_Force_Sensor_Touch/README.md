# 第16课 压力/力敏传感器

## 实验目标

用微动开关检测碰撞，用 FSR 力敏传感器读取压力大小，并用 LED 做简单保护提示。

## 需要的元器件

- ESP32-S3 开发板 1 块
- 微动开关 1 个
- FSR 力敏传感器 1 个
- 10k 电阻 1 个
- LED 1 个
- 杜邦线若干

## 接线

| 元器件 | ESP32-S3 引脚 |
| --- | --- |
| 微动开关一端 | GPIO4 |
| 微动开关另一端 | GND |
| FSR 分压输出点 | GPIO1 |
| LED | GPIO42 |

FSR 需要和 10k 电阻组成分压电路，再把中间点接到 ADC 引脚。

## 核心知识

- 微动开关只有按下和松开两种状态，适合做碰撞检测和边界保护。
- FSR 受力越大，电阻会变化，ADC 读数也会变化。
- 实际项目中先记录轻压、正常夹持、过压时的 ADC 数值，再设置阈值。
- 简单项目可以用轮询读取；需要快速响应时再使用中断。

## 实践项目

制作一个简单夹爪保护器：碰到边界或夹持力过大时点亮 LED，并在串口输出当前压力等级。
