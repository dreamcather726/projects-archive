# 第27课 多电机协调控制与精确运动

## 实验目标

用编码器控制小车行驶距离和转弯角度，让机器人执行一段简单路线。

## 需要的元器件

- ESP32-S3 开发板 1 块
- TB6612 电机驱动模块 1 块
- 带编码器的双电机小车底盘 1 套
- 电池盒或电机电源 1 组
- 杜邦线若干

## 接线

| 模块 | ESP32-S3 引脚 |
| --- | --- |
| TB6612 STBY | GPIO8 |
| 左电机 AIN1/AIN2/PWMA | GPIO9/GPIO10/GPIO11 |
| 右电机 BIN1/BIN2/PWMB | GPIO12/GPIO13/GPIO14 |
| 左编码器 A 相 | GPIO4 |
| 右编码器 A 相 | GPIO5 |

## 核心知识

- 复杂路径可以拆成多个小动作。
- 直线距离可以用轮子转过的圈数估算。
- 原地转 90 度时，左右轮走的距离大小相同、方向相反。
- 接近目标时降低 PWM，可以减少冲过头。
- 每一步完成后停一下，方便观察和调试。

## 实践项目

让机器人执行：

> 前进 50cm -> 右转 90 度 -> 前进 50cm

如果实测距离不准，先检查：

- `PULSES_PER_REVOLUTION`
- `WHEEL_DIAMETER_CM`
- `WHEEL_BASE_CM`
- 电机方向是否正确
