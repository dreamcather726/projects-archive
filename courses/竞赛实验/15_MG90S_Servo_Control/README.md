# 第15课 舵机控制 MG90S

## 实验目标

使用 ESP32-S3 控制 MG90S 舵机转到指定角度，理解舵机信号线、电源和共地接线方式。

## 需要的元器件

- ESP32-S3 开发板 1 块
- MG90S 舵机 1 个
- 外部 5V 电源 1 个
- 杜邦线若干
- USB 数据线 1 根
- Arduino 库：`ESP32Servo`

## 接线

| 舵机线 | 接法 |
| --- | --- |
| 棕色或黑色 GND | 外部电源 GND，并和 ESP32 GND 连在一起 |
| 红色 VCC | 外部 5V |
| 橙色或黄色信号线 | GPIO4 |

不要用 ESP32 的 3.3V 直接给舵机供电。
