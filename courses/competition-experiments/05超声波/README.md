# ESP32-S3 超声波测距课堂实验

本课程共 2 课时，每课时 45 分钟。课程使用 HC-SR04 超声波模块完成距离测量，
再搭配有源蜂鸣器制作一个具有三级报警速度的倒车雷达。

本组程序统一使用：

- TRIG：GPIO 12
- ECHO：GPIO 13
- 有源蜂鸣器：GPIO 21

## 学习目标

1. 理解超声波发射、反射和接收的测距过程。
2. 使用 `delayMicroseconds()` 产生 10 微秒触发脉冲。
3. 使用 `pulseIn()` 测量 ECHO 高电平持续时间。
4. 根据声速把回波时间换算为厘米距离。
5. 使用 `if` 按距离划分安全、注意、较近和危险区域。
6. 让有源蜂鸣器随障碍物距离缩短而加快报警。

### 第 1 课时后半：原理讲解（0.5 课时）

#### 超声波测距过程

1. ESP32-S3 向 TRIG 发送一个至少 10 微秒的高电平脉冲。
2. HC-SR04 发出一组约 40 kHz 的超声波。
3. 超声波遇到物体后反射回来。
4. 模块在 ECHO 引脚输出一段高电平，高电平时间表示声音往返所用时间。
5. ESP32-S3 测量这段时间并计算距离。

#### 距离计算公式

常温下声速约为 `343 m/s`，换算后约为 `0.0343 cm/us`：

```text
距离 = 回波时间 × 0.0343 ÷ 2
```

必须除以 2，因为超声波经历了“模块到物体”和“物体回到模块”两段路程。

例如 ECHO 高电平持续 `1000 us`：

```text
距离 = 1000 × 0.0343 ÷ 2 = 17.15 cm
```

#### `pulseIn()`

```cpp
unsigned long echoTime = pulseIn(PIN_ECHO, HIGH, 30000);
```

- 第一个参数：要测量的引脚。
- 第二个参数：要测量高电平还是低电平。
- 第三个参数：最长等待时间，单位为微秒。
- 返回值：目标电平持续的时间，单位为微秒。
- 超过 30 ms 仍未收到完整回波时返回 `0`，避免程序一直等待。

`pulseIn()` 在测量期间会等待脉冲完成，属于阻塞函数。基础实验中使用方便，后续需要
同时完成多个任务时，可以再学习中断或非阻塞测量方法。

#### 倒车雷达报警规则

| 测量距离 | 状态 | 有源蜂鸣器 |
|---:|---|---|
| 大于 100 cm | 安全 | 关闭 |
| 50～100 cm | 注意 | 慢速鸣叫 |
| 20～50 cm | 较近 | 快速鸣叫 |
| 小于或等于 20 cm | 危险 | 连续鸣叫 |
| 没有收到回波 | 测量失败 | 关闭，避免误报警 |

## HC-SR04 接线

经典 HC-SR04 模块通常使用 5V 供电，并且 ECHO 可能输出接近 5V。ESP32-S3 的 GPIO
只能承受 3.3V，因此 ECHO 不能直接连接 GPIO 13，必须先降压。

| HC-SR04 | 连接位置 | 说明 |
|---|---:|---|
| VCC | 5V | 按模块标注供电 |
| TRIG | GPIO 12 | ESP32-S3 向模块发送触发脉冲 |
| ECHO | GPIO 13 | 必须经过电阻分压或电平转换 |
| GND | GND | 与 ESP32-S3 共地 |

### ECHO 电阻分压

可使用 1kΩ 和 2kΩ 电阻组成分压：

```text
HC-SR04 ECHO ── 1kΩ ──┬── GPIO 13
                       │
                      2kΩ
                       │
                      GND
```

ECHO 为 5V 时，GPIO 13 处约为：

```text
5V × 2kΩ ÷ (1kΩ + 2kΩ) ≈ 3.33V
```

如果使用原生支持 3.3V ECHO 的其他超声波模块，应以该模块说明书为准。

## 有源蜂鸣器接线

| 有源蜂鸣器模块 | ESP32-S3 | 说明 |
|---|---:|---|
| IN | GPIO 21 | 控制响和停 |
| GND | GND | 与开发板共地 |
| VCC | 按模块标注 | 连接 3.3V 或 5V |

> 建议使用带驱动电路的有源蜂鸣器模块。工作电流较大的裸蜂鸣器不能直接由 GPIO
> 供电。少数模块为低电平触发，如果响停状态相反，需要交换代码中的 `HIGH` 和 `LOW`。

## 关键代码讲解

### 发送触发脉冲

```cpp
digitalWrite(PIN_TRIG, LOW);
delayMicroseconds(2);
digitalWrite(PIN_TRIG, HIGH);
delayMicroseconds(10);
digitalWrite(PIN_TRIG, LOW);
```

先输出短暂低电平可以让每次触发都从明确状态开始。

### 处理测量失败

```cpp
if (distance == 0) {
  Serial.println("未收到回波");
}
```

`pulseIn()` 超时返回 `0`，换算出的距离也为 `0`。主程序发现距离为 `0` 后关闭蜂鸣器。

## 影响测量结果的因素

- 障碍物太小或表面倾斜，超声波可能反射到其他方向。
- 海绵、布料等柔软材料会吸收超声波。
- 距离太近时，模块还没有结束发射就收到反射波，可能进入盲区。
- 多个超声波模块同时工作时会互相干扰。
- 温度会改变声速，要求较高时应进行温度补偿。
- 测量间隔太短时，上一束超声波的反射可能影响下一次结果。

## 常见问题

- **始终显示未收到回波：** 检查 VCC、GND、TRIG GPIO 12、ECHO GPIO 13 和分压接线。
- **距离总是不稳定：** 使用面积较大的平整障碍物，并让它正对传感器。
- **距离约为实际值的两倍：** 计算公式漏除了 2。
- **串口没有输出：** 检查端口，串口监视器波特率选择 `115200`。
- **蜂鸣器始终响：** 检查是否为低电平触发模块，以及 ECHO 是否有稳定测量值。
- **ESP32-S3 异常或发热：** 立即断电，检查是否把 5V ECHO 直接接入了 GPIO。
