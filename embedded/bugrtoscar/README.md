# bugrtoscar

基于 **STM32F407ZGT6、FreeRTOS 和 Keil MDK** 开发的四轮麦克纳姆底盘控制项目。

项目可以采集 JY61P IMU 数据，通过上位机发送控制命令，并使用串口控制多台 Emm_V5 闭环步进电机驱动器。

## 主要功能

### JY61P IMU 数据采集

- JY61P 的 USART3 固定使用 9600 波特率。
- 解析加速度、角速度、Roll、Pitch、Yaw、温度和版本信息。
- 校验传感器数据帧，并统计有效帧、校验错误和串口丢包数量。
- 支持静止状态下的 Yaw 漂移修正。
- 将 IMU 数据实时上报给电脑端软件。

### Emm_V5 电机控制

- 电机使能与失能。
- 速度模式控制。
- 相对位置和绝对位置控制。
- 单电机停止及全部电机紧急停止。
- 多电机同步运动。
- 当前位置清零和电机回零。
- 查询电压、电流、速度、位置、位置误差和运行状态等参数。

### 麦克纳姆轮底盘控制

- 支持前进、后退、左右横移和原地旋转。
- 支持平移与旋转组合运动。
- 自动完成 X 型麦克纳姆轮四轮速度分解。
- 对四轮速度统一缩放，避免单轮超速后改变合成运动方向。
- 四台电机确认命令后同步启动。
- 电机通信超时后自动重试，连续失败时取消本轮控制。
- 上位机失联 500 ms 后自动广播急停。

### 上位机通信

- 使用带 CRC16 校验的二进制串口协议。
- 支持链路测试、状态查询、单电机控制和整车控制。
- 主动上报 IMU 数据及电机回复。
- 提供 Python 图形化测试工具，可显示传感器数据、控制电机和发送紧急停止命令。

## 串口分配

| 用途 | STM32 串口 | 引脚 | 默认波特率 |
|---|---|---|---:|
| Windows/Linux 上位机 | USART1 | PA9 / PA10 | 115200 |
| 视觉模块预留接口 | USART2 | PA2 / PA3 | 115200 |
| JY61P IMU | USART3 | PB10 / PB11 | 9600 |
| Emm_V5 电机总线 | USART6 | PG14 / PG9 | 115200 |

## 软件特点

- 使用 FreeRTOS 分别调度控制任务和 IMU 数据任务。
- 串口采用 DMA 循环接收和中断发送。
- 任务、任务栈和内核对象全部静态分配。
- 应用层、板级驱动、设备驱动和通信协议分层组织。
- 提供 CRC 校验、参数检查、超时重试、栈溢出检测和串口错误统计。
- 使用独立看门狗，只有控制和数据任务都健康时才刷新。
- 串口半帧超时或异常长帧只复位对应解析器，不会导致整机停机。

## 编译

1. 使用 Keil MDK 5 打开 `otherWork/STM32F407ZGT6/STM32F407ZGT6.uvprojx`。
2. 使用 Arm Compiler 6 编译工程。
3. 将生成的固件下载到 STM32F407ZGT6 开发板。

也可以使用 VS Code 的 Keil Assistant 打开工程并按 `F7` 编译。

> 首次测试底盘时，请先架空车轮，确认四个电机的地址和正转方向正确，并确保紧急停止功能可用后再落地运行。
