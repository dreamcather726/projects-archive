# JY61P IMU 库

- 接口：USART3，PB10(TX) / PB11(RX)，固定 9600、8N1。
- 协议：WIT 标准串口协议，11 字节帧，帧头 `0x55`。
- 已解析：`0x51` 三轴加速度与温度、`0x52` 三轴角速度、`0x53` Roll/Pitch/Yaw 与版本号。
- 应用层收齐三类帧后，通过 PC 串口输出一行 ASCII 文本。
- 上电时显式开启陀螺仪自动校准：`FF AA 63 00 00`。模块静止时会自动估计角速度零偏，
  该命令不会执行 Yaw 归零。
- 上电时把 `0x2A` 加速度滤波寄存器设置为 `300`：`FF AA 2A 2C 01`。
- 配置前发送正确的小端解锁命令 `FF AA 69 88 B5`，命令间隔为 200ms。
- 上电打开加速度、角速度和姿态角输出：`FF AA 02 0E 00`。
- 不发送 Yaw 归零、保存或修改传感器波特率的命令；JY61P 必须预先配置为 9600。
- 滤波值越小抗振越强、实时性越低；官方建议根据环境在 `200~500` 间调试。
- STM32 端增加静止 Yaw 锁定：连续 20 组样本满足三轴角速度不超过 `2.5°/s` 且
  合加速度为 `0.90g~1.10g` 时，保持输出 Yaw 不变并吸收慢速积分漂移；检测到运动后
  自动解锁并保持角度连续。`STATUS` 中的 `YAW_LOCK=1` 表示静止锁定已经生效。

JY61P 是六轴模块，没有磁力计或其他绝对航向参考。Yaw 主要来自陀螺仪积分，因此
任何软件都不能同时“彻底消除漂移”并“准确识别无限慢的匀速旋转”。当前静止锁定适合
设备确实存在停稳阶段的场景；若必须长期测量绝对航向，应改用带磁力计的九轴模块，
或使用编码器、视觉、GNSS 等外部航向参考。

PC 串口使用 115200 8N1，输出示例：

```text
ACC[g]=0.000,0.000,1.000;GYRO[dps]=0.000,0.000,0.000;YPR[deg]=0.000,0.000,0.000;TEMP[C]=25.000;VER=18455
```

该输出供普通串口助手使用“文本/ASCII”模式查看，不再兼容需要 WIT 原始二进制帧的维特上位机。

PC 发送 `STATUS` 后会收到当前诊断数据，例如：

```text
STATUS IMU_BAUD=9600 YAW_LOCK=1 VALID=123 CHECKSUM=0 IMU_DROP=0 IMU_DMA=0 MOTOR_DROP=0 MOTOR_DMA=0
```

`IMU_BAUD` 始终报告 USART3 的固定配置值 9600。若 `VALID` 一直为 0，请检查
JY61P 自身是否也设置为 9600，以及供电、共地和 TX→PB11 接线。
