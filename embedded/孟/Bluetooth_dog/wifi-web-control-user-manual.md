# RobotDog WiFi 网页端控制说明书

版本：2026-07-16

本文档用于指导他人使用 `LeArm_ESP32_Arduino` 工程中的 RobotDog WiFi 网页上位机。网页上位机运行在 ESP32 上，电脑或手机和 ESP32 连接到同一个 WiFi 后，即可通过浏览器调整舵机中位、姿态参数、连续运动和动作记忆。

## 1. 功能概览

网页端支持以下功能：

- 查看 ESP32 的 WiFi 连接状态和控制地址。
- 调整 4 个腿部舵机的中位角度。
- 设置每条腿的前进方向，并分别微调前进、后退摆动偏移。
- 控制站立、休息、半蹲、趴下。
- 控制前进、后退、左转、右转、停止。
- 调整步态参数，例如摆腿角度、推地角度、步态间隔。
- 编辑最多 16 帧动作记忆，并支持播放一次或循环播放。
- 导出当前调好的 `config.h`，用于重新编译烧录后长期保存配置。

## 2. 使用前准备

### 2.1 硬件

需要准备：

- ESP32 或 ESP32-S3 开发板。
- 4 个舵机。
- 舵机外部供电，建议不要直接从开发板 5V 小电流口带多个舵机。
- 电脑或手机，用于访问网页端。
- 可选：PS2 手柄接收模块。

默认舵机引脚在 `config.h` 中：

| 腿部编号 | 页面名称 | 默认 GPIO |
| --- | --- | --- |
| 0 | 前左 Front Left | GPIO19 |
| 1 | 前右 Front Right | GPIO18 |
| 2 | 后左 Rear Left | GPIO5 |
| 3 | 后右 Rear Right | GPIO4 |

如果实际接线不同，请修改 `config.h` 中的 `ROBOT_DOG_SERVO_PINS`。

### 2.2 软件

Arduino IDE 使用时需要：

- 安装 ESP32 开发板支持包。
- 安装 `ESP32Servo` 库。
- 打开 `LeArm_ESP32_Arduino.ino`。
- 选择实际使用的 ESP32 板型和串口。

串口监视器波特率设置为 `115200`。

## 3. 配置 WiFi

打开 `LeArm_ESP32_Arduino.ino`，在文件开头找到：

```cpp
static const char *CONTROL_WIFI_SSID = "REDACTED_CONFIGURE_LOCALLY";
static const char *CONTROL_WIFI_PASSWORD = "REDACTED_CONFIGURE_LOCALLY";
```

将 `CONTROL_WIFI_SSID` 改为现场路由器 WiFi 名称，将 `CONTROL_WIFI_PASSWORD` 改为 WiFi 密码，然后重新编译烧录。

注意：当前程序使用路由器 WiFi 模式。电脑或手机必须和 ESP32 在同一个局域网内，才能访问网页端。如果 ESP32 没有成功连上 WiFi，网页端不会有可访问的局域网地址。

## 4. 烧录与打开网页

1. 确认舵机供电可靠，机械腿不要顶住限位。
2. 用 USB 将 ESP32 连接电脑。
3. 在 Arduino IDE 中编译并上传程序。
4. 打开串口监视器，波特率选择 `115200`。
5. 等待串口打印类似内容：

```text
RobotDog WiFi SSID: your_wifi_name
RobotDog control URL: http://192.168.x.x
```

6. 在电脑或手机浏览器中打开串口打印的地址，例如：

```text
http://192.168.1.23
```

页面标题为 `RobotDog WiFi 上位机`。

## 5. 页面功能说明

### 5.1 顶部姿态按钮

- `站立`：4 个舵机回到已保存中位。
- `休息`：应用休息 / 坐下的四路独立舵机角度。
- `半蹲`：应用半蹲的四路独立舵机角度。
- `趴下`：应用趴下的四路独立舵机角度。
- `保存到设备`：把当前中位、姿态角度、腿方向、动作参数和动作记忆保存到 ESP32，断电后仍然保留。
- `导出 config.h`：下载当前网页参数生成的配置文件。
- `恢复出厂配置`：清除 ESP32 中保存的调整，恢复为当前固件内 `config.h` 的配置，并回到站立姿态。

### 5.2 连续运动

- `前进`：启动连续前进步态。
- `后退`：启动连续后退步态。
- `左转`：启动连续左转步态。
- `右转`：启动连续右转步态。
- `停止`：停止连续运动并回到站立姿态。

建议第一次调试时把机器人架空，确认 4 条腿方向正确后再落地测试。

连续运动区下方还有“慢速单步调试”：前进、后退各有 2 个步态相位，左转、右转各有 4 个步态相位。每按一次按钮只执行一个相位，切换方向后会从第 1 步重新开始，方便观察每条腿是否正确。

### 5.3 每腿步态、舵机中位与前进方向

“每条腿前进 / 后退调试”中，每条腿都有两项独立参数：

- `前进摆动偏移`：该腿在前进摆动相位相对中位的偏移，范围 `-45°` 到 `45°`。
- `后退摆动偏移`：该腿在后退摆动相位相对中位的偏移，范围 `-45°` 到 `45°`。

正数表示舵机角度增加，负数表示舵机角度减小。页面会同时显示“中位 + 偏移”得到的目标角度，可以用 `-1`、`+1` 逐度调节。调节后用慢速单步按钮检查，再测试连续运动。

每条腿都有独立调节区：

- 滑条：快速调整该腿舵机中位角度。
- `-1` / `+1`：每次微调 1 度。
- 数字输入框：直接输入目标中位角度。
- `前进正向` / `前进反向`：修正该腿参与步态时的运动方向。

程序会把最终舵机输出限制在 `35` 到 `145` 度之间，避免打到机械限位。改变“前进摆腿角度”时，四条腿的前进偏移幅度会一起更新；改变“后退摆腿角度”时，四条腿的后退偏移幅度会一起更新。单独微调某条腿后，不要再次改变对应方向的全局摆腿角度。

调中位建议流程：

1. 点击 `站立`。
2. 观察 4 条腿是否对称。
3. 对不正的腿用 `-1` / `+1` 微调。
4. 小幅测试 `前进`。
5. 如果某条腿前进时方向相反，切换该腿的 `前进正向` 或 `前进反向`。

### 5.4 姿态微调

`休息 / 坐下`、`半蹲`、`趴下` 都有前左、前右、后左、后右四个独立角度。可以使用每路旁边的 `-1`、`+1` 微调，也可以直接输入角度并点击 `应用并预览`。

站立姿态使用上方“舵机中位”中的四路角度。姿态调好后，顶部对应按钮会直接使用这组角度。

### 5.5 动作参数

参数含义：

| 参数 | 作用 |
| --- | --- |
| 手动最大偏移 | PS2 单舵机模式下用左右方向键调整姿态时的最大偏移 |
| 前进摆腿 / 推地 / 频率间隔 | 分别控制前进时的摆腿角度、支撑腿推地角度和步态间隔 |
| 后退摆腿 / 推地 / 频率间隔 | 分别控制后退时的摆腿角度、支撑腿推地角度和步态间隔 |
| 左转摆腿 / 推地 / 频率间隔 | 分别控制左转时的摆腿角度、推地角度和步态间隔 |
| 右转摆腿 / 推地 / 频率间隔 | 分别控制右转时的摆腿角度、推地角度和步态间隔 |
| 左转四腿方向选择 | 前左、前右、后左、后右均可单独选择正向或反向 |
| 右转四腿方向选择 | 前左、前右、后左、后右均可单独选择正向或反向 |

修改参数后点击 `应用动作参数`，参数会立即生效。

建议从小动作开始调试：

- 各方向摆腿角度：先从 `20` 到 `30` 度测试，再逐步增大。
- 各方向推地角度：先从 `8` 到 `12` 度测试。
- 各方向频率间隔：先用 `260` ms 左右，确认稳定后再减小；数值越小，动作越快。
- 如果转向时某条腿动作相反，只切换对应转向分组中该腿的 `正向` / `反向`，不会影响其他腿或另一个转向动作。

左右转使用两相同步步态：摆腿相位四条腿同时动作，推地相位四条腿同时反向动作。左转时左侧两腿使用已校准的前进方向、右侧两腿使用后退方向；右转时左右侧方向互换，确保两个转向命令互为反向。

### 5.6 动作编辑与记忆播放

动作记忆由多帧组成。每帧包含：

- 前左角度。
- 前右角度。
- 后左角度。
- 后右角度。
- 保持时间 ms。

常用按钮：

- `读取当前姿态`：把当前 4 个舵机角度填入编辑框。
- `预览姿态`：让舵机立即转到编辑框中的 4 个角度。
- `加入记忆`：把编辑框内容加入动作记忆，并自动保存到设备。
- `记录当前`：把当前舵机角度加入动作记忆，并自动保存到设备。
- `播放一次`：从第 1 帧播放到最后 1 帧后停止。
- `循环播放`：不断循环播放动作记忆。
- `停止播放`：停止当前动作播放。
- `清空记忆`：删除所有动作帧，并同步更新设备中的掉电保存内容。

每条已加入的动作帧也可以单独 `预览`、`更新`、`删除`。新增、更新、删除和清空动作帧都会立即写入 ESP32 的 NVS 存储区并回读校验，不需要再点击 `保存到设备`。断电再上电后，程序会自动恢复最后一次成功保存的动作记忆。

动作记忆最多保存 `16` 帧。单帧保持时间范围为 `80` 到 `10000` ms。

## 6. 保存配置的方法

网页上的调整会立即控制当前机器人。动作记忆在每次新增、更新、删除或清空后自动写入 ESP32 的 NVS 存储区；其它配置可在确认调试结果后点击 `保存到设备`。固件会在写入后重新读取并校验，只有校验通过网页才会显示保存成功。

板载保存步骤：

1. 在网页端完成中位、方向、动作参数和动作记忆调试；动作记忆编辑成功后已经自动保存。
2. 需要保存中位、方向和动作参数时，点击 `保存到设备`，按钮显示 `已完成` 后即保存成功。
3. 保存状态显示 `已从设备加载` 后，重新启动或断电再上电，机器人会读取板载配置和动作记忆，并按保存的中位站立。

`导出 config.h` 仍可用于备份，或把当前参数固化成新烧录固件的出厂默认值。点击 `恢复出厂配置` 会删除板载保存值，并恢复到固件中的 `config.h`。

## 7. PS2 手柄辅助控制

网页端和 PS2 手柄可以同时存在。当前程序中：

- `R1`：从第 1 帧开始播放网页端录制的动作一次，播放完成后保持最后一帧姿态。
- `R2`：从第 1 帧开始循环播放网页端录制的动作。
- `L1`：停止动作播放，并保持停止时的当前姿态。
- `叉`：站立。
- `方块`：休息。
- `圆圈`：半蹲。
- `三角`：趴下。
- 坐标模式下，左摇杆上下控制前进、后退，右摇杆左右控制左转、右转；方向键仍可控制四个方向。
- 单舵机模式下，上下方向键使用与网页相同的连续前进/后退步态，松开后停止。
- 单舵机模式下，左右方向键仍用于调整整体左右姿态。

`R1`、`R2` 和 `L1` 只在按键从松开变为按下时触发，因此长按不会反复重启动作。播放动作时会停止当前连续行走；播放过程中仍可用姿态键或方向控制中断动作。没有录制动作帧时，按 `R1` 或 `R2` 不执行动作。

PS2 接收串口当前使用 `Serial2`，RX 引脚为 `GPIO34`，波特率为 `9600`。如果接收模块引脚不同，需要修改 `PS2_CTL.cpp`。

## 8. 常见问题

### 8.1 浏览器打不开网页

检查：

- ESP32 是否成功烧录并运行。
- 串口监视器是否打印 `RobotDog control URL`。
- 手机或电脑是否和 ESP32 连接同一个 WiFi。
- `CONTROL_WIFI_SSID` 和 `CONTROL_WIFI_PASSWORD` 是否正确。
- 路由器是否开启了 AP 隔离。开启 AP 隔离时，同一 WiFi 下设备可能无法互相访问。

### 8.2 串口提示 WiFi 连接失败

检查 WiFi 名称、密码、2.4G/5G 支持情况和信号强度。很多 ESP32 板卡只支持 2.4G WiFi，如果现场 WiFi 只有 5G，需要换成 2.4G 热点或路由器。

### 8.3 舵机抖动或重启

优先检查供电。多个舵机同时动作时电流较大，USB 口通常不适合直接给舵机供电。建议舵机单独供电，并保证舵机电源 GND 和 ESP32 GND 共地。

### 8.4 点前进后某条腿方向反了

在该腿的调节区切换 `前进正向` 或 `前进反向`。如果转向时某条腿方向不对，在动作参数对应的左转或右转分组中单独切换该腿的 `正向` / `反向`。

### 8.5 调好的参数重启后丢失

动作记忆的新增、更新、删除和清空会自动保存。其它网页参数修改后仍需要点击一次 `保存到设备`；按钮显示 `已完成` 后再重启，机器人会加载保存的中位和其它参数。

### 8.6 点击恢复配置后刚刚调的参数没了

`恢复出厂配置` 会清除 NVS 中保存的调整，并重新读取当前固件内置的 `config.h`。需要保留当前调整时，请不要点击该按钮。

## 9. 调试建议

- 第一次上电时先让机器人架空，避免腿部卡住。
- 中位角度先调对，再调步态。
- 步态角度每次只改一个参数，便于判断影响。
- 不要让舵机长时间顶住机械限位。
- 动作记忆播放前，先逐帧预览，确认没有危险姿态。
- 如果机器人落地后动作变弱或复位，优先检查舵机电源电流是否足够。

## 10. 网页接口附录

普通使用者不需要直接调用接口。下面接口用于二次开发或调试。

| 地址 | 参数 | 作用 |
| --- | --- | --- |
| `/` | 无 | 打开网页控制台 |
| `/status` | 无 | 获取当前状态 JSON |
| `/set` | `leg`, `angle` | 设置某条腿中位角度 |
| `/direction` | `leg`, `direction` | 设置某条腿前进方向，`direction` 为 `1` 或 `-1` |
| `/params` | 动作参数 | 应用步态和姿态参数 |
| `/pose-settings` | `pose`, `a0`, `a1`, `a2`, `a3` | 设置并预览休息、半蹲或趴下的四路角度 |
| `/save` | 无 | 把当前设置和动作记忆保存到 ESP32 NVS |
| `/config` | 无 | 导出 `config.h` |
| `/reset` | 无 | 清除板载保存值并恢复当前固件配置 |
| `/stand` | 无 | 站立 |
| `/rest` | 无 | 休息 |
| `/half-crouch` | 无 | 半蹲 |
| `/crouch` | 无 | 趴下 |
| `/motion` | `command` | 连续运动，支持 `forward`、`backward`、`left`、`right`、`stop` |
| `/motion-step` | `command`, `step` | 单步预览前进、后退、左转或右转的指定步态相位 |
| `/gait-leg` | `leg`, `forwardOffset`, `backwardOffset` | 设置某条腿独立的前进、后退摆动偏移 |
| `/pose-angles` | `a0`, `a1`, `a2`, `a3` | 直接设置 4 个舵机角度 |
| `/action/add` | `a0`, `a1`, `a2`, `a3`, `durationMs` | 添加动作帧 |
| `/action/update` | `index`, `a0`, `a1`, `a2`, `a3`, `durationMs` | 更新动作帧 |
| `/action/delete` | `index` | 删除动作帧 |
| `/action/clear` | 无 | 清空动作帧 |
| `/action/play` | `loop` | 播放动作帧，`loop=1` 为循环 |
| `/action/stop` | 无 | 停止动作播放 |
