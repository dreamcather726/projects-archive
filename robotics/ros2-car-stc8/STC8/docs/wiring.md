# 四台电机接线：每台独立 DIR、PWM、编码器 A 相

使用 **STC8H1K08 TSSOP20** 核心板和两片 TB6612。每台电机占用三个 STC 引脚：DIR 输出控制方向、PWM 输出控制驱动力、A 相输入反馈转动脉冲。

本接线对应 Keil 目标 **`STC8_4Motor_AOnly`**，定义 `MOTOR_ENCODER_AB=0`。烧录文件为 `Build/Objects/STC8_4Motor_AOnly/STC8_4Motor_AOnly.hex`。

## 1. 四台电机的三个信号

接核心板排针时，看板上的 **P1.x / P3.x** 丝印。括号内为芯片的 TSSOP20 脚号，不是排针序号。M1～M4 对应上位机的 `--m1`～`--m4`。

| 电机 | 默认位置 | PWM：STC → TB6612 | DIR：STC → 方向输入 | 编码器 A：编码器 → STC |
|---|---|---|---|---|
| M1 | 左前 | **P1.0（19）** → #1 PWMA | **P1.1（20）** → #1 AIN1 | A1 → **P3.2（13）**，INT0 |
| M2 | 右前 | **P1.2（1）** → #1 PWMB | **P1.3（2）** → #1 BIN1 | A2 → **P3.3（14）**，INT1 |
| M3 | 左后 | **P1.4（3）** → #2 PWMA | **P1.5（4）** → #2 AIN1 | A3 → **P3.6（17）**，INT2 |
| M4 | 右后 | **P1.6（5）** → #2 PWMB | **P1.7（6）** → #2 BIN1 | A4 → **P3.7（18）**，INT3 |

四个 DIR 彼此独立，四个 PWM 彼此独立，四个 A 相分别计数。M1～M4 的位置可以按实际安装调整，但一台电机的 PWM、DIR、A 相必须保持同一行对应关系。

### 硬件 PWM 与中断能力核对

下面的功能依据 STC8H1K08 官方资料第 3～4 页（PDF 第 3 页为中断说明，第 4 页为 TSSOP20 引脚图），并已核对工程里的初始化配置。

| 电机 | PWM 引脚与硬件功能 | A 相引脚与硬件中断 | DIR 引脚与用途 |
|---|---|---|---|
| M1 | P1.0：PWM1P，PWMA 通道 1 正输出 | P3.2：INT0，配置下降沿 | P1.1：推挽 GPIO 输出 |
| M2 | P1.2：PWM2P，PWMA 通道 2 正输出 | P3.3：INT1，配置下降沿 | P1.3：推挽 GPIO 输出 |
| M3 | P1.4：PWM3P，PWMA 通道 3 正输出 | P3.6：INT2，硬件下降沿触发 | P1.5：推挽 GPIO 输出 |
| M4 | P1.6：PWM4P，PWMA 通道 4 正输出 | P3.7：INT3，硬件下降沿触发 | P1.7：推挽 GPIO 输出 |

四路 PWM 由芯片硬件产生，**共同使用 20 kHz 频率，各自独立设置占空比**。[motor_hal.c](../Peripheral/Source/motor_hal.c) 按 `BOARD_PWM_ROUTE=0` 选择默认引脚路由，`PWMA_ENO=0x55` 只使能四个正输出。四个 N 互补输出均关闭，因此 P1.1、P1.3、P1.5、P1.7 可以作为独立 DIR GPIO，不会被 PWM 占用。

[motor_hal.c](../Peripheral/Source/motor_hal.c) 将四个 A 相引脚配置为输入，启用 INT0～INT3，统一使用下降沿计数。[encoder.c](../Firmware/Source/encoder.c) 定义四个中断入口，分别更新 M1～M4 的计数。INT2、INT3 只支持下降沿触发，与当前计数方式匹配。PWM 使用专用 PWMA 外设，串口使用 Timer1，控制节拍使用 Timer0，当前接法没有引脚重叠。

这是芯片功能及固件配置核对；实际波形和最高不丢计数的编码器频率仍需上板测量。

## 2. 两片 TB6612 逐脚连接

`#1` 表示第一片 TB6612，控制 M1、M2；`#2` 表示第二片，控制 M3、M4。模块上的 A01/A02、B01/B02 有时也标成 AO1/AO2、BO1/BO2，都是接电机两根功率线的输出端。

| TB6612 接口 | 第一片 #1 | 第二片 #2 |
|---|---|---|
| PWMA | P1.0，M1 PWM | P1.4，M3 PWM |
| AIN1 | P1.1，M1 DIR | P1.5，M3 DIR |
| AIN2 | M1 DIR 经你的硬件取反 | M3 DIR 经你的硬件取反 |
| AO1 / AO2 | M1 的两根电机功率线 | M3 的两根电机功率线 |
| PWMB | P1.2，M2 PWM | P1.6，M4 PWM |
| BIN1 | P1.3，M2 DIR | P1.7，M4 DIR |
| BIN2 | M2 DIR 经你的硬件取反 | M4 DIR 经你的硬件取反 |
| BO1 / BO2 | M2 的两根电机功率线 | M4 的两根电机功率线 |
| STBY | **P5.4（芯片脚 7）** | 同一个 **P5.4** |
| VCC | 逻辑电源 | 同一逻辑电源 |
| VM | 电机电源 | 电机电源 |
| GND | 系统公共地 | 系统公共地 |

每个 DIR 的连接关系都是：

```text
STC DIR ─────────────→ 该通道 IN1
        └→ 你的反相电路 → 该通道 IN2
```

**IN1 和 IN2 要保持相反，不能将两个输入直接并接到 DIR。** 这四路反相信号由你之前约定的硬件提供，不额外占用 STC 引脚。

默认该台参数 `polarity=0` 时，正控制值输出 DIR=1、IN1=1、IN2=0；负控制值输出 DIR=0、IN1=0、IN2=1。机械上的前进方向取决于电机安装和两根功率线的接法。如果某台正指令实际倒转，可交换该台的两根电机功率线，或在上位机将该台“方向反转”参数设为 1、停机应用，并导出 JSON 到电脑，无需重新编译。

两片 STBY 接在一起，由 P5.4 统一使能；建议此线上加 10 kΩ 下拉。STBY=0 时两片驱动都待机。不要将 STBY 固定接高电平，固件需要用它执行上电、STOP 和失联停机。

## 3. 每台编码器接线

| 编码器线 | 连接位置 |
|---|---|
| 电源正极 / VCC | 按编码器额定电压接电源 |
| 电源负极 / GND | 系统公共地 |
| A 相 | 按第 1 节的 A1～A4 分别接 STC |
| B 相 | 本方案不连接，单独绝缘 |

电机的两根功率线和编码器的电源线是不同用途，按电机厂家标注识别，不按线颜色猜测。编码器 A 相输出电平须适配 STC 的供电；如为开集电极输出，应按编码器要求将上拉接至兼容的逻辑电源。

固件在 A 相**下降沿**计一次，速度按脉冲频率计算。仅有 A 相时，计数的正负号由控制方向推定，不能独立识别手动反转或外力反转。速度单位为 count/s；减速箱输出轴一圈实测 N 次计数时，`RPM = count/s × 60 / N`。

## 4. 上位机串口与供电

| 接口 | 连接位置 |
|---|---|
| USB-TTL TXD | → 核心板 **RXD / P3.0（芯片脚 11）** |
| USB-TTL RXD | ← 核心板 **TXD / P3.1（芯片脚 12）** |
| USB-TTL GND | → 系统公共地 |
| 核心板 VCC | → 稳定的逻辑电源 |
| 核心板 GND | → 系统公共地 |

串口参数为 **115200、8N1、无流控**。核心板的 RXD 与 P3.0 是同一个信号，TXD 与 P3.1 也是同一个信号。USB-TTL 信号电平必须与 STC 供电兼容。

STC、两片 TB6612、四台编码器和 USB-TTL **全部共地**。TB6612 的 VCC 是逻辑供电，VM 是电机供电；电机功率电源不要从核心板排针或 USB-TTL 小电源输出取电。STC 与驱动逻辑电源应采用兼容电平，编码器电源按实际规格接，避免把高电压编码器输出直接送入 STC。

STC-ISP 设置内部时钟 **24 MHz**，**P5.4 为普通 GPIO，关闭外部复位功能**。VREF 按核心板原理图连接到参考源或 VCC，不悬空。照片中的 P1.0 接有板载 LED，接 M1 PWM 时 LED 可能随占空比变化。

本方案共占 15 个 I/O：4 PWM＋4 DIR＋4 A 相＋2 串口＋1 STBY。P3.4、P3.5 保留未用。

## 5. 首次检查

先架空车轮，选择并烧录 `STC8_4Motor_AOnly`。将 COM3 替换为实际串口：

```powershell
python Host/motor_host.py --port COM3 --mode query
python Host/motor_host.py --port COM3 --mode pwm --m1 150 --m2 0 --m3 0 --m4 0 --seconds 2
python Host/motor_host.py --port COM3 --mode stop
```

150 表示 15% PWM，作为低占空比试转；电机能否起转取决于负载和电源。依次测试 M1～M4，确认只转指定电机，且对应编号的计数变化。随后用负值检查反向。如果电机转动但对应计数始终为零，检查该台 A 相接线、编码器供电及输出电平。

引脚、PWM 频率和极性配置见 [board_config.h](../Firmware/Include/board_config.h)。完整协议和速度控制说明见 [usage.md](usage.md)。芯片脚号依据 [STC 官方引脚资料](https://www.stcmicro.com/datasheet/STC8H1K08_Features.pdf)，驱动接口及工作状态依据 [TB6612 官方资料](https://toshiba.semicon-storage.com/info/datasheet_en_20141001.pdf?did=10660)。
