# 已确认的功能与实现位置

参考厂家 [Emm V5.0 说明书](https://blog.csdn.net/zhangdatou666/article/details/132644047) 的运动、参数、反馈和故障管理功能，针对 STC8H1K08、TB6612 和四台 A 相直流编码电机实现。运行参数集中在 parameters.h/.c，硬件配置集中在 board_config.h；上位机通过 motor_host.py 使用串口。

| 编号 | 功能 | V4 实现 |
|---:|---|---|
| 1 | 设备信息 | 版本、参数格式版本、能力位、四台状态；统一 QUERY 命令 |
| 2 | 单台控制 | SINGLE 选择 M1～M4，不改变其他台目标 |
| 3 | PWM | 四台独立正负千分比，硬件 20 kHz |
| 4 | 速度闭环 | 每台 PI；count/s 在线控制；上位机按各自 CPR 换算 RPM |
| 5 | 同步控制 | BATCH 一帧设置四台独立模式/目标，同一控制周期应用 |
| 6 | 启停 | 单台零 PWM、全体 STBY 关闭、减速停止；上电默认全停 |
| 7 | 加减速 | 每台 PWM/速度目标加减速步长和换向等待可设 |
| 8 | 闭环参数 | 每台 Kp、Ki、积分限幅，可停机读写 |
| 9 | 电机参数 | 每台极性、PWM/速度上限、输出轴 A 相每圈计数 |
| 10 | 实时状态 | 四台模式、目标、PWM、速度、32 位计数和全局故障 |
| 11 | 定时反馈 | 由上位机每 100 ms 查询，固件不主动上报 |
| 12 | 清零 | 单台/全部停止后清零对应计数 |
| 13 | 堵转/无反馈 | 各台 PWM、速度、时间阈值；报告电机位图并全停 |
| 14 | 失联保护 | 可设超时，定时中断关闭 STBY，锁存故障并显式清除 |
| 15 | 参数管理 | RAM 读写、默认值；电脑 JSON 保存/重新下发，掉电恢复默认 |
| 16 | 指令确认 | 序号、CRC、错误码，参数越界不部分执行四台目标 |
| 17 | 串口界面 | 端口列表、连接/断开、版本与状态；单后台线程使用串口 |
| 18 | 控制面板 | 四台分别设置模式、单位、目标；单台/全体停止和同步应用 |
| 19 | 参数页面 | 停机读取/应用/恢复，JSON 导入导出，显示设备参数状态 |
| 20 | 曲线 | 各台最近 30 秒速度目标、速度反馈、实际 PWM |
| 21 | 配置/日志 | JSON 导入导出；导入只改编辑区；CSV 运行记录含故障位图；当前事件日志可导出 TXT |
| 22 | 程序接口 | 命令行和 MotorClient Python API，适合后续 ROS2 节点调用 |

约束：A 相方向由控制输出推定，未加入精确位置闭环、绝对定位或自动回零；没有电流采样，因此不提供力矩环、软件过流检测；STBY 共用，单台停止在其他电机运行时为零 PWM 制动。独立机械转动方向仍需通过接线和实测确认。

固件在 8 KB CODE / 1 KB XDATA 内构建。软件验证包括 C 逻辑与上电默认参数、Python 协议测试、Tk 界面交互，以及 Python 客户端连接同一份 C 固件逻辑的集成测试。硬件 PWM 波形、编码器最高不丢计数频率和机械闭环效果需上板实测。

V4.1 实板串口验证：用户截图确认 9152 字节接收、143 个有效状态帧、CRC 错误 0，固件状态正常。电机功率输出、实际编码器计数和闭环效果仍需逐台验证。
