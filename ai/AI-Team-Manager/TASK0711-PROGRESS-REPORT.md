## 实现与计算规则

新增 taskProgress 纯投影。输入仅为后端计划、调度状态、实际候选检查点、绑定源摘要的测试、独立审查、集成记录和 Worker 事件，不读取模型输出长度、Token 或运行时长来估算百分比。该投影不写入业务状态，不触发模型调用。数据在原 UI 刷新链更新，前端只显示投影并进行 CSS 过渡。

Worker 的验证节点固定为：候选采集、当前版本测试、独立审查、整体集成、用户交付。整体节点为每个任务的前三项加两个公共集成/交付节点；并非把公共阶段在总进度里重复计算。界面标记“已验证 x/y 个阶段”，百分比是这些真实验证节点的覆盖率，不声称开发工作量已经完成相同比例。实际开发细分步骤没有可验证总量时不做预测。

例如两个任务中一个通过候选/测试/审查，另一个仍在开发：整体已验证 3/8、进度条 37%；第一个 Worker 3/5、60%，第二个 0/5。单任务集成 READY 为 4/5、80%，仍显示“等待用户交付”；必须所有候选和集成证明匹配、交付时间已记录、调度任务均 COMPLETED 才能显示 100%。计划或调度数据不完整则 total/percent 为 null，显示不确定进度和当前阶段。

测试需命令覆盖、正数测试数量、成功退出并绑定当前候选摘要；审查需当前摘要、PASS、未过期、无缺失证据或严重问题；集成需候选摘要/审查 ID、集成测试与集成审查全部一致。CLI 结束本身不增加节点。中断后采集到的真实候选也可作为已采集节点，但不因此通过测试/审查/交付。代码版本变化会使旧节点失效，允许真实进度回退，不强行保持单调上升。

## UI 与时间线

- GPT 任务详情显示整体验证条、阶段、完成/剩余节点；时间线默认折叠，包含各任务节点和公共集成/交付节点。
- 选中 Worker 显示自己的任务名称、阶段、验证条、节点数和最新状态时间，详情中查看自己的步骤及执行状态历史；切换加载期间清空旧 Worker 进度。已复用 Worker 的历史任务与当前任务按 task_id/worker_id 区分。
- 任务中心显示同一整体条及九类总览：等待执行、正在执行、测试中、等待审查、审查通过、等待集成、等待交付、完成、失败/阻塞。审查通过为验证计数，可与等待集成等状态重叠，不能把所有总览相加当总任务数。详情抽屉展示所选任务的节点和时间线。
- 时间只采用实际调度、测试、审查、候选采集和交付记录，未记录显示“未记录”；失败/阻塞尝试可显示实际结束时间，但状态仍为失败/阻塞。测试中由认证测试工具事件表示，不从聊天文字猜测。
- 原重试栏继续显示次数/等待与原 Session；进度计数不随倒计时增加。保留暂停、取消和恢复的后台接口。减少动画设置关闭进度过渡，没有新增持续轮询或装饰动画。

## 验收与限制

新后端专项 14 项：单 Worker 验证节点、多个 Worker 隔离/复用、503 重试不增量、暂停/恢复/取消、失败/零测试/旧测试、阻塞/旧审查、READY 与交付、集成冲突/错误绑定、实时测试事件、未知与重建稳定性、实际时间与阻塞原因、失败尝试时间、TeamSession 投影接入、认证测试/中断候选检查点。新 DOM 专项 2 项：无障碍未知值与交付边界、时间线缺失时间/错误文本注入防护。

浏览器使用安装的 Edge、生产 Webview 脚本/CSS 和生产后端投影，场景输入为明确标记的测试夹具。覆盖五档 1920×1080、1600×900、1366×768、1280×720、760×900；GPT/Worker/任务中心、任务抽屉与步骤展开、Worker 切换、页面切换、关闭重开、Webview 新建后恢复同一后端投影、重试等待不增长、未知值、等待交付/完成和减少动画。所有页面无脚本错误、无文档横向溢出，主要操作与聊天区可访问。截图已进行视觉审阅。

本次 UI/投影验证不冒充新的真实 GPT/Claude 运行或上游网络修复；原 LARGE 最终模型验收仍等待用户确认网关恢复。Webview 重建测试重用同一后端数据；扩展宿主重启仍遵循原有“任务暂停并等待显式恢复”规则，禁止进度 UI 自动续行。
