## 重试实现与安全验收

复用已实现核心：默认 3 次重试、共 4 个 CLI 尝试，2/4/8 秒退避并正向抖动，最大单次等待 60000ms。有效 Retry-After 作为等待下限；429 缺失或无效等待、等待超过上限时转人工，不提前重试。HTTP 502/503/504、明确模型通道不可用、ECONNRESET、ETIMEDOUT 等只是候选，仍须经过无副作用检查。

认证、权限、CLI 不兼容、Session 异常优先拒绝自动重放。助手执行文本、工具、思考/未知子活动、权限/MCP 调用、正数或不完整用量、计费记录、候选变化或不完整扫描均会阻止重试。明确网关拒绝路由、没有执行活动的特殊情况可以支持未进入模型执行的判断，不把一般未知用量当零。失败的 CLI 进程退出并完成权限登记清理后，才允许复用原 MCP、Session、任务、Worker、目录、权限与租约；不换模型。

一个逻辑任务只创建一个用户消息和 RequestRecord。重试元数据追加在原记录，实际用量只来自 CLI；不虚构 Provider 内部请求次数。暂停和取消会中断 AbortSignal 等待。扩展重启把中断请求保留为取消/待恢复，不自动重放。普通重试只刷新 UI，GPT 决策修订不因每次等待而推进；终止事件、最终执行和审查仍有证据记录。

| 要求 | 验证 |
|---|---|
| 首次 503、第二次成功 | 通过，真实子进程故障夹具 |
| 三次 503、第四次成功 | 通过，四次 CLI 启动 |
| 四次失败 | 通过，耗尽后停止并保留记录 |
| Session、任务、Worker、目录保持 | 通过，参数与持久记录断言 |
| 用户消息和 RequestRecord 不重复 | 通过，内存及重新读取存储均断言 |
| Token 不重复登记 | 通过，单记录用量和正数/部分/未知用量阻止重放断言 |
| 用户取消后不重试 | 通过，等待中取消和进程次数断言 |
| 认证失败 | 通过，不重试 |
| 权限拒绝 | 通过，不重试 |
| Session 恢复失败 | 通过，不重试 |
| 工具/MCP 已调用 | 通过，认证 HTTP MCP 实际调用后拒绝重试 |
| 文件修改/外部修改 | 通过，实际磁盘变化被拦截 |
| 多 Worker 并发重试 | 通过，两个原 Session、独立记录和租约 |
| 文件锁/权限保持 | 通过，原租约 ID、MCP 配置、allowedTools 不变，越界写入被拒绝 |
| 重启不重放 | 通过，重新加载不调用执行接口 |
| 成功事件进入 GPT 监督 | 通过，真实 Worker 事件去重并生成监督摘要 |
| 耗尽保留现场 | 通过，原 Session 和请求记录可重新加载 |
| Retry-After/等待边界/抖动 | 通过，默认参数及取消等待测试 |

以上为隔离 CLI 故障注入，实际运行子进程、HTTP 权限/MCP 与磁盘；不是声称真实上游在本轮发生并恢复 503。没有真实模型请求。
