程序执行流程图

流程图说明

这个流程图展示了程序从启动到退出的完整执行过程，包括以下几个主要部分：

1. 程序启动

用户执行 python main.py 命令启动程序

2. 导入模块

导入必要的系统模块和自定义模块，包括：

  • sys - 系统模块
  • PyQt5.QtWidgets.QApplication - GUI应用程序类
  • 自定义模块：interaction_module, script_module, serial_module, ui_module

3. 类定义

定义 FingerControllerApp 类，继承自 FingerControllerUI

4. main函数执行

创建QApplication实例和FingerControllerApp实例

5. 初始化过程

初始化各个模块，包括：

  • 调用父类初始化
  • 创建SerialPortClient实例
  • 创建ScriptService实例
  • 创建InteractionController实例
  • 绑定信号
  • 刷新串口列表

6. 信号绑定

绑定界面控件的信号与相应的槽函数，包括：

  • 刷新按钮点击 → 刷新串口列表
  • 连接按钮点击 → 连接/断开串口
  • 滑块值变化 → 更新手指角度并发送指令
  • 预设动作按钮点击 → 应用预设动作
  • 加载按钮点击 → 加载脚本文件
  • 保存按钮点击 → 保存脚本文件
  • 运行按钮点击 → 执行脚本
  • 停止按钮点击 → 停止脚本

7. 用户交互

等待并处理用户的操作，包括点击按钮、滑动滑块、关闭窗口等

8. 窗口关闭

处理窗口关闭事件，进行清理工作，包括：

  • 调用controller.close_cleanup()
  • 停止脚本线程
  • 关闭串口
  • 退出程序

模块职责

  • UI模块：负责创建和显示界面控件
  • 控制层：处理用户交互逻辑，协调各模块工作
  • 串口模块：负责与机械手通信
  • 脚本模块：负责执行脚本指令
