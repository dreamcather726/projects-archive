# 灵巧手控制器程序实现详解

## 程序运行说明

### 一、所需库安装

程序需要安装以下库：

1. **PyQt5** - 用于创建GUI界面
2. **pyserial** - 用于串口通信

### 二、安装命令

在命令行中执行以下命令安装所需库：

```bash
pip install PyQt5 pyserial
```

### 三、运行步骤

1. 确保所有依赖库已安装
2. 打开命令行，进入程序所在目录
3. 执行以下命令启动程序：
   ```bash
   python main.py
   ```
## 认识这个程序

### 1. 这个程序是什么
它是一个电脑桌面软件，就像一个遥控器，用来连接和控制机械手，让它按照我们的命令做各种动作。

### 2. 这个程序能做什么
- **找朋友**：搜索并连接机械手
- **手动控制**：用滑块调节每根手指的弯曲程度
- **快速动作**：一键执行预设手势，比如张开、握拳、OK手势
- **自动表演**：写脚本让机械手自动完成一连串动作，就像编舞一样
- **看日记**：实时看到机械手在做什么，就像看它的日记一样

### 3. 学习思路：三层结构
我们把程序分成三层来讲，就像一个汉堡包：
- **第一层：外表层** —— 你能看到的界面，就像汉堡的面包
- **第二层：控制层** —— 程序的大脑，就像汉堡的肉饼
- **第三层：底层** —— 真正干活的部分，就像汉堡的底座

---

## 第一层 —— 外表层（界面）

### 1. 外表层是什么
就是你打开软件看到的整个窗口，所有按钮、滑块、文字、显示区域，都属于外表层，就像我们的脸一样，是程序的"外表"。

### 2. 外表层包括哪些内容
- **串口连接区**：选择接口、刷新、连接，就像交朋友前要先找到对方
- **手指控制区**：四个滑块，对应四根手指，就像游戏里的控制器
- **预设手势区**：快速动作按钮，就像游戏里的快捷技能
- **脚本编辑区**：写自动运行的指令，就像写作业一样
- **日志显示区**：显示程序在做什么，就像看机器人的日记

### 3. 外表层的工作规则
- **只负责显示**，不负责思考，就像镜子一样
- **只接收你的操作**，不自己做决定
- **把你的操作传递给大脑**，就像信使一样
- **把结果显示给你看**，就像展示板一样

### 4. 外表层的实现方式
**代码示例：ui_module.py**

```python
# 1. 类定义和初始化模块
class FingerControllerUI(QWidget):
    """
    手指控制器界面（纯 UI）
    整个窗口只创建控件，不做任何业务绑定和操作
    """

    def __init__(self):
        super().__init__()
        
        # 1.1 串口相关控件声明
        self.port_combo: QComboBox  # 串口选择下拉框
        self.refresh_btn: QPushButton  # 刷新按钮
        self.connect_btn: QPushButton  # 连接按钮
        self.status_bar: QStatusBar  # 状态栏

        # 1.2 手指控制相关控件声明
        self.finger_sliders: List[QSlider] = []  # 手指滑块列表
        self.finger_labels: List[QLabel] = []  # 手指角度标签列表

        # 1.3 预设动作按钮声明
        self.preset_buttons: Dict[str, QPushButton] = {}  # 预设动作按钮字典

        # 1.4 脚本相关控件声明
        self.script_editor: QTextEdit  # 脚本编辑器
        self.load_btn: QPushButton  # 加载脚本按钮
        self.save_btn: QPushButton  # 保存脚本按钮
        self.run_btn: QPushButton  # 执行脚本按钮
        self.stop_btn: QPushButton  # 停止按钮
        self.script_log: QTextEdit  # 脚本执行日志

        # 1.5 调用创建界面的方法
        self._setup_ui()

    def _setup_ui(self) -> None:
        """创建并摆放所有 UI 控件（不绑定信号、不做业务逻辑）"""
        # 2. 窗口设置模块
        # 2.1 设置窗口标题和大小
        self.setWindowTitle("我的手指控制器")  # 窗口标题
        self.setGeometry(100, 100, 800, 600)  # 窗口位置和大小：x=100, y=100, 宽800, 高600

        # 2.2 创建主布局（水平布局，左右分栏）
        main_layout = QHBoxLayout()

        # 3. 左侧面板模块
        # 3.1 创建左侧面板（垂直布局）
        left_panel = QVBoxLayout()

        # 4. 串口设置区域模块
        # 4.1 创建串口设置分组框
        port_group = QGroupBox("串口设置")  # 创建分组框，标题是"串口设置"
        port_layout = QHBoxLayout()  # 创建水平布局
        port_label = QLabel("串口:")  # 创建标签
        self.port_combo = QComboBox()  # 创建下拉框

        self.refresh_btn = QPushButton("刷新")  # 创建刷新按钮
        self.connect_btn = QPushButton("连接")  # 创建连接按钮

        # 4.2 添加控件到布局
        port_layout.addWidget(port_label)  # 添加标签
        port_layout.addWidget(self.port_combo)  # 添加下拉框
        port_layout.addWidget(self.refresh_btn)  # 添加刷新按钮
        port_layout.addWidget(self.connect_btn)  # 添加连接按钮
        port_group.setLayout(port_layout)  # 设置分组框的布局
        left_panel.addWidget(port_group)  # 添加分组框到左侧面板

        # 5. 手指控制区域模块
        # 5.1 创建手指控制分组框
        finger_group = QGroupBox("手指控制")  # 创建分组框，标题是"手指控制"
        finger_layout = QVBoxLayout()  # 创建垂直布局

        # 5.2 循环创建四个手指的控件
        for i in range(1, 5):  # 从1到4，循环四次
            finger_hbox = QHBoxLayout()  # 为每个手指创建水平布局
            finger_label = QLabel(f"手指{i}: 90°")  # 创建手指角度标签
            self.finger_labels.append(finger_label)  # 把标签添加到列表

            slider = QSlider(Qt.Horizontal)  # 创建水平滑块
            slider.setMinimum(90)  # 设置滑块最小值为90（伸直）
            slider.setMaximum(180)  # 设置滑块最大值为180（弯曲）
            slider.setValue(90)  # 设置滑块初始值为90（伸直）
            self.finger_sliders.append(slider)  # 把滑块添加到列表

            # 5.3 添加控件到水平布局
            finger_hbox.addWidget(finger_label)  # 添加标签
            finger_hbox.addWidget(slider)  # 添加滑块
            finger_layout.addLayout(finger_hbox)  # 添加水平布局到垂直布局

        finger_group.setLayout(finger_layout)  # 设置分组框的布局
        left_panel.addWidget(finger_group)  # 添加分组框到左侧面板

        # 6. 预设动作区域模块
        # 6.1 创建预设动作分组框
        preset_group = QGroupBox("预设动作")  # 创建分组框，标题是"预设动作"
        preset_layout = QGridLayout()  # 创建网格布局

        # 6.2 创建预设动作按钮
        preset_names = ["张开", "握拳", "OK手势", "指示"]  # 预设动作名称
        for idx, name in enumerate(preset_names):  # 遍历预设动作名称
            btn = QPushButton(name)  # 创建按钮
            self.preset_buttons[name] = btn  # 把按钮添加到字典
            preset_layout.addWidget(btn, idx // 2, idx % 2)  # 添加按钮到网格布局
            # idx//2 是行号，idx%2 是列号，这样就排成2x2的网格

        preset_group.setLayout(preset_layout)  # 设置分组框的布局
        left_panel.addWidget(preset_group)  # 添加分组框到左侧面板

        # 7. 状态栏模块
        # 7.1 创建状态栏
        self.status_bar = QStatusBar()  # 创建状态栏
        self.status_bar.showMessage("未连接")  # 设置初始消息
        left_panel.addWidget(self.status_bar)  # 添加状态栏到左侧面板

        # 8. 布局设置模块
        # 8.1 添加左侧面板到主布局，占1份空间
        main_layout.addLayout(left_panel, 1)

        # 9. 右侧脚本控制区域模块
        # 9.1 创建右侧面板（垂直布局）
        right_panel = QVBoxLayout()  # 创建右侧面板（垂直布局）

        # 9.2 创建脚本控制分组框
        script_group = QGroupBox("脚本控制")  # 创建分组框，标题是"脚本控制"
        script_layout = QVBoxLayout()  # 创建垂直布局

        # 9.3 创建脚本编辑器
        self.script_editor = QTextEdit()  # 创建文本编辑器
        # 设置占位文本，提示脚本格式
        self.script_editor.setPlaceholderText(
            "# 脚本格式示例:\n"
            "# FINGER1:180  # 手指1弯曲\n"
            "# FINGER2:90   # 手指2复位\n"
            "# DELAY:500    # 等待500毫秒\n\n"

            "FINGER1:90\n"
            "FINGER2:90\n"
            "FINGER3:90\n"
            "FINGER4:90\n"
        )
        script_layout.addWidget(self.script_editor)  # 添加文本编辑器到布局

        # 9.4 创建脚本操作按钮
        script_btn_layout = QHBoxLayout()  # 创建水平布局
        self.load_btn = QPushButton("加载脚本")  # 创建加载按钮
        self.save_btn = QPushButton("保存脚本")  # 创建保存按钮
        self.run_btn = QPushButton("执行脚本")  # 创建执行按钮
        self.stop_btn = QPushButton("停止")  # 创建停止按钮

        # 9.5 添加按钮到布局
        script_btn_layout.addWidget(self.load_btn)  # 添加加载按钮
        script_btn_layout.addWidget(self.save_btn)  # 添加保存按钮
        script_btn_layout.addWidget(self.run_btn)  # 添加执行按钮
        script_btn_layout.addWidget(self.stop_btn)  # 添加停止按钮
        script_layout.addLayout(script_btn_layout)  # 添加按钮布局到脚本布局

        # 9.6 创建日志显示
        self.script_log = QTextEdit()  # 创建文本编辑器（用于显示日志）
        self.script_log.setReadOnly(True)  # 设置为只读
        self.script_log.setMaximumHeight(150)  # 设置最大高度
        script_layout.addWidget(QLabel("执行日志:"))  # 添加日志标签
        script_layout.addWidget(self.script_log)  # 添加日志显示到布局

        script_group.setLayout(script_layout)  # 设置分组框的布局
        right_panel.addWidget(script_group)  # 添加分组框到右侧面板

        # 9.7 添加右侧面板到主布局，占1份空间
        main_layout.addLayout(right_panel, 1)
        self.setLayout(main_layout)  # 设置窗口的主布局
```

**代码讲解**：

1. **类结构**：
   - `class FingerControllerUI(QWidget):` - 定义一个名为 `FingerControllerUI` 的类，继承自 `QWidget`，就像创建一个新的盒子，这个盒子是专门用来装界面控件的
   - `"""..."""` - 三引号包围的文本是类的文档字符串，用来解释这个类的作用，就像给盒子贴个标签，说明里面装的是什么,不参与代码执行

2. **初始化方法**：
   - `def __init__(self):` - 定义初始化方法，当创建这个类的实例时会自动执行，就像打开盒子时自动整理里面的东西
   - `super().__init__()` - 调用父类 `QWidget` 的初始化方法，就像先继承盒子的基本功能
   - 变量声明：`self.port_combo: QComboBox` - 声明一个名为 `port_combo` 的变量，类型是 `QComboBox`，就像在盒子里预留一个位置放下拉框
   - `self._setup_ui()` - 调用 `_setup_ui` 方法来创建界面，就像开始布置盒子里的具体内容

3. **界面布局**：
   - `main_layout = QHBoxLayout()` - 创建一个水平布局，就像把盒子分成左右两格
   - `left_panel = QVBoxLayout()` - 创建一个垂直布局作为左侧面板，就像在左格里又叠了几层
   - `port_group = QGroupBox("串口设置")` - 创建一个分组框，标题是"串口设置"，就像在盒子里放一个带标签的小格子
   - `port_layout = QHBoxLayout()` - 在分组框里创建水平布局，就像在小格子里再排列东西

4. **控件创建**：
   - `self.port_combo = QComboBox()` - 创建一个下拉框，就像做一个可以选择的菜单
   - `self.refresh_btn = QPushButton("刷新")` - 创建一个按钮，文字是"刷新"，就像做一个可以按的开关
   - `slider = QSlider(Qt.Horizontal)` - 创建一个水平滑块，就像做一个可以拖动的调节器
   - `slider.setMinimum(90)` - 设置滑块最小值为90，就像规定调节器的最低位置
   - `slider.setMaximum(180)` - 设置滑块最大值为180，就像规定调节器的最高位置
   - `slider.setValue(90)` - 设置滑块初始值为90，就像把调节器放在初始位置

5. **布局添加**：
   - `port_layout.addWidget(port_label)` - 把标签添加到布局里，就像把东西放在格子里
   - `port_group.setLayout(port_layout)` - 把布局设置给分组框，就像把格子固定在盒子里
   - `left_panel.addWidget(port_group)` - 把分组框添加到左侧面板，就像把小盒子放进大盒子
   - `main_layout.addLayout(left_panel, 1)` - 把左侧面板添加到主布局，占1份空间，就像给左格分配空间

6. **预设按钮网格布局**：
   - `preset_layout = QGridLayout()` - 创建网格布局，就像画一个棋盘
   - `preset_names = ["张开", "握拳", "OK手势", "指示"]` - 定义预设动作名称列表，就像列一个清单
   - `for idx, name in enumerate(preset_names):` - 遍历预设动作名称，就像按清单逐个处理
   - `btn = QPushButton(name)` - 创建按钮，文字是动作名称，就像做一个带标签的开关
   - `self.preset_buttons[name] = btn` - 把按钮添加到字典里，就像给每个开关编个号
   - `preset_layout.addWidget(btn, idx // 2, idx % 2)` - 把按钮添加到网格布局，`idx//2` 是行号，`idx%2` 是列号，就像把开关放在棋盘的特定位置

7. **脚本编辑器设置**：
   - `self.script_editor = QTextEdit()` - 创建文本编辑器，就像做一个可以写字的本子
   - `self.script_editor.setPlaceholderText(...)` - 设置占位文本，提示脚本格式，就像在本子上写示例
   - `self.script_log.setReadOnly(True)` - 设置日志显示为只读，就像做一个只能看不能写的本子

8. **重要参数解释**：
   - `self`：代表当前对象，就像自己
   - `QWidget`：所有界面元素的基础类，就像所有控件的"妈妈"
   - `QHBoxLayout`：水平布局，控件从左到右排列，就像排队一样
   - `QVBoxLayout`：垂直布局，控件从上到下排列，就像叠积木一样
   - `QGridLayout`：网格布局，控件按行和列排列，就像棋盘一样
   - `QComboBox`：下拉框，点击后出现多个选项，就像选择菜单一样
   - `QPushButton`：按钮，点击后触发操作，就像门铃一样
   - `QSlider`：滑块，拖动后改变数值，就像音量调节器一样
   - `QTextEdit`：文本编辑器，可以输入多行文本，就像笔记本一样
   - `QStatusBar`：状态栏，显示状态信息，就像公告栏一样

9. **重要语法解释**：
   - `def`：定义函数或方法的关键字，就像给一个动作起名字
   - `:`：冒号，表示代码块的开始，就像画一个框，里面是具体的操作
   - `self.`：访问实例变量的前缀，就像指向自己的某个部分
   - `()`：括号，里面放参数，就像给动作传递信息
   - `[]`：方括号，用于列表或字典的索引，就像指定位置
   - `for ... in ...:`：循环语句，遍历一个集合，就像逐个处理清单上的项目
   - `if ...:`：条件语句，根据条件执行不同的操作，就像做选择

10. **重要特点**：
    - 只创建控件，不绑定信号（信号绑定在 main.py 中统一处理），就像只做开关，不接电线
    - 不包含任何业务逻辑，只负责界面显示，就像只做外观，不做内部功能
    - 所有控件都是公开属性，供其他模块访问，就像把开关的接口露出来，方便别人使用

11. **如何理解**：
    - 把界面想象成一个"画板"，我们只是在上面摆放各种"控件"（按钮、滑块等）
    - 这些控件现在还不会动，只是静态的"摆设"
    - 当用户操作这些控件时，它们会产生"信号"，但信号的处理由控制层负责

### 5. 外表层的特点
- **不直接和机械手对话**，就像你不会直接和机器人的内部零件说话一样
- **不执行复杂逻辑**，就像镜子不会思考一样
- **只做人和程序之间的"桥梁"**，就像翻译官一样，把你的操作告诉程序，把程序的结果告诉你

## 第二层 —— 控制层（大脑）

### 1. 控制层是什么
它是程序的大脑，就像我们的大脑一样，所有操作都要经过它处理，是整个程序的"指挥中心"。

### 2. 大脑的第一个任务：接收信号
- **你点按钮**，大脑收到点击信号，就像你告诉大脑要做什么
- **你滑滑块**，大脑收到数值变化，就像你告诉大脑要调整什么
- **你运行脚本**，大脑收到启动指令，就像你告诉大脑要开始表演了

### 3. 大脑的第二个任务：判断与处理
- **是否连接了设备？** 就像你要打电话前先检查手机是否有信号
- **指令是否合法？** 就像你要确认对方说的话是否能听懂
- **角度是否在合理范围？** 就像你要确认动作是否安全
- **脚本是否可以运行？** 就像你要确认作业是否正确

### 4. 大脑的第三个任务：指挥工作
- **告诉底层**：发送什么指令，就像指挥官给士兵下命令
- **告诉界面**：显示什么内容，就像老师在黑板上写答案
- **告诉脚本**：什么时候开始、停止，就像导演喊"开始"和"停"

### 5. 大脑的实现方式
**代码示例：interaction_module.py**

```python
# 1. 类定义和初始化模块
class InteractionController:
    """
    用户交互控制器

    说明：
    - ui：来自 ui_module 的纯控件对象（不要求是特定类，只要包含所需属性）
    - serial_client：来自 serial_module 的串口客户端
    - script_service：来自 script_module 的脚本服务（内部管理线程）
    """

    def __init__(self, ui, serial_client: SerialPortClient, script_service: ScriptService):
        # 1.1 保存界面、串口客户端和脚本服务的引用
        self.ui = ui  # 界面对象，用来操作界面控件
        self.serial_client = serial_client  # 串口客户端，用来和机械手通信
        self.script_service = script_service  # 脚本服务，用来执行脚本

            "握拳": [180, 180, 180, 180],  # 四个手指都弯曲
            "OK手势": [180, 180, 90, 90],  # 食指和中指弯曲，其他伸直
            "指示": [90, 180, 180, 180],  # 食指伸直，其他弯曲
        }

            return

            self.ui.status_bar.showMessage(f"发送指令: {command.strip()}")  # 显示发送的指令

        # 5.1 打开文件选择对话框

            return
        try:
            with open(file_path, "r", encoding="utf-8") as f:  # 打开文件
                self.ui.script_editor.setText(f.read())  # 读取内容到编辑器
            self.ui.script_log.append(f"已加载脚本: {file_path}")  # 显示加载成功
        except Exception as e:  # 如果加载失败
            self.ui.script_log.append(f"加载失败: {str(e)}")  # 显示错误信息

    def save_script(self) -> None:
        """保存编辑区脚本到文件"""
        # 5.2 打开文件保存对话框
        file_path, _ = QFileDialog.getSaveFileName(
            self.ui, "保存脚本文件", "", "Text Files (*.txt);;All Files (*)"
        )
        if not file_path:  # 如果用户取消保存
            return
        try:
            with open(file_path, "w", encoding="utf-8") as f:  # 打开文件
                f.write(self.ui.script_editor.toPlainText())  # 写入内容
            self.ui.script_log.append(f"已保存脚本: {file_path}")  # 显示保存成功
        except Exception as e:  # 如果保存失败
            self.ui.script_log.append(f"保存失败: {str(e)}")  # 显示错误信息

    def run_script(self) -> None:
        """执行脚本"""
        # 5.3 如果没连接串口，就提示
        if not self.serial_client.is_connected:
            self.ui.script_log.append("请先连接串口")
            return

        # 5.4 获取脚本内容并分割成指令列表
        script_text = self.ui.script_editor.toPlainText()  # 获取编辑器内容
        commands = script_text.split("\n")  # 按换行分割成指令

        self.ui.script_log.append("开始执行脚本...")  # 显示开始执行
        self.script_service.start(commands)  # 启动脚本执行

    def stop_script(self) -> None:
        """停止脚本执行"""
        if self.script_service.is_running:  # 如果脚本正在运行
            self.script_service.stop()  # 停止脚本
            self.ui.script_log.append("脚本已停止")  # 显示已停止

    def on_script_finished(self) -> None:
        """脚本执行完成回调"""
        self.ui.script_log.append("脚本执行完成")  # 显示执行完成

    def close_cleanup(self) -> None:
        """
        程序退出清理：
        1) 停止脚本线程并等待结束
        2) 关闭串口连接
        """
        if self.script_service.is_running:  # 如果脚本正在运行
            self.script_service.stop()  # 停止脚本
            self.script_service.wait()  # 等待脚本线程结束
        if self.serial_client.is_connected:  # 如果串口已连接
            self.serial_client.disconnect()  # 断开连接
```

### 一、通信模块（和灵巧手对话）

2. **建立连接**：打开通道，让电脑和机械手通话，就像拨通电话
3. **发送指令**：把控制命令发给机械手，就像在电话里说话

```python
# 1. 类定义和初始化模块
class SerialPortClient:
    """
    串口客户端（纯通信封装）

    说明：
    - 默认使用 pyserial 的 serial.Serial 作为串口构造器；
    - 测试时可通过 serial_factory 注入 mock，以实现"无需硬件"的独立测试。
    """

    def __init__(
        self,
        config: SerialConfig | None = None,
        serial_factory: Callable[..., object] = serial.Serial,
    ) -> None:
        # 1.1 初始化串口配置
        self._config = config or SerialConfig()  # 如果没有配置，使用默认配置
        self._serial_factory = serial_factory  # 串口构造器，用来创建串口对象
        self._serial: Optional[object] = None  # 串口对象，初始为None

# 2. 串口扫描模块
    def scan_ports(self) -> List[str]:
        """扫描并返回可用串口端口名列表（如：COM3）"""
        ports = serial.tools.list_ports.comports()  # 扫描所有可用串口
        return [p.device for p in ports]  # 返回端口名列表

# 3. 连接状态模块
    @property
    def is_connected(self) -> bool:
        """是否已连接（底层串口对象存在且处于打开状态）"""
        if not self._serial:  # 如果串口对象不存在
            return False
        is_open = getattr(self._serial, "is_open", False)  # 检查串口是否打开
        return bool(is_open)  # 返回连接状态

# 4. 连接管理模块
    def connect(self, port: str) -> None:
        """
        连接指定端口

        :param port: 端口名（如 COM3）
        :raises: 底层串口初始化异常（保持原行为：异常由上层捕获并提示）
        """
        # 4.1 创建并初始化串口对象
        self._serial = self._serial_factory(
            port=port,  # 端口名
            baudrate=self._config.baudrate,  # 波特率（通信速度）
            timeout=self._config.timeout,  # 超时时间
        )

    def disconnect(self) -> None:
        """断开连接（若已连接则关闭串口）"""
        # 4.2 如果串口对象不存在，直接返回
        if not self._serial:
            return
        # 4.3 获取关闭方法并执行
        close = getattr(self._serial, "close", None)  # 获取关闭方法
        if callable(close):  # 如果关闭方法存在
            close()  # 关闭串口

# 5. 数据发送模块
    def send_raw_text(self, text: str) -> None:
        """
        发送原始文本（按传入内容原样发送，不强制补换行）

        说明：
        - 用于保持原代码行为：滑块发送时已经自带 '\n'；
        - 同时也方便脚本模块自行决定是否补换行。
        """
        # 5.1 如果没连接，直接返回
        if not self.is_connected:
            return
        # 5.2 获取写入方法并执行
        write = getattr(self._serial, "write", None)  # 获取写入方法
        if not callable(write):  # 如果写入方法不存在
            raise RuntimeError("底层串口对象不支持 write()")  # 抛出错误
        write(text.encode("utf-8"))  # 发送数据（编码为字节）

    def send_command(self, command: str) -> None:
        """
        发送一条命令（保证命令以 '\n' 结尾）

        :param command: 不含或可含换行的指令字符串，如 'FINGER1:90'
        """
        # 5.3 根据命令是否以换行结尾决定是否添加换行
        if command.endswith("\n"):  # 如果命令已经以换行结尾
            self.send_raw_text(command)  # 直接发送
        else:  # 如果命令没有以换行结尾
            self.send_raw_text(command + "\n")  # 添加换行后发送
```

**代码讲解**：

1. **类结构**：
   - `class SerialPortClient:` - 定义一个名为 `SerialPortClient` 的类，就像创建一个通信员

### 二、脚本模块（自动执行动作）

1. **读取脚本内容**：就像读剧本一样
2. **识别指令**：手指控制、延时等待，就像理解剧本里的台词和动作

4. **在后台运行**：不卡住界面，就像后台工作人员在准备道具
5. **实时输出执行日志**：就像舞台旁边的字幕
6. **可以随时停止**：就像导演喊"停"

```python
# 1. ScriptRunner 类 - 脚本执行线程模块
class ScriptRunner(QThread):
    """
    脚本执行线程类
    作用：在后台执行脚本指令，不卡住UI界面
    继承自QThread，重写run()方法实现线程逻辑
    """
    # 1.1 信号定义
    log_signal = pyqtSignal(str)        # 信号：向外输出日志字符串
    finished_signal = pyqtSignal()     # 信号：脚本执行完成

    # 1.2 初始化模块
    def __init__(self, serial_client: SerialPortClient, commands: List[str]):
        """
        构造函数
        :param serial_client: 串口客户端，提供发送接口
        :param commands: 脚本指令列表
        """
        super().__init__()  # 初始化父类QThread
        self.serial_client = serial_client  # 注入串口客户端
        self.commands = commands            # 要执行的指令
        self.running = True                 # 线程运行标志位

    # 1.3 线程运行模块
    def run(self) -> None:
        """
        线程入口函数
        自动被调用，遍历执行所有脚本指令
        """
        # 遍历每一行指令
        for cmd in self.commands:
            # 如果运行标志为False，终止执行
            if not self.running:
                break

            # 去除首尾空白字符
            cmd = cmd.strip()
            # 空行或#注释行 → 跳过
            if not cmd or cmd.startswith("#"):
                continue

            # 1.3.1 指令处理模块
            # 指令1：控制所有手指
            if cmd.startswith("ALL:"):
                self.send_command(cmd)
            # 指令2：控制单个手指
            elif cmd.startswith("FINGER"):
                self.send_command(cmd)
            # 指令3：延时
            elif cmd.startswith("DELAY"):
                try:
                    # 分割指令，取出毫秒数
                    delay_ms = int(cmd.split(":")[1])
                    self.log_signal.emit(f"等待 {delay_ms}ms")
                    time.sleep(delay_ms / 1000)  # 转成秒
                except Exception:
                    self.log_signal.emit(f"无效的DELAY命令: {cmd}")
            # 未知指令
            else:
                self.log_signal.emit(f"未知命令: {cmd}")

        # 全部执行完毕 → 发完成信号
        self.finished_signal.emit()

    # 1.4 命令发送模块
    def send_command(self, command: str) -> None:
        """
        发送串口指令函数
        :param command: 要发送的指令字符串（不含换行）
        """
        # 检查串口客户端是否已连接
        if self.serial_client and self.serial_client.is_connected:
            try:
                # 调用串口客户端发送指令
                self.serial_client.send_command(command)
                # 输出日志
                self.log_signal.emit(f"发送: {command}")
                # 短延时，保证硬件处理
                time.sleep(0.05)
            except Exception as e:
                self.log_signal.emit(f"发送失败: {str(e)}")

    # 1.5 停止模块
    def stop(self) -> None:
        """停止线程执行"""
        self.running = False


# 2. ScriptService 类 - 脚本服务模块
class ScriptService(QObject):
    """
    脚本服务（线程管理外观模式）
    作用：
    - 封装ScriptRunner，对外提供简单接口
    - 上层只调用 start/stop，不关心线程细节
    - 统一转发日志/完成信号
    """

    # 2.1 信号定义
    log_signal = pyqtSignal(str)        # 日志信号
    finished_signal = pyqtSignal()     # 完成信号

    # 2.2 初始化模块
    def __init__(self, serial_client: SerialPortClient):
        super().__init__()
        self._serial_client = serial_client   # 串口客户端
        self._runner: Optional[ScriptRunner] = None  # 当前执行线程

    # 2.3 运行状态模块
    @property
    def is_running(self) -> bool:
        """查询是否正在运行脚本"""
        if not self._runner:
            return False
        return bool(self._runner.isRunning())

    # 2.4 脚本启动模块
    def start(self, commands: List[str]) -> None:
        """
        启动脚本执行
        每次创建新线程，与原代码逻辑保持一致
        """
        # 创建新线程
        runner = ScriptRunner(self._serial_client, commands)
        # 信号转发：线程 → 服务层
        runner.log_signal.connect(self.log_signal.emit)
        runner.finished_signal.connect(self.finished_signal.emit)
        # 保存线程引用
        self._runner = runner
        # 启动线程
        runner.start()

    # 2.5 脚本停止模块
    def stop(self) -> None:
        """停止当前脚本"""
        if self._runner and self._runner.isRunning():
            self._runner.stop()

    # 2.6 线程等待模块
    def wait(self) -> None:
        """等待线程结束（程序退出时用）"""
        if self._runner and self._runner.isRunning():
            self._runner.wait()
```

```python
class FingerControllerApp(FingerControllerUI):
    """整合后的主窗口（仅在主入口中做信号绑定与关闭清理）"""

    def __init__(self):
        super().__init__()  # 初始化父类（外表层）

        # 创建底层模块
        self.serial_client = SerialPortClient()  # 串口客户端，用于和机械手通信
        self.script_service = ScriptService(self.serial_client)  # 脚本服务，用于执行脚本
        # 创建控制层，把界面、串口客户端、脚本服务都传进去
        self.controller = InteractionController(self, self.serial_client, self.script_service)

        # 绑定所有信号
        self._bind_signals()
        # 刷新串口列表
        self.controller.refresh_ports()

    def _bind_signals(self) -> None:
        """集中绑定全部信号（UI 模块不做任何绑定）"""
        # 绑定按钮点击信号
        self.refresh_btn.clicked.connect(self.controller.refresh_ports)  # 刷新按钮 → 刷新串口
        self.connect_btn.clicked.connect(self.controller.toggle_connection)  # 连接按钮 → 连接/断开

        # 绑定滑块信号
        for idx, slider in enumerate(self.finger_sliders, start=1):  # 遍历每个滑块
            # 滑块值变化 → 调用控制层的方法
            slider.valueChanged.connect(lambda value, i=idx: self.controller.on_slider_changed(i, value))

        # 绑定预设按钮信号
        for name, btn in self.preset_buttons.items():  # 遍历每个预设按钮
            # 按钮点击 → 应用对应预设动作
            btn.clicked.connect(lambda _, n=name: self.controller.apply_preset_by_name(n))

        # 绑定脚本操作按钮信号
        self.load_btn.clicked.connect(self.controller.load_script)  # 加载脚本
        self.save_btn.clicked.connect(self.controller.save_script)  # 保存脚本
        self.run_btn.clicked.connect(self.controller.run_script)  # 执行脚本
        self.stop_btn.clicked.connect(self.controller.stop_script)  # 停止脚本

        # 绑定脚本服务信号
        self.script_service.log_signal.connect(self.script_log.append)  # 日志信号 → 显示到日志区
        self.script_service.finished_signal.connect(self.controller.on_script_finished)  # 完成信号 → 处理完成

    def closeEvent(self, event) -> None:
        """窗口关闭事件：停止脚本线程、关闭串口（保持原程序退出时的资源释放行为）"""
        self.controller.close_cleanup()  # 调用控制层的清理方法
        event.accept()  # 接受关闭事件
```

1. **初始化过程**：

   - 在 `__init__` 方法中：
     - 创建 `SerialPortClient` 实例，用于串口通信，就像安装电话
     - 创建 `ScriptService` 实例，用于脚本执行，就像请一个助手
     - 创建 `InteractionController` 实例，作为控制层，就像请一个指挥官
     - 调用 `_bind_signals()` 绑定所有信号，就像把所有电线都接好

2. **信号绑定**：
   - **按钮点击信号**：就像按下门铃，会触发相应的动作

     - `save_btn` → `controller.save_script`（保存脚本）

   - **滑块信号**：就像移动开关，会改变相应的状态

## 总结

我们用三层结构来理解它的实现，就像一个汉堡包：

1. **外表层**：就像汉堡的面包，负责显示和接收操作
   - 使用 PyQt5 创建漂亮的界面
   - 包含串口设置、手指控制、预设动作、脚本编辑等区域
   - 只负责显示，不负责思考，就像镜子一样

2. **控制层**：就像汉堡的肉饼，负责判断、处理、指挥
   - 处理用户的所有操作，就像大脑一样
   - 协调各个模块的工作，就像指挥官一样
   - 管理程序的状态，就像管家一样

3. **底层**：就像汉堡的底座，负责通信和执行任务
   - 串口通信模块：和机械手说话，就像电话接线员一样
   - 脚本执行模块：自动执行动作，就像自动化助手一样

三层分工明确、互相配合，让程序稳定、清晰、容易理解，这就是编程中最核心的思想：**分层、分工、分步实现**。
