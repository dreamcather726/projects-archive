## 认识这个程序（7分钟）

### 1. 这个程序是什么

首先，我们来认识一下这个程序。它是一个电脑桌面软件，专门用来连接和控制机械手的。简单来说，它就像一个遥控器，让我们可以用电脑来指挥机械手做各种动作。

### 2. 这个程序能做什么

那它具体能做什么呢？

- 第一，它可以搜索并连接机械手，找到设备在哪里
- 第二，它有四个滑块，我们可以用滑块来控制每根手指的角度
- 第三，它有预设动作按钮，比如张开、握拳，一键就能执行
- 第四，它可以写脚本，让机械手自动完成一连串动作，就像编一个小剧本
- 第五，它还有日志显示，我们可以实时看到程序在做什么

### 3. 学习思路：三层结构

为了让大家更容易理解，我们把程序分成三层来讲：

- **第一层：外表层**——就是你打开软件看到的界面，所有按钮、滑块、文字都在这一层
- **第二层：控制层**——这是程序的大脑，所有操作都要经过它处理
- **第三层：底层**——这是真正干活的部分，负责和机械手通信、执行动作

接下来，我们就一层一层地来剖析这个程序。

## 第一层 —— 外表层（界面）（15分钟）

### 1. 外表层是什么

首先，我们来看第一层——外表层。外表层就是你打开软件后看到的整个窗口，所有的按钮、滑块、文字、显示区域，都属于外表层。

### 2. 外表层包括哪些内容

外表层主要包括五个部分：

- **串口连接区**：在这里选择要连接的接口，点击刷新和连接按钮
- **手指控制区**：有四个滑块，分别对应四根手指，可以拖动调整角度
- **预设手势区**：有几个按钮，比如张开、握拳，一键执行预设动作
- **脚本编辑区**：在这里写脚本，让机械手自动执行动作
- **日志显示区**：显示程序的运行情况，比如发送了什么指令、执行了什么动作

### 3. 外表层的工作规则

外表层有什么特点呢？它就像一个"传声筒"，只负责：

- 显示信息，不负责思考
- 接收你的操作，不自己做决定
- 把你的操作传递给大脑（控制层）
- 把结果显示给你看

### 4. 外表层的实现方式

现在，我们来看一下外表层的代码是怎么写的。

（展示代码：ui_module.py - 类定义和初始化）

```python
class FingerControllerUI(QWidget):
    """
    手指控制器界面（纯 UI）
    整个窗口只创建控件，不做任何业务绑定和操作
    """

    def __init__(self):
        super().__init__()
        self.port_combo: QComboBox
        self.refresh_btn: QPushButton
        self.connect_btn: QPushButton
        self.status_bar: QStatusBar

        self.finger_sliders: List[QSlider] = []
        self.finger_labels: List[QLabel] = []

        self.preset_buttons: Dict[str, QPushButton] = {}

        self.script_editor: QTextEdit
        self.load_btn: QPushButton
        self.save_btn: QPushButton
        self.run_btn: QPushButton
        self.stop_btn: QPushButton
        self.script_log: QTextEdit

        self._setup_ui()
```

同学们看，这段代码做了什么呢？

1. **定义类**：创建了一个叫 `FingerControllerUI` 的类，它继承自 `QWidget`，这是 PyQt5 中创建窗口的基础类。

2. **声明控件变量**：在 `__init__` 方法里，声明了所有需要用到的控件变量。这里的 `self.***` 表示这是一个**实例变量**，可以在类的其他方法中访问和使用：

   | 变量名 | 类型 | 含义（小朋友版） |
   |--------|------|------------------|
   | `port_combo` | `QComboBox` | 串口选择下拉框，就像学校食堂的菜单，点击后会弹出好多选项让你选 |
   | `refresh_btn` | `QPushButton` | 刷新按钮，就像刷新作业页面，点击后会重新检查有哪些设备可以连接 |
   | `connect_btn` | `QPushButton` | 连接按钮，就像打开家门的钥匙，点击后可以和机械手交朋友（连接）或说再见（断开） |
   | `status_bar` | `QStatusBar` | 状态栏，就像教室后面的黑板，用来显示现在程序在做什么 |
   | `finger_sliders` | `List[QSlider]` | 手指控制滑块列表，就像玩游戏时的音量调节，拖动它可以控制每根手指的弯曲程度 |
   | `finger_labels` | `List[QLabel]` | 手指角度标签列表，就像温度计显示温度一样，显示每根手指现在的角度 |
   | `preset_buttons` | `Dict[str, QPushButton]` | 预设动作按钮字典，就像游戏里的快捷技能，点击一下就能立刻做出对应的手势 |
   | `script_editor` | `QTextEdit` | 脚本编辑器，就像写作文的本子，你可以在这里写指令让机械手自动执行 |
   | `load_btn` | `QPushButton` | 加载脚本按钮，就像打开之前写好的作文本，从文件中读取已经写好的脚本 |
   | `save_btn` | `QPushButton` | 保存脚本按钮，就像保存作文一样，把你写的脚本保存到电脑里 |
   | `run_btn` | `QPushButton` | 执行脚本按钮，就像按下播放键，让机械手开始按照脚本做动作 |
   | `stop_btn` | `QPushButton` | 停止脚本按钮，就像按下暂停键，让机械手立刻停止当前的动作 |
   | `script_log` | `QTextEdit` | 脚本执行日志，就像机器人的日记，记录它做了什么动作，遇到了什么问题 |

   **关于 PyQt5 控件类型**：
   - `QComboBox`：下拉框，就像你书包里的铅笔盒，打开后能看到好多铅笔可以选
   - `QPushButton`：按钮，就像电梯里的楼层按钮，按一下就能触发相应的操作
   - `QStatusBar`：状态栏，就像学校的广播，随时告诉你现在发生了什么事
   - `QSlider`：滑块，就像你玩游戏时的方向键，拖动它可以改变数值
   - `QLabel`：标签，就像你的名字标签，用来显示文字或图片
   - `QTextEdit`：文本编辑器，就像你写作业的本子，可以输入和编辑很多行文字
   - `QGroupBox`：分组框，就像你的书包，把相关的东西放在一起，还能贴上标签

3. **调用创建界面的方法**：最后调用 `self._setup_ui()` 方法来实际创建界面。

```python
def _setup_ui(self) -> None:
    """创建并摆放所有 UI 控件（不绑定信号、不做业务逻辑）"""
```

```python
    # 手指控制区域
    finger_group = QGroupBox("手指控制")
```

这部分代码创建手指控制区域，就像在教室里排队一样：

   - `slider.setMaximum(180)`：设置滑块最大值为180，就像玩具的最右边位置
   - `slider.setValue(90)`：设置滑块初始值为90，就像玩具一开始放在最左边
   - `self.finger_sliders.append(slider)`：把滑块添加到列表中，就像把玩具的位置记下来

```python
    preset_group = QGroupBox("预设动作")

    preset_names = ["张开", "握拳", "OK手势", "指示"]
```

这部分代码创建预设动作区域，就像在教室里安排座位一样：

1. **创建分组框**：`preset_group = QGroupBox("预设动作")`
   - 就像在教室前面挂一个牌子，上面写着"预设动作区"

2. **创建网格布局**：`preset_layout = QGridLayout()`
   - 就像在桌子上画一个2x2的网格，分成4个格子，用来放4个按钮
   - 布局范围是2行2列，正好放下4个按钮

3. **定义预设动作名称**：`preset_names = ["张开", "握拳", "OK手势", "指示"]`
   - 就像给4个座位起名字：张开、握拳、OK手势、指示

4. **循环创建预设按钮**：
   - `for idx, name in enumerate(preset_names)`：按顺序给每个动作分配一个编号（0,1,2,3）
   - `btn = QPushButton(name)`：为每个动作创建一个按钮，就像给每个座位做一个名牌
   - `self.preset_buttons[name] = btn`：把按钮保存起来，就像把座位信息记录在本子上
   - `preset_layout.addWidget(btn, idx // 2, idx % 2)`：确定每个按钮的位置

   **每个按键的位置是怎么确定的呢？**
   就像安排座位号一样：
   - 第一个按钮（张开）：编号是0 → 行=0÷2=0，列=0%2=0 → 坐在第1排第1列
   - 第二个按钮（握拳）：编号是1 → 行=1÷2=0，列=1%2=1 → 坐在第1排第2列
   - 第三个按钮（OK手势）：编号是2 → 行=2÷2=1，列=2%2=0 → 坐在第2排第1列
   - 第四个按钮（指示）：编号是3 → 行=3÷2=1，列=3%2=1 → 坐在第2排第2列

   这样就形成了一个2x2的网格，四个按钮整整齐齐地排列在一起，就像教室的座位表一样。

## 第二层 —— 控制层（大脑）（20分钟）

### 1. 控制层是什么

控制层是程序的大脑，所有操作都要经过它处理。就像我们的大脑一样，它接收信息，分析信息，然后做出决策。

### 2. 大脑的第一个任务：接收信号

控制层的第一个任务是接收信号。当你操作界面上的控件时，比如：

- 你点击按钮，大脑收到点击信号
- 你拖动滑块，大脑收到数值变化信号
- 你点击执行脚本，大脑收到启动指令

### 3. 大脑的第二个任务：判断与处理

收到信号后，大脑要进行判断和处理：

- 是否连接了设备？
- 指令是否合法？
- 角度是否在合理范围？
- 脚本是否可以运行？

### 4. 大脑的第三个任务：指挥工作

判断完成后，大脑要指挥其他模块工作：

- 告诉底层：发送什么指令
- 告诉界面：显示什么内容
- 告诉脚本：什么时候开始、停止

```python
    """
    串口客户端（纯通信封装）

        self._serial: Optional[object] = None
```

`SerialPortClient` 类的构造函数做了什么呢？

```python
def send_raw_text(self, text: str) -> None:
    """
    发送原始文本（按传入内容原样发送，不强制补换行）

    说明：
    - 用于保持原代码行为：滑块发送时已经自带 '\n'；
    - 同时也方便脚本模块自行决定是否补换行。

    if not self.is_connected:
        return
    write = getattr(self._serial, "write", None)
    if not callable(write):
        raise RuntimeError("底层串口对象不支持 write()")
    write(text.encode("utf-8"))
```

这个方法发送原始文本数据：

2. **获取 write 方法**：使用 `getattr` 获取 `write` 方法，默认为 None
3. **检查 write 方法**：如果 `write` 不是可调用的，抛出异常
4. **发送数据**：调用 `write` 方法，发送编码后的文本

### 二、脚本模块（自动执行动作）

脚本模块的任务是自动执行动作，具体包括：

1. 读取脚本内容
2. 识别指令：手指控制、延时等待
3. 按顺序一步步执行
4. 在后台运行，不卡住界面
5. 实时输出执行日志
6. 可以随时停止

（展示代码：script_module.py - ScriptRunner 类定义和初始化）

```python
class ScriptRunner(QThread):
    """
    脚本执行线程类
    作用：在后台执行脚本指令，不卡住UI界面
    继承自QThread，重写run()方法实现线程逻辑
    """
    # 信号：向外输出日志字符串
    log_signal = pyqtSignal(str)
    # 信号：脚本执行完成
    finished_signal = pyqtSignal()

    def __init__(self, serial_client: SerialPortClient, commands: List[str]):
        """
        构造函数
        :param serial_client: 串口客户端，提供发送接口
        :param commands: 脚本指令列表
        """
        super().__init__()  # 初始化父类QThread
        self.serial_client = serial_client  # 注入串口客户端
        self.commands = commands            # 要执行的指令
        self.running = True                 # 线程运行标志位
```

`ScriptRunner` 类是脚本执行的核心，它继承自 `QThread`，可以在后台执行脚本，避免卡住界面：

1. **定义信号**：
   - `log_signal`：用于向外输出日志字符串
   - `finished_signal`：用于通知脚本执行完成

2. **构造函数**：
   - 接收两个参数：`serial_client`（串口客户端）和 `commands`（脚本指令列表）
   - 初始化父类 `QThread`
   - 保存串口客户端和指令列表
   - 设置 `running` 标志位为 True，表示线程正在运行

   **变量说明**（小朋友版）：

   | 变量名 | 类型 | 含义（小朋友版） |
   |--------|------|------------------|
   | `self.serial_client` | `SerialPortClient` | 串口客户端，就像快递员，负责把指令送到机械手那里 |
   | `self.commands` | `List[str]` | 脚本指令列表，就像购物清单，存储着要执行的所有指令 |
   | `self.running` | `bool` | 线程运行标志位，就像开关，打开（True）时继续执行，关闭（False）时停止 |

（展示代码：script_module.py - ScriptRunner 的 run 方法）

```python
def run(self) -> None:
    """
    线程入口函数
    自动被调用，遍历执行所有脚本指令
    """
    # 遍历每一行指令
    for cmd in self.commands:
        # 如果运行标志为False，终止执行
        if not self.running:
            break

        # 去除首尾空白字符
        cmd = cmd.strip()
        # 空行或#注释行 → 跳过
        if not cmd or cmd.startswith("#"):
            continue

        # 指令1：控制所有手指
        if cmd.startswith("ALL:"):
            self.send_command(cmd)
        # 指令2：控制单个手指
        elif cmd.startswith("FINGER"):
            self.send_command(cmd)
        # 指令3：延时
        elif cmd.startswith("DELAY"):
            try:
                # 分割指令，取出毫秒数
                delay_ms = int(cmd.split(":")[1])
                self.log_signal.emit(f"等待 {delay_ms}ms")
                time.sleep(delay_ms / 1000)  # 转成秒
            except Exception:
                self.log_signal.emit(f"无效的DELAY命令: {cmd}")
        # 未知指令
        else:
            self.log_signal.emit(f"未知命令: {cmd}")

    # 全部执行完毕 → 发完成信号
    self.finished_signal.emit()
```

`run` 方法是线程的入口函数，自动被调用，它的工作流程是：

1. **遍历指令**：遍历 `self.commands` 中的每一条指令

2. **检查运行状态**：如果 `self.running` 为 False，终止执行

3. **处理指令**：
   - 去除首尾空白字符
   - 跳过空行或注释行（以 # 开头的行）
   - 根据指令类型执行不同的操作：
     - `ALL:` 指令：控制所有手指，调用 `send_command` 发送指令
     - `FINGER` 指令：控制单个手指，调用 `send_command` 发送指令
     - `DELAY` 指令：延时等待，解析毫秒数，发送日志，然后等待
     - 未知指令：发送日志提示

4. **发送完成信号**：全部执行完毕后，发送 `finished_signal` 信号

（展示代码：script_module.py - ScriptRunner 的 send_command 方法）

```python
def send_command(self, command: str) -> None:
    """
    发送串口指令函数
    :param command: 要发送的指令字符串（不含换行）
    """
    # 检查串口客户端是否已连接
    if self.serial_client and self.serial_client.is_connected:
        try:
            # 调用串口客户端发送指令
            self.serial_client.send_command(command)
            # 输出日志
            self.log_signal.emit(f"发送: {command}")
            # 短延时，保证硬件处理
            time.sleep(0.05)
        except Exception as e:
            self.log_signal.emit(f"发送失败: {str(e)}")

    def stop(self) -> None:
        """停止线程执行"""
        self.running = False
```

`send_command` 方法负责发送串口指令：

1. **检查连接状态**：如果串口客户端存在且已连接，继续执行

2. **发送指令**：
   - 调用 `self.serial_client.send_command(command)` 发送指令
   - 发送日志，显示发送的指令
   - 短延时 0.05 秒，保证硬件有足够的时间处理指令

3. **异常处理**：如果发送失败，发送错误日志

`stop` 方法用于停止线程执行，只需将 `running` 标志位设置为 False 即可。

（展示代码：script_module.py - ScriptService 类定义和初始化）

```python
class ScriptService(QObject):
    """
    脚本服务（线程管理外观模式）
    作用：
    - 封装ScriptRunner，对外提供简单接口
    - 上层只调用 start/stop，不关心线程细节
    - 统一转发日志/完成信号
    """

    log_signal = pyqtSignal(str)        # 日志信号
    finished_signal = pyqtSignal()     # 完成信号

    def __init__(self, serial_client: SerialPortClient):
        super().__init__()
        self._serial_client = serial_client   # 串口客户端
        self._runner: Optional[ScriptRunner] = None  # 当前执行线程
```

`ScriptService` 类是脚本服务，封装了 `ScriptRunner`，对外提供简单的接口：

1. **定义信号**：与 `ScriptRunner` 相同，包括 `log_signal` 和 `finished_signal`

2. **构造函数**：
   - 接收一个参数：`serial_client`（串口客户端）
   - 初始化父类 `QObject`
   - 保存串口客户端
   - 初始化 `_runner` 为 None，表示当前没有执行线程

   **变量说明**（小朋友版）：

   | 变量名 | 类型 | 含义（小朋友版） |
   |--------|------|------------------|
   | `self._serial_client` | `SerialPortClient` | 串口客户端，就像传递消息的小信使，负责和机械手通信 |
   | `self._runner` | `Optional[ScriptRunner]` | 当前执行的脚本线程，就像正在工作的机器人，为 None 时表示机器人在休息 |

（展示代码：script_module.py - ScriptService 的方法）

```python
@property
def is_running(self) -> bool:
    """查询是否正在运行脚本"""
    if not self._runner:
        return False
    return bool(self._runner.isRunning())

def start(self, commands: List[str]) -> None:
    """
    启动脚本执行
    每次创建新线程，与原代码逻辑保持一致
    """
    # 创建新线程
    runner = ScriptRunner(self._serial_client, commands)
    # 信号转发：线程 → 服务层
    runner.log_signal.connect(self.log_signal.emit)
    runner.finished_signal.connect(self.finished_signal.emit)
    # 保存线程引用
    self._runner = runner
    # 启动线程
    runner.start()

def stop(self) -> None:
    """停止当前脚本"""
    if self._runner and self._runner.isRunning():
        self._runner.stop()

def wait(self) -> None:
    """等待线程结束（程序退出时用）"""
    if self._runner and self._runner.isRunning():
        self._runner.wait()
```

`ScriptService` 类的方法：

1. **is_running 属性**：检查是否正在运行脚本
   - 如果 `_runner` 为 None，返回 False
   - 否则，返回 `_runner.isRunning()` 的结果

2. **start 方法**：启动脚本执行
   - 创建新的 `ScriptRunner` 实例
   - 连接信号：将 `runner` 的信号连接到自己的信号
   - 保存线程引用
   - 启动线程

3. **stop 方法**：停止当前脚本
   - 如果 `_runner` 存在且正在运行，调用 `_runner.stop()` 停止

4. **wait 方法**：等待线程结束
   - 如果 `_runner` 存在且正在运行，调用 `_runner.wait()` 等待

同学们看，脚本模块由 `ScriptRunner` 和 `ScriptService` 两个类组成：

- `ScriptRunner` 是实际执行脚本的线程，负责解析和执行指令
- `ScriptService` 是脚本服务，封装了线程管理，对外提供简单的接口

脚本模块就像一个"自动化助手"，按照脚本的要求自动执行动作，在后台运行，不会影响界面的响应。

```python
def _bind_signals(self) -> None:
    """集中绑定全部信号（UI 模块不做任何绑定）"""
    self.refresh_btn.clicked.connect(self.controller.refresh_ports)
    self.connect_btn.clicked.connect(self.controller.toggle_connection)

    for idx, slider in enumerate(self.finger_sliders, start=1):
        slider.valueChanged.connect(lambda value, i=idx: self.controller.on_slider_changed(i, value))

    for name, btn in self.preset_buttons.items():
        btn.clicked.connect(lambda _, n=name: self.controller.apply_preset_by_name(n))

    self.load_btn.clicked.connect(self.controller.load_script)
    self.save_btn.clicked.connect(self.controller.save_script)
    self.run_btn.clicked.connect(self.controller.run_script)
    self.stop_btn.clicked.connect(self.controller.stop_script)
```

工作流程是这样的：

- **第一步**：你在外表层操作（如点击按钮、拖动滑块）
- **第二步**：操作产生信号，通过绑定关系传给控制层（大脑）
- **第三步**：控制层分析信号，做出决策（如检查连接状态、验证指令）
- **第四步**：控制层指挥底层模块执行操作（如发送串口指令、运行脚本）
- **第五步**：底层执行完成后，通过信号将结果返回给控制层
- **第六步**：控制层更新外表层，向你显示执行结果

这样就形成了一个完整的流程：操作 → 处理 → 执行 → 反馈
