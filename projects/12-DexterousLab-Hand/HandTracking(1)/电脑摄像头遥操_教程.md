## 1. 这个程序是做什么的？

你有没有想过，用自己的手就能控制一只机器手？就像这样：

```
你的手做出动作  →  电脑摄像头看到  →  机器手跟着动
```

这个程序就是实现这个功能的！它有两个主要功能：

### 功能一：手部追踪控制
- 电脑摄像头拍摄你的手
- 程序识别你每个手指的弯曲程度
- 把角度信号发送给机器手
- 你的手做什么动作，机器手就跟着做什么动作

### 功能二：脚本控制
- 你可以编写"动作脚本"
- 程序会按顺序执行你写的指令
- 比如：先张开手，等1秒，再握拳

### 为什么学习这个？

- **有趣又实用**：亲手控制机器手，体验科技的力量
- **学习编程**：了解Python、计算机视觉、串口通信等知识
- **培养逻辑思维**：分析问题、解决问题的能力
- **为未来做准备**：人工智能和机器人是未来的重要方向

```python
def get_finger_bend(landmarks, tip_idx, mcp_idx):
    """计算单个手指的弯曲程度（0~1 数值越小越弯）"""
    # 获取手指尖的坐标
    tip = np.array([landmarks.landmark[tip_idx].x,
                    landmarks.landmark[tip_idx].y])
    # 获取手指根部的坐标
    mcp = np.array([landmarks.landmark[mcp_idx].x,
                   landmarks.landmark[mcp_idx].y])
    # 计算两点之间的距离
    dist = np.linalg.norm(tip - mcp)
    return dist
```

```
    ●────●                  ●╲
    │    │                  │ ╲
    │    │                  ●──● ← 指尖靠近根部
    ●────●                  ↑ 距离变小
    ↑
   根部
```

### 4.5 脚本执行线程（第67-107行）

```python
class ScriptRunner(QThread):
    """脚本执行线程"""
    log_signal = pyqtSignal(str)
    finished_signal = pyqtSignal()
```

**什么是线程？**
> 线程就像一条"流水线"。程序可以在一条流水线上做摄像头追踪，同时在另一条流水线上发送指令。这样两件事可以同时进行，不会卡住。

#### 4.5.1 类的组成模块

`ScriptRunner`类由以下5个核心模块组成：

| 模块 | 类型 | 作用 |
|------|------|------|
| **类定义** | 类声明 | 继承自`QThread`，使其能独立运行 |
| **信号定义** | pyqtSignal | 用于线程间通信 |
| **__init__方法** | 构造函数 | 初始化线程，接收串口和命令列表 |

| **send_command方法** | 辅助函数 | 发送命令到串口 |
| **stop方法** | 控制函数 | 停止线程执行 |

#### 4.5.2 信号（Signal）详解

```python
log_signal = pyqtSignal(str)        # 日志信号，传递字符串
finished_signal = pyqtSignal()      # 完成信号，无参数
```

**信号的作用**：
- **log_signal**：当执行命令时，发送日志信息到主界面（如"发送: FINGER1:90"）
- **finished_signal**：当所有命令执行完毕时，通知主程序更新状态栏

**信号传递流程**：
```
ScriptRunner线程 ──log_signal──→ 主界面（显示日志）
        │
        └──finished_signal──→ 主界面（更新状态栏）
```

#### 4.5.4 run方法详解（核心逻辑）

```python
def run(self):
    for cmd in self.commands:
        if not self.running:           # 检查是否需要停止
            break

        cmd = cmd.strip()              # 去除首尾空格
        if not cmd or cmd.startswith('#'):  # 跳过空行和注释
            continue

        # 解析命令
        if cmd.startswith('ALL:'):
            self.send_command(cmd)     # ALL命令：控制所有手指
        elif cmd.startswith('FINGER'):
            self.send_command(cmd)     # FINGER命令：控制单个手指
        elif cmd.startswith('DELAY'):
            try:
                delay_ms = int(cmd.split(':')[1])  # 提取延迟时间
                self.log_signal.emit(f'等待 {delay_ms}ms')
                time.sleep(delay_ms / 1000)       # 转换为秒并等待
            except:
                self.log_signal.emit(f'无效的DELAY命令: {cmd}')
        else:
            self.log_signal.emit(f'未知命令: {cmd}')

    self.finished_signal.emit()       # 所有命令执行完毕
```

**执行流程图**：

```
开始
  ↓
遍历命令列表
  ↓
检查运行标志 ──否──→ 停止执行
  ↓是
去除空格
  ↓
是否空行或注释？ ──是──→ 跳过，处理下一条
  ↓否
命令类型判断
  ├─ ALL: ──→ send_command()
  ├─ FINGER: ──→ send_command()
  ├─ DELAY: ──→ 提取时间 → 等待
  └─ 其他 ──→ 输出错误
  ↓
还有命令？ ──是──→ 继续处理
  ↓否
发送完成信号
  ↓
结束
```

#### 4.5.5 send_command方法详解

```python
def send_command(self, command):
    if self.serial_port and self.serial_port.is_open:
        try:
            full_cmd = command + '\n'           # 添加换行符
            self.serial_port.write(full_cmd.encode('utf-8'))  # 编码并发送
            self.log_signal.emit(f'发送: {command}')  # 发送日志信号
            time.sleep(0.05)                    # 等待50毫秒
        except Exception as e:
            self.log_signal.emit(f'发送失败: {str(e)}')
```

**关键步骤**：
1. **检查串口状态**：确保串口已打开
2. **添加换行符**：串口通信通常需要换行符作为命令结束标志
3. **编码为字节**：`encode('utf-8')`将字符串转换为字节流
4. **发送数据**：通过串口写入字节流
5. **发送日志**：通知主界面显示发送的命令
6. **短暂延迟**：等待50毫秒，确保指令被机器手接收

**为什么需要延迟？**
- 机器手处理指令需要时间
- 避免指令发送过快导致丢失
- 给串口缓冲区留出处理时间

#### 4.5.6 stop方法详解

```python
def stop(self):

```

**停止机制**：
- 将`self.running`设为`False`
- `run()`方法中的循环会检测这个标志
- 一旦检测到`False`，立即退出循环
- 线程自然结束

#### 4.6.4 run方法详解（核心逻辑）

```python
def run(self):
    cap = cv2.VideoCapture(0)  # 打开默认摄像头
    
    with mp_hands.Hands(
        model_complexity=0,  # 模型复杂度（0-2），0最简单
        min_detection_confidence=0.5,  # 检测置信度阈值
        min_tracking_confidence=0.5) as hands:  # 追踪置信度阈值
        
        while self.running:
            ret, frame = cap.read()  # 读取一帧
            if not ret:  # 读取失败
                break
            
            frame = cv2.flip(frame, 1)  # 水平翻转，镜像效果
            frame.flags.writeable = False  # 提高性能
            frame = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)  # 转换颜色空间
            results = hands.process(frame)  # MediaPipe处理
            frame.flags.writeable = True  # 恢复可写
            frame = cv2.cvtColor(frame, cv2.COLOR_RGB2BGR)  # 转换回BGR
            
            finger_data = {}  # 存储手指数据
            
            if results.multi_hand_landmarks and results.multi_handedness:
                for idx, handedness in enumerate(results.multi_handedness):
                    hand_type = handedness.classification[0].label  # Left / Right
                    landmarks = results.multi_hand_landmarks[idx]
                    
                    # 计算每个手指的弯曲度
                    thumb_bend   = get_finger_bend(landmarks, mp_hands.HandLandmark.THUMB_TIP, mp_hands.HandLandmark.THUMB_MCP)
                    index_bend   = get_finger_bend(landmarks, mp_hands.HandLandmark.INDEX_FINGER_TIP, mp_hands.HandLandmark.INDEX_FINGER_MCP)
                    middle_bend  = get_finger_bend(landmarks, mp_hands.HandLandmark.MIDDLE_FINGER_TIP, mp_hands.HandLandmark.MIDDLE_FINGER_MCP)
                    ring_bend    = get_finger_bend(landmarks, mp_hands.HandLandmark.RING_FINGER_TIP, mp_hands.HandLandmark.RING_FINGER_MCP)
                    pinky_bend   = get_finger_bend(landmarks, mp_hands.HandLandmark.PINKY_TIP, mp_hands.HandLandmark.PINKY_MCP)
                    
                    # 映射到角度
                    thumb_angle   = map_bend_to_angle(thumb_bend, 'thumb')
                    index_angle   = map_bend_to_angle(index_bend, 'index')
                    middle_angle  = map_bend_to_angle(middle_bend, 'middle')
                    ring_angle    = map_bend_to_angle(ring_bend, 'ring')
                    pinky_angle   = map_bend_to_angle(pinky_bend, 'pinky')
                    
                    # 存储数据
                    finger_data[hand_type] = {
                        'thumb': {'bend': thumb_bend, 'angle': thumb_angle},
                        'index': {'bend': index_bend, 'angle': index_angle},
                        'middle': {'bend': middle_bend, 'angle': middle_angle},
                        'ring': {'bend': ring_bend, 'angle': ring_angle},
                        'pinky': {'bend': pinky_bend, 'angle': pinky_angle}
                    }
                    
                    # 绘制手部骨骼
                    mp_drawing.draw_landmarks(
                        frame,
                        landmarks,
                        mp_hands.HAND_CONNECTIONS,
                        mp_drawing_styles.get_default_hand_landmarks_style(),
                        mp_drawing_styles.get_default_hand_connections_style())
            
            # 转换为QImage
            h, w, ch = frame.shape
            bytes_per_line = ch * w
            qt_image = QImage(frame.data, w, h, bytes_per_line, QImage.Format_BGR888)
            self.frame_signal.emit(qt_image)  # 发送视频画面
            
            # 发送手指数据
            if finger_data:
                self.data_signal.emit(finger_data)  # 发送手指数据
    
    cap.release()  # 释放摄像头
```

   - 确保`cap.release()`在退出时执行

4. **错误处理**：
   - 检查`ret`变量确保图像读取成功
   - 处理可能的摄像头打开失败情况

## 6. 常见问题解答

### Q1: 点击"开始追踪"后画面卡住不动怎么办？

**可能原因**：
- 摄像头被其他程序占用
- 驱动没有安装

**解决方法**：
1. 关闭其他使用摄像头的程序（如微信、QQ）
2. 重新插拔摄像头
3. 检查设备管理器中摄像头驱动是否正常

### Q2: 串口连接失败怎么办？

**检查清单**：
- [ ] USB线是否插好？
- [ ] 机器手是否开机？
- [ ] 串口是否被其他程序占用？
- [ ] 驱动是否安装？

### Q3: 手部识别不准确怎么办？

**调节方法**：
- 保持光线充足、均匀
- 背景不要太复杂
- 手要完全在画面内
- 离摄像头距离适中（约30-50厘米）

### Q4: 机器手反应慢怎么办？

**优化建议**：
- 检查USB连接是否稳定
- 减少画面中其他手的干扰
- 在代码中调低`min_tracking_confidence`值（不建议低于0.3）

### Q5: 程序运行报错怎么办？

**常见错误及解决方法**：

| 错误信息 | 原因 | 解决方法 |
|---------|------|----------|
| `No module named 'cv2'` | 没安装OpenCV | 运行`pip install opencv-python` |
| `No module named 'mediapipe'` | 没安装MediaPipe | 运行`pip install mediapipe` |
| `No module named 'serial'` | 没安装pyserial | 运行`pip install pyserial` |
