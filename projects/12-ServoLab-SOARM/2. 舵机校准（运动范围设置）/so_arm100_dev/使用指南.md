## 🔌 硬件连接

1. 将USB转串口模块连接到电脑
2. 给舵机供电（推荐12V 5A以上电源）
3. **重要**: 每次只连接一个舵机进行ID设置

## 🎯 舵机ID设置步骤

### 方法1：使用图形化向导（推荐）

运行示例程序：

```bash
python examples/setup_motor_ids.py
```

按照提示操作：
1. 选择串口获取方式（推荐自动检测）
2. 选择"设置所有舵机ID"
3. 程序会依次提示你连接每个舵机
4. 每设置完一个舵机，断开它，连接下一个
5. 重复直到所有6个舵机都设置完成

### 方法2：单独设置某个舵机

如果只需要设置某一个舵机的ID：

```python
from core.motor_setup import MotorSetup

setup = MotorSetup("COM3")  # 替换为你的串口
setup.setup_single_motor("shoulder_pan", target_id=1)
```

### 方法3：使用Python脚本

```python
from core.motor_setup import MotorSetup

# 创建设置工具
setup = MotorSetup("COM3")  # Windows
# setup = MotorSetup("/dev/ttyUSB0")  # Linux

# 设置所有舵机
setup.setup_all_motors()
```

## ⚠️ 常见问题

### 1. 找不到舵机

**可能原因**：
- 舵机未通电
- 串口选择错误
- USB驱动未安装（CH340或CP2102）

**解决方法**：
```python
from core.motor_bus import MotorBus

bus = MotorBus("COM3", 1_000_000)
bus.connect()
motors = bus.scan_motors(range(0, 254))  # 扫描所有ID
print(f"找到的舵机: {motors}")
bus.disconnect()
```

### 2. 波特率不匹配

如果舵机波特率被修改过，尝试不同的波特率：

```python
from config.motor_config import SCAN_BAUDRATES

for baudrate in SCAN_BAUDRATES:
    print(f"尝试波特率: {baudrate}")
    bus = MotorBus("COM3", baudrate)
    if bus.connect():
        motors = bus.scan_motors(range(1, 10))
        if motors:
            print(f"成功! 波特率={baudrate}")
            break
        bus.disconnect()
```

### 3. ID设置失败

**步骤**：
1. 确保只连接一个舵机
2. 检查供电是否稳定
3. 尝试先关闭扭矩：
```python
bus.disable_torque(current_id)
time.sleep(0.2)
bus.write_control_table(current_id, "ID", new_id)
```

### 4. Windows系统找不到COM口

在设备管理器中检查：
1. 打开"设备管理器"
2. 展开"端口(COM和LPT)"
3. 查看CH340或USB Serial Port的COM编号

## 🔧 高级用法

### 直接使用MotorBus类

```python
from core.motor_bus import MotorBus
from config.motor_config import OperatingMode

# 创建总线连接
bus = MotorBus("COM3", 1_000_000)
bus.connect()

# 读取舵机位置
position = bus.get_present_position(motor_id=1)
print(f"当前位置: {position}")

# 设置操作模式为位置模式
bus.set_operating_mode(motor_id=1, mode=OperatingMode.POSITION)

# 使能扭矩
bus.enable_torque(motor_id=1)

# 设置目标位置
bus.set_goal_position(motor_id=1, position=2048)  # 中间位置

# 断开连接
bus.disconnect()
```

### 使用上下文管理器

```python
from core.motor_bus import MotorBus

with MotorBus("COM3", 1_000_000) as bus:
    # 自动连接
    position = bus.get_present_position(1)
    print(f"位置: {position}")
    # 自动断开
```
