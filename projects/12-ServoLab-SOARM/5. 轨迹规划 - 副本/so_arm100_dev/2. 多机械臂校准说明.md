# 多机械臂校准说明

## 问题说明

当使用多个SO-ARM100机械臂时（如遥操作的主从臂配置），**每个机械臂的校准数据必须独立存储**，因为：

1. **零点偏移不同**：每个舵机的机械零点位置不同
2. **运动范围差异**：即使是相同型号，实际运动范围也可能有细微差异
3. **独立控制**：遥操作时需要分别加载各自的校准数据

## 解决方案

系统现在支持通过 `robot_id` 参数区分不同机械臂的校准文件。

### 校准文件命名规则

```
calibration/
├── so_arm100_calibration_leader.json      # 主臂校准数据
├── so_arm100_calibration_follower.json    # 从臂校准数据
├── so_arm100_calibration_robot1.json      # 其他机械臂
└── so_arm100_calibration_default.json     # 默认（单臂使用）
```

## 使用方法

### 1. 校准主臂（Leader）

```bash
python examples/calibrate_motors.py
```

**交互过程：**
```
请输入机械臂ID (默认 default): leader
请输入串口名称 (默认 COM3): COM3

# 选择 "1. 完整校准流程"
# 按提示完成校准...

✓ 校准数据已保存到: calibration/so_arm100_calibration_leader.json
```

### 2. 校准从臂（Follower）

**重要：断开主臂，连接从臂到另一个串口**

```bash
python examples/calibrate_motors.py
```

**交互过程：**
```
请输入机械臂ID (默认 default): follower
请输入串口名称 (默认 COM3): COM24

# 选择 "1. 完整校准流程"
# 按提示完成校准...

✓ 校准数据已保存到: calibration/so_arm100_calibration_follower.json
```

### 3. 运行遥操作

现在遥操作程序会自动加载对应的校准文件：

```bash
python examples/teleoperation.py
```

```python
# 程序内部自动处理
leader = SO100Robot(port="COM3", robot_id="leader")      # 加载 leader 校准
follower = SO100Robot(port="COM24", robot_id="follower")  # 加载 follower 校准
```

## 代码示例

### 创建机械臂实例时指定 robot_id

```python
from core.robot import SO100Robot

# 主臂
leader = SO100Robot(
    port="COM3",
    robot_id="leader",  # 使用 leader 校准文件
    max_relative_target=None
)

# 从臂
follower = SO100Robot(
    port="COM24",
    robot_id="follower",  # 使用 follower 校准文件
    max_relative_target=None
)

# 连接时自动加载对应的校准文件
leader.connect()    # 加载 so_arm100_calibration_leader.json
follower.connect()  # 加载 so_arm100_calibration_follower.json
```

### 单机械臂使用（向后兼容）

如果只有一个机械臂，可以使用默认值：

```python
robot = SO100Robot(port="COM3")  # robot_id 默认为 "default"
robot.connect()  # 加载 so_arm100_calibration_default.json
```

## 校准数据管理

### 查看现有校准文件

```bash
dir calibration\so_arm100_calibration_*.json
```

### 备份校准数据

```bash
# 备份主臂校准
copy calibration\so_arm100_calibration_leader.json calibration\backup\

# 备份从臂校准
copy calibration\so_arm100_calibration_follower.json calibration\backup\
```

### 重新校准某个机械臂

只需运行校准程序并指定相同的 `robot_id`，新数据会覆盖旧文件：

```bash
python examples/calibrate_motors.py
# 输入 robot_id: leader
# 完成校准后自动保存到 so_arm100_calibration_leader.json
```

## 注意事项

### ⚠️ 重要提示

1. **每个机械臂必须单独校准**
   - 不能共用校准文件
   - 即使是相同型号也要分别校准

2. **校准顺序**
   - 先校准主臂（leader）
   - 再校准从臂（follower）
   - 确保每次只连接一个机械臂

3. **串口识别**
   - 记录每个机械臂对应的串口号
   - 建议贴标签标识主臂和从臂

4. **校准文件命名**
   - 使用有意义的 robot_id（如 leader, follower）
   - 避免使用特殊字符
   - 保持命名一致性

### 🔧 故障排查

#### 问题1：找不到校准文件

```
WARNING - 未找到校准文件: calibration/so_arm100_calibration_leader.json
WARNING - 请先为机械臂 'leader' 运行校准程序
```

**解决方法：**
- 确认已为该 robot_id 运行过校准
- 检查 calibration 目录下是否有对应文件
- 确认 robot_id 拼写正确

#### 问题2：遥操作时从臂不跟随

**可能原因：**
- 主臂或从臂使用了错误的校准文件
- 校准数据不匹配

**解决方法：**
```python
# 检查加载的校准文件
print(f"主臂校准: {leader.calibration_data}")
print(f"从臂校准: {follower.calibration_data}")

# 重新校准
# 1. 校准主臂（robot_id=leader）
# 2. 校准从臂（robot_id=follower）
```

#### 问题3：校准数据混淆

**解决方法：**
1. 删除所有校准文件
2. 重新逐个校准
3. 使用清晰的命名

```bash
# 清理旧校准文件
del calibration\so_arm100_calibration_*.json

# 重新校准
python examples/calibrate_motors.py  # robot_id: leader
python examples/calibrate_motors.py  # robot_id: follower
```

## API 参考

### SO100Robot 构造函数

```python
SO100Robot(
    port: str = "COM3",
    baudrate: int = 1_000_000,
    calibration_dir: str = "./calibration",
    robot_id: str = "default",  # 新增参数
    max_relative_target: Optional[float] = None,
    disable_torque_on_disconnect: bool = True
)
```

**参数说明：**
- `robot_id`: 机械臂唯一标识，用于区分校准文件
  - 默认值: `"default"`
  - 推荐值: `"leader"`, `"follower"`, `"robot1"`, `"robot2"` 等

### MotorCalibration.save_calibration

```python
calibrator.save_calibration(robot_id: str = "default")
```

**参数说明：**
- `robot_id`: 保存的机械臂ID
- 文件名格式: `so_arm100_calibration_{robot_id}.json`

## 最佳实践

### 双臂遥操作工作流

1. **硬件准备**
   ```
   主臂 → USB转串口 → COM3
   从臂 → USB转串口 → COM24
   ```

2. **校准主臂**
   ```bash
   # 只连接主臂
   python examples/calibrate_motors.py
   # robot_id: leader
   # port: COM3
   ```

3. **校准从臂**
   ```bash
   # 断开主臂，连接从臂
   python examples/calibrate_motors.py
   # robot_id: follower
   # port: COM24
   ```

4. **验证校准**
   ```bash
   # 同时连接双臂
   # 检查校准文件
   dir calibration\so_arm100_calibration_*.json
   
   # 应该看到：
   # so_arm100_calibration_leader.json
   # so_arm100_calibration_follower.json
   ```

5. **运行遥操作**
   ```bash
   python examples/teleoperation.py
   # leader port: COM3
   # follower port: COM24
   ```

### 多机械臂系统

如果有3个或更多机械臂：

```python
# 机械臂1
robot1 = SO100Robot(port="COM3", robot_id="robot1")

# 机械臂2
robot2 = SO100Robot(port="COM24", robot_id="robot2")

# 机械臂3
robot3 = SO100Robot(port="COM25", robot_id="robot3")
```

每个都需要独立校准并保存对应的校准文件。
