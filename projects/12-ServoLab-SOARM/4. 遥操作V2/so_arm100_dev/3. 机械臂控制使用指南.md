## 🎯 概述

### 主要功能

- ✅ **连接管理** - 自动连接串口和加载校准数据
- ✅ **观测读取** - 读取关节位置（归一化值）
- ✅ **动作发送** - 发送目标位置指令
- ✅ **安全限制** - 限制最大相对移动距离
- ✅ **自动配置** - 自动配置PID参数和扭矩限制
- ✅ **上下文管理** - 支持`with`语句自动连接/断开

### 设计特点

参考LeRobot项目设计：
- 归一化位置值：`[-1, 1]`（-1=最小位置，1=最大位置，0=中间位置）
- 自动加载校准数据
- 安全的相对移动限制
- 夹爪特殊保护（降低扭矩）

### 最简示例

```python
from core.robot import SO100Robot

# 创建机械臂实例
robot = SO100Robot(port="COM3")

# 连接
robot.connect()

# 使能扭矩
robot.enable_torque_all()

# 读取当前位置
obs = robot.get_observation()
print(obs)
# {'shoulder_pan': 0.05, 'shoulder_lift': -0.12, ...}

# 发送动作（移动到中间位置）
action = {motor: 0.0 for motor in obs.keys()}
robot.send_action(action)

# 断开连接
robot.disconnect()
```

### 使用上下文管理器

```python
from core.robot import SO100Robot

with SO100Robot(port="COM3") as robot:
    robot.enable_torque_all()
    
    # 读取观测
    obs = robot.get_observation()
    
    # 发送动作
    action = {"shoulder_pan": 0.5}
    robot.send_action(action)

# 自动断开连接
```

## 📚 核心API

### 初始化参数

```python
robot = SO100Robot(
    port="COM3",                      # 串口名称
    baudrate=1_000_000,               # 波特率（默认1Mbps）
    calibration_dir="./calibration",  # 校准数据目录
    max_relative_target=0.1,          # 最大相对移动距离（10%范围）
    disable_torque_on_disconnect=True # 断开时关闭扭矩
)
```

### 连接/断开

```python
# 连接（自动加载校准数据）
robot.connect(auto_load_calibration=True)

# 断开连接
robot.disconnect()

# 检查连接状态
if robot.is_connected:
    print("已连接")
```

### 扭矩控制

```python
# 使能所有舵机扭矩
robot.enable_torque_all()

# 关闭所有舵机扭矩
robot.disable_torque_all()
```

### 读取观测

```python
# 读取所有关节位置（归一化到 [-1, 1]）
obs = robot.get_observation()

# 示例输出
{
    'shoulder_pan': 0.05,    # 稍微偏右
    'shoulder_lift': -0.12,  # 稍微向下
    'elbow_flex': 0.0,       # 中间位置
    'wrist_flex': 0.23,      # 向上
    'wrist_roll': 0.0,       # 中间位置
    'gripper': -0.8          # 几乎关闭
}
```

### 发送动作

```python
# 发送动作指令（归一化值 [-1, 1]）
action = {
    'shoulder_pan': 0.5,   # 移动到75%位置
    'shoulder_lift': 0.0,  # 移动到中间
}

# 发送并返回实际发送的动作（可能被限幅）
actual_action = robot.send_action(action)
```

### 查询舵机信息

```python
# 获取所有舵机详细信息
info = robot.get_motor_info()

# 示例输出
{
    'shoulder_pan': {
        'id': 1,
        'position': 2048,
        'load': 120,
        'voltage': 124,       # 12.4V
        'temperature': 35     # 35°C
    },
    ...
}
```

## 💡 示例程序

### 示例1: 基础控制

```python
from core.robot import SO100Robot
import time

robot = SO100Robot(port="COM3", max_relative_target=0.1)

try:
    # 连接
    robot.connect()
    robot.enable_torque_all()
    
    # 读取当前位置
    print("当前位置:", robot.get_observation())
    
    # 移动到中间位置
    action = {motor: 0.0 for motor in robot.get_observation().keys()}
    robot.send_action(action)
    time.sleep(2.0)
    
    # 读取新位置
    print("新位置:", robot.get_observation())
    
finally:
    robot.disconnect()
```

### 示例2: 逐步移动

```python
from core.robot import SO100Robot
import time

with SO100Robot(port="COM3") as robot:
    robot.enable_torque_all()
    
    # 逐步移动shoulder_pan从-0.5到0.5
    for target in [-0.5, -0.25, 0.0, 0.25, 0.5]:
        action = {'shoulder_pan': target}
        robot.send_action(action)
        print(f"目标: {target}, 当前: {robot.get_observation()['shoulder_pan']:.3f}")
        time.sleep(1.0)
```

### 示例3: 安全控制（带限制）

```python
from core.robot import SO100Robot

# 限制单步最大移动5%范围
robot = SO100Robot(port="COM3", max_relative_target=0.05)

with robot as r:
    r.enable_torque_all()
    
    # 即使目标是1.0，实际每次只移动5%
    for _ in range(20):
        action = {'shoulder_pan': 1.0}
        actual = r.send_action(action)
        print(f"实际移动到: {actual['shoulder_pan']:.3f}")
        time.sleep(0.1)
```

### 示例4: 监控舵机状态

```python
from core.robot import SO100Robot
import time

with SO100Robot(port="COM3") as robot:
    robot.enable_torque_all()
    
    # 移动shoulder_pan
    robot.send_action({'shoulder_pan': 0.8})
    
    # 监控状态
    for i in range(10):
        info = robot.get_motor_info()
        sp_info = info['shoulder_pan']
        
        print(f"时刻 {i}:")
        print(f"  位置: {sp_info['position']}")
        print(f"  负载: {sp_info['load']}")
        print(f"  温度: {sp_info['temperature']}°C")
        
        time.sleep(0.5)
```

## 🔧 高级功能

### 自定义配置

```python
robot = SO100Robot(port="COM3")
robot.connect()

# 手动配置单个舵机
robot.bus.write_control_table(1, "P_Coefficient", 20)
robot.bus.write_control_table(1, "Max_Torque_Limit", 800)
```

### 原始位置控制

```python
# 如果不想使用归一化值，可以直接使用MotorBus
from core.motor_bus import MotorBus

bus = MotorBus("COM3", 1_000_000)
bus.connect()

# 发送原始位置值（0-4095）
bus.set_goal_position(1, 2048)  # ID=1, 位置=2048

bus.disconnect()
```

### 重新加载校准数据

```python
robot = SO100Robot(port="COM3")
robot.connect(auto_load_calibration=False)  # 不自动加载

# 手动加载校准数据
robot._load_calibration()
```

## 📋 位置值说明

### 归一化值映射

```
归一化值    实际含义
-1.0        最小位置（range_min）
 0.0        中间位置
+1.0        最大位置（range_max）
```

### 转换公式

**归一化 → 原始位置：**
```python
pos = (normalized + 1) / 2 * (range_max - range_min) + range_min
```

**原始位置 → 归一化：**
```python
normalized = (pos - range_min) / (range_max - range_min) * 2 - 1
```

### 示例

假设某关节校准范围是 `[512, 3584]`：

```
归一化值    原始位置
-1.0        512
-0.5        1280
 0.0        2048
+0.5        2816
+1.0        3584
```

## 🛡️ 安全机制

### 1. 最大相对移动限制

```python
# 限制单步最大移动10%范围
robot = SO100Robot(max_relative_target=0.1)

# 当前位置: 0.0
# 目标位置: 1.0
# 实际移动到: 0.1（被限制）
```

### 2. 范围限制

所有动作自动限制在校准范围内：

```python
# 即使发送超出范围的值，也会被截断
action = {'shoulder_pan': 2.0}  # 超出范围
robot.send_action(action)       # 实际发送1.0
```

### 3. 夹爪保护

夹爪自动配置降低扭矩，避免烧坏：

```python
# 在configure()中自动设置
Max_Torque_Limit: 500      # 50%最大扭矩
Protection_Current: 250    # 50%最大电流
Overload_Torque: 25        # 25%过载扭矩
```

## 🐛 故障排查

### 问题1: 无法连接串口

**现象：** `RuntimeError: 无法连接到串口: COM3`

**解决：**
- 检查串口是否被占用
- 确认串口名称正确（Windows: COMx, Linux: /dev/ttyUSBx）
- 检查USB线缆连接

### 问题2: 未加载校准数据

**现象：** `RuntimeError: 未加载校准数据，无法发送动作`

**解决：**
```bash
# 先运行校准程序
python examples\calibrate_motors.py
```

### 问题3: 舵机不动

**检查：**
```python
# 1. 扭矩是否使能
robot.enable_torque_all()

# 2. 检查电源供电
info = robot.get_motor_info()
print(info['shoulder_pan']['voltage'])  # 应该>110 (11V)

# 3. 检查目标位置是否有效
obs = robot.get_observation()
print(obs)
```

### 问题4: 移动速度太快

**解决：**
```python
# 方法1: 使用max_relative_target限制
robot = SO100Robot(max_relative_target=0.05)  # 限制5%

# 方法2: 调整Goal_Time（舵机自动插补）
robot.bus.write_control_table(1, "Goal_Time", 1000)  # 1000ms到达
```

### 问题5: 舵机抖动

**解决：**
```python
# 降低P系数
robot.bus.write_control_table(1, "P_Coefficient", 10)  # 默认16

# 或增加D系数
robot.bus.write_control_table(1, "D_Coefficient", 40)  # 默认32
```
