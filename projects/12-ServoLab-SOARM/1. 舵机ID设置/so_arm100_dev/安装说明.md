# 安装说明

## 依赖安装步骤

### 方法1：使用requirements.txt（推荐）

```bash
cd C:\Users\wuwu\Desktop\so_arm100_dev
pip install -r requirements.txt
```

这会自动安装：
- `feetech-servo-sdk` - 飞特舵机SDK（LeRobot官方使用）
- `pyserial` - 串口通信
- `numpy` - 数据处理

### 方法2：手动逐个安装

```bash
pip install feetech-servo-sdk>=1.0.0
pip install pyserial>=3.5
pip install numpy>=1.21.0
```

### 方法3：备用方案（如果上面的失败）

如果 `feetech-servo-sdk` 安装失败，可以尝试：

```bash
# 方案A：从GitHub安装
pip install git+https://github.com/FeetechRC/feetech-servo-sdk.git

# 方案B：使用旧版包名
pip install scservo_sdk

# 方案C：手动下载安装
# 1. 访问：https://pypi.org/project/feetech-servo-sdk/
# 2. 下载.whl文件
# 3. pip install 下载的文件.whl
```

## 验证安装

安装完成后，验证是否成功：

```python
import scservo_sdk as scs
print(f"SCServo SDK版本: {scs.__version__ if hasattr(scs, '__version__') else '已安装'}")
```

或在命令行：
```bash
python -c "import scservo_sdk; print('SDK安装成功')"
```

## 常见问题

### 1. pip install git+https 失败

**可能原因**：
- 没有安装Git
- 网络连接问题

**解决方法**：
- 安装Git：https://git-scm.com/downloads
- 或使用离线安装方法

### 2. Windows上提示缺少Microsoft Visual C++

**解决方法**：
安装 Microsoft C++ Build Tools：
https://visualstudio.microsoft.com/visual-cpp-build-tools/

### 3. 串口权限问题（Linux）

```bash
sudo usermod -a -G dialout $USER
# 然后注销重新登录
```

## 验证硬件连接
