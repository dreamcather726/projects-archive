# STM32F407 麦克纳姆轮底盘控制器

本项目是一个基于 **STM32F407ZGT6、FreeRTOS 和 Keil MDK** 的麦克纳姆轮底盘控制程序。

控制器可以接收 JY61P IMU 数据，与 Windows/Linux 上位机通信，并通过串口控制多台 Emm_V5 闭环步进电机驱动器。

系统学习请先阅读 [底盘完整学习手册](Docs/CHASSIS_STUDY_GUIDE.md)：包含全部现有功能、文件职责、启动/任务时序、四轮计算、IMU、协议、安全保护、PC调试和学习练习。

## 主要功能

### 1. JY61P IMU 数据采集

- 通过 USART3 接收 JY61P 数据。
- USART3 固定使用 9600 波特率，启动时不再扫描其他速率。
- 解析加速度、角速度、Roll、Pitch、Yaw、温度和版本信息。
- 校验 JY61P 数据帧，并统计有效帧、校验错误和串口丢包数量。
- 带有静止状态下的 Yaw 漂移修正。
- 将 IMU 数据实时发送给上位机显示。

### 2. Emm_V5 电机控制

通过 USART6 控制 Emm_V5 闭环步进电机驱动器，支持：

- 电机使能和失能。
- 速度模式控制。
- 相对/绝对位置模式控制。
- 单电机停止和全部电机紧急停止。
- 多电机同步运动。
- 当前位置清零。
- 电机回零。
- 查询版本、电压、电流、速度、位置、位置误差及运行状态等参数。

### 3. 四轮麦克纳姆底盘控制

- 支持前进、后退、左右横移和原地旋转。
- 支持平移与旋转组合运动。
- 自动完成 X 型麦克纳姆轮四轮速度分解。
- 当某个车轮速度超过限制时，对四轮统一缩放，保持运动方向不变。
- 四台电机依次确认控制命令后，再广播同步启动。
- 电机回复超时重试一次，连续失败则请求全车停车并锁定。
- 电机地址、正转方向和最大转速可在 `Config/Inc/app_config.h` 中配置。

当前默认电机地址：

| 车轮 | 地址 |
|---|---:|
| 右前轮 | 1 |
| 左前轮 | 2 |
| 左后轮 | 3 |
| 右后轮 | 4 |

### 4. 上位机通信

STM32 通过 USART1 与上位机通信，使用带 CRC16 校验的二进制协议，支持：

- 链路测试和设备状态查询。
- 单电机控制和麦克纳姆底盘控制。
- 紧急停止。
- IMU 数据主动上报。
- 电机原始回复转发。
- 查询 IMU 波特率、有效帧数、校验错误、DMA 错误、丢包数量和底盘忙状态。
- 运动命令执行后自动启用通信失联保护；500 ms 内没有合法帧即广播急停。
- 配套 PC 工具每200ms发送 PING；运动另有500ms授权，PING不能续期。
- STM32 启动先请求全车停车，再检测四个电机与新鲜完整 IMU 样本；通过后才允许运动。
- 电机序列失败、运行巡检无回复或 IMU 停更会请求全车停车并锁定，重新自检通过才恢复。

完整帧格式及命令说明见 [Docs/HOST_PROTOCOL.md](Docs/HOST_PROTOCOL.md)。
目录职责与代码阅读顺序见 [Docs/CODE_GUIDE.md](Docs/CODE_GUIDE.md)，硬件调试见 [Docs/UART_DEBUG_GUIDE.md](Docs/UART_DEBUG_GUIDE.md)。

### 5. PC 测试工具

`PC_Tools/jy61p_motor_test.py` 提供图形化测试界面，可用于：

本阶段只维护人工上位机调试程序，不包含香橙派自动控制程序。安装、按钮操作、日志与故障处理见 [PC_Tools/README.md](PC_Tools/README.md)。

- 选择并连接电脑串口。
- 连接后自动检测下位机、实时 IMU 数据及 1～4 号电机；可手动重新自检。
- 实时显示 JY61P 数据。
- 控制单台 Emm_V5 电机。
- 控制麦克纳姆底盘运动。
- 查询控制器和电机状态。
- 一键发送全部电机紧急停止命令。

新固件自检由 STM32 执行，PC 只查询检测结果；点击“重新自检”会先请求全车停车，
再读取电机 FLAG 和检测实时 IMU，不执行使能或运动命令。检测期间暂停普通电机控制，
鲜红色的“全部急停”按钮在串口连接后始终可用。在线显示为绿色，未收到数据或回复显示为红色。
启动检测失败或运行故障会禁止运动；排查后点击“重新自检”，通过后重新发送动作。
STM32 在运动布防期间周期巡检电机，并检查 IMU 完整样本是否停更。
电机地址以 `Config/Inc/app_config.h` 为准；PC 默认按2/1/3/4显示四轮掩码，自定义地址时需同步修改显示映射。
连接旧固件时，PC 仍使用 `SELF_TEST_MOTOR_ADDRESSES` 的只读自检，默认 `(1, 2, 3, 4)`。

PC 工具连接期间每200ms发送 PING；运动命令在点击按钮时发送一次。
执行运动后，STM32 连续500ms未收到合法上位机帧会广播停车。PING只维持链路，
不会延长下面的运动授权。

运动还有独立500ms授权：界面默认不勾选“持续授权当前动作”，单次动作超时会停车锁定。
需要持续运动时显式勾选，工具每200ms用独立 RENEW 命令续期，绝不重复发送相对位置动作。
急停优先发送并锁定；重新自检通过才可恢复。单电机与底盘控制切换前先发全车 STOP。
香橙派须按新版[协议说明](Docs/HOST_PROTOCOL.md)适配 RENEW 和57字节状态载荷，续期应依赖控制任务健康状态。
软件广播停车也不能替代硬件急停或电机驱动器自身的断线保护。重新编译下载固件后，
先架空车轮验证：缺电机/IMU时禁止运动、运动中拔掉电机/IMU时停车并锁定、重新自检后不自动恢复动作。

安装依赖并启动：

```powershell
cd PC_Tools
python -m pip install -r requirements.txt
python jy61p_motor_test.py
```

## 串口分配

| 用途 | STM32 串口 | 引脚 | 默认波特率 |
|---|---|---|---:|
| Windows/Linux 上位机 | USART1 | PA9 / PA10 | 115200 |
| 视觉模块预留接口 | USART2 | PA2 / PA3 | 115200 |
| JY61P IMU | USART3 | PB10 / PB11 | 9600 |
| Emm_V5 电机总线 | USART6 | PG14 / PG9 | 115200 |

所有串口均使用 8N1、无硬件流控。串口接收采用 DMA 循环缓冲区，发送采用软件环形缓冲区和 TXE 中断，应用任务不会阻塞等待串口发送。

## 软件特点

- 使用 FreeRTOS 抢占式调度，控制和 IMU 数据分别由独立任务处理。
- 任务、任务栈和内核对象全部静态分配，运行期间不使用动态内存。
- 使用 STM32 独立看门狗；只有全部已启用任务都正常运行时才喂狗。
- 半帧等待超过 50 ms 或电机回复溢出时只复位对应解析器，不会让整机进入 Fault。
- 应用层、板级驱动、设备驱动和协议层相互分离。
- 提供栈溢出检测、断言故障入口、串口错误计数和参数范围检查。
- 功能开关及底盘参数集中放在 `Config/Inc/app_config.h`。

## 编译

工程使用 Keil MDK 5 和 Arm Compiler 6：

1. 使用 Keil 打开 `STM32F407ZGT6.uvprojx`。
2. 选择 `STM32F407ZGT6` Target。
3. 编译并将程序下载到开发板。

也可以使用 VS Code 的 Keil Assistant 打开工程并按 `F7` 编译。

## 测试

运行 C 单元测试和 Python 协议测试：

```powershell
powershell -ExecutionPolicy Bypass -File Tests/run_tests.ps1
```

检查 IMU、上位机与 IWDG 功能开关的八种组合：

```powershell
powershell -ExecutionPolicy Bypass -File Tests/check_feature_switches.ps1
```

> 首次测试底盘时，请先架空车轮，确认四个电机的地址和正转方向正确，并保证紧急停止功能可用后再落地运行。
