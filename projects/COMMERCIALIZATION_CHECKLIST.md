# 项目商品化与交付审核清单

此目录仅用于**私有作品归档**。商品化前必须逐项完成以下核验；尚未完成不表示可以销售。

## 一、权利与许可证（阻断项）

- [ ] 确认代码、讲义、硬件图纸和媒体资源的作者及所有权；涉及雇主、实习单位、学校或团队项目须取得允许个人商业使用的书面许可。
- [ ] 列清第三方代码、库、模型和素材；保留原许可证及必要版权通知。
- [ ] 对 AGPL/GPL 等有源代码披露义务的依赖逐项评估；如使用 Ultralytics 模型或权重，先核对最新授权条件。
- [ ] 禁止把从百度网盘、下载目录或其他开源仓库收集的材料直接包装成个人原创付费项目。

## 二、安全与隐私（阻断项）

- [ ] 逐文件扫描密钥、访问令牌、私钥、Wi-Fi 密码、证书、云端设备 ID 与真实客户/学生数据。
- [ ] 发现有效凭据时先撤销或轮换，并检查历史提交；仅在发行副本中替换不等于凭据安全。
- [ ] 检查压缩包、模型权重、安装程序和可执行文件的许可及来源，不得未经验证自动打包上传。

## 三、工程可复现性

- [ ] 明确设备型号、固件版本、系统环境、编译器和依赖版本。
- [ ] 在干净环境完成构建/安装/测试，记录命令、截图或日志及预期结果。
- [ ] 硬件工程进行上板验收；急停、断线、故障等安全功能必须实测。
- [ ] 为模拟器和真实设备明确标注功能边界，不能把仿真效果当作实车交付。
- [ ] 视觉模型注明数据集、相机、性能和测距误差，不能宣称未经验证的精度。

## 四、付费资料交付

- [ ] 独立制作发行包，不直接公开整个私有资产仓库。
- [ ] 包含 README、环境配置、教程、源码、示例数据、常见报错、已验证功能和已知限制。
- [ ] 明确是否包含硬件、是否支持退款、升级及技术支持的具体范围。
- [ ] 检查发布平台规则及商品类目。不要提供共享密钥或将用户授权内容二次出售。

## 来源与版本

- 本合集包含历史归档快照和个人独立仓库的特定版本；后续改动并不会自动回传到源仓库。
- 任何商业发行应从此合集建立**独立、审核通过的交付分支或单独发行包**，不修改原始代码资产。
