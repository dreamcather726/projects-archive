## 详细执行步骤

1. **程序启动**：用户在命令行执行 `python main.py`

2. **导入模块**：
   - 导入系统模块 `sys`
   - 导入 PyQt5 的 `QApplication` 类
   - 导入自定义模块：`InteractionController`、`ScriptService`、`SerialPortClient`、`FingerControllerUI`

3. **类定义**：
   - 定义 `FingerControllerApp` 类，继承自 `FingerControllerUI`

4. **main函数执行**：
   - 创建 `QApplication` 实例，这是 PyQt5 应用程序的核心
   - 创建 `FingerControllerApp` 实例
   - 调用 `window.show()` 显示窗口
   - 执行 `app.exec_()` 启动应用程序主循环

5. **FingerControllerApp初始化**：
   - 调用父类 `FingerControllerUI` 的初始化方法，创建所有界面控件
   - 创建 `SerialPortClient` 实例，用于串口通信
   - 创建 `ScriptService` 实例，用于执行脚本
   - 创建 `InteractionController` 实例，处理用户交互
   - 调用 `_bind_signals()` 绑定所有信号和槽
   - 调用 `controller.refresh_ports()` 刷新可用串口列表

6. **信号绑定**：
   - 刷新按钮点击 → 刷新串口列表
   - 连接按钮点击 → 连接/断开串口
   - 滑块值变化 → 调用 `on_slider_changed` 方法
   - 预设动作按钮点击 → 应用预设动作
   - 加载按钮点击 → 加载脚本文件
   - 保存按钮点击 → 保存脚本文件
   - 运行按钮点击 → 执行脚本
   - 停止按钮点击 → 停止脚本
   - 脚本服务日志信号 → 更新日志显示
   - 脚本服务完成信号 → 调用 `on_script_finished` 方法

7. **用户交互处理**：
   - 用户操作界面控件，触发相应的信号
   - 信号被绑定的槽函数处理
   - 槽函数执行相应的逻辑，如发送指令、执行脚本等

8. **窗口关闭处理**：
   - 用户点击窗口关闭按钮
   - 触发 `closeEvent` 事件
   - 调用 `controller.close_cleanup()` 进行清理
   - 停止脚本线程
   - 关闭串口
   - 退出程序

## 各模块职责

- **UI模块**：负责创建和显示界面控件
- **控制层**：处理用户交互逻辑，协调各模块工作
- **串口模块**：负责与机械手通信
- **脚本模块**：负责执行脚本指令
