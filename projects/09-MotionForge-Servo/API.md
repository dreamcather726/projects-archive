# API 文档（动作脚本）

## 脚本文件（JSON）
文件扩展名：`.json`

### 顶层字段
- `version`：整数，当前为 `1`
- `channels`：整数数组，表示参与录制/回放的关节通道
- `meta`：对象，元数据（创建时间、采样率、零位等）
- `steps`：数组，按 `index` 顺序执行

### step 字段
- `index`：步骤序号（如 1、2、3…）
- `angles`：对象，键为通道号字符串，值为角度（精确到 0.1°）
- `event`：可选字符串，例如 `"click"`

### 示例
```json
{
  "version": 1,
  "channels": [0, 1, 2],
  "meta": {"created_at": "20260101_000000", "sample_hz": 20},
  "steps": [
    {"index": 1, "angles": {"0": 70.0, "1": 90.0, "2": 110.0}},
    {"index": 2, "angles": {"0": 72.0, "1": 91.2, "2": 109.9}, "event": "click"}
  ]
}
```

## 下发协议（串口）
- 舵机控制：`CH{channel}:{deg}`，如 `CH0:72.0`
- `deg` 支持 0.1° 精度（下位机按浮点解析）
