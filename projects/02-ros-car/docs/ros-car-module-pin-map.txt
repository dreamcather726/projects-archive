ROS 小车 ESP32-S3 模块引脚分配表
文件格式: TXT
建议编码: UTF-8 with BOM
换行格式: Windows CRLF
生成日期: 2026-06-30

说明:
1. 本文件按模块整理用户提供的 P2/P3 引脚图。
2. 巡线模块有两种方案: I2C 版和 4 路 IO 版, 二选一使用。
3. I2C 不是单独一个引脚, 实际需要 SDA 和 SCL 两根信号线。
4. ESP32-S3 GPIO 是 3.3V 逻辑; HC-SR04 的 5V ECHO 不能直接接 GPIO, 需要分压或电平转换。

============================================================
1. 推荐接线方案
============================================================

方案 A: I2C 巡线模块, 推荐优先使用
- 巡线 SDA: G8,  P2-10
- 巡线 SCL: G9,  P2-13
- 超声波 TRIG: G14, P2-18
- 超声波 ECHO: G48, P3-15
- 优点: 节省 GPIO, G10-G13 可留作后续扩展。

方案 B: 4 路 IO 巡线模块
- OUT1 / 左外: G10, P2-14
- OUT2 / 左内: G11, P2-15
- OUT3 / 右内: G12, P2-16
- OUT4 / 右外: G13, P2-17
- 超声波 TRIG: G14, P2-18
- 超声波 ECHO: G48, P3-15
- 优点: 适合 4 路数字输出巡线模块, 程序读取逻辑简单。

============================================================
2. 模块引脚总览
============================================================

模块: 电源/系统
- 5V: P2-20
- GND: P3-20
- EN / RST: P2-1
- BOOT: G0, P3-13
- BAT: G45, P3-14
- 备注: EN/RST 和 BOOT 与复位、下载启动相关, 不建议随意复用。

模块: 电机 A
- PWMA: G4, P2-2
- AN1:  G5, P2-3
- A+:   G6, P2-4
- A-:   G7, P2-5
- 备注: 左右电机方向需要实车测试确认, 程序里建议用常量统一命名。

模块: 电机 B
- PWMB: G1,  P3-3
- BN1:  G2,  P3-4
- B+:   G42, P3-5
- B-:   G41, P3-6
- 备注: 与电机 A 成对使用, 调试时先低速测试方向。

模块: 按键
- KEY1: G15, P2-6
- KEY2: G16, P2-7
- KEY3: G17, P2-8
- KEY4: G18, P2-9

模块: I2C 巡线预留
- SDA: G8, P2-10
- SCL: G9, P2-13
- VCC: 5V 或 3.3V, 按模块规格选择
- GND: P3-20
- 备注: 如果模块是 5V 供电, 要确认 SDA/SCL 信号电平是否兼容 3.3V。

模块: 4 路 IO 巡线预留
- OUT1: G10, P2-14
- OUT2: G11, P2-15
- OUT3: G12, P2-16
- OUT4: G13, P2-17
- VCC: 5V 或 3.3V, 按模块规格选择
- GND: P3-20
- 备注: 与 I2C 巡线方案二选一, 避免重复占用。

模块: 超声波
- VCC:  5V, P2-20
- GND:  GND, P3-20
- TRIG: G14, P2-18
- ECHO: G48, P3-15
- 备注: HC-SR04 的 ECHO 通常为 5V, 必须降压到 3.3V 后再接 ESP32-S3。

模块: LCD 显示
- LCD-CS:  G47, P3-16
- LCD-DC:  G21, P3-17
- LCD-SDA: G20, P3-18
- LCD-SCL: G19, P3-19

模块: 音频 / I2S
- DIN:  G40, P3-7
- LRC:  G39, P3-8
- BCLK: G38, P3-9

模块: 通信 / USB
- UART TX: TX, P3-1
- UART RX: RX, P3-2
- USB D+:  G3 / USD+,  P2-11
- USB D-:  G46 / USD-, P2-12

模块: PSRAM 保留
- PSRAM-1: G37, P3-10
- PSRAM-2: G36, P3-11
- PSRAM-3: G35, P3-12
- 备注: 如果板载 PSRAM 已使用这些引脚, 不建议当普通 IO 使用。

============================================================
3. 程序常量命名建议
============================================================

// I2C 巡线模块方案
PIN_LINE_SDA = G8
PIN_LINE_SCL = G9

// 4 路 IO 巡线模块方案
PIN_LINE_OUT1 = G10
PIN_LINE_OUT2 = G11
PIN_LINE_OUT3 = G12
PIN_LINE_OUT4 = G13

// 超声波模块
PIN_ULTRASONIC_TRIG = G14
PIN_ULTRASONIC_ECHO = G48

// 电机 A
PIN_MOTOR_A_PWM = G4
PIN_MOTOR_A_IN1 = G5
PIN_MOTOR_A_PLUS = G6
PIN_MOTOR_A_MINUS = G7

// 电机 B
PIN_MOTOR_B_PWM = G1
PIN_MOTOR_B_IN1 = G2
PIN_MOTOR_B_PLUS = G42
PIN_MOTOR_B_MINUS = G41

============================================================
4. 注意事项
============================================================

1. 所有外设必须和 ESP32-S3 共地。
2. 5V 供电外设不代表信号也能直接接 ESP32-S3, GPIO 输入最高按 3.3V 逻辑处理。
3. BOOT、EN/RST、USB、PSRAM 相关引脚尽量保留原用途。
4. 如果后续同时增加更多 I2C 外设, G8/G9 可以作为同一条 I2C 总线共享, 但每个 I2C 设备地址不能冲突。
5. 如果使用 4 路 IO 巡线模块, G10-G13 建议全部保留给巡线, 不要再接其他实时输入。
