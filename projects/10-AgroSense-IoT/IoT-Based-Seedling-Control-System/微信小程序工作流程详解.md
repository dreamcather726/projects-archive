# 微信小程序端工作流程详解

## 项目概述

本微信小程序是基于华为云IoT平台的智能育苗控制系统的前端应用，实现了对远程育苗设备的实时监控和控制功能。系统支持多设备管理、用户权限控制、阈值设置等核心功能，为育苗环境提供智能化的管理解决方案。

## 目录结构说明

```
├── app.js                # 小程序入口文件，包含全局配置和生命周期
├── app.json              # 小程序全局配置

```

## 核心功能模块

### 1. 全局登录状态管理

在 `app.js`中实现了全局登录状态管理机制，确保用户登录状态在整个应用中一致：

```javascript
// 全局数据
globalData: {
  userInfo: null,
  isLoggedIn: false // 全局登录状态标志
},

// 设置登录状态
setLoginStatus(status) {
  this.globalData.isLoggedIn = status;
},

// 获取登录状态
isLoggedIn() {
  return this.globalData.isLoggedIn;
}
```

- 登录时，在 `logs.js`中将状态设置为 `true`
- 退出登录时，在 `index.js`中将状态设置为 `false`
- 各功能模块通过调用 `app.isLoggedIn()`检查用户登录状态

#### 3.4 退出登录功能

```javascript
navigateToLogs() {
  console.log('执行退出登录操作')
  // 清除定时器，停止获取华为云数据
  if (this.dataRefreshTimer) {
    clearInterval(this.dataRefreshTimer);
    console.log('已停止数据刷新定时器');
  }
  // 清除登录状态和token
  wx.removeStorageSync('token');
  wx.removeStorageSync('userInfo');
  // 清除内存中的token信息
  if (typeof iotapi !== 'undefined') {
    iotapi.tokenInfo = null;
  }
  // 设置全局登录状态为未登录
  const app = getApp();
  app.setLoginStatus(false);
  // 跳转到登录页面
  wx.navigateTo({ url: '/pages/logs/logs' });
}
```

## 应用工作流程

### 1. 启动流程

1. **应用初始化**：

   - 小程序启动时，执行 `app.js`中的 `onLaunch`函数
   - 初始化全局数据和状态
   - 尝试获取用户信息
2. **用户登录**：

   - 首次使用或会话过期时，进入登录页面(`logs.js`)
   - 用户输入用户名和密码登录
   - 登录成功后，保存用户信息并设置全局登录状态
   - 跳转到主控制页面

### 2. 主控制页面工作流程

1. **页面加载**：

   - 获取用户信息和权限
   - 初始化UI状态
   - 设置数据刷新定时器
2. **数据刷新循环**：

   - 每2秒调用一次 `fetchDeviceData()`函数
   - 检查登录状态
   - 调用 `iotapi.getAllDevicesData()`获取设备数据
   - 解析和更新UI显示
3. **设备控制操作**：

   - 用户触发控制操作（水泵、风扇、自动模式）
   - 检查用户权限
   - 更新UI状态
   - 调用 `iotapi.sendDeviceCommand()`发送控制命令

### 3. 阈值设置流程

1. **进入设置页面**：

   - 从主页面点击阈值设置按钮进入
   - 检查用户权限，普通用户限制为只读模式
   - 从本地存储加载已保存的阈值设置
2. **修改和保存阈值**：

   - 管理员用户可以修改阈值输入框
   - 点击保存按钮触发保存操作
   - 验证输入有效性
   - 保存到本地存储
   - 调用 `iotapi.sendthreshold()`发送阈值设置命令

### 4. 退出登录流程

1. **用户触发退出登录**：
   - 点击退出登录按钮
   - 清除数据刷新定时器
   - 清除本地存储的用户信息和token
   - 设置全局登录状态为未登录
   - 跳转到登录页面

## 安全与权限控制

1. **用户权限分级**：

   - 普通用户：只能查看设备状态和阈值设置，不能操作设备或修改设置
   - 管理员：拥有全部权限
2. **权限验证机制**：

   - 设备控制操作前检查用户权限
   - 设置页面根据权限控制输入框可编辑状态
   - 命令发送前验证用户类型
3. **登录状态管理**：

   - 全局登录状态标志
   - 退出登录时清除所有相关数据
   - API调用前检查登录状态

## 错误处理与容错机制

1. **网络错误处理**：

   - API调用失败时显示错误提示
   - token过期自动重新获取
   - 设备数据获取失败时保留之前的数据
2. **数据验证**：

   - 阈值输入的有效性验证
   - 设备ID和命令参数的类型检查
   - 登录状态的多层检查
3. **异常状态处理**：

   - 未登录状态下不进行数据获取和解析
   - 设备数据错误时显示错误信息但不崩溃
   - 权限不足时给予明确提示

## 总结

本微信小程序通过与华为云IoT平台的深度集成，实现了对智能育苗设备的高效监控和控制。系统采用分层设计，将UI界面、业务逻辑和API交互清晰分离，同时实现了完善的权限控制和错误处理机制，保证了系统的稳定性和安全性。通过定时数据刷新和实时命令下发，确保了用户能够及时获取设备状态并进行精确控制，为育苗环境管理提供了智能化的解决方案。
