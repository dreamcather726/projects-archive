# IoT育苗控制系统 - 信息传输流程表

## 一、数据采集流程

| 步骤 | 节点              | 操作         | 数据类型             | 详细说明                           |
| ---- | ----------------- | ------------ | -------------------- | ---------------------------------- |
| 1.1  | Arduino传感器节点 | 环境数据采集 | 温度、湿度、光照强度 | 通过传感器模块实时采集环境参数     |
| 1.2  | Arduino传感器节点 | 土壤数据采集 | 土壤湿度             | 通过土壤湿度传感器采集土壤水分数据 |
| 1.3  | Arduino传感器节点 | 设备状态采集 | 水泵状态、风扇状态   | 读取执行设备的工作状态信息         |
| 1.4  | Arduino传感器节点 | 数据预处理   | 原始数据格式化       | 对采集数据进行初步处理和格式化     |

## 二、数据本地传输流程

| 步骤 | 节点              | 操作         | 数据类型         | 详细说明                       |
| ---- | ----------------- | ------------ | ---------------- | ------------------------------ |
| 2.1  | Arduino传感器节点 | 数据发送     | 格式化传感器数据 | 通过LORA发送数据               |
| 2.2  | 树莓派中控        | 数据接收     | 传感器数据       | 接收来自Arduino的数据          |
| 2.3  | 树莓派中控        | 数据验证     | 完整性检查       | 验证数据的完整性和有效性       |
| 2.4  | 树莓派中控        | 数据本地存储 | 处理后数据       | 将数据存储到本地缓存或显示界面 |

## 三、云端上传流程

| 步骤 | 节点          | 操作         | 数据类型     | 详细说明                             |
| ---- | ------------- | ------------ | ------------ | ------------------------------------ |
| 3.1  | 树莓派中控    | 数据打包     | JSON格式数据 | 将数据组织成华为云平台要求的JSON格式 |
| 3.2  | 树莓派中控    | MQTT连接建立 | 连接请求     | 与华为云IoT平台建立安全MQTT连接      |
| 3.3  | 树莓派中控    | 数据加密     | TLS加密数据  | 使用TLS协议对数据进行加密            |
| 3.4  | 树莓派中控    | 数据发布     | 加密数据包   | 向指定MQTT主题发布数据               |
| 3.5  | 华为云IoT平台 | 数据接收     | 加密数据包   | 接收来自设备的数据                   |
| 3.6  | 华为云IoT平台 | 数据解密验证 | 解密后数据   | 验证设备身份并解密数据               |
| 3.7  | 华为云IoT平台 | 数据存储     | 结构化数据   | 将数据存储到云端数据库               |
| 3.8  | 华为云IoT平台 | 设备影子更新 | 设备状态信息 | 更新设备影子以反映最新状态           |

## 四、数据获取与展示流程

| 步骤 | 节点          | 操作         | 数据类型     | 详细说明                             |
| ---- | ------------- | ------------ | ------------ | ------------------------------------ |
| 4.1  | 电脑端/小程序 | 影子数据请求 | 请求消息     | 发送获取设备影子数据的请求           |
| 4.2  | 华为云IoT平台 | 请求处理     | 处理请求     | 处理影子数据获取请求                 |
| 4.3  | 华为云IoT平台 | 影子数据返回 | 影子数据JSON | 返回包含最新设备状态的影子数据       |
| 4.4  | 电脑端/小程序 | 数据接收     | 影子数据     | 接收来自云端的设备影子数据           |
| 4.5  | 电脑端/小程序 | 数据解析     | 结构化数据   | 解析JSON格式的影子数据               |
| 4.6  | 电脑端/小程序 | 数据存储     | 本地数据对象 | 将解析后的数据存储到本地数据结构     |
| 4.7  | 电脑端/小程序 | 数据展示     | 可视化界面   | 在UI界面上展示各项环境参数和设备状态 |

## 五、指令下发流程

| 步骤 | 节点          | 操作         | 数据类型     | 详细说明                     |
| ---- | ------------- | ------------ | ------------ | ---------------------------- |
| 5.1  | 电脑端/小程序 | 控制指令生成 | 指令JSON     | 根据用户操作生成控制指令     |
| 5.2  | 电脑端/小程序 | 指令发送     | 加密指令     | 将控制指令发送至华为云平台   |
| 5.3  | 华为云IoT平台 | 指令转发     | 指令消息     | 将控制指令转发至对应设备     |
| 5.4  | 树莓派中控    | 指令接收     | 控制指令     | 接收来自云端的控制指令       |
| 5.5  | 树莓派中控    | 指令解析     | 具体操作指令 | 解析控制指令内容             |
| 5.6  | 树莓派中控    | 指令执行     | 设备控制信号 | 向执行设备发送控制信号       |
| 5.7  | 执行设备      | 操作执行     | 物理动作     | 水泵/风扇执行相应的开关操作  |
| 5.8  | 树莓派中控    | 状态上报     | 执行结果     | 将执行结果和新状态上报至云端 |

## 六、数据同步与更新机制

| 步骤 | 节点           | 操作         | 数据类型     | 详细说明                      |
| ---- | -------------- | ------------ | ------------ | ----------------------------- |
| 6.1  | 电脑端数据获取 | 定期请求     | 影子数据请求 | 每5秒定时发送影子数据获取请求 |
| 6.2  | 华为云IoT平台  | 数据准备     | 最新影子数据 | 准备设备的最新影子数据        |
| 6.3  | 华为云IoT平台  | 数据推送     | 影子数据更新 | 向订阅客户端推送影子数据更新  |
| 6.4  | 电脑端/小程序  | 数据刷新     | 实时数据更新 | 更新本地数据并刷新UI显示      |
| 6.5  | 设备端         | 状态变更检测 | 状态变化     | 检测设备状态是否发生变化      |
| 6.6  | 设备端         | 增量更新     | 变更数据     | 仅发送发生变化的数据部分      |
