# IoT育苗控制系统

## 项目概述

这是一个基于物联网技术的智能育苗控制系统，通过Arduino传感器节点采集环境数据，树莓派作为中控处理和上传数据，华为云IoT平台提供数据传输和存储服务，并支持电脑端数据获取和手机微信小程序远程监控与控制。

## 系统架构

### 1. 硬件架构
- **Arduino传感器节点**：负责采集温度、湿度、光照强度、土壤湿度等环境参数
- **树莓派中控**：接收传感器数据，进行本地处理，并上传至云平台
- **执行设备**：水泵、风扇等执行机构，根据控制指令动作

### 2. 软件架构
- **Arduino端**：传感器数据采集和本地控制逻辑
- **树莓派端**：数据处理、云平台通信、UI界面展示
- **华为云IoT平台**：数据传输、存储和设备管理
- **电脑端数据获取**：远程监控和数据获取
- **微信小程序**：移动设备端监控和控制

## 主要功能模块

### 1. 数据采集模块
- 采集环境温度、湿度、光照强度
- 采集土壤湿度
- 监测水泵和风扇工作状态
- 采集天气状况数据

### 2. 数据传输模块
- 基于MQTT协议的数据上传
- 设备影子同步机制
- 双向通信支持（数据上报和指令下发）

### 3. 数据处理与存储
- 原始数据处理和格式化
- 云端数据存储
- 设备状态实时更新

### 4. 监控与控制
- 树莓派本地UI界面展示
- 电脑端远程数据获取
- 微信小程序移动监控
- 设备远程控制功能

## 核心文件说明

### Arduino端
- `Arduinos/Farmer/Farmer.ino`：传感器数据采集和控制主程序

### 树莓派端
- `树莓派中控/main.py`：树莓派中控主程序，处理数据和控制逻辑
- `树莓派中控/main.ui`：树莓派UI界面设计
- `树莓派中控/PIC/`：界面图片资源

### 电脑端
- `电脑端数据获取/main.py`：从云平台获取设备数据的客户端程序

### 手机端
- `IoT-Based-Seedling-Control-System/手机控制/`：微信小程序代码

## 技术栈

- **硬件**：Arduino、树莓派、各类传感器
- **通信协议**：MQTT、TLS加密
- **云服务**：华为云IoT平台
- **开发语言**：Python、Arduino C++、JavaScript
- **界面框架**：PyQt（树莓派）、微信小程序框架

## 使用说明

### 1. 硬件连接
将Arduino传感器节点与树莓派按照电路图正确连接，确保供电稳定。

### 2. 设备配置
- 在`设备连接属性.txt`中配置华为云设备信息
- 确保树莓派和Arduino程序中的设备ID与云平台一致

### 3. 启动系统
1. 运行树莓派中控程序：`python main.py`
2. 运行电脑端数据获取程序：`python main.py`
3. 通过微信小程序扫描二维码登录

### 4. 数据更新频率
- 设备影子数据获取间隔：5秒
- 支持实时数据刷新和状态更新

## 系统特点

1. **实时监控**：环境数据实时采集和展示
2. **远程控制**：支持通过手机小程序远程控制设备
3. **数据可视化**：直观展示各项环境参数和设备状态
4. **安全性**：采用TLS加密通信，确保数据传输安全
5. **可扩展性**：支持多设备同时接入和管理

## 维护与故障排除

1. **连接问题**：检查网络连接和云平台设备状态
2. **数据异常**：检查传感器连接和校准
3. **程序崩溃**：查看日志文件，重启相关服务

## 注意事项

1. 确保设备ID、用户名、密码等敏感信息安全保存
2. 定期更新程序和依赖库
3. 长时间不使用时，建议断开设备电源
