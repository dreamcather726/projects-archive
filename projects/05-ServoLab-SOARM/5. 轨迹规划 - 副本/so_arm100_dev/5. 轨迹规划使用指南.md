# SO-ARM100 轨迹规划使用指南

## 概述

轨迹规划模块提供了完整的运动规划和控制功能，包括：
- **关节空间轨迹规划**：点到点运动、多路径点轨迹
- **多种插值方法**：线性、三次样条、五次多项式、梯形速度曲线
- **运动控制器**：轨迹执行、暂停/继续、紧急停止
- **轨迹记录与回放**：记录手动拖动轨迹并回放
- **运动原语**：常用动作（挥手、点头、抓取放置）

## 快速开始

### 运行演示程序

```bash
python examples/trajectory_demo.py
```

### 基础用法

```python
from core.robot import SO100Robot
from core.motion_controller import MotionController

# 创建机械臂和控制器
robot = SO100Robot(port="COM3")
robot.connect()
robot.enable_torque_all()

controller = MotionController(robot)

# 点到点运动
controller.move_to_position({'shoulder_pan': 0.5}, duration=2.0)

# 回到零位
controller.move_home()

robot.disconnect()
```

## 核心API

### 1. MotionController - 运动控制器

```python
from core.motion_controller import MotionController

controller = MotionController(
    robot,                      # SO100Robot实例
    control_frequency=50.0,     # 控制频率（Hz）
    position_tolerance=0.02,    # 位置到达容差
    max_tracking_error=0.2      # 最大跟踪误差
)
```

#### 主要方法

| 方法 | 功能 | 返回值 |
|------|------|--------|
| `move_to_position(target, duration)` | 移动到目标位置 | bool |
| `move_through_waypoints(waypoints, duration)` | 经过多个路径点 | bool |
| `move_home(duration)` | 移动到零位 | bool |
| `execute_trajectory(trajectory)` | 执行轨迹 | bool |
| `pause()` | 暂停运动 | None |
| `resume()` | 继续运动 | None |
| `stop()` | 停止运动 | None |
| `emergency_stop()` | 紧急停止（关闭扭矩） | None |
| `jog(joint, direction, speed)` | 点动控制 | bool |

### 2. JointTrajectoryPlanner - 轨迹规划器

```python
from core.trajectory import JointTrajectoryPlanner

planner = JointTrajectoryPlanner(
    interpolation_method='cubic_spline',  # 插值方法
    max_velocity=1.0,                     # 最大速度
    max_acceleration=2.0                  # 最大加速度
)
```

#### 插值方法

| 方法 | 说明 | 适用场景 |
|------|------|---------|
| `linear` | 线性插值 | 简单运动 |
| `cubic_spline` | 三次样条（推荐） | 平滑运动 |
| `quintic` | 五次多项式 | 高精度需求 |
| `trapezoidal` | 梯形速度曲线 | 速度控制 |

#### 规划方法

```python
# 点到点
trajectory = planner.plan_point_to_point(
    start={'shoulder_pan': 0.0},
    goal={'shoulder_pan': 0.5},
    duration=2.0
)

# 多路径点
trajectory = planner.plan_via_waypoints(
    waypoints=[
        {'shoulder_pan': 0.0},
        {'shoulder_pan': 0.3},
        {'shoulder_pan': 0.5}
    ],
    duration=5.0
)
```

### 3. Trajectory - 轨迹对象

```python
# 在任意时刻采样
position = trajectory.sample(t=1.5)        # 位置
velocity = trajectory.sample_velocity(t)    # 速度
acceleration = trajectory.sample_acceleration(t)  # 加速度

# 转换为数组（用于可视化）
times, positions = trajectory.to_array(dt=0.02)

# 获取最大速度/加速度
max_vel = trajectory.get_max_velocity()
max_acc = trajectory.get_max_acceleration()
```

### 4. TrajectoryRecorder - 轨迹记录器

```python
from core.motion_controller import TrajectoryRecorder

recorder = TrajectoryRecorder(robot, frequency=50.0)

# 开始记录（需先关闭扭矩）
robot.disable_torque_all()
recorder.start_recording()

# 手动拖动机械臂...

# 停止记录
data = recorder.stop_recording()

# 转换为轨迹
trajectory = recorder.get_trajectory()

# 回放
robot.enable_torque_all()
controller.execute_trajectory(trajectory)

# 保存/加载
recorder.save_to_file("my_trajectory.json")
data = TrajectoryRecorder.load_from_file("my_trajectory.json")
```

### 5. MotionPrimitives - 运动原语

```python
from core.motion_controller import MotionPrimitives

primitives = MotionPrimitives(controller)

# 挥手
primitives.wave(amplitude=0.3, frequency=1.5, duration=3.0)

# 点头
primitives.nod(amplitude=0.25, count=3)

# 抓取放置
primitives.pick_and_place(
    pick_position={'shoulder_pan': 0.3, 'shoulder_lift': 0.4, ...},
    place_position={'shoulder_pan': -0.3, 'shoulder_lift': 0.4, ...}
)
```

## 使用示例

### 示例1：平滑点到点运动

```python
from core.robot import SO100Robot
from core.motion_controller import MotionController

robot = SO100Robot(port="COM3")
robot.connect()
robot.enable_torque_all()

controller = MotionController(robot)

# 移动到目标位置（自动规划平滑轨迹）
controller.move_to_position(
    target={
        'shoulder_pan': 0.5,
        'shoulder_lift': 0.3,
        'elbow_flex': -0.2
    },
    duration=3.0,    # 3秒完成
    blocking=True    # 阻塞等待完成
)

robot.disconnect()
```

### 示例2：多路径点轨迹

```python
# 定义路径点序列
waypoints = [
    {'shoulder_pan': 0.0, 'shoulder_lift': 0.0},
    {'shoulder_pan': 0.4, 'shoulder_lift': 0.3},
    {'shoulder_pan': 0.0, 'shoulder_lift': 0.5},
    {'shoulder_pan': -0.4, 'shoulder_lift': 0.3},
    {'shoulder_pan': 0.0, 'shoulder_lift': 0.0},
]

# 执行轨迹
controller.move_through_waypoints(waypoints, duration=10.0)
```

### 示例3：异步控制

```python
# 非阻塞执行
controller.move_to_position(target, duration=5.0, blocking=False)

# 做其他事情...
import time
time.sleep(2.0)

# 暂停
controller.pause()
time.sleep(1.0)

# 继续
controller.resume()

# 或者停止
# controller.stop()

# 等待完成
controller.wait_for_completion(timeout=10.0)
```

### 示例4：轨迹记录与回放

```python
from core.motion_controller import TrajectoryRecorder

# 创建记录器
recorder = TrajectoryRecorder(robot, frequency=50.0)

# 关闭扭矩，允许手动拖动
robot.disable_torque_all()
print("请手动拖动机械臂...")

# 开始记录
recorder.start_recording()
input("按回车停止记录...")
data = recorder.stop_recording()

# 转换为轨迹
trajectory = recorder.get_trajectory()
print(f"记录了 {len(data)} 个点，时长 {trajectory.duration:.2f}s")

# 回放
robot.enable_torque_all()
controller.execute_trajectory(trajectory)

# 保存轨迹
recorder.save_to_file("demo_trajectory.json")
```

### 示例6：监控运动状态

```python
from core.motion_controller import MotionState

# 非阻塞执行
controller.move_to_position(target, blocking=False)

# 监控状态
while controller.state == MotionState.RUNNING:
    status = controller.get_status()
    print(f"进度: {status.progress*100:.1f}%, "
          f"跟踪误差: {status.tracking_error:.4f}")
    time.sleep(0.5)

print(f"最终状态: {controller.state}")
```

## 运动学模块（高级）

### SO100Kinematics - 运动学

```python
from core.kinematics import SO100Kinematics, Pose

kinematics = SO100Kinematics()

# 正运动学：关节 -> 位姿
joint_positions = {'shoulder_pan': 0.0, 'shoulder_lift': 0.3, ...}
pose = kinematics.forward_kinematics(joint_positions)
print(f"末端位置: ({pose.x:.3f}, {pose.y:.3f}, {pose.z:.3f})")

# 逆运动学：位姿 -> 关节
target_pose = Pose(x=0.25, y=0.0, z=0.3, roll=0, pitch=1.57, yaw=0)
joints = kinematics.inverse_kinematics(target_pose, current_joints)
if joints:
    print(f"关节解: {joints}")
```

### 笛卡尔空间轨迹（高级）

```python
from core.trajectory import CartesianTrajectoryPlanner
from core.kinematics import SO100Kinematics
import numpy as np

kinematics = SO100Kinematics()
cartesian_planner = CartesianTrajectoryPlanner(kinematics)

# 直线运动
start_pose = np.array([0.2, 0.0, 0.3, 0, 1.57, 0])
end_pose = np.array([0.3, 0.1, 0.3, 0, 1.57, 0])

trajectory = cartesian_planner.plan_linear_path(
    start_pose, end_pose,
    current_joints=robot.get_observation(),
    duration=3.0
)

if trajectory:
    controller.execute_trajectory(trajectory)
```

## 故障排查

### 问题1：运动抖动

**原因**：控制频率太低或速度太快

**解决**：
```python
# 提高控制频率
controller = MotionController(robot, control_frequency=100.0)

# 或降低速度
planner = JointTrajectoryPlanner(max_velocity=0.3)
```

### 问题2：跟踪误差大

**原因**：轨迹规划的加速度超出舵机能力

**解决**：
```python
# 降低加速度
planner = JointTrajectoryPlanner(max_acceleration=0.5)

# 或增加运动时间
controller.move_to_position(target, duration=5.0)  # 给更多时间
```

### 问题3：轨迹记录数据丢失

**原因**：未及时保存

**解决**：
```python
# 记录后立即保存
data = recorder.stop_recording()
recorder.save_to_file("backup.json")
```

### 问题4：逆运动学无解

**原因**：目标位置超出工作空间

**解决**：
```python
# 检查工作空间
bounds = kinematics.get_workspace_bounds()
print(f"工作空间: {bounds}")

# 检查可达性
if kinematics.check_reachability(target_pose):
    # 执行运动
    pass
```

## 最佳实践

1. **先测试再执行**
   - 使用仿真或低速度测试新轨迹
   - 确认安全后再提高速度

2. **使用三次样条插值**
   - 默认推荐，平滑且高效
   - 避免速度突变和冲击

3. **合理设置时间**
   - 时间太短会导致速度过快
   - 建议每30cm运动至少1秒

4. **监控跟踪误差**
   - 误差过大说明规划不合理
   - 调整速度/加速度限制

5. **使用紧急停止**
   - 遇到危险立即调用`emergency_stop()`
   - 会关闭扭矩确保安全
