# SO-ARM100 遥操作使用指南

## 概述

遥操作（Teleoperation）允许通过手动拖动一个机械臂（主臂/Leader），实时控制另一个机械臂（从臂/Follower）进行镜像动作。

## 系统架构

```
主臂（Leader）                从臂（Follower）
  ├─ 扭矩关闭                  ├─ 扭矩开启
  ├─ 人工拖动                  ├─ 自动跟随
  └─ 读取位置 ────────────────→ └─ 执行动作
         |                           |
         └─── 50Hz 同步循环 ────────┘
```

## 快速开始

### 1. 硬件连接

- **主臂**：连接到串口（如 COM22）
- **从臂**：连接到串口（如 COM24）
- 确保两个机械臂都已完成校准

### 2. 运行遥操作

```bash
python examples/teleoperation.py
```

### 3. 交互式配置

程序会提示输入：
```
请输入主臂（Leader）串口 (默认 COM22): COM22
请输入从臂（Follower）串口 (默认 COM24): COM24
请输入控制频率 Hz (默认 50): 50
```

### 4. 开始操作

- 程序启动后，主臂扭矩自动关闭
- 手动拖动主臂，从臂会实时跟随
- 按 `Ctrl+C` 停止遥操作

## 核心功能

### TeleOperation 类

```python
from examples.teleoperation import TeleOperation

# 创建遥操作实例
teleop = TeleOperation(
    leader_port="COM3",      # 主臂串口
    follower_port="COM24",   # 从臂串口
    frequency=50.0           # 控制频率（Hz）
)

# 使用上下文管理器
with teleop:
    teleop.run(duration=60)  # 运行60秒
```

### 关键参数

| 参数 | 说明 | 默认值 | 建议范围 |
|------|------|--------|---------|
| `leader_port` | 主臂串口 | - | COM3, COM24等 |
| `follower_port` | 从臂串口 | - | COM3, COM24等 |
| `frequency` | 控制频率 | 50 Hz | 30-100 Hz |
| `duration` | 运行时长 | None（无限） | 任意秒数 |

## 工作流程

### 1. 初始化阶段

```python
teleop.connect()
```

- 连接主臂和从臂
- 加载校准数据
- 主臂：关闭扭矩（允许拖动）
- 从臂：启用扭矩（执行控制）

### 2. 同步循环

```python
while running:
    # 1. 读取主臂位置
    leader_obs = leader.get_observation()
    
    # 2. 发送给从臂
    follower.send_action(leader_obs)
    
    # 3. 频率控制（50Hz）
    time.sleep(0.02)
```

### 3. 断开阶段

```python
teleop.disconnect()
```

- 断开双臂连接
- 从臂自动关闭扭矩（如配置）

## 性能监控

程序每50次迭代输出一次状态：

```
2026-01-23 16:20:15 - INFO - 遥操作运行中... 迭代: 500, 实际频率: 49.8 Hz, 耗时: 10.0s
```

**监控指标：**
- **迭代次数**：执行的循环次数
- **实际频率**：实际控制频率（应接近目标频率）
- **耗时**：总运行时间

## 注意事项

### ⚠️ 安全提示

1. **首次使用**
   - 确保两个机械臂都已校准
   - 初始位置应接近，避免突然大幅度移动
   - 周围留出足够操作空间

2. **运行中**
   - 缓慢拖动主臂，观察从臂跟随
   - 如有异常立即按 `Ctrl+C` 停止
   - 监控实际频率，过低可能导致延迟

3. **停止后**
   - 从臂扭矩会自动关闭
   - 主臂和从臂都可以手动移动

### 🔧 故障排查

#### 问题1：从臂不跟随

**可能原因：**
- 从臂扭矩未启用
- 串口连接错误
- 校准数据不匹配

**解决方法：**
```python
# 检查从臂扭矩
follower.enable_torque_all()

# 检查连接状态
print(f"主臂连接: {leader.is_connected}")
print(f"从臂连接: {follower.is_connected}")
```

#### 问题2：实际频率过低

**可能原因：**
- 通信延迟
- 目标频率过高
- 系统负载过大

**解决方法：**
- 降低频率到 30-40 Hz
- 减少日志输出级别
- 关闭其他占用串口的程序

#### 问题3：跟随有延迟或抖动

**可能原因：**
- 频率不稳定
- 通信重试次数过多
- PID参数不合适

**解决方法：**
```python
# 调整控制频率
teleop = TeleOperation(frequency=30)  # 降低频率

# 调整从臂PID参数（在configure中）
follower.bus.write_control_table(motor_id, "P_Coefficient", 12)
```

## 高级用法

### 1. 限时遥操作

```python
with TeleOperation("COM3", "COM24") as teleop:
    teleop.run(duration=120)  # 运行2分钟
```

### 2. 自定义控制逻辑

```python
class CustomTeleOp(TeleOperation):
    def run(self, duration=None):
        while True:
            leader_obs = self.leader.get_observation()
            
            # 自定义变换（如缩放、镜像）
            action = self.transform(leader_obs)
            
            self.follower.send_action(action)
            time.sleep(self.dt)
    
    def transform(self, obs):
        # 示例：反向镜像
        return {k: -v for k, v in obs.items()}
```

### 3. 添加数据记录

```python
import json
from datetime import datetime

data_log = []

while running:
    leader_obs = leader.get_observation()
    follower.send_action(leader_obs)
    
    # 记录数据
    data_log.append({
        "timestamp": datetime.now().isoformat(),
        "leader": leader_obs,
        "follower": follower.get_observation()
    })

# 保存数据
with open("teleoperation_log.json", "w") as f:
    json.dump(data_log, f, indent=2)
```

## API 参考

## 性能优化

### 1. 提高频率稳定性

```python
# 使用更精确的计时
import time

loop_start = time.perf_counter()
# ... 执行控制逻辑 ...
elapsed = time.perf_counter() - loop_start
time.sleep(max(0, dt - elapsed))
```

### 2. 减少通信开销

- 使用批量读写（`sync_read`, `sync_write`）
- 减少日志输出频率
- 只读写必要的寄存器

### 3. 系统优化

- 关闭不必要的后台程序
- 使用高性能 USB 串口适配器
- 确保电源稳定充足
